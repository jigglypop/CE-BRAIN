# CE-BRAIN

고정된 뉴런들의 전기적 상호작용과 과거 흔적이 어떻게 기억·학습·현재의 세계모델을 만드는가를
하나의 공통 구조로 설명하려 한다. 뉴런은 고정된 점이고, 변하는 것은 상태와 관계다. 핵심 전제 C1–C8을
하나씩 원장에 등록된 실데이터로 판정한다. 기능적 거리와 변화 비용이 리만 계량인지(C4)도 판정 대상이다.

$$
dx=\big[-G^{-1}\nabla E+T\,\nabla\!\cdot G^{-1}+F\big]dt+\sqrt{2T\,G^{-1}}\,dB
$$

$G$는 변화 비용(계량), $E$는 기억이 머무는 지형, $F$는 신호 방향이다. 잡음은 Itô로 읽고, $T\nabla\!\cdot G^{-1}$는 $G$가 상태에
따라 변할 때 정상 분포를 $e^{-E/T}$로 지키는 보정이다(상수 $G$면 0). 식과 결과, 판정, 참고문헌은
[논문](paper/CE-BRAIN.md)에 있다.

작업을 시작할 때는 [상태 원장](ledger/STATE.md) 한 파일만 먼저 읽는다. 결함 목록, 작업 대기열, 어느 파일의 어느 절을 열지가 거기 있다.
