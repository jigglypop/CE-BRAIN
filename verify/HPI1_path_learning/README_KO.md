# HPI1 이력 경로 학습 — 2026-09-18 결과 보존본

고정된 800상태 clone-emission HMM에서 예측오류가 남는 관측 이력을 찾아 기존의 같은 감각 슬롯 여섯 개를 재사용한다. 새 경로를 같은 입력으로 정제하고 훈련 로그가능도가 나빠지지 않을 때만 채택한다. 기존 HMM/EM 계열의 연구 구현이며 새로운 생물학 법칙은 아니다.

## 보존한 비교

시드 248–263, 같은 체크포인트와 같은 추가 EM 160회에서 일반 EM은 13/16, 경로 보완은 16/16 문맥 분리를 완료했다. 고정한 길이 변경 검사도 13/16에서 16/16으로 바뀌었다. 익숙한 과제의 다른 제시 순서에서 보상 예측은 95.3125%에서 100%, 로그예측오차는 0.033871789에서 0.028816864 nats/기호였다.

실패했던 251·254·262만 보완됐으며 기존 13개 완료 사례의 최초 분리 시점은 그대로다. 평균 시간차 0.5216→0.3066은 완료 사례의 분모가 13→16으로 바뀐 효과이므로 동일 사례의 시간 예측 개선이 아니다. 세 개선/무퇴행의 짝지은 정확 검정 p=0.25이므로 일반적 우위를 확정하지 않는다.

이는 모델 초기화의 계산 결과다. 100% 생물학 정확도, 실제 칼슘 신호 적합, 새로운 동물 예측, MaleCNS 재현을 뜻하지 않는다. 추가 EM 횟수와 상태 수는 같지만 경로 탐색 비용은 추가된다. 변형 추론에는 기존 보상 보호 가정이 남아 있다.

## 실행

```bash
python -m pip install -r verify/HPI1_path_learning/requirements.txt
python verify/HPI1_path_learning/check.py
python verify/HPI1_path_learning/run.py --seed 262 --output /new/path/hpi1_seed262
```

Windows 저장소에서는 위 python 명령을 `.codex/hooks/python.cmd python`으로 실행한다. 이미 학습된 원본 baseline을 사용하려면 `--checkpoint /path/to/seed_262.npz`를 추가한다. 출력 폴더가 존재하면 중단한다. 체크포인트에는 800상태, 50×20회 학습의 원본 배열이 필요하다. 16개 전체는 248–263을 각각 다른 출력 경로로 실행한다.

`hpi1.py`는 전달된 패키지에서 채택된 함수 본문을 변경 없이 모은 파일이다. `PROVENANCE.json`은 원본 ZIP 및 소스 해시, `RESULTS.json`은 기존 결과와 제한, `PAIRED_RESULTS.csv`는 32개 짝지은 결과를 보존한다. 대형 체크포인트·실패 후보 구현·캐시는 Git에 넣지 않는다. 원본 전체 ZIP은 대화 첨부에 그대로 보존되어 있다.

## 다음 단계

경로 보완을 학습 종료 뒤가 아니라 진행 중에 적용한다. 같은 초기화와 입력을 사용해 기존 추가 학습과 비교하며, 모든 실제 갱신의 상태를 기록한다. 학습 완료·보상 예측·길이 변경 반응을 유지하면서 같은 사례의 분리 시간차가 개선되는지 확인한다. 아직 그 개선 결과는 이 커밋에 포함하지 않는다.

문헌 기준: Sun et al., Nature 640, 165–175 (2025), DOI 10.1038/s41586-024-08548-w. 논문의 과제와 공개 가공 통계를 참고한 후향적 개발이며, 모델 확률과 칼슘 형광은 서로 다른 관측이다.
