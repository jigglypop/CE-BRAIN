# 놀람 이득: 짧은 이탈 불일치를 칼만 식 갱신으로 판정 (2026-09-30)

전제: C3 (현재 상태에 남는 과거 흔적). 흔적의 갱신 이득이 고정인지, 상태가 기록에서 멀수록 커지는지(혁신 구동 칼만)를 가른다.

동기: C3-8부터 짧은 이탈(5–15 s) 뒤 되돌아옴을 모든 식이 0.22–0.29로 과대 예측한다(실측 0.166 ± 0.017). 여섯 후보(관측 잡음 상관,
기록장 여러 봉우리, 세션 고정 끌개, 논렘 쓸기, 스파이크 수 잡음, 빈 방향 인공물)가 모두 배제됐다. 델타 규칙·칼만 통합식 검토에서 나온 새
후보: 고정 이득 필터는 크게 틀려도 덜 고친다(헛똑똑이). 칼만에서 이를 벗어나는 길은 혁신이 과정 잡음을 키우는 것이다. 식으로는
τ ḣ = (1 + λ·u)(e^{iθ} − h), u = 1 − g(θ − arg h)(기록 우물 밖일수록 1). λ = 0이면 v3.

모형만 본 탐색(실측 새로 보지 않음): C1-7 해에서 λ = 0 → R(5–15) 0.20, λ = 3 → 0.04. 기제는 R을 실측 수준까지 내릴 수 있다. 표준 관측을
지키면서 그럴 수 있는지가 판정 대상이다.
