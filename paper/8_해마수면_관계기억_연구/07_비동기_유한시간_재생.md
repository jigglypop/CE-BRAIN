# 7. ARTC-1: 주변 응답·비동기 시점·다단계 재생을 연결한 추가 검산

2026-09-08. 앞선 우주-뇌 다리와 PGC를 바탕으로 한 새 독립 NumPy/SciPy 시험이다. 이 문서의 숫자는 이번 게시 세션에서 새로 실행했다. 기존 뇌 런타임과 생물학 자료에는 적용하지 않았다. 단위는 무차원이다.

## 7.1 질문과 변화

사용자의 방향은 각 부분의 정체성을 유지하되 주변과의 관계가 다음 상태를 바꾸고, 해마 색인에서 재생한 내용이 느린 기억으로 남는가이다. 이전 단계는 (i) 주변을 줄이면 Schur 보정/이력 커널이 남는다, (ii) 표지와 자원의 순서가 포착량을 바꾼다, (iii) PGC의 1회 최적은 다단계 최적이 아니다를 각각 확인했다.

이번에는 알려진 숨은 주변 반응을 유한시간 전달 커널에 남기고, 그 커널로 여러 사건의 순서·쓰기 강도를 함께 선택한다. 신경계가 실제 이 최적화를 수행한다는 주장이 아니라, 축약과 시간 정보를 버렸을 때 무엇을 잃는지 보는 기준해다.

## 7.2 자원이 주변 경로를 거쳐 도착하면 최적 재생은 즉시가 아닐 수 있다

공급 impulse가 초기 전구 상태 q(0)=1, 이용가능 자원 P(0)=0을 만들고

\[
\dot q=-kq,\quad \dot P=kq-bP,\quad k,b>0
\]

라고 하자. k!=b이면

\[
P(t)=\frac{k}{k-b}(e^{-bt}-e^{-kt}),\quad \int_0^\infty P(t)dt=1/b.
\]

시각 r>=0에 생긴 단위 표지는 T_r(t)=exp[-a(t-r)]1_(t>=r), a>0다. 포화·자원 소모를 무시한 소신호 겹침량은

\[
\Gamma(r)=\int_r^\infty T_r(t)P(t)dt
=\frac{k}{k-b}\left[\frac{e^{-br}}{a+b}-\frac{e^{-kr}}{a+k}\right].
\]

미분의 유일한 0점으로

\[
\boxed{r^*=\frac{\log\{k(a+b)/[b(a+k)]\}}{k-b}}.
\]

k=b의 극한은 r*=a/[b(a+b)]다. k>b에서 r=0의 미분은 양수이고 무한대 쪽은 음수이므로 r*는 r>=0의 전역 최대다. 또한

\[
\frac{dr^*}{da}=\frac1{(a+b)(a+k)}>0,\quad
0<r^*<t_{peak}=\frac{\log(k/b)}{k-b}.
\]

표지가 빨리 사라지는 영역은 자원 peak에 더 가까운 늦은 재생이 유리하다. a→0에서 r*→0, a→infinity에서 r*→t_peak다. 이는 다른 영역을 같은 순간에 강제로 재생해야 한다는 결론과 다르다. 수명·전달률이 실제로 다르다는 생물학적 동정은 별도다.

예제 a=1,k=2,b=.25: r*=.6879844596, 자원 peak=1.1882523095, 즉시 겹침=.5333333333, 최적 겹침=.6735859555이다. 증가율은 약26.3%의 모형 겹침량이지 인간 기억 정확도 증가율이 아니다. a=.2,1,3의 최적 지연은 .2814151343,.6879844596,.9420906432다.

독립 적분+scalar optimizer 32개 비교에서 최적시각 최대 차이1.8133e-8. k=b 극한 대조오차4.3194e-8,64개 a의 단조성과 peak 이하 조건도 검사했다.

## 7.3 주변을 즉시 평형으로 만들지 않고 기억 커널을 유지한다

signed eligibility h와 느린 연결 w를

\[
\dot h=-Ch+\sum_j\alpha_jd_{e_j}\delta(t-r_j),\qquad
\dot w=-d_s w+P(t)Lh,\quad C=C^T\succ0
\]

로 둔다. h는 비음수 화학농도가 아니라 효과 방향을 보존하는 선형 응답 좌표다. 실제 계산은 L=I다. q,P는 소비 없이 정해진 경로를 따르며, 포화와 capture에 따른 h 소모를 넣지 않았다. 따라서 이전 f→s 물질전달 모형의 보존 증명을 이 식에 그대로 적용하지 않는다.

주어진 읽기시각 H에서

\[
\boxed{w(H)=w_0(H)+\sum_j\alpha_jV_{e_j}(r_j),\quad
V_e(r)=\int_r^H e^{-d_s(H-t)}P(t)Le^{-C(t-r)}d_e\,dt.}
\]

과거 주변 상태는 e^-C(t-r)로 보존된다. C=U diag(c_l)U^T에서 각 mode의 적분을 지수함수로 정확히 계산할 수 있다. replay 시점의 P(r)와 무한시간 C^-1만 쓰는 정적 근사는 미래 자원 변화와 유한 도착 시간을 잃는다.

상수 P=1,d_s=0에서 kernel=LC^-1(I-e^-CDelta), Delta→infinity에서 LC^-1다. 따라서 Schur형 준정적 보정은 충분히 빠른/긴 시간 극한이고 유한시간 기억을 대체하는 보편식이 아니다. 별도 diagonal 예제의 정적 근사오차는 Delta=1,10,100에서2.4841,.1668,3.14e-13이었다.

고정 C와 알려진 P 아래 전달 선형성이 성립한다. C>0, 유한 이벤트수와 유계 쓰기예산이면 h의 norm은 감쇠 impulse norm 합으로 제한되고 유한 H의 w도 유계다. 실제 비선형 화학계의 안정성·식별성 증명은 아니다.

## 7.4 사건 순서와 강도를 공동 최적화한다

관측해 저장한 기억 손실은 R(w)=w^TH_Rw/2-b_R^Tw+c0, H_R=X^TX/N+lambda I다. H_R는 학습 Hessian이지 시공간 metric이 아니다. 슬롯 r_j와 사건들의 순열 pi가 고정되면 V_pi의 열은 위 V_(pi_j)(r_j)다.

\[
J_\pi(\alpha)=R(w_0+V_\pi\alpha)+\frac\xi2\|\alpha\|^2,
\quad \alpha>=0,\quad \|\alpha\|^2<=B.
\]

방향 d_e는 단위 norm으로 고정했으므로 이 예산은 실제 impulse 제곱 norm 합이다. 임의 norm 방향이면 대각 비용행렬을 써야 한다. 쓰기량은 ATP/FLOP가 아니다.

Q_pi=V_pi^T H_R V_pi+xi I>0, l_pi=V_pi^T(H_Rw0-b_R)다. 활성 지지집합 S의 내부에서는

\[
\alpha_S=-(Q_{SS}+2\mu I)^{-1}l_S,\quad
\mu>=0,\quad \mu(\|\alpha\|^2-B)=0.
\]

양의 모드에서 norm은 mu에 대해 단조감소하므로 예산이 활성일 때 scalar root를 구할 수 있다. 가능한 지지집합을 비교하고 부호·비활성 gradient의 KKT 조건을 검사한다. 네 사건은24개 순열과15개 비어 있지 않은 지지집합이므로 전수 비교할 수 있다. 최적 pi는 해당 유한 슬롯/사건/쓰기 방향 집합에서의 전역 최소다. 임의 길이 수면·미지의 계수·국소 신경 회로의 전역 최적이라는 주장이 아니다. 계산비용이 factorial×exponential이라 대형 모델의 실용 해법도 아니다.

이로써 이전 PGC의 이번 한 번 최적을 작은 계획 블록 전체 최적으로 확장했다. 다음 블록에서 실제 관측으로 방향과 모델을 갱신하려면 별도 인과 경계를 유지해야 한다. 재생은 새로운 독립 증거를 만들지 않는다.

## 7.5 실행 조건과 대조

로컬 protocol은 첫 실행 전에 작성했고 외부 시각 인증 사전등록은 아니다.32개 수학 진단과24개 고정 시드27100–27123을 사용했다. 각 시드에서64개 관측,6차원 선형 읽기,4개 관측 사건의 고정 방향,슬롯(0,.4,1,1.8),읽기 H=5,예산3이다. 자원 k=2,b=.25,느린 감쇠=.01,쓰기 penalty=.01,관측잡음=.05다. C는 알려진 SPD 주변 확산/감쇠 행렬로 공급했다. 이를 자료에서 찾아내지 않았다.

후보 결과 y는 학습 관측에서만 얻는다. 테스트256개 covariate와 목표는 모든 선택이 끝난 뒤 생성하며, 평가에는 slow weight만 사용한다. 총6144개 시험점이다. 새로운 Gaussian 입력의 선형 평균 예측이지 해마 주소 검색·문맥별 사건 회상·실제 장면 기억 시험이 아니다. 이전95%대 기억 분류 점수와 직접 비교하면 안 된다.

무작위 순서군도 강도는 공동 최적화한다. 순차 탐욕군은 남은 후보를 모두 볼 수 있지만 미래 슬롯의 공동 효과를 최적화하지 않는다. 정적 근사군은 같은 후보/예산에서 C^-1와 현재 P(r)를 쓰고 최종 실제 동역학으로 평가한다. 직접 slow군은 포착 제약을 우회한 다른 전달 모형이며 강한 공학 기준선이다. 모든 방법에 동일 resource trace를 주되 직접slow는 그것을 쓰지 않는다. 동일 상한은 같은 소비량이나 같은 FLOP를 의미하지 않는다.

| 방법 | 관측목표+쓰기비용 | 새 입력 MSE | 실제 사용 쓰기량 |
|---|---:|---:|---:|
| 공동 순서·강도+정확한 kernel |.303020|.611563|2.851213|
| 무작위 순서+공동 강도 |.316243|.638338|2.852902|
| 순차 탐욕 |.373081|.751006|2.840953|
| 정적 Schur형 근사 |.310767|.628360|2.807724|
| 직접 느린 쓰기 |.237148|.491424|2.316967|

공동 kernel의 MSE는 순차 탐욕 대비18.5675%,무작위순서 대비4.1945%,정적근사 대비2.6731% 작았다. 순차 대비 seed-paired95% MSE차 [-.17483,-.10433],무작위 대비[-.04033,-.01476]다.24시드 중 무작위 대비21개 개선/2개 악화/1개 동률,정적 대비21개 개선/3개 악화였다. 저장 목적 최적이 새로운 입력의 모든 시드에서 최선임을 뜻하지 않는다. bootstrap5000회,시드단위,다중비교 보정 없는 개발 판정이다.

직접 느린 쓰기는 MSE .491424로 공동 kernel보다 좋았다. joint−direct paired95% 차이는 [.06569,.17417]이며24시드 중18개에서 joint가 나빴다. 생물학 제약이 필요 없는 구현에서 포착 모사를 반드시 써야 할 근거는 없다.

같은 네 방향·같은 진폭 sqrt(3/4)·같은 resource trace를 유지한24개 순열의 저장손실 max−min은 시드 평균 .03361845였다. 이것은 정확히 같은 총 쓰기량이어도 순서가 결과를 바꾸는 모형 내 대조다. 임의 최적 위상이나 수면의 생물학적 필요성을 입증하지 않는다.

## 7.6 검산과 재현

지수 kernel 대 독립 DOP853 ODE32개 최대오차2.0262e-13. 주24개 선택의 terminal ODE 비교 최대2.4769e-13. QCQP 해 대 독립 SLSQP32개 목적차6.1784e-13. 주 계획 전체 KKT 최대잔차7.724e-12였다. 저장된 slow/진폭과 동일 관측을 Python scalar sum으로 재계산한360개 지표의 최대오차4.4409e-16이다.

전체24개 시드를 재실행해 full results JSON이 bitwise identical이었다. 첫 시도에서는 ODE 함수의 slots 인자를 빠뜨렸고, 그 수정 뒤에는 NumPy int의 JSON 직렬화 오류가 있었다. 두 구현 경계만 수정했으며 protocol의 시드/계수/비교군/평가를 바꾸지 않았다. 실패 로그는 배포 ZIP에 남긴다.

Git에는 source/protocol/aggregate result/validation을 게시하고 full96KB 결과는 소스로 재생성하거나 배포 ZIP에서 읽는다. aggregate의 full_results_sha256으로 원 실행을 확인한다. 환경 차이 때문에 버전이 다르면 byte 일치를 일반적으로 약속하지 않는다.

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python repro/verify_artc.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python repro/check_results.py
```

Windows에서는 위 두 환경변수를1로 설정한 뒤 python 명령을 실행한다. check_results는 results_first.json이 없는 새 복제에서는 재실행 byte비교를 null로 표시하며, 나머지 검사를 수행한다. Git 전용 기존 검사기·전체 CE-BRAIN 테스트·Rust/CUDA 검사를 실행했다고 주장하지 않는다.

## 7.7 다음에 남는 문제

지금의 새 명제는 자원의 전달/성숙시간과 이력 decay가 다르면 지역별 최적 상대시점이 달라지고, 주변 응답을 유한시간 kernel로 보존해 작은 다단계 정책을 최적화할 수 있다는 것이다. 실제 신경계의 파형/재생시점/후속 기억변화를 같은 계수로 예측하는지, 국소 규칙으로 근사할 수 있는지, 자원소모·포화·비선형 가소성을 넣어도 경쟁 모형보다 설명력이 남는지는 미검증이다.

생물학 동기: Shires et al.(2012), DOI10.1038/ncomms2250; Geva-Sagiv et al.(2023), DOI10.1038/s41593-023-01324-5. 재생의 효용 기반 선택 자체는 Mattar & Daw(2018), DOI10.1038/s41593-018-0232-z 등 선행연구가 있다. 이 문헌들은 ARTC의 계수·최적 지연·성능을 검증한 출처가 아니다.
