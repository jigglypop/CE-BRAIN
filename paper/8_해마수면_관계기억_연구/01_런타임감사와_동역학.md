# 1. 코드 감사에서 방향·기억 동역학으로

## 1.1 출발 코드와 정확성 부채

참조는 CE-BRAIN `1098722`다. 아래는 해당 판본의 코드 감사 기록이며 이 게시에서 런타임 패치를 적용하지 않았다.

`runtime.py`는 W @ x로 전달하므로 행은 수신자, 열은 발신자다. Python의 `dale_sign.unsqueeze(1)`은 행에 부호를 적용하지만 Rust의 해당 함수는 col_idx로 발신자를 결정한다. 단순히 차원을 고치는 것만으로 충분하지 않다. 억제 이득 4가 이미 적용된 가중치에 abs와 이득을 재적용하면 -4 → -16 → -64가 된다. from_snapshot 생성자가 같은 처리를 하므로 저장·복원 연속성에 영향을 줄 수 있다. bounded delta=0도 실제 가중치를 바꾸면서 반환 norm은 0일 수 있다.

HippocampusMemory의 `detach().float().to(device)`는 동일 dtype/device에서 소유권 복사를 보장하지 않는다. 역사적 기억은 clone해야 한다. forget_tau 설정은 전역 FORGET_TAU를 쓰는 경로와 연결되지 않았다. 구조 투영의 두 임계값은 기존 연결 상태를 보존하지 않아 정상적인 theta_off < theta_on에서 hysteresis가 아니다. 수면 시간상수의 숫자는 초인데 1ms step으로 설명된 경로에는 1000배 단위 불일치가 있다.

이 부채는 경로별로 평가한다. dale_law=False인 별도 실험이나 CCEP 분석을 이 오류만으로 일괄 무효화하지 않는다. 기존 manifest와 원본을 보존한 채 새 schema에서 수리해야 한다.

## 1.2 BeliefController 국소 감사

제공된 deep-review 패키지는 원본 모듈의 Git blob 일치 확인, 기존 7개 테스트와 신규 7개 회귀 검사, 128개 선형 Gaussian 대조를 기록한다. 기존 테스트는 원본/후보 모두 7개 통과, 신규 회귀는 원본 7개 실패/후보 7개 통과였다. 이 수치는 이번 게시에서 새로 실행한 것이 아니다.

정보형 posterior 갱신에서 분모는 관측잡음 R여야 하는데 원본은 이미 사전 불확실성이 포함된 innovation variance를 다시 사용했다. P=R=H=y=1인 예에서 정확한 posterior 평균·분산은 (0.5,0.5), 원본은 약 (1/3,2/3)이었다. 수정안의 128개 기준식 최대오차는 1.58e-7이었다.

더 큰 구조적 한계는 행동과 무관한 미래 분산과 공통 action_cost가 고정 길이 후보마다 같은 상수가 된다는 점이다. 초기 action_effect=0과 결정적 동률 선택은 무행동에 갇힐 수 있다. 고정 b_action으로는 상태에 따라 뒤집히는 행동 효과를 동시에 표현할 수 없다. 외부 observation을 받는 belief 경로의 기본 전이가 identity인 경우 뇌 재귀 가중치의 기여를 별도 개입으로 확인해야 한다.

## 1.3 방향·소산·이력의 후보

활동 축약좌표 x, 이력 m, p=grad Phi(x)에 대해

\[
\dot x=(J-D)p-Lm+B(x)u,\qquad
\dot m=L^Tp-\Lambda m,
\]

J^T=-J, D>=0, Lambda>0를 둔다. 고정 모수에서 E=Phi(x)+m^Tm/2이면

\[
\dot E=-p^TDp-m^T\Lambda m+p^TB(x)u.
\]

반대칭항과 활동-기억 교환항은 저장함수를 만들지 않는다. 입력이 없고 추가 성장조건이 충족되면 안정성을 분석할 수 있다. 학습 중에는 partial_theta Phi dot(theta)가 추가되므로 고정모수 증명을 그대로 승계하지 않는다. E는 ATP 소비량이 아니다.

상수 L,Lambda에서 m을 소거하면 이력 커널 K(v)=L exp(-Lambda v)L^T가 나온다. 임의 무한 과거를 유한 변수로 무조건 정확히 표현한다는 정리가 아니라, 선택한 유한 지수합 kernel에 대한 닫힌 표현이다.

## 1.4 기하와 방향은 분리한다

A_±=-alpha I ± omega J의 두 감쇠 회전은 F_+F_+^T=F_-F_-^T이나 signed response가 다르다. 공분산 역행렬로 만든 계량만으로 전달 방향 전체를 복원하지 못한다. 위치 의존 G(x)를 잠재함수 Phi=x^TG(x)x/2에 쓰면 grad Phi에는 (x^T partial_k G x)/2가 추가된다. G_t가 시간에 따라 바뀌는 것과 공간곡률이 0이 아닌 것은 다르다.

제공된 DMH1 기록은 32개 시드의 알려진 모델족에서 전체 모델 RMSE 0.000855/선택 일치 100%, 방향 제거 0.416457/68.31%, 기억 제거 0.358099/67.65%를 보고한다. 주 시험은 G=I이고 숨은 상태·미분을 학습에 제공했다. 곡률을 실제 뇌에서 발견하거나 일반 지능을 검증한 결과가 아니다. 기존의 별도 coupled-v1 계열과 DMH1을 동일 실행으로 합치지 않는다.
