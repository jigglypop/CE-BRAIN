이 묶음은 코드 감사 → 방향·기억 동역학 → 해마의 내용 주소 → 수면 표지·포착 → 직접 검증 → PGC 재생 최적화 → 우주 연구의 비동기 관계 구조라는 대화 진전을 정리한다. 기존 런타임·동결된 실험·정준 원장을 변경하지 않는 독립 연구 기록이다. 서로 다른 축약모형의 결과를 하나의 생물학적 이론이 검증된 것처럼 합치지 않는다.

## 핵심 결론

사건의 정체성을 유지한 채 관계를 학습한다. 해마는 내용으로 돌아가는 사건 색인이며, 주소만으로 내용을 무손실 복원하지 않는다. 재생과 국소 표지·가소성 자원의 결합으로 빠른 변화가 느린 피질 가중치에 남는 경로를 구현했다. 그러나 수면이라는 라벨, 특정 호르몬의 고유 작용, 특정 위상의 보편적 우월성은 확인하지 못했다. PGC는 명시한 유한 후보·이차 손실·구간 고정 포착률에서 한 번의 최적 쓰기를 계산하지만, 전체 수면의 전역 최적 정책은 아니다.

## 증거 범위

이전 수치는 제공된 보고서·코드·결과 파일을 확인하여 보존한 과거 실행 기록이다. 이번 게시에서 해당 벤치마크 전체를 다시 실행한 것은 아니다. 원본 ZIP 6개의 SHA-256과 크기는 [source_manifest.json](source_manifest.json)에 기록한다. 5개 내부 MANIFEST에서 201개 파일 해시를 재검사해 불일치 0을 확인했다. 해시 일치는 과학적 타당성이나 테스트의 충분성을 입증하지 않는다.

이 Git 묶음에는 세션의 통합 서술과 아티팩트 출처를 게시한다. 원본 ZIP·대형 NPZ 예측 배열 전체를 Git에 실은 것은 아니다. 원본은 대화의 첨부 자료로 보존되며, Git 문서만으로 과거 모든 시험을 재실행할 수 있다고 주장하지 않는다. 추가 검산을 게시할 때에는 실행 소스·조건·결과를 별도 repro 경로에 함께 둔다.

새 식의 지위는 합성 계산모형의 조건부 정리와 검산이다. 인간/동물의 뇌 기전, 무한차원, 의식, AGI, 우주 상수와 뇌의 동일성을 입증한 것이 아니다.
