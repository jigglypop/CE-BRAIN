# 6. 출처·증거 수준·다음 검증 의무

## 이번 게시에서 확인한 것

2026-09-08 사용자 요청에 따라 CE-BRAIN 세션 진전을 새 독립 디렉터리에 게시한다. 기준 원격 main은10987227f572fe789ea3b68d5026e3b3faacc14f였다. 기존 main 이력을 재작성하거나 동결된 런타임/원장을 덮어쓰지 않는다. 이후 추가 검산은 자체 protocol/source/result를 보존한다.

제공된 원본 ZIP6개를 실제 파일에서 읽고 archive SHA-256을 계산했다. DMH1 13개, sleep-index7개, sleep-validation70개, PGC104개, cosmos-bridge7개의 내부 파일 hash, 합계201개를 기존 MANIFEST와 비교해 불일치0이었다. deep-review의 SOURCE_MANIFEST는 별도 source receipt이므로 일반 payload manifest 검사와 합산하지 않았다.

## 과거 결과와 이번 결과

01–05장의 성능·실행 숫자는 제공된 과거 실행 보고와 결과 파일을 바탕으로 재구성한 서술이다. 이 게시에서 모든 과거 시험을 전수 재실행한 것이 아니다. 해시 확인만으로 성능 수치나 생물학적 해석이 증명되는 것은 아니다. 대화에서 잠시 언급됐으나 현 세션 파일로 제공되지 않은 coupled-v1, 초기 isolated audit 묶음 전체까지 보유·재게시했다고 주장하지 않는다.

새 Git 문서는 원본 전체 대화의 문자 그대로 전사가 아니라 수식·조건·실패·다음 의무의 통합본이다. 원본 ZIP와 대형 예측 배열은 이번 Git tree에 포함하지 않았으며 대화 첨부와 source_manifest의 hash로 구분한다. 이 경계를 숨겨 Git만으로 과거 전체 실험을 재현할 수 있다고 쓰지 않는다.

## 유지하는 실패와 한계

- 원본 정확성 부채: Dale 행/열, 이득 재적용, 스냅샷/소유권, 시간단위, observer 계산.
- 모듈 실행과 인과적 효능은 다르다. 외부 관측 별도 정책의 성과를 뇌 가중치 효과로 귀속하지 않는다.
- 색인은 내용저장을 대체하지 않으며 semantic encoder/CA3를 학습한 결과가 아니다.
- 수면 라벨 동치, 위상 정확도 음성, 화학 인자의 비식별성은 철회하지 않는다.
- 단순 느린 갱신이 저예산에서 우세한 PGC 결과를 보존한다.
- 저장오차 감소와 사실성 향상, replay count와 independent evidence count를 구분한다.
- 수학적 안정성은 가정한 국소/고정모수 조건이며 전체 뇌·학습의 보편 안정성이 아니다.

## 다음 통합의 통과 기준

같은 경험·쓰기량·후보 접근 권한·읽기 시점에서 무작위/최대사건오차/PGC/다단계/직접느린갱신을 비교한다. 수면과 각성의 차이는 이름이 아니라 입력·상태·조절 동역학에 명시한다. 총 자원량을 맞춘 시점/순서 셔플 대조를 둔다. 해마와 빠른 상태 제거 후 slow만 읽고, 시험 정답이 학습 경로로 들어오지 않도록 한다. 주변 적응과 후보 탐색의 연산·쓰기 비용도 기록한다. 실제 뇌 주장으로 승격하려면 독립 신경/행동/개입 자료가 별도로 필요하다.
