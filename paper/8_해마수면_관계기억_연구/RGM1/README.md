# RGM-1 게시: 부위별 반응·기억·기하의 재현 기준

2026-09-08. 상태: 조건부 수학·합성 검산, BIO_EVIDENCE_L0. 인간 피질 집단 템플릿의 50개 고유값은 출처 검증 후 입력으로 사용했으며, 새로운 생물학 적합이나 독립 개체 검증이 아니다. 기존 CE-BRAIN 런타임을 대체하지 않는다.

## 1. 그대로 보존한 소스와 이번 재실행

첨부 `CE_BRAIN_RGM1_regional_geometry_memory_20260908.zip`의 manifest 34항목을 확인해 불일치0이었다. [원본 소스 해시](SOURCE_MANIFEST.json)에 게시한 파일의 SHA-256을 남긴다. 원본 코드·프로토콜·결과를 바이트 그대로 보존했다. 큰 NPZ와 초기 탐색 파일 전체는 Git에 중복 게시하지 않았다. 해당 자료는 원래 첨부에 남으며, 최종 NPZ는 실행 시 재생성된다. 원래 장문의 서술 대신 이 입구가 주장과 범위를 요약한다.

이번 실행: 관련 테스트17개 통과, 전체 verify 재실행의 results.json은 기존과 바이트 일치, 독립 에너지/RMS604개 재계산 최대차1.2622e-14. 고유값 원본은 NSBLab/BrainEigenmodes의 Git blob `d53ffd0a5244211fdea238266e2714a221c6a2a5`와 일치한다. 50개 고유값을 50개 인간 표본으로 세지 않는다.

## 2. 부위 차이를 유지하는 흔적과 학습

입력 흔적 E, 지시 흔적 I, 표지 T에 대해

$$\dot E_i=-d_iE_i,\qquad \dot I=-KI,\qquad \dot T_i=gE_iI_i-c_iT_i.$$

K는 양의 정부호 대칭 행렬이며 화학 프록시의 비음수성을 위해 비대각 성분이 비양수다. 지역별 소멸과 공간결합을 분리하되 모두 같은 연산자에서 반응을 계산한다. 부위별 계수는 이번에 공급한 예이며 뇌 부위 이름에 적합하지 않았다. 전달이0이면 기존 LBT1 정확해로 돌아간다.

LBT1의 국소 표지로 u=T/(K_T+T), a=k_+u²,b=k_-u, m=W a/(a+b)를 계산하고

$$w^+=m+(w-m)e^{-q(a+b)}$$

로 갱신한다. 태그 없는 연결은 그대로이며 연결 ID와 발신자 부호를 바꾸지 않는다. 신경 방향성 전체를 대칭 확산으로 환원하지 않는다.

## 3. 공통 스펙트럼과 남겨야 할 방향 정보

고정 C에서 K=C+sI>0이면 logdet 생성함수와 시간반응은 같은 역행렬 모멘트로 연결된다.

$$\mathcal F^{(n)}(s)=\frac{(-1)^{n-1}(n-1)!}{2}\operatorname{tr}K^{-n},\qquad
\int_0^\infty t^n b^Te^{-Kt}b\,dt=n!b^TK^{-(n+1)}b.$$

이 함수는 대사 에너지나 우주 진공 퍼텐셜이 아니다. 같은 고유값(1,4)도 고정 입력의 방향이 다르면 적분반응은1과.625로 달라진다. 따라서 고유벡터·입력·관측 위치를 버리지 않는다. 96개 모멘트의 독립 적분 최대차1.63e-14였다.

평균 m과 부위 차이 d는 a_bar,delta,g를 사용하면

$$\dot m=-\bar a m-\delta d,\qquad\dot d=-\delta m-(\bar a+2g)d.$$

차이를 소거하면 초기 d와 지수 기억커널이 남는다. 평균이0인 두 상태가 같은 다음 반응을 가져야 한다는 가정은 채택하지 않는다. 기준이 회전하면 -U^T Udot 항이 필요하다. 이를 뺀 예제의 평균오차.575를 생물학 성능으로 세지 않는다.

## 4. 주름과 확산은 서로 다른 동역학

별도 얇은 층의 성장 압축 N, 굽힘 B, 내부 지지 S를 사용한 소변형 모형의 모드 성장률은

$$\sigma(k)=Nk^2-Bk^4-S|k|,\quad k_*=(S/(2B))^{1/3},\quad N_c=3Bk_*^2.$$

이는 선형 탄성 반공간 프록시와 주기 경계의 스케일링이다. 3차원 태아 뇌, 전체 성장·유전자 모형을 계산한 것이 아니다. 안정 수동 확산만으로 접힘을 발생시키지 않는다. 등거리 외재 굽힘만으로 내재 확산이 항상 변한다고 주장하지 않는다.

초기 quartic=1에서는 최대기울기3.183으로 소변형 범위를 벗어났다. 원본 실패는 [보강 기록](source/REFINEMENT.json)에 남긴다. 1000 검사 뒤 최종300은 분석적 진폭 범위로 선택됐고 최대기울기.184 미만이었다. 실제 피질 물성 적합이 아니다. 독립 적분기 최대장차1.52e-9,64/128격자 차이7.74e-12를 확인했다.

## 5. 재현과 다음 범위

소스 디렉터리에서 실행한다. 출력 results.json/NPZ/validation만 재생성한다.

```bash
cd source
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m unittest discover -p test_rgm.py -v
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python verify.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python check_results.py
```

실행 환경은 Python3.13.5/NumPy2.3.5/SciPy1.17.0이었다. 다른 환경에서 바이트 일치를 보장하지 않는다. 전체 Windows·저장소 하네스는 미실행이다. 소스/링크/크기 범위만 검증했다.

RGM-1은 고정 기하 또는 구간 고정 계수만 정의한다. 성장 표면의 보존 농도로 해석할 때 필요한 추가항은 후속 RGM-2에서 별도 가정과 반례로 다뤘다. RGM-2는 이번 Git 소스 쓰기 요청의 보안 판정 오류로 게시하지 못했으며, 대화의 로컬 배포 자료로만 제공한다. 이 Git 디렉터리는 RGM-1에 한정된다. 이전 정적 식 전체를 폐기하는 것이 아니다.
