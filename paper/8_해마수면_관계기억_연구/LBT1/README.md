# LBT-1 게시본과 연구 재시작 지점

## 1. 보존한 진전

이 디렉터리는 사용자가 요청한 LBT-1 국소 가소성 코드·유도·합성 검증과 첨부한 CE 우주식을 보존한다. 기존 런타임, 봉인된 기록, CE8 패치를 수정하거나 자동으로 병합하지 않는다. 상위 연구 기록을 이어가는 별도 후보이며, 이 모듈의 통과를 실제 인간 뇌 알고리즘의 발견으로 승격하지 않는다. 증거 수준은 `BIO_EVIDENCE_L0`다.

입력 흔적과 지시 흔적이 국소 표지를 만들고, 지연된 실행 사건이 표지에 따라 연결을 바꾼다. ID와 발신 부호는 유지되며, 갱신기에 정답 라벨·미래 손실·전역 경사를 전달하지 않는다. 핵심 규칙과 한계는 원본 [알고리즘](source/ALGORITHM_KO.md), 원본 [보고서](source/REPORT_KO.md)에 있다. 두 파일과 실행 소스는 이전 첨부에서 바꾸지 않았다. 그 안의 푸시 상태·자료 접근 문장은 당시 기록이다.

## 2. 재시작과 재현

[재시작 실행기](restart.py)는 게시 파일의 SHA-256을 확인하고, 새로운 외부 폴더에 소스만 복사해 검사한다. 추적 중인 소스·결과를 덮어쓰지 않는다. 네트워크 접속·패키지 설치·Git 변경·실험장비 제어는 하지 않는다. 의존성은 [requirements.txt](source/requirements.txt)에 명시했다.

저장소 루트에서 다음을 실행한다.

```bash
python "paper/8_해마수면_관계기억_연구/LBT1/restart.py"
```

Windows에서는 저장소의 승인된 Python 실행기를 사용한다.

```powershell
.codex/hooks/python.cmd python "paper/8_해마수면_관계기억_연구/LBT1/restart.py"
```

전체 재시작은 원래 14개 테스트, 고정 프로토콜의 합성 검사 두 번, 독립 지표 재계산을 실행한다. `--quick`은 무결성과 14개 테스트만 실행한다. 결과는 새 임시 폴더에 기록되며, `--output`으로 지정하려면 저장소 밖의 아직 없는 경로여야 한다. ChatGPT 앱이나 원격 서버 프로세스를 재시작하는 기능은 아니다.

[게시 결과 요약](published_results.json)은 전체 결과의 해시도 보존한다. 전체 results.json과 합성 NPZ는 실행으로 재생성하며, 원본은 대화의 ZIP 첨부에도 있다. 환경이 다르면 수치 바이트가 달라질 수 있으므로 원본 해시 일치 여부를 별도로 보고한다.

## 3. 첨부 CE식의 지위

[CE식 원문](references/CE식.txt)은 사용자가 제공한 17,723바이트를 그대로 저장한 참고자료다. 한 순환 스펙트럼 함수의 질량제곱 미분으로 퍼텐셜·곡률 반응·게이지 보정·뮤온 전자기 구성항을 연결한다는 원문의 서술을 보존했다. 최종 통일장이론·절대 상수 결정은 미완성이라는 원문의 경계도 그대로 둔다.

이 게시에서 우주식을 새로 검증하지 않았다. 원문에 적힌 검증 ZIP·14개 파일 패치·게시 실행기는 이번 첨부에 없으므로, 해당 코드가 저장소에 반영되었다고 주장하지 않는다. 원문 속 대화용 인용 토큰과 sandbox 링크는 원본 기록이며 Git의 로컬 링크가 아니다. 물리적 스펙트럼 함수를 뇌 분자의 실측 기전과 동일시하지 않는다.

## 4. 다음 연구의 시작 조건

큰 목표는 국소 학습이 기억과 후속 반응을 어떻게 바꾸는지 실제 관측·개입으로 식별하는 것이다. 다음 질문은 평균 변화가 같은 조건에서, 여러 가시의 공동변화가 가지별 실행 사건의 공유와 맞는지다. 공유된 측정잡음과 공통 입력도 경쟁 설명으로 유지한다.

먼저 필요한 원자료가 실제로 여러 가시·같은 시행·수상돌기 소속·실행 신호 시각·후속 변화를 함께 제공하는지 확인한다. 자료가 없으면 계수 식별이나 생물학적 성공을 만들지 않는다. 기존 BTSP의 한 세포 공간구간을 동시 다가시 반복 시행으로 재해석하지 않는다. 합성자료는 분석기 검산으로만 사용한다. 실제 자료 접근과 신규 실험은 아직 수행되지 않았다.

CE6–8은 실험·정책 선택의 계산 기준으로 남기며, LBT-1이 전체 기억·행동·수면 시스템을 이미 대체했다고 쓰지 않는다. 이전 CE8 main 패치와 국소 감사 보완의 게시 상태는 별도 확인 대상이다.

## 5. 이번 게시 검사와 제한

[게시 전 기록](publication_receipt.json)과 [MANIFEST](MANIFEST.json)에 출처·실행 범위·파일 해시를 기록했다. 이전 ZIP의 20개 manifest 항목을 확인했고, 현재 환경에서 14개 테스트·전체 합성 실행·192개 독립 지표 검사를 다시 통과했다. 이는 새로운 생물학적 증거가 아니다.

직접 Git 복제는 컨테이너의 github.com DNS 오류로 사용할 수 없어 인증된 GitHub 연결로 게시한다. 전체 저장소 문서 하네스·전체 런타임·Windows 실행기는 이번 환경에서 실행하지 않았다. 새로 추가한 파일의 소스 해시·관련 검사·상대 링크·크기만 검증한다. 원격 main의 최종 커밋 확인은 실제 ref 갱신 뒤 별도 영수증으로 남긴다.
