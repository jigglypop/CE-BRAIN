# 6. 실제 ID의 상호연결과 숨은 상태 경유

## 6.1 집단의 흐름에서 실제 경로로

앞 장은 집단별 연결 분포가 다르고 세부형이 그 차이 일부를 설명한다는 사실을 보였다.
하지만 범주 사이에 들어오는 연결과 나가는 연결이 있다는 것만으로 같은 분절을 경유하는
경로가 존재하지는 않는다. 서로 다른 두 분절을 하나의 범주로 합치면 실제로 연결되지 않은
두 edge가 이어져 보일 수 있다. 따라서 이번에는 모든 원시 연결의 실제 ID를 맞췄다.

[공식 full graph](https://male-cns.janelia.org/download/)의 v1.0 `minconf-0.5` 배포본에서
151,856,684개 행을 전량 사용했다. 추가 weight·confidence 문턱, top-K, 뉴런 부분망을
적용하지 않았다. 원시 행의 두 ID를 손실 없이 부호화하고 전체를 정렬했을 때 중복된
방향성 ID 쌍은 0개였다. 이전의 connection-record 개수와 이번 고유 dyad 개수가 같다는
것을 비로소 전량 확인한 것이다. 원본의 자기 연결 123쌍·weight 542는 캐시에 보존하되,
이 장의 상호연결과 두 단계 경로 지표에서만 제외한다.

## 6.2 상호연결은 분석 범위에 따라 달라진다

실제 쌍을 확보했으므로 이제 반대 방향 연결의 존재를 물을 수 있다. [정의] dyad 상호성은
자기 연결을 제외한 방향성 ID 쌍 중 역방향 ID 쌍도 있는 비율이다. 양방향 한 쌍은 두 개의
방향성 dyad로 센다. 전체 151,856,561개 중 8,871,458개가 해당해 **5.8420%**였다.
이는 양방향 unordered pair 4,435,729개에 해당한다.

같은 계산을 superclass가 지정된 뉴런끼리의 연결에 조건화하면 25,582,837개 중
7,647,520개, **29.8932%**다. 더 큰 비율이 전체망을 더 정확하게 나타내는 것은 아니다.
전체 자료에는 이 판본에서 outgoing 연결이 관측되지 않은 post-only target으로 향하는
연결이 많고, 그 target에는 관측된 역방향 연결이 있을 수 없다. 해당 dyad는 119,105,009개,
nonself 전체의 78.4326%다. 그 weight 177,619,313은 nonself weight의 56.9598%다.
이는 주석 결측과 다른 구분이며 물리적 신호 소실률도 아니다.

연결 존재와 전달량을 구별하려면 weight 지표를 따로 읽어야 한다. 역방향이 있는 edge가
차지하는 전체 nonself weight는 16.8744%이지만, 각 방향에서 두 weight의 최솟값만 센
균형분은 7.3899%다. 양방향 edge가 있어도 두 방향의 접촉 수가 같지 않기 때문이다.
앞 장의 범주 합계에서 계산한 12.28%는 다른 단위·분모여서 이 값과 직접 비교하지 않는다.

![전량 분절과 주석 뉴런 조건부의 실제 dyad 상호성](../../../verify/MaleCNS/figures/dyad-return/exact_reciprocity.png)

그림 1. 위 패널은 고유 방향성 연결, 아래 패널은 접촉 weight를 분모로 쓴다. 두 패널 모두
자기 연결을 제외한다. 오류 막대를 넣지 않은 것은 한 graph의 전수 수치가 독립 동물 표본의
추정치가 아니기 때문이다. 재구성·주석·synapse 판독의 불확실성이 없다는 뜻은 아니다.

## 6.3 미주석 경계를 경유하는 실제 경로

상호연결의 단위를 고정한 뒤 두 edge가 같은 중간 ID에서 만나는지 검사했다. 양 끝점은
27개 superclass로 지정된 뉴런이며 중간 분절은 제외 없이 네 집단으로 나눈다. [정의]
두-edge walk는 첫 연결의 도착 ID가 둘째 연결의 출발 ID와 같은 순서 있는 세 ID다.
각 edge의 자기 연결을 제외한 뒤 시작과 끝 ID가 같은 되짚기를 빼면 서로 다른 세 ID의
경로만 남는다. 동일 endpoint 쌍에 중간 ID가 여러 개면 각각 다른 walk로 센다.

| 중간 ID 집단 | 실제 매개 ID 수 | 전체 두-edge walk | 시작 ID로 되짚기 | 서로 다른 세 ID |
|---|---:|---:|---:|---:|
| Assigned neuron | 165,327 | 9,579,474,710 | 7,647,520 | 9,571,827,190 |
| Annotated glia | 741 | 64,621 | 1,053 | 63,568 |
| Annotated unclassified | 14,254 | 5,088,879 | 48,992 | 5,039,887 |
| Unannotated segment | 652,640 | 7,283,276 | 480,286 | 6,802,990 |

표 1. 경로 수는 unique ID triple의 개수이며 weight 곱이나 개별 synapse 연쇄의 개수가
아니다. 모든 중간 raw source ID 1,834,661개를 검사했다. 표의 매개 ID 수는 assigned
source에서 들어오고 assigned target으로 나가는 연결이 모두 있는 경우만 센다.

미주석 segment를 경유한 7,283,276개는 범주 수준의 착시만으로 생긴 수치가 아니다.
예를 들어 `10231 -> 957741 -> 10029`는 두 연결이 실제 미주석 ID `957741`을 공유하고
각 weight가 1이다. 그렇다고 `957741`을 독립된 완전한 뉴런으로 확정할 수는 없다.
같은 이유로 Glia 주석을 경유한 접촉을 교세포의 신경 전달 기전으로 해석하지 않는다.

![실제 중간 ID를 공유하는 두 단계 경로](../../../verify/MaleCNS/figures/dyad-return/actual_id_two_edge_paths.png)

그림 2. 두 지표는 규모 차이를 읽기 위한 로그 count 축에 점으로 표시했다. 선택한 경로
예시는 각 집단의 매개 count가 큰 ID에서 뽑았고, 전량의 대표 표본이나 독립 확인 집합은
아니다. 저장한 20개 예시 모두 원시 정렬 캐시의 두 key와 weight를 재확인했다.

## 6.4 구조적 경유에서 조건부 이력 항으로

실제 경유가 확인됐으므로 3장의 내부 상태 소거와 연결할 수 있는 범위를 좁혀 말할 수 있다.
원시 분절 $i$에서 $j$로 가는 weight를 $w_{ij}$, 전체 outgoing 합을 $s_i=\sum_jw_{ij}$라
두자. [공리: 구조적 대리모형] $s_i>0$이면 $P_{ji}=w_{ij}/s_i$인 비음수 전이를 공급한다.
행은 도착이고 열은 출발이다. outgoing이 없는 ID는 흡수 상태로 보완한다. 이 보완은 관측된
self-edge의 추가가 아니라 모형 선택이며, 모형의 한 step을 생리적 시간으로 환산하지 않는다.

$K$를 raw에 등장한 assigned annotation ID의 상태 집합, $H$를 나머지 raw ID의 상태 집합이라 하자.
각 상태의 확률 질량 벡터를 $k_t,h_t$라 하면 블록 전이는

$$
k_{t+1}=P_{KK}k_t+P_{KH}h_t,\qquad
h_{t+1}=P_{HK}k_t+P_{HH}h_t
$$

다. 여기서 $P_{AB}$는 $B$에서 $A$로 가는 블록이다. 숨은 상태 식을 반복 대입하면
[산출]

$$
k_{t+1}=P_{KK}k_t+P_{KH}P_{HH}^{t}h_0+
\sum_{r=0}^{t-1}P_{KH}P_{HH}^{t-1-r}P_{HK}k_r
$$

를 얻는다. $t=0$에서 합은 비어 있다. 두 번째 항은 초기 숨은 상태의 효과이고,
마지막 항은 $K$를 떠나 $H$를 거쳐 다시 들어오는 구조적 이력이다.

첫 숨은 경유 연산자는 $P_{KH}P_{HK}$다. 위의 실제 witness 때문에 이 연산자의
$(10029,10231)$ 성분은 $1/(s_{10231}s_{957741})>0$ 이상이다. 다른 항이 비음수이므로
이를 상쇄하지 못한다. 따라서 **이 구조적 대리모형에서 첫 숨은 경유 항이 0이 아님**은
실제 경로와 양의 정규화로부터 따라온다. 이 장의 dyad 실행은 그 값의 크기나 전체 커널의
감쇠 시간을 계산하지 않았다. 7장은 이 중 54개 초기 probe의 첫 복귀량을 후속 계산한다.
정규화 분모에는 주석 뉴런 바깥의 모든 outgoing weight도
포함해야 하므로, 주석 부분망 안에서 다시 정규화한 전이로 대체할 수 없다.

이 산출은 선택한 관측과 대리 전이에서 성립하는 `BIO_EVIDENCE_L0` 결론이다. 비영인
경유 항만으로 모든 관측의 비마르코프성이나 학습으로 형성된 기억이 증명되는 것은 아니다.
관측을 더 합치거나 허용 초기상태를 제한하면 같은 과거 효과가 구별되지 않을 수 있다.
signed 신경 전달에서는 상쇄도 생길 수 있어 이 비음수 경로 논증을 그대로 옮기지 않는다.

## 6.5 다음에 구별할 것

경유 항의 존재 다음에는 그 크기와 관측 가능한 차이가 필요하다. 후속
[7장](07_전체전달의_숨은경유와_미래정보.md)은 같은 전체 outgoing 분모를 유지한 희소
연산자로 64 step 첫 경유량과 27쌍 초기 구성의 미래 관측 Fisher를 계산했다. 초기 hidden
자극, 같은 관측의 자율 기억 축약, 연결 변화의 Fisher는 별도 다음 비교로 남는다.
생물학적 부호·시간·가소성은 별도 자료로
교정하며, 해부학적 ROI는 세포형 이름이 아니라 실제 synapse 좌표·영역 대응으로 붙인다.

이 장의 정적 ID 연결·경로 관측은 범위를 명시한 `BIO_EVIDENCE_L1` 구성요소다.

기록은 [별도 ID 경로 원장](../../../ledger/malecns_dyad_return_findings.md), 계산과 그림은
