# 5. 실제 전체 입력에서 보인 방향과 세부형의 정보

## 5.1 자료 점검에서 관측으로

앞 장의 계획에서 첫 실제 질문은 동일한 상위분류에 속한 뉴런을 평균 하나로 대신해도
같은 다음 연결 분포를 얻는가였다. MaleCNS v1.0의 full weights 모든 151,856,684행을
읽고 311,833,243의 접촉 가중치 합을 보존했다. 27개 뉴런 superclass, 교세포, 분류가
누락된 annotation, annotation에 없는 segment를 합쳐 30개 범주로 관찰했다.

이 계산은 전체 뇌의 작은 부분망을 뽑은 실험이 아니다. 모든 원시 연결을 집계하지만,
결과를 읽는 관측은 범주 수준이다. 30×30 행렬이 전체 뉴런의 상세 연결을 무손실로
대체한다는 뜻은 아니다. 정확한 값·입력과 소스 해시·실행 환경은
[별도 분석 원장](../../../ledger/malecns_structure_findings.md)에 둔다.

## 5.2 버릴 수 없는 경계와 방향 비대칭

전체 접촉 가중치의 55.01%는 주석된 세포에서 미주석 segment로 향했고, 40.20%는
양쪽 모두 annotation에 있었다. 미주석 분절을 삭제하면 연결의 절반 이상을 잃는 셈이다.
이는 미주석 분절 하나하나가 독립 뉴런이라는 뜻이 아니다. 분절의 세포 대응과 관측 경계를
해결하기 전에 닫힌 신경 동역학으로 해석할 수 없다는 의미다.

관측된 방향은 단순히 대칭적이지 않았다. `ol_intrinsic→visual_projection`은 약
771만 접촉인 반면 반대 방향은 약 132만이었다. `vnc_intrinsic→vnc_motor`는 약
222만 대 약 1.9만이었다. 반면 `ascending_neuron↔vnc_intrinsic`은 약 159만 대
164만으로 두 방향 규모가 비슷했다. 따라서 모든 방향을 같은 비대칭 법칙 하나로
설명하거나 원시 연결을 무조건 대칭화하는 것은 관측된 차이를 없앤다.

이 결과의 단위는 **세포 정체성 범주 사이의 접촉 합**이다. neuropil 간 전달이나 실제
한 뉴런에서 시작해 되돌아오는 경로는 아직 세지 않았다. 서로 다른 뉴런이 같은 범주에
속한다는 이유로 하나의 연속 경로를 만들면 안 된다.

![전체 raw 접촉의 범주별 방향 합](../../../verify/MaleCNS/figures/structure-v1/whole_category_flow.png)

그림 1. 모든 raw weight의 합. 회색은 0, 색은 로그 척도다. 물리적 위치 지도나
실제 뉴런 사이의 경로 그림이 아니다.

## 5.3 집단 평균만으로 닫히지 않는 전달

source $i$의 접촉을 target 범주별로 합하고 전체 outgoing 접촉으로 나누어 분포 $q_i$를
정의했다. 이것은 [2장](02_전체망과_측정.md)의 구조적 대리모형이며 실제 발화의 전이확률이
아니다. 같은 superclass의 모든 $q_i$가 같아야 집단 상태만 남긴 정확한 Markov 폐쇄가
가능하다. 27개 superclass 모두에서 이 필요조건은 성립하지 않았다.

이 차이가 시냅스 수가 작은 뉴런에서 생기는 단순 표본 차이일 수 있어, source별 접촉 수와
target 범주별 접촉 수를 고정한 stub 재배치의 기대 분산과 비교했다. 실제 가중 분산은
그 기대값의 1.279–599.623배였다. `cb_intrinsic`은 약 302배, `ol_intrinsic`은 약
61배, `vnc_intrinsic`은 약 163배였다. 그러나 `ENS`와 4개뿐인 `cb_efferent`는 각각
약 1.28배와 1.66배였다. 이를 모두 동일한 강도의 결과로 표현하지 않는다.

관측/기대 비율은 p값이 아니다. 시냅스 weight를 연결 레코드 수로 바꾸거나 분류된
뉴런 표적만 조건부로 읽으면 크기가 달라졌다. 특히 후자는 범주별 원래 out-weight의
중앙 41.51%만 남겼다. 미주석 경계를 제거해 얻은 작은 계가 원래 전체망이라는 주장은
지지되지 않는다.

이 단계가 [3장의 내부 상태 소거](03_정보손실과_기억.md)와 연결되는 지점은 분명하다.
같은 집단 관측이어도 어떤 뉴런에 상태가 실렸는지에 따라 다음 관측이 달라질 수 있다.
따라서 그 대리모형의 정확한 축약에는 추가 내부 정보 또는 이력 의존 표현이 필요하다.
아직 이것을 동물이 기억을 저장하는 기전으로 해석하지 않는다.

## 5.4 세부 세포형이 보존하는 구별성

넓은 superclass가 여러 세부형을 섞었다는 대안을 먼저 확인했다. 총 166,700 assigned
뉴런 중 outgoing 접촉이 있는 165,665개에 대해 자신의 전체 outgoing row를 제외하고,
다른 뉴런의 superclass 평균 또는 같은 `(superclass,type)` 평균으로 자신의 target
분포를 예측했다. 미주석·교세포를 포함한 30개 target 범주는 그대로 남겼다.
같은 세부형의 양의 outflow peer가 없으면 superclass 보류 모형을 사용했다.

균등 Dirichlet 총량 alpha=1에서 contact-weighted cross-entropy는 superclass 모형의
0.995924에서 세부형 모형의 0.886486 nats로 낮아졌다. 상대 감소는 10.989%다.
alpha=10과 100에서도 감소는 10.974%, 10.565%였다. 뉴런마다 같은 비중을 주는
평균에서도 10.566%, 10.534%, 10.063% 감소해, 총량이 큰 소수 뉴런만의 개선은 아니었다.

이 결과는 “세부형 이름이 다른 뉴런의 구조적 표적 분포를 구별하는 데 도움이 된다”는
catalogue 내부 관측이다. type 결측 계층의 개선은 1% 미만이었다. type 정의가 연결을
이용해 정해졌을 가능성이 있으므로 이를 독립적인 세포형 검증으로 읽지 않는다.

음성 결과는 다음 해석을 제한한다. `cb_endocrine`에서는 alpha 1/10/100 모두 성능이
나빠졌고, alpha=100의 `vnc_motor`는 약 10.93% 악화했다. 9개 소형 또는 세분되지 않은
범주는 fallback이나 같은 그룹 때문에 개선이 0이었다. 더 작은 집단으로 나누면 언제나
잘 예측한다는 주장은 이 관측과 맞지 않는다.

![27범주의 source 보류 예측](../../../verify/MaleCNS/figures/structure-v1/type_source_loo.png)

그림 2. alpha=1의 범주별 보류 loss와 양의 outflow source 수. 낮을수록 좋다.
개선이 없는 범주와 악화하는 범주도 표시했다.

## 5.5 이름을 섞으면 같은 개선이 생기는가

더 작은 집단을 만든 것 자체가 개선의 이유인지 확인하기 위해 type label 대조를
48회 수행했다. source의 모든 관측 접촉과 degree를 그대로 두고 superclass 안에서
type 이름을 섞었다. 두 번째 대조에서는 각 superclass의 out-weight decile 안에서만
이름을 섞어 type별 연결량 구간의 구성까지 유지했다. type 결측과 zero-out은 고정했다.

실제 label의 loss 감소가 +10.989%인 데 비해 superclass 내부 24회 재배치는
−7.113%에서 −6.649%, degree 구간까지 제한한 24회는 −7.020%에서 −6.597%였다.
즉 이 대조에서는 임의로 만든 세부형이 개선을 재현하지 못했고 오히려 악화했다.
catalogue의 세부형에는 이 두 단순 배치 조건을 넘는 target 분포의 구별성이 있었다.

![실제 세부형과 48회 label 대조](../../../verify/MaleCNS/figures/structure-v1/type_label_controls.png)

그림 3. 각 점은 한 번의 전체 label 재배치다. 독립 동물이나 생물학 반복이 아니며
p값을 표시한 그림이 아니다. 두 번째 대조에서 degree 구간은 재배치만 제한하고 predictor는
기존처럼 `(superclass,type)` peer 전체를 사용한다.

이 결과에도 연결 기반 type 정의라는 대안은 남는다. 같은 연결로 만든 이름이 같은
연결을 설명하는 정도를 확인했을 수 있으므로, 독립 type annotation·공간 및 ROI 제약·
다른 개체에서의 재현을 건너뛰지 않는다.

## 5.6 현재 주장과 다음 반증

지금 지지되는 것은 한 성체 수컷 CNS의 source-locked 접촉 구조에 방향 차이와
세포형별 target 분포의 구별성이 존재한다는 범위고정 관측이다. 이 구조 구성요소는
`BIO_EVIDENCE_L1`로 읽는다. 미래의 실제 신경 활동, 학습 전후 변화, 기하학적 기억의
인과 기전이나 기능계량 전체는 여전히 `BIO_EVIDENCE_L0`다.

이후 [실제 ID 경로 장](06_실제ID의_상호연결과_숨은경유.md)에서 전량 dyad의 상호연결과
미주석 중간 ID의 경유를 확인했다. 공간·ROI 조건 대조는 아직 남아 있으며, 실제 초기상태·
기억 커널·Fisher 계산은 이 입력과 경계 조건을 명시한 동역학 단계에서 수행해야 한다.

전체 코드와 결과표를 읽고 다시 그리는 [실행 notebook](../../../verify/MaleCNS/whole_structure_companion.ipynb)과
[HTML 읽기본](../../../verify/MaleCNS/whole_structure_companion.html)을 함께 제공한다.
