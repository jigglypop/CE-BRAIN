# 1. 현재 연구의 핵심과 구현 경계

## 1.1 복원한 중심 질문

전체망 연구에 앞서 고정할 것은 뉴런의 정체성과 분석 좌표이며, 바꿀 것은 연결의 전달
효과와 이력이다. [공유 대화](https://chatgpt.com/share/6aa7e99b-480c-83e8-9127-b73b348d49d5)는
군집·방향 전달·숨은 상태·미래 정보의 관계로 발전했다. 최신 수학적 제안은 회로를 묶을 때
잃는 정보를 계산하고, 허용 오차에 필요한 내부 좌표를 남기는 것이다. 프랙탈 여부와
관측분포의 곡률은 이 질문과 구분한다. 과거 초파리 수치는 유충 64개 Kenyon 전사 부분망의
보고값이며, 이번에 원본 실행 패키지를 확보하거나 재현한 결과가 아니다.

이 목적은 [기존 PRD](../../../.codex/PRD.md)의 고정점과 연결·기능의 계량 표현을 따른다.
물리적 세포 위치를 고정하는 것, 신경 활동을 고정하는 것, 출력분포의 좌표를 고정하는 것은
서로 다른 조건이다. 아래 코드가 표현하는 공간부터 구분해야 한다.

## 1.2 저장소에 들어온 연구

중심 질문을 실제 코드와 연결하면 세 가지 계산 표면이 있다.

| 구현 | 이미 표현한 것 | 아직 표현하지 못한 것 |
|---|---|---|
| [RGM-1 `rgm_core.py`](../../8_해마수면_관계기억_연구/RGM1/source/rgm_core.py) | 지역별 반응, 대칭 양의 소산 연산자, 내부 차이를 제거한 기억, 별도 탄성 접힘 프록시 | 전체 방향성 신경망의 동역학이나 실제 성장·전류 계수 |
| [RGM-3 `resource_core.py`](../../8_해마수면_관계기억_연구/RGM3/resource_core.py) | 자유 자원량·결합량·영역 크기의 분리, 유한 자원 경쟁, 보존적 국소 갱신 | 해당 변수를 같은 뉴런의 실제 분자량으로 교정한 사상 |
| [HPI-1 `predictive_core.py`](../../8_해마수면_관계기억_연구/HPI1/predictive_core.py) | 고정 방출 슬롯과 학습 전이, 관측 이력에서 문맥 추론, 미래분포 기반 정보기하 | 대규모 전체 커넥톰, 온라인 국소 학습, 원신경기록에서의 동일 기전 |
| [HPI-1 `path_geometry.py`](../../8_해마수면_관계기억_연구/HPI1/path_geometry.py) | 선형 전달의 경로 미분과 전체 시간 공분산을 사용하는 Gaussian 정보행렬 | 관측모형 없이 시냅스 수로부터 생물학적 계량을 유일하게 추론 |

RGM-3의 고정 친화도·동일 연결에서는 경쟁만으로 한쪽만 살아남지 않는 결과가 남아 있다.
협동 포착은 그 뒤 추가한 후보이며 원래 고정계의 유일평형 조건을 자동으로 이어받지 않는다.
HPI-1도 무작위 초기화의 문맥 복원 실패를 보존한다. 과거 완결 에피소드로 초기화한 개선은
온라인 학습 또는 독립 생물 검증과 구분된다. 이번에는 HPI-1의 핵심 19개 테스트를 실행해
통과했으며, RGM의 과거 전체 계산은 다시 실행하지 않았다.

HPI의 저자 공개 11마리 요약 재분석은 실제 동물에서 나온 요약값을 이용하지만 새 코호트나
원신경기록의 적합이 아니다. 그 결과와 합성 HMM을 더해 하나의 뇌 알고리즘 확인으로 세지 않는다.
관련 지위와 원결과는 [기존 연구 입구](../../8_해마수면_관계기억_연구/README.md)에 연결했다.

## 1.3 전체망 실행 전에 해결할 코드 문제

이 코드들을 전체 CNS 연구에 사용하려면 입출력 계약도 맞아야 한다.
[현재 runtime](https://github.com/jigglypop/reality_stone/blob/v0.3.0/python/reality_stone/clarus/runtime.py)은 dense 가중치를
보관하면서 CSR을 함께 만든다. 166,700차원 float32 행렬 하나만 약 111 GB이므로,
현재 생성자에 전체망을 넣는 방식은 연구의 시작 경로로 적절하지 않다. 원본 연결표를
배치로 읽고 희소 행렬이나 행렬 연산 함수로 전달을 계산해야 한다.

같은 코드의 작은 실제 실행에서 `dale_law=True`인 snapshot 복원은 가중치를 바꾸었고,
0 delta 갱신도 0이라고 보고하면서 실제 가중치를 바꾸었다. 기억값은 호출자의 float32
텐서와 저장소를 공유했다. 이는 소스에 남아 있는 행 부호 적용·억제 이득 재적용·소유권
문제를 확인한 것이다. 전체망 기억·학습 실험에 이 경로를 쓴다면 먼저 수정하고 원본 대
복원본의 같은 입력 전이를 비교해야 한다. 이번 요청에서는 분석과 계획을 수행했으며
runtime 패치를 적용하지 않았다. 재현 조건은 [별도 원장](../../../ledger/malecns_inventory.md)에 있다.

[기존 connectome replay](https://github.com/jigglypop/reality_stone/blob/v0.3.0/python/reality_stone/clarus/connectome_replay.py)는
OpenWorm 선충의 고정 manifest와 CSV용이다. MaleCNS를 읽는 모듈로 재사용할 수 없으므로,
공식 Arrow 스키마와 body ID를 보존하는 별도 어댑터가 필요하다.

## 1.4 아직 끝나지 않은 자료와 해석

구현 존재와 계산 완료를 구별하면 남은 작업도 분명해진다. MICrONS의 앞선 15블록 분석은
완료 기록이 있지만 후속 radial 방향·관측 조건 비교는 현재 14블록 로그와 소스만 있고
최종 배열·결과가 없다. HPI-2와 공유 대화의 FMC·CPA·geometry-memory 실행 패키지는
현재 로컬 정본이 확인되지 않았다. 이들은 완료한 새 결과로 이식하지 않는다.

따라서 다음 단계는 이전 숫자를 성체 초파리에 대입하는 것이 아니라, 전체 MaleCNS에서
같은 질문을 판별할 입력·전달·관측을 구성하는 일이다. 이 구분이 다음 장의 자료 설계를 결정한다.
