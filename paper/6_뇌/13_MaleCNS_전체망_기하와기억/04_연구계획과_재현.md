# 4. 전체망 연구계획과 재현 경로

## 4.1 목표와 현재 단계

앞 장의 수학을 실제 입력으로 판별하기 위한 목표는 **전체 MaleCNS에서 방향 연결과
내부 이력이 관측 반응·기능적 구별성을 얼마나 보존하는지 밝히는 것**이다. 전체망 원본을
유지하고 계산만 배치·희소·저차원 방식으로 수행한다. 이 문서는 연구계획이며 봉인된
사전등록이나 생물학적 양성 결과가 아니다. 수치 허용오차·모형 선택·평가 분할은 첫 적합 전에
실행 가능한 설정으로 고정하고, 이후 수정은 개발 이력에 남긴다.

현재는 공유 대화와 코드의 대응, 공식 데이터 구성, 보유 파일의 판본·해시·스키마를
확인하고 full weights의 모든 행에서 수지·ID·NULL을 집계했다. 이후 전체 범주 방향·경계,
구조적 집단 전달의 폐쇄 필요조건, 세부형 source-LOO와 48회 label 대조를 계산해 [첫 관측](05_실제전체망_첫관측.md)에
반영했다. 이어 [실제 ID 경로](06_실제ID의_상호연결과_숨은경유.md)에서 전량 중복 0개,
dyad 상호성·post-only 경계·실제 중간 ID를 경유하는 두 단계 walk를 계산했다.
이후 [전체 전달의 미래 정보](07_전체전달의_숨은경유와_미래정보.md)에서 모든 active raw ID와
terminal 경계를 보존한 희소 전이를 완성했고, 27쌍 초기 probe의 16 step 관측 Fisher와
64 step 첫 숨은 복귀를 계산했다. 생리적 신경 동역학의 반응 적합·자율 시간 축약·프랙탈
비교·생물학적 기억 검증은 이와 구별한다. 이어 [관측과 이력 비교](08_관측경계와_이력축약의_성공과실패.md)에서
60출력 관측, 두 lifting의 자율 유한 이력 예측과 초기항 대조를 계산했다. 원형의 정확한
이력 재현은 통과했지만 짧은 절단은 음수 분포와 비단조 오차를 만들었다. 확률을 보존하는
실용 축약과 새 입력의 보류 예측은 아직 남았다.
이후 [연결 효능과 관측기하](09_연결효능의_미분과_관측기하.md)에서 세 공유 효능 좌표의
전량 Jacobian과 여섯 독립 차분 대조를 완료했다. 첫 step의 세 TBC 범주는 same-superclass
방향이 보이지 않았지만 step 2..16에서는 세 구조 좌표가 모두 수치 rank 3이었다.
공통 배수 gauge는 항상 0이며 같은 rank에서도 30/60 관측의 정보량은 달랐다.
자료 적격성 확인이 현재 목표에서 벗어나지 않는 이유는 방향·좌표·결측을 잃으면 같은
계량이나 같은 전달을 비교할 수 없기 때문이다.

## 4.2 단계별 수행과 판정

| 순서 | 실제 수행할 일 | 비교·통과 조건 | 실패·미확립의 의미 |
|---|---|---|---|
| 1. 전체 입력 어댑터 | full weights의 모든 body·행을 스트리밍 인덱싱; 전체 annotation·stats·NT·partner·point 결합 | 원행수·시냅스 수 합·ID 역변환 보존. 64개·Top-K 제한 없음. 전체/신경세포/미분류/경계별 coverage와 중복 집계 보고 | 불일치는 입력 변환 문제. 부분 CSR로 대체해 통과시키지 않음 |
| 2. 부위와 경계 | 전체 CNS를 유지하며 세포형·neuropil별 incoming/outgoing, 상호연결·경로·다중 partner 집계 | 감각→중앙뇌→하행→VNC→운동 경로 및 피드백을 포함. 미분류 접촉과 좌표 결측을 별도 보고 | 유형·ROI 결측은 연결 부재가 아님. 뇌 영역을 잘라낸 결과를 전체 결과로 쓰지 않음 |
| 3. 방향 전달 | 같은 전체 입력에서 방향 원형, 대칭화, 방향 반전, 차수·상호성·가중치 보존 대조 비교 | 같은 관측·입력·모형시간·누출·예산에서 impulse/반응분포 차이. 부호·정규화 가정 민감도 병기 | 공급한 모형의 방향 효과만 판정. 실제 전기 전달은 미확립 |
| 4. 기억이 필요한 축약 | 전체 연산자 위에 ROI·세포형 관측을 두고 평균만, 평균+초기항, 평균+기억, 같은 차원 일반 축약 비교 | 같은 현재 관측·다른 내부 상태의 미래 차이. 기억 차원 대비 오류·연산량, 양성·안정성 조건을 함께 확인 | 초기상태 재구성과 구동된 자율 축약을 혼동하지 않음 |
| 5. 정보기하와 연결 변화 | 같은 likelihood에서 full/group Fisher, 관측가능 공간, 선택 연결 변화의 미분 계산 | 대칭 거리만·일반 저차원 모형·연결 셔플과 같은 입력 예산 비교. 미분은 독립 유한차분 대조 | SPD·곡률 발생은 학습 기전 확인이 아님. 관측에 불변인 방향은 비식별로 보고 |
| 6. 여러 척도 검사 | 전체망에서 지역 규모·coarse operator·시간응답의 척도 관계 조사 | 알려진 재귀 구조의 양성대조, 평평한 격자, 차수·공간·유형 조건 대조. 척도 범위와 추정 오차 고정 | 직선만 맞거나 대조군과 구분 못 하면 프랙탈 미확립 |
| 7. 실제 기능 자료 | 같은 세포/유형의 활동·개입·지연·수용체 근거에 전달모형을 결박 | 원신호 측정모형, 독립 trial/session/animal 평가, 상태·기전 대조 | 자료가 없으면 해당 생물 endpoint 미실행. 정적 EM 성공으로 대체하지 않음 |

## 4.3 세 경쟁 경로와 첫 선택

이 단계들을 하나의 특정 기하에 맞추지 않기 위해 세 경로를 경쟁시킨다. 첫 경로는 전체
해부학 연결에 따른 방향 전달과 숨은 이력이다. 두 번째는 같은 입력·출력을 가진 일반
선형 상태공간/저차원 예측모형이다. 세 번째는 공간 거리·세포형·차수와 같은 간단한
구조만으로 반응 또는 연결 기록을 설명하는 모형이다. 프랙탈성은 이들과 별개인 척도 가설이다.

첫 실행 경로는 전체 입력 어댑터와 방향 전달의 관측 문제다. 현재 보유 자료가 직접
제공하는 것은 구조이기 때문이다. 전압·호르몬·표적 수용체를 측정하지 않았으므로
그 변수의 수치를 임의로 확정하지 않는다. 기존 게임 CSR의 transmitter 부호를 사용한
대리 실험은 별도 민감도 조건으로만 남긴다.

## 4.4 전체망의 계산 설계

전체망을 유지하려면 dense 행렬지수와 전부의 고유벡터가 필요하다는 가정을 버려야 한다.
입력은 Arrow record batch로 읽고, 방향 COO/CSR과 원 ID 사상을 저장한다. 전달에는
희소 행렬-벡터 곱을 사용한다. 현재 7장은 이산 확률 전이이며, 연속시간 모형을 별도로
채택할 때는 Krylov 방식의 지수 작용을 검토한다. 출력이 적을 때는 adjoint
반응을, 필요한 기억 차원에는 행렬을 직접 만들지 않는 관측 Gramian 연산을 사용한다.
검증된 SciPy 희소 도구를 활용하고 새로운 고유해법을 직접 구현하지 않는다.

단, raw segment마다 뉴런 상태가 존재한다고 가정하지 않는다. 먼저 전체 원본 ID 사상과
해석 가능한 세포 대응을 분리한다. 신경세포 연산자를 만들 때 미해결 segment 접촉은
명시적 경계 입력·출력 또는 불확실한 연결로 보고하며, 임의로 0으로 두어 닫힌 전체 뇌라고
부르지 않는다. 이러한 경계의 처리와 불확실성을 정하기 전 전체 신경 동역학 단계는 열지 않는다.

관측·입력 probe 수를 제한하는 것은 전체 노드를 제거하는 것과 다르다. 모든 연결은
전달에 남기며, 보고하는 오차가 어떤 probe와 시간 구간에 대한 것인지 명시한다.
작은 블록의 직접 해와 비교해 수치 허용오차를 정한 뒤 전체망에서 반복 차수·시간 격자
증가에 따른 수렴을 확인한다. 메모리 절감을 위해 주변 회로를 지운 경우에는 그 경계
오차가 별도로 드러나야 한다. 기존 166,700-node dense runtime 실행은 선행조건이 아니다.

## 4.5 분할과 음성 결과

계산이 수렴한 뒤에도 같은 동물을 여러 표본으로 세지 않아야 한다. 현재 전체 CNS는
동일 개체의 구조다. 영역·세포형·뉴런 쌍을 나눈 평가는 내부 보류 예측이고, 좌우 비교는
동일 개체의 공간 전이다. 다른 성별·발달기의 커넥톰은 독립 복제와 분포 차이를 동시에
갖는다. 유충 64개 보고를 성체의 확인 집합으로 재사용하지 않는다.

구조 예측에서는 평가 뉴런의 연결로 만든 군집·차수·유형 추정이 학습 입력으로 새지 않도록
분할 안에서 특징을 다시 구성한다. 공개 annotation 자체가 연결을 이용해 정해졌을 가능성은
별도 한계로 보고한다. 대리 동역학의 원형과 축약 비교는 같은 원형을 정답으로 삼는
수치 검증이며 관측된 생물 반응의 예측과 구별한다.

평균만으로 충분하거나, 임의 저차원 모형이 같은 오차를 내거나, 방향/공간 대조에서
추가 이득이 사라지는 경우도 주 결과다. 곡률이 증가해도 정보가 감소할 수 있고, 기억
좌표 수를 늘려 오차가 줄어드는 사실만으로 생물학적 기억 메커니즘이 밝혀지지 않는다.

## 4.6 바로 확인 가능한 재현

현재 입력과 코드 확인은 저장소 루트에서 다음 명령으로 조회할 수 있다.

```powershell
.codex/hooks/python.cmd doctor
.codex/hooks/python.cmd python .codex/hooks/data_registry.py find malecns
.codex/hooks/python.cmd pytest paper/8_해마수면_관계기억_연구/HPI1/test_predictive.py -q
.codex/hooks/python.cmd python .codex/hooks/repository_harness.py
```

HPI 검사는 2026-09-14에 19개가 통과했다. 이 명령은 전체 MaleCNS의 과학적 분석을
실행하지 않는다. runtime의 작은 실패 재현, 전체 입력 조사와 남은 파일 경계는
[별도 원장](../../../ledger/malecns_inventory.md)에 기록했다. 과거 SHA로 잠긴 파일과
기존 증거 저장소는 보존한다. 새 구현·결과는 해당 소스와 입력 판본을 함께 명시한다.

전량 정렬 dyad, raw source 인덱스, 흡수 경계를 명시한 전체 희소 전이와 관련 검사 5개는
완료됐다. 60출력과 자율 이력 비교도 끝났고, 단순 유한 이력 절단의 음수 실패를 확인했다.
세 공유 효능 좌표의 Jacobian·독립 차분·관측별 Fisher와 비식별 방향도 계산했다.
다음 진행 조건은 **같은 효능 좌표의 끝점 관측 → 이력의 결합 likelihood → 두 관측의
정보 차이와 확률을 보존하는 축약**이다. 같은 경로의 시점별 endpoint Fisher를 단순히
합산하지 않으며 signed 축약을 likelihood에 사용하지 않는다. 확률 보존·같은 총 예산의 일반 축약·새 입력 평가와
대안 경계 모형은 이력 압축 채택 전에 따로 비교한다. 해부학적 ROI 대응은 별도 입력
경로로 유지한다. 인간 해마·호르몬·AGI까지의
통합 주장은 그 단계의 관측과 반증을 별도로 통과해야 한다.
