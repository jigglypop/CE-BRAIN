# 시간표현과 고정 그래프 기억

## 1. 고정된 회로가 다른 시간 궤적을 만든다

고정 그래프 연구는 $\dot x=Fx+Bu$와 $\tau_e\dot e=x-e$를 사용했다. $F,B$는 학습 전후에 고정했고, 입력에 따라 $x^{(a)}(t)=e^{Ft}Bu_a$가 달라지게 했다. 냄새마다 별도 시간 함수를 저장하지 않고 같은 회로를 서로 다른 입력으로 읽는 방향이다.

학습은 하나의 연결 기억 배열에 누적했다. 존재하는 연결의 해당 구획에 조절신호가 들어왔을 때만 당시 흔적을 기록하고, 같은 기억에서 여러 냄새의 출력을 읽었다. 그러나 검사 회로의 80노드 순환 전달망은 KC 해부학이 아니다.

## 2. 기존 실행 결과

학습 시각 A 2초·B 6초인 계산 예에서 이전 부분모형의 상대 억압 정점은 2.89·8.05초, 고정 전달 후보는 1.60·5.62초였다. 노드 수는 같지만 입력 정규화·연결 구조·이득·상태 수가 달라 동일 비용 성능 비교가 아니다. 두 결과 모두 생물 측정 시각을 맞힌 것이 아니다.

Kropf 연구의 시간적으로 분산된 KC 표현과 지연 선택적 반응은 원보고서가 참고한 생물학적 동기다. 원시 시간곡선을 확보하지 못했으므로 KC·MBON·행동의 새 오차 감소를 계산하지 않았다.

## 3. 초 단위 표현과 분 단위 발현을 나눈다

다른 연구 가지의 유도–발현 분리는 초 단위 시간표현과 별개다. 반복 BAY의 후기 크기를 재보정한 뒤 발현 시간상수 120·300·600·900초를 비교했다. 대표 600초 후보는 3.5분 18.27%, 16.5분 78.01% 강화를 계산했지만 초기 정답을 맞힌 결과는 아니다.

반복 역치 .035/.045/.055에서도 3회 후기 강화는 약 78%로 보정됐지만 2회 결과는 13.78/1.47/0%로 달랐다. 이 범위는 후보 시나리오이지 신뢰구간이 아니다. 역치나 시간상수가 알려진 생물 상수라는 주장은 보류한다.

## 4. 남은 연결

학습 전 KC 시간반응으로 표현을 제한하고, 한 냄새·지연에서 계수를 고정한 뒤 다른 냄새·지연의 MBON 파형을 읽는 검증은 미완성이다. 현재 문서는 이 미실행 계획을 새 성공으로 표시하지 않는다.
