# 실측 자료와 평가 단위

## 1. 자료의 정체성

정적 관측 예측의 원본은 Bergmann 등의 저자 저장소 `aclinlab/bergmann-et-al`의 `CorrelationAnalysis/all KC values.csv`다. 고정 커밋은 `0b2da3f9c865626f8858881a468394c8eff68fa7`이다. 원보고서들은 이 가공 측정의 같은 바이트를 재사용했다.

| 항목 | 값 |
|---|---|
| 파일 크기 | 17,682바이트 |
| Git blob | `965d7e038fa23ba4226cda865d8802157f0d18c8` |
| SHA-256 | `5733b69eda14e5c557e784e96da917091877dc86a3a4a9c6026eae2520c8765a` |
| 유효 칼슘값 | 1,540 |
| 완전한 7조건 기록 벡터 | 220 |
| 보존한 음수값 | 39 |

220은 고유 동물 수가 아니다. 같은 슬롯 번호를 영역·유전자형을 넘어서 같은 동물로 연결하지 않았고, 마지막 완전 빈 행만 제외했다. 냄새 이름과 농도를 임의 대응하지 않고 위치 1–7로 보존했다.

## 2. 무엇을 예측했는가

여섯 영역은 Calyx·γ·β·β′·α·α′이며, 각 영역에 22c/31c × ctrl/TRPA 네 그룹이 있다. 입력은 같은 영역·조건의 대조군 평균, 목표는 처리군 평균이다. 냄새 분자나 전기 입력에서 첫 칼슘 반응을 예측한 것이 아니다.

한 냄새 위치를 모든 영역에서 동시에 제외하고 나머지 위치로 보정한 다음 보류 대조군 평균을 입력한다. 주 평가의 오차는 6영역×7조건, 42개 평균에 균등 가중했다. 평균값이 잡음을 줄여 주므로 개별 기록 오차와 같지 않다.

## 3. 보류와 독립 검증을 구별한다

후속 연구는 두 조건 동시 보류, 기록 슬롯 홀짝 분할, 난수 기록 분할, 내부 모델 선택을 추가했다. 같은 기록이 재사용되고 동물·반구 ID 대응이 불완전하므로 확정적인 animal-disjoint 검증이라고 부르지 않는다.

특히 최신 설정은 이전 보류 점수를 보고 수정한 뒤 선택했다. 코드의 보류 표적 비참조 검사는 계수 적합의 경계를 확인하지만 전체 개발이 맹검이었다는 증거가 아니다. 최신 네 평가를 개발 패널로 명시한다.

## 4. 관측량을 합치지 않는다

이 자료는 칼슘 지표의 처리값이다. EPSC, PPR, 발화율, 소포 방출확률, 행동을 같은 단위로 변환하지 않는다. 따라서 칼슘 RMSE 감소와 기존 PPR 잔차 18.18%포인트를 합산하지 않는다. 원시 영상·정량 cAMP 파형·새 개체 자료는 이번 게시에서 추가되지 않았다.
