# 고정 뉴런의 EM 위치와 연결 기록 보류 예측

문서 유형: 검증 원장. 대상은 뉴런을 물리적 고정점으로 두는 [연구 PRD](../../.codex/PRD.md)의 구조 연결 가지다. 같은 뉴런의 위치와 전자현미경 시냅스 annotation을 결합한다. 관측은 `BIO_EVIDENCE_L1`, 비용 모형과 이번 개발 비교는 `BIO_EVIDENCE_L0`로 구분한다.

## 질문과 판정 범위

이번 질문은 **학습에 등장하지 않은 양쪽 뉴런의 연결 기록을 공간 비용으로 예측할 수 있는가, 방향별 비용은 등방 거리보다 추가로 필요한가**다. 이미 공개·분석한 한 EM 체적의 재사용이며 독립 동물 확인 실험이나 사전등록 검증이 아니다. 이전 Allen 전기생리 표지와 이번 EM 표지는 다른 표본·측정이다.

15블록·아홉 모형의 계산을 완료했다. **거리 항의 내부 예측 개선은 관찰됐지만, 축별 quadratic 비용은 등방 radial보다 전체 점수가 좋지 않았다.** 모든 기하 후보가 SPD 내부라는 사실만으로 특정 방향 비용을 채택하지 않는다. 단위·좌표 대응, 분할, 최적화 검사는 생물학적 메트릭의 확인과 구별한다.

## 고정점과 리만 비용 후보

$p_i\in\mathbb R^3$는 µm 단위로 고정한 뉴런 $i$의 체세포 위치이고, $\delta_{ij}=p_j-p_i$는 그 사이 변위다. 뉴런의 활동이 상수라는 가정은 없다. $L_0=100\,\mathrm{\mu m}$는 계수의 수치 크기를 정하는 길이 기준이다.

$c_{ij}$는 순서를 보존한 문맥이다. 주 비교는 앞 뉴런의 axon 재구성 전략과 뒤 뉴런의 dendrite 재구성 전략을 묶는다. 보조 비교는 양쪽의 공개 세포형을 함께 묶는다. $a$는 전체 절편, $u_c$는 문맥별 편차이며 $a+u_c$가 방향쌍의 기본 log odds다.

| 후보 | 관측 확률의 logit | 비용과 지위 |
|---|---|---|
| 문맥만 | $a+u_c$ | 공간 비용 없음 |
| 등방 quadratic | $a+u_c-\beta\|\delta\|^2/L_0^2$ | $g=(\beta/L_0^2)I$ |
| 축별 quadratic | $a+u_c-\sum_k\beta_k\delta_k^2/L_0^2$ | $g=\operatorname{diag}(\beta_X,\beta_Y,\beta_Z)/L_0^2$ |
| 등방 radial | $a+u_c-\gamma\|\delta\|/L_0$ | $g=(\gamma^2/L_0^2)I$의 길이를 logit에서 뺌 |
| 부호 제한 없는 quadratic | 축별 식과 같고 계수 부호 자유 | 음수 성분이 생기면 리만 메트릭으로 부적격. 세포형 포함 보조 비교에만 둠 |

quadratic은 $\delta^Tg\delta$, radial은 $\sqrt{\delta^Tg\delta}$를 관측 logit에 넣는다. 두 형태 모두 양의 계수에서는 상수 리만 메트릭과 양립한다. 따라서 radial의 우세는 관측 연결함수의 차이이며 리만기하학 전체의 반증이 아니다. 메트릭 성분 단위는 여기서 $\mathrm{\mu m}^{-2}$이고 비용은 무차원이다. 전도도 S·전력 W·호르몬 농도 단위를 얻은 것이 아니다.

축별 후보는 원 이미지 축에 정렬된 대각 행렬로 제한한다. 엄격히 양수인 세 고유값에서만 SPD로 표시하고, 정확한 0과 음수는 별도 기록한다. 공간적으로 변하는 일반 메트릭이나 임의 회전을 포함하는 모든 SPD 행렬을 적합한 것은 아니다. 이 상수 비용은 장애물 없는 주변 공간의 직선 변위를 사용하며 실제 축삭 경로의 측지선·전도 지연을 측정하지 않는다.

리만 길이는 $\delta$와 $-\delta$에 같다. 이번 순방향·역방향의 확률 차이는 순서 있는 문맥에서 생기며, 대칭인 $g$ 자체가 연결 화살표를 복원한다고 주장하지 않는다. 호르몬·화학 반응에 따른 변화는 이 표에 실측 입력으로 들어 있지 않다. [해마·호르몬 평가](고정뉴런_해마호르몬_화학반응_평가.md)의 수용체·가소성 후보와 이번 위치 비용을 관측 없이 합산하지 않는다.

## 보류 분할과 동일 목적함수

정수 root ID에 `sha256("fixed-neuron-microns-node-v1:" + root)`를 적용하고 처음 16자리 16진수의 나머지 5로 노드를 나눈다. 다섯 그룹의 중복 허용 비순서 조합 15개가 평가 블록이다. 같은 그룹 블록에서는 해당 그룹 내부 방향쌍을, 다른 그룹 블록에서는 두 그룹을 잇는 양방향쌍을 평가한다.

각 블록의 학습은 두 평가 그룹의 노드를 모두 제외한다. 모든 방향쌍은 정확히 한 번 평가되고 역방향도 같은 블록에 놓인다. 같은 그룹 블록은 약 80%, 서로 다른 그룹 블록은 약 60%의 노드를 학습에 쓴다. 모형 비교 안에서는 학습·평가 쌍이 같다. 학습 자료 비율이 다른 15블록을 동일 크기의 독립 반복으로 해석하지 않는다.

그룹별 노드 수는 285/268/260/273/262개, 블록별 학습 방향쌍은 623,310–1,182,656개다. 보조 비교에서 학습에 없는 평가 문맥은 총 5,390쌍이다. 다른 평가 블록끼리도 노드·학습 자료를 공유한다. 공간적으로 가까운 뉴런을 별도 체적으로 분리하지 않았으므로 독립 동물·독립 공간의 신뢰구간이나 일반화 확인으로 보고하지 않는다.

범주 이름의 정수 번호는 공개 메타데이터 전체에서 만든다. 실제 적합 범주와 계수는 해당 학습 블록에서만 정하고, 학습에 없는 평가 문맥은 편차 0으로 예측한다. 공개 메타데이터와 graph holdout의 구별을 유지한다.

$y_{ij}$는 0/1 annotation 표지, $z_{ij}$는 후보 logit, $N$은 해당 학습쌍 수다. 모든 모형은 같은 목적함수를 최소화한다.

$$
\frac{1}{N}\left\{\sum_{(i,j)\in\mathrm{train}}\left[\log(1+e^{z_{ij}})-y_{ij}z_{ij}\right]+\frac12\sum_cu_c^2\right\}.
$$

문맥 편차의 ridge 계수는 1이고 전체 절편·거리 계수에는 벌점이 없다. 원 L-BFGS-B 계산의 희소 문맥 적합이 길어져, 같은 목적함수의 정확한 Hessian을 쓰는 Newton 계산으로 교체했다. 각 Newton 이차 부분문제에서 문맥 편차와 절편을 Schur 보완으로 소거하고, 최대 3개 거리 계수의 경계 조합을 열거한다. 원 비선형 문맥 문제를 매번 완전히 풀어 소거하는 방법이라는 뜻은 아니다. 표본·벌점·분할·모형은 유지했다.

기존 코드와 완료한 2블록 기록은 보존했다. 기존 실행은 블록 2의 일부 적합 뒤 의도적으로 종료했으며, 전체 결과가 완성된 실행으로 세지 않는다. 첫 완료 블록의 아홉 모형을 대조했을 때 새 목적값은 모두 기존 이하였고 차이 크기는 최대 $1.43\times10^{-9}$였다. 평가 logit의 최대 절대 차이는 0.010365, RMS 차이는 최대 0.000395이며 평균 log loss 차이의 절댓값은 최대 $5.20\times10^{-7}$였다. 수치적으로 완전히 같은 예측이라고 부르지 않는다. 새 계산은 $N$으로 나누기 전 projected-gradient 최대 잔차 $10^{-5}$ 이하를 요구한다. [실제 자료 수치 대조](../../verify/Q-NPF-04/fixed_points_metric/microns_solver_comparison_result.json).

모든 105개 기하 적합이 SPD 내부다. 부호 자유 보조 모형도 기존 양의 해에서 이미 무제약 정상조건을 만족해 추가 Newton 반복 없이 같은 예측을 유지했다. 이는 선택한 함수·표본에서의 내부해이며 생물학적 에너지 비용을 확인한 것은 아니다. 전체 135개 적합의 최대 projected-gradient 잔차는 $9.881521\times10^{-6}$, Newton 반복 수는 0–13회다.

원 좌표와 공개 변환 좌표는 1,348점 전체를 사용한 affine 대응에서 최대 오차 $9.094947\times10^{-13}$ µm로 연결됐다. 선형 부분은 수치 정밀도 안에서 약 5도 XY 회전이고 Y 이동은 약 −396.671032 µm다. 이 계산은 저장된 좌표의 일관성 검사이며 좌표의 독립 보류 예측·실제 pia 법선 측정이 아니다.

행벡터 표기로 변환이 $q=pA+b$일 때 $A$는 가역 선형 부분, $b$는 이동이다. 비용 행렬을 $g_q=A^{-1}g_pA^{-T}$로 함께 바꾸면 변위 비용은 같다. 전체 비대각 성분을 유지한 계산의 최대 비용 오차는 $2.842171\times10^{-14}$였다. 좌표변환에 맞춰 행렬을 옮기는 대수 검사를 생물학적 확인으로 세지 않는다. 원 이미지 대각 후보와 회전 뒤 새로 대각으로 제한한 후보도 구분해야 한다.

### 재구성 전략별 관측 차이

다음은 이미 얻은 보류 예측을 나눈 요약이며 각 하위집단에서 다시 적합한 결과가 아니다. 세포형 포함 열도 같은 하위집단의 두 모형을 비교한다.

| 앞 axon → 뒤 dendrite 전략 | 방향쌍 | 양성 / 비율 | 전략 문맥만 LL | 전략 등방 radial LL | 세포형 포함 문맥만 LL | 세포형 포함 등방 radial LL |
|---|---:|---:|---:|---:|---:|---:|
| full → clean | 97,543 | 4,130 / 4.2340% | 0.175694 | 0.180733 | 0.168802 | 0.166066 |
| full → extended | 309,251 | 12,952 / 4.1882% | 0.174075 | 0.165120 | 0.156388 | 0.148853 |
| partial → clean | 337,538 | 15,843 / 4.6937% | 0.189641 | 0.171892 | 0.145323 | 0.133442 |
| partial → extended | 1,071,424 | 45,376 / 4.2351% | 0.175456 | 0.162160 | 0.148933 | 0.136768 |

**주 비교의 full→clean 하위집단에서는 공통 거리 계수가 오히려 예측을 악화시켰다.** 등방 quadratic 0.180351, 축별 quadratic 0.179152도 문맥만 0.175694보다 나쁘다. 세포형을 포함하면 세 거리 후보 모두 해당 문맥 기준보다 개선된다. 이를 재구성 누락의 직접 효과나 세포형만의 인과 교정으로 단정할 수 없다. 전체 평균의 개선이 모든 관측 조건의 공통 공간 법칙을 보장하지 않는다는 제한으로 남긴다.

| 판정 항목 | 지위 |
|---|---|
| 동일 root의 실제 3D 체세포 위치·방향 annotation 대응 | 관측 확보, L1 |
| 양 끝 노드를 제외한 내부 보류에서 거리의 추가 예측 정보 | 이번 비교에서 지지됨. 독립 체적·동물 검증은 아님 |
| 고정 quadratic 함수 안의 축별 개선 | 관찰됨. 일반 방향 비용의 확정은 아님 |
| 현재 축별 quadratic의 등방 radial 대비 우세 | 전체 점수에서 성립하지 않음 |
| 모든 재구성 조건의 공통 거리 법칙 | 주 비교의 한 하위집단에서 악화하여 미확립 |
| 참 음성률·전도도·호르몬 반응·유일한 뇌 메트릭 | 이번 자료로 확인하지 않음, 통합 사상 L0·미완료 |

## 식별 한계와 다음 조건

$\pi$를 실제 연결 확률, $s$를 민감도, $f$를 거짓 양성 확률이라고 하면 관측 확률은 $s\pi+f(1-\pi)$다. 재구성 전략 표지는 $s,f$의 실측 교정값이 아니다. 유한 체적 경계·재구성 선택·세포형의 공간적 분포가 남아 있으므로 예측에서 얻은 $g$를 유일한 생물학적 비용으로 대입하지 않는다.

후속 방향 검사는 **같은 radial 관측 연결함수에서 등방·방향 비용을 비교 → 재구성 조건에 따라 거리 효과가 다른 대안과 구별 → 별도 체적 또는 독립 기능 관측으로 전이**하는 순서다. 관측 층의 조건부 거리 계수를 곧바로 물리적 메트릭으로 해석하지 않는다. 새 모형의 양의 계수나 작은 점수 차이만으로 진행 조건을 통과했다고 하지 않는다. 전기 전달 교정과 같은 고정 뉴런의 호르몬·수용체 상태를 결합해야 한다는 원래 목표도 유지한다.

모든 원자료는 보유 자료를 재사용했다. 새 다운로드와 새 CE_RUN은 없다. 원자료·실행 소스의 SHA-256을 시작 시 대조하고 결과 배열·블록 기록의 해시를 전체 결과에 저장한다. 최종 파일의 해시·용량·위치는 데이터 원장에 등록한다. 등록된 기존 결과를 덮어쓰지 않는다.

분할·단위 등의 관련 검사 5개와 새 수치 해법 검사 4개를 통과했다. 결과 배열의 shape·유한값·root 유일성과 전체 평가쌍 합계, 결과에 저장된 배열·블록 해시도 확인했다. 검사는 계산의 범위를 확인하며 과학적 증거 등급을 올리지 않는다. 원 L-BFGS-B 프로세스는 의도적 중단, 전체 Schur 계산 프로세스는 종료 코드 0으로 종료했다.
