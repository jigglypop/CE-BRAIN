# 광학 대조의 원기록 경로와 후속 자료

**선충 광학 대조의 정확한 원기록은 찾았지만, 조사한 공개 파일에는 필요한 파형이 없었다.** 같은 입력을 계속 찾는 대신, 원기록 누락을 명시하고 S1 자극·S1/S2 반응·행동이 함께 있는 별도 공개 자료의 접근 경로를 확인했다. 생물 endpoint는 이번 단계에서 새로 계산하지 않았다.

## 선충 원기록 추적

[앞선 원표 확인](Q_NPF_04_선충_광학대조_원표확인.md)에서 빠졌던 panel e의 생성 코드는 저자 저장소의 `scripts/fconnectivity/figures/2Pspotcharacterization/off_target_z.py`다. 로컬 Git 판본 `1dbc5e0a2b609d54bc9b1c90c73d4e3bf183d3c7`을 재사용했다.

코드는 `20210209/pumpprobe_20210209_163726`의 별도 2D 기록을 읽는다. 필요한 입력은 `neuron.txt` 두 번째 열, 기록 시각 `T`, 자극 event 인덱스와 펄스 수다. 첫 10표본 평균을 빼고 같은 평균으로 나누며 시간축 끝 3표본을 제외한다. 기존 세션 6·9를 이 기록으로 간주하지 않는다.

로컬 원자료 파일명과 보유 131개 세션의 기록 이름에서 해당 입력을 찾지 못했다. OSF 목록은 678행이지만 페이지 간 중복 2행이 있어 고유 파일은 676개였다. 마지막 페이지의 next는 없으나 목록 완전성은 검증되지 않았다. 이 조사 범위에서 해당 입력을 찾지 못했으며, 1.14GB 전체 archive의 내부도 조사하지 않았다. 공개 저장소 전체에 없다고 단정하지 않는다. 코드를 확보한 것을 파형 복원이나 광학 보정 완료로 세지 않는다.

## 다음 자료 후보

[Rowland 등의 논문](https://www.nature.com/articles/s41593-023-01413-5)과 [공식 데이터 DOI](https://doi.gin.g-node.org/10.12751/g-node.h27xvl/)가 연결하는 공개 archive는 `doi/S1S2_all-optical_data`다. 안내문을 실제로 받아 확인했다.

| 공개 파일 | 안내문상 내용 | 이번 확보 상태 |
|---|---|---|
| `sessions_lite_flu_2022-08-11.pkl` | S1/S2 활동·S1 광자극·lick 행동, 11개 기록 세션 | 본체 미다운로드·스키마 미검증 |
| `pupil_size_data` | 동공 크기, 3개 세션 | 본체 미다운로드·같은 세션 대응 미검증 |
| `source_data_images` | 도표용 이미지 | 시계열 대체물로 사용하지 않음 |

[저자 코드 안내](https://github.com/Packer-Lab/popping-off)는 `behaviour_trials`, `photostim`, `trial_subsets`, `outcome`, `s1_bool`, `s2_bool` 등의 필드를 설명한다. 이는 예상 스키마이며 실제 데이터의 필드 존재·단위·표적 ID·시각 결박을 확인한 결과가 아니다. 11개 세션을 11개 독립 동물로 세지 않으며 3개 동공 세션을 모든 기록에 결합하지 않는다.

다음 단계는 이 archive의 데이터 본체 판본·크기·체크섬을 확인한 뒤 필요한 기록을 확보하고, 세션 ID·표적·자극 시각·무자극 시행·S1/S2 반응이 결박되는지 검사하는 것이다. 별도 광학 대조와 모든 공통 입력이 자동으로 확보됐다고 간주하지 않는다. 이전 선충 음성 결과를 새 자료의 양성 근거로 바꾸지 않는다.
