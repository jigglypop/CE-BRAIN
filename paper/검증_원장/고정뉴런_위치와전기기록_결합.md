# 고정 뉴런 위치와 실제 전기 기록의 결합

유형: 검증 원장. **위치·기록 결합과 명령 검사 완료. 클램프 반응은 범위 한정 관측(`BIO_EVIDENCE_L1`), 공간 메트릭은 실제 검증 미완료(`L0`).**

[전류 비용 계량 후보](고정뉴런_전류비용_리만계량.md)를 실제 자료에 적용하려면 같은 뉴런의 위치·전압·연결 전류가 필요하다. 이번에는 보유 Allen synphys 자료를 재사용해 이 연결을 검사했다. 핵심 결과는 **좌표와 동시 기록은 결합되지만, 측정 클램프 전류를 후보식의 연결 전류로 그대로 사용할 수 없다는 것**이다. 전체 연구 목표의 완료나 고정점 가설의 반증을 뜻하지 않는다.

## 1. 위치의 계보와 단위 규약

고정 upstream `b187927abf1e8df46d11b47eeb88c8e2c76aee3c`의 [실험 로더](../../verify/Q-NPF-04/fixed_points_metric/allen_sources/aisynphys__data__experiment.py)는 `site.mosaic`의 세포 표시점을 읽고, [DB 생성 코드](../../verify/Q-NPF-04/fixed_points_metric/allen_sources/aisynphys__pipeline__multipatch__experiment.py)는 이를 `Cell.position`에 복사한다. [세포쌍 코드](../../verify/Q-NPF-04/fixed_points_metric/allen_sources/aisynphys__data__pair.py)의 거리는 위치 차의 유클리드 노름이며 별도 배율이 없다. 원본 표시점 파일·현미경 보정 및 실제 DB 생산 commit의 동일성은 아직 확인하지 않았다.

[단위 대조 결과](../../verify/Q-NPF-04/fixed_points_metric/allen_position_units_result.json)는 보유 원자료 세 실험의 42·30·30개 세포쌍에서, 좌표로 계산한 거리와 DB의 미터 단위 거리가 일치함을 보여 준다. 최대 절대 차이는 $1.36\times10^{-20}$이다. **내부 단위 규약은 미터와 일치한다. 독립적인 현미경 보정 정확도까지 입증한 것은 아니다.**

## 2. 같은 세포와 같은 시계

작은 DB의 `recording`·`sync_rec`·`patch_clamp_recording` 표는 비어 있으므로 테이블 존재만으로 원파형 보유를 판정하지 않았다. 기존 NWB 부분 캐시와 `cell.electrode_id → electrode.device_id → NWB electrode_name` 경로를 사용했다.

[동시 기록 결합 결과](../../verify/Q-NPF-04/fixed_points_metric/allen_spatial_recordings_result.json)의 대상은 **mouse VisP, 실험 4863 / 외부 ID `1630015960.701`, 시행 0**이다. 세포 24114·24115·24117·24118·24119와 장치 0·1·3·5·6을 결합했다. 모두 전압 명령·전류 기록의 VC 채널이며 시작 시각·50 kHz 샘플률·352,835개 샘플 길이가 일치한다. 이 다섯 위치의 차 행렬 rank는 3이다. 막전압 보정이나 전극·세포 품질 통과를 이 결합 검사로 대신하지 않는다.

**수치 오류 교정:** [최초 결합 재고](../../verify/Q-NPF-04/fixed_points_metric/allen_joint_inventory_result.json)는 첫 실험의 세 점을 평균 중심화한 뒤 부동소수점 잔차를 세 번째 축으로 잘못 세었다. 새 [검사 코드](../../verify/Q-NPF-04/fixed_points_metric/allen_spatial_recordings.py)는 첫 점과의 차를 사용해 행 수를 $n-1$로 제한한다. 해당 세 점의 rank는 2로 교정됐다. 전체 DB의 네 세포 이상 실험을 같은 방식으로 재계산한 결과 rank 3인 2,692개라는 기존 재고 수는 유지됐다. 수치 rank는 위치 측정 오차 아래 식별성의 증명이 아니다.

전체 메타데이터를 읽던 첫 시도는 추가 캐시 16 MiB 한도에서 종료됐다. 받은 바이트를 보존하고 첫 시행의 결합을 완성했다. 이것을 전체 실험군의 메타데이터 검사 완료로 보고하지 않는다.

## 3. 실제 자극은 독립이지만 공간 기울기 가정과 다르다

[명령 검사](../../verify/Q-NPF-04/fixed_points_metric/allen_spatial_commands_result.json)는 장치별 첫 자극의 시작 시각 1.04166, 2.0446699, 3.0476799, 4.05069, 5.0536998초에서 모든 명령 채널을 읽었다. 자극 전 $[-2,-1)$ ms와 자극 중 $[0.4,0.8)$ ms의 평균 차이를 고정해 계산했다.

실제 변화는 각 세포를 하나씩 올리는 약 $60$ mV 대각 행렬이며 rank는 5다. 이 명령을 상수 전압과 3차원 기울기의 조합으로 투영한 상대 잔차는 **44.72%**다. 이는 입력 형태의 투영잔차이고 신경 반응의 예측 오차가 아니다. 투영한 기울기는 rank 3이지만 잔차를 버리고 원래 명령을 $V=Pa$로 취급할 수는 없다. 세포별 입출력 연산자를 먼저 추정한 뒤 공간으로 투영하려면 선형 중첩이 성립하는지 별도 검사해야 한다. 큰 탈분극 명령을 작은 선형 섭동으로 가정하지 않는다.

## 4. 공통 시험 명령에서 관측된 전류

[공통 모드 검사 코드](../../verify/Q-NPF-04/fixed_points_metric/allen_common_mode.py)는 전류를 읽기 전에 원장에 등록했다. 기존 시행 0을 그대로 사용했으며 기준선 $[8,13)$ ms, 공통 시험 펄스 후반 $[23,25)$ ms를 고정했다. 빠진 캐시 블록 65,536바이트만 보충하고 같은 코드를 실행했다. 사후 탐색적 측정모형 검사이며 독립 확증 실험은 아니다.

| 장치 / 세포 ID | 전압 명령 변화 (mV) | 측정 전류 변화 (pA) | 기준선 SD (pA) |
|---|---:|---:|---:|
| 0 / 24114 | −10.000000475 | −83.43 | 4.19 |
| 1 / 24115 | −10.000000475 | −149.16 | 4.43 |
| 3 / 24117 | −10.000000475 | −112.50 | 5.53 |
| 5 / 24118 | −10.000000475 | −90.17 | 5.00 |
| 6 / 24119 | −10.000000475 | −47.96 | 4.60 |

[결과](../../verify/Q-NPF-04/fixed_points_metric/allen_common_mode_result.json)의 전류 변화 합은 **−483.23 pA**다. 기준선 SD는 기술적 변동량이며 시행 간 불확실성이나 p값이 아니다. 명령이 동일하다는 사실도 접근저항을 교정한 실제 막전압이 동일하다는 뜻은 아니다.

**[조건부 비교]** 기존 닫힌 균형 모형은 $Y\mathbf1=0$, $\mathbf1^\top Y=0$을 가정한다. 이 모형에 명령을 실제 전압으로, 클램프 전류를 연결 전류로 그대로 넣으면, 공통 전압 변화에 대한 연결 전류 변화와 모든 연결 전류의 합을 0으로 예측한다. 관측값은 이 직접 치환과 맞지 않는다. 누설·축전·접근저항·미관측 회로의 기여는 아직 분리되지 않았으므로 원인을 하나로 확정하지 않는다. 교정된 연결 전류 모형의 균형 조건을 반증한 결과도 아니다.

## 5. 다음 진행 조건

고정된 세포 위치를 유지하면서 **계측·막 성분을 포함한 뉴런별 전류 모형 → 보류 펄스 예측 → 연결 성분의 식별 → 공간 계량** 순서로 진행한다. 공통 시험 펄스의 반복 기록과 전극·막 보정값으로 현재 차이를 설명할 수 있는지 먼저 확인한다. 관측 밖 경계나 지연이 필요하면 이를 새 모형에 명시하고 비용·대칭성·좌표변환 조건을 다시 검사한다. 원 전류를 임의로 평균 제거하거나 ridge로 양의 정부호 행렬을 만들어 다음 단계로 넘기지 않는다.

재현 코드는 [위치·기록 결합](../../verify/Q-NPF-04/fixed_points_metric/allen_spatial_recordings.py), [명령 방향](../../verify/Q-NPF-04/fixed_points_metric/allen_spatial_commands.py), [공통 전류](../../verify/Q-NPF-04/fixed_points_metric/allen_common_mode.py)다. 모든 결과는 입력·코드 해시를 보존하며 기존 결과를 덮어쓰지 않는다. 이번 관측은 해당 마우스 VisP 기록의 클램프 반응에 한정하고, 계량 및 전체 연구 목표는 미완료로 유지한다.
