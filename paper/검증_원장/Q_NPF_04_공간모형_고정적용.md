# Q-NPF-04 — 공간 확산 모형의 파라미터 고정 적용

작성일: 2026-09-05. 기존 Minnie 관측 그래프와 합성 그래프의 탐색적 비교다. 독립 표본의 재현이나 생물학적 기전 검증이 아니다.

## 질문과 실행 조건

[공간 대안 검토](Q_NPF_04_오류분포_근거와_공간대안.md)에서 확보한 SGSG 코드의 L2/3 예제 파라미터를 현재 Minnie v1718의 23P 347세포에 그대로 적용할 수 있는지 확인했다. 실제 좌표·관측 연결·기존 결과는 재사용했다. 추가 다운로드는 없었다.

원본 코드의 공간 그래프 생성 함수와 확산 함수를 수정 없이 불러왔다. 실제 347세포의 변환된 세포체 좌표를 사용했다. 예제의 별도 모집단 추출·재표집은 수행하지 않았고, 모두 23P로 분류된 집단이므로 세부형별 가중치는 넣지 않았다. 저자 예제의 세부형 분류와 현재 분류는 동일하지 않다. 원 예제의 공간 부피와 밖으로 이어지는 경로도 재현하지 않았다.

거리 47, 연결 선택 계수 0.029, y축 척도 1.5, 방향성 계수 0.45, 확산 목표 2.325, 보호 단계 6, 최대 단계 100을 포함한 예제 설정을 고정했다. 관측 상호연결 수 또는 연결 밀도로 조정하지 않았다. 16개 seed를 고정했고, 생성 평균 연결 수가 관측값의 ±20%를 벗어나면 상호연결 초과 해석에 쓰지 않기로 먼저 정했다. 이 기준은 잠정 비교 적합성 점검이며 통계적 수용역이 아니다.

## 결과

| 항목 | 실제 관측 | 생성 16회의 평균 | 생성 16회의 범위 |
|---|---:|---:|---:|
| 방향성 연결 수 | 5,995 | 8,323.56 | 5,229–11,560 |
| 연결의 평균 세포체 거리, µm | 73.80 | 74.00 | 69.78–77.23 |
| 세포별 출력 연결 수의 표준편차 | 10.22 | 21.70 | 14.42–28.73 |
| 세포별 입력 연결 수의 표준편차 | 8.36 | 26.27 | 19.88–31.34 |
| 연결이 전혀 없는 세포 수 | 0 | 14.56 | 8–19 |

표의 범위는 16개 생성 결과의 최솟값과 최댓값이며 신뢰구간이 아니다. 평균 거리도 각 그래프 평균의 단순 평균이다.

생성 평균 연결 수가 관측보다 **38.84% 많아 사전에 정한 밀도 비교 조건을 통과하지 못했다.** 평균 거리는 비슷하지만 입력·출력 연결 수의 편차와 고립 세포 수는 크게 다르다. 단순 거리 평균의 일치로 모형 적합성을 인정할 수 없다.

상호연결은 관측 221쌍에 대해 생성 평균 296.75쌍, 범위 64–593쌍으로 기록됐다. 밀도와 차수 분포가 다른 상태이므로 이 차이를 기존 잔차의 설명·반증 또는 상호연결 결핍으로 해석하지 않는다. 기존 입출력·거리 기대값 모형의 꼬리 확률도 이 생성 모형에 옮겨 쓰지 않는다.

## 실행 오류와 검증

첫 계약의 seed 값은 저자 코드가 사용하는 NumPy 구형 난수기의 32비트 범위를 벗어나 첫 그래프 생성 전에 실패했다. [첫 계약](../../verify/Q-NPF-04/allen_synphys/sgsg_fixed_transfer_contract.json)과 코드를 보존하고, 범위 안의 seed로 고친 [후속 계약](../../verify/Q-NPF-04/allen_synphys/sgsg_fixed_transfer_seed32_contract.json)을 별도로 만들었다. 생물학적 결과나 seed별 출력에 따라 선택한 변경이 아니다.

저자 코드에는 선택 후보 합이 0인 행을 정규화할 때 나눗셈 경고가 있었다. [검증 코드](../../verify/Q-NPF-04/allen_synphys/verify_sgsg_transfer.py)로 16회 모두 다시 실행해 7,593개 영합 행이 선택 수 0이며 난수 선택에 들어가지 않음을 확인했다. 생성 그래프와 단계 이력은 모두 유한했고 저장 결과와 정확히 일치했다. 원본 코드는 수정하지 않았다. 이는 이번 실행 경로의 확인이며 모든 입력에 대한 수치 안전성 보장은 아니다.

저장된 각 그래프를 직접 세포쌍별로 세어 상호연결 수와 대조했다. 자기 연결이 없고 root ID와 좌표가 유지됨도 확인했다. [검증 결과](../../verify/Q-NPF-04/allen_synphys/sgsg_transfer_verification.json)에 재실행 seed와 해시를 남겼다.

## 판정과 다음 조건

**저자 L2/3 파라미터를 현재 좁은 23P 모집단에 그대로 옮기는 방식은 비교 기준으로 부적합하다.** 공간 연속성이라는 기전 자체를 반증한 결과는 아니다. 관측 자료의 선택·부피 경계·세포형 통합 및 파라미터 이동이 함께 달라졌다.

다음 비교에서는 상호연결 수를 제외한 교정 항목으로 연결 수와 거리·차수 분포를 점검하고, 다른 고정 seed에서 적합성을 평가해야 한다. 이 관측 자료를 이미 본 사실은 유지하므로 독립 확인으로 부르지 않는다. 모형을 맞추더라도 오류 분포와 누락 문제는 별도로 남는다. 전체 뇌 구조와 인과 기전은 아직 미확립이다.
