# Q-NPF-04 — 공간 모형의 입출력·거리 재적합 잔차

작성일: 2026-09-05. 보유한 합성 그래프 64개에 같은 기준모형을 적용한 탐색적 비교다. 새 동물·새 생성 표본·생물학적 확인 실험은 없다.

## 질문과 기준

[공간 모형의 선택 방식 분리](Q_NPF_04_공간모형_선택방식_분리.md)에서 실제 상호연결 221쌍에 비해 확률 반올림 SGSG의 평균은 134.17쌍이었다. 다만 연결 수와 차수 편차가 정확히 같지 않아 차이 86.83쌍 전체를 특수한 상호연결 구조로 해석할 수 없었다.

이번에는 실제 자료에 사용한 [입출력·거리 기대값 모형](Q_NPF_04_입출력_기대값_동시보존.md)을 합성 그래프마다 별도로 적합했다. 각 세포의 입력·출력 연결 수 및 전체 거리 구간별 연결 수를 기대값으로 맞춘 독립 방향성 연결 모형이다. 상호연결 기대값은 서로 다른 두 세포의 양방향 확률 곱을 합한 값이다.

잔차는 `관측 상호연결 수 − 그 그래프에 적합한 기준모형의 기대값`으로 정의했다. 모든 여백의 최대 절대 오차가 0.00001 연결 이하여야 비교하도록 고정했다. 기존 적합 함수와 실패 시 Newton 보정 함수를 재사용했고, 64개 중 하나라도 실패하면 전체 비교를 해석하지 않기로 했다. 그래프를 다시 생성하거나 파라미터를 조정하지 않았다.

이 절차는 관측·생성 그래프의 여백을 서로 같게 만드는 것이 아니다. 각자 다른 여백에 같은 기준모형을 적용해 잔차를 요약한다. 정확한 차수 조건부 검정이나 재구성 오류 보정과도 다르다.

## 결과

| 항목 | 실제 자료 | 생성 그래프 64개의 평균 |
|---|---:|---:|
| 상호연결 수 | 221 | 134.1719 |
| 각 그래프에 적합한 기준 기대값 | 168.9808 | 131.9239 |
| 기준 기대값을 뺀 잔차 | +52.0192 | +2.2480 |

단순 상호연결 차이는 다음처럼 분리됐다.

`86.8281쌍 = 기준 기대값 차이 37.0569쌍 + 잔차 차이 49.7712쌍`

이는 같은 수량을 두 항으로 나눈 대수적 분해이며 인과 기여율이 아니다. 연결 수·차수·거리 구간을 기준모형에 반영한 뒤에도 실제 잔차와 이 공간 모형의 평균 잔차 사이에는 약 49.77쌍의 차이가 남았다.

생성 잔차 64개의 범위는 −16.0732부터 +28.4843쌍, 표본 표준편차는 10.4646쌍이었다. 잔차 평균의 Monte Carlo 표준오차는 1.3081쌍이다. 범위는 생성 결과의 최솟값과 최댓값이며 생물학적 신뢰구간이 아니다. 실제 +52.02쌍은 이번 64개 생성 잔차보다 컸지만, 이를 p=0이나 독립 확인 결과로 해석하지 않는다. 꼬리 p값은 계산하지 않았다.

## 해석의 범위

**이번에 고정한 공간 모형 변형에서는 같은 기준모형을 적용해도 실제 상호연결 잔차와의 차이가 남았다.** 앞선 단순 수 차이 전체가 기본 연결 수 차이 때문인 것은 아니었다. 그러나 모든 공간 모형, 축삭 형태 가설 또는 다른 파라미터에서 같은 결론이 성립한다는 뜻은 아니다.

SGSG 변형은 이전 분석을 본 뒤 탐색적으로 선택했다. 입력 차수 표준편차의 적합성도 허용 경계에 걸려 있다는 기존 한계를 유지한다. 이 재적합이 그 불확실성을 없애지는 않는다. 같은 표본·층·선정 부피, 관측 누락과 오류 분포의 미확인, 세포형 세분 부족도 남는다.

다음 질문은 이 잔차 차이가 어떤 공간·세포별 연결 패턴에 집중되는가다. 단순 파라미터 조정으로 실제 상호연결 수에 맞추기보다 보유 관측 그래프와 생성 그래프의 잔차 위치를 같은 기준으로 대조해야 한다. 특정 기전과 다른 설명을 가를 추가 관측·개입은 아직 확보하지 않았다. 전체 뇌 구조와 인과 기전은 미확립이다.

## 검증과 저장

64개 모두 적합 오차 기준을 통과했다. 저장 확률에서 다시 계산한 최대 여백 오차는 약 0.000007525 연결이다. 64개 그래프 각각의 세포별 입력·출력과 여섯 거리 구간의 합을 확인했다. 양방향 확률 곱과 실제 상호연결 수는 세포쌍별 직접 집계로 대조했다. 첫·마지막 그래프 두 개는 적합을 다시 실행해 저장 확률과 일치함을 확인했다. 전체 64개를 독립적으로 다시 적합한 검사는 아니다.
