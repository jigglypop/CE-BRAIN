# 관측 이웃 수를 제한한 인간 방향 예측

Allen의 관측 이웃 수 분포를 이용해 Peng의 입력 정보를 줄이자 역할 특징의 예측 이득은 감소했지만 세 분할 모두에서 남았다. 선형 깊이 기준 손실 0.61210에 비해 제한 후 역할 모형은 0.58379·0.58227·0.59820이었다. 정보량 감소가 예측력을 약화시키는 것은 확인했으나, 이것만으로 기관 간 차이를 설명한 것은 아니다. 같은 자료의 탐색적 `BIO_EVIDENCE_L1`이다.

## 두 자료의 정보량과 제한 방식

가림 뒤 표적의 두 세포 중 하나에 닿는 관측 단방향 연결 수를 셌다. seed0에서 Allen 80표적의 분포는 0개 29표적, 1개 29표적, 2개 19표적, 3개 3표적이었다. Peng 881표적은 각각 95·257·284·173표적이며, 나머지 72표적에는 4–6개가 있었다. 따라서 같은 절반 가림이라도 이용 가능한 이웃 정보는 다르다.

각 분할에서 Allen의 관측 수 분포를 정렬하고, 별도의 고정 표적 ID 해시 순서에 따라 Peng 표적마다 관측 수 상한을 배정했다. 배정과 연결 선택은 방향 정답을 사용하지 않았다. 기존 반대 가림 묶음의 연결 중 표적 세포에 닿는 연결만 후보로 삼아 해시 순서로 상한만큼 남겼다. 학습·평가 양쪽에 같은 제한을 적용하고 환자를 통째로 제외해 재적합했다.

후보가 상한보다 적으면 있는 연결만 사용했다. 그러므로 이는 **Allen 분포에서 정한 관측 수 상한 검사**이며, Allen의 실제 분포·기록 구조·환자 수를 정확히 맞춘 표본은 아니다. 제한 후 Peng에서 이웃 정보가 없는 표적은 분할별 384·370·396개로 약 42–45%였다. Allen은 약 35–39%여서 제한 후 오히려 없는 경우가 더 많았다.

## 검증과 해석

관측 집합이 표적을 포함하지 않고 상한을 넘지 않음을 확인했다. 원래 가린 묶음뿐 아니라 상한 때문에 제외한 연결까지 모두 뒤집어도 특징이 바뀌지 않는지 검사했다. 모든 환자 제외 적합의 기울기 문턱과 깊이 기준 재현도 통과했다. 실제 사용 연결 인덱스·상한 분포·달성 분포·특징·예측을 보존했다.

- 원래 질문에 답했다. 관측 이웃을 줄이면 Peng 내부의 예측 이득이 약해진다.
- Allen의 불안정한 결과를 정보량 차이 하나로 인과적으로 설명하지 못한다. 제한 후에도 Peng 이득은 남고, 두 자료는 생물 표본·측정·깊이 기준·추정 표본 수가 다르다.
- 표적의 연결 존재는 이미 알려져 있고 다른 방향 일부를 사용하는 과제다. 회로 전체의 생물학적 원리를 확립한 것이 아니다.
- 후속 검사는 더 큰 독립 인간 자료 또는 공통 측정 조건에서 필요하다. 같은 자료의 가림 조건을 계속 바꾸는 것만으로 독립 증거를 늘릴 수 없으므로, 다음에는 현재 지지·미확립·입력 부족을 통합해 새로운 판별 질문을 정한다.
