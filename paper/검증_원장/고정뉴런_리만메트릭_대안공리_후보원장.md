# 고정 뉴런과 리만 메트릭의 대안 공리 136개

유형: 연구 후보 원장. 지위: **사용자가 요청한 가정·공리의 확장 / 전 항목 `BIO_EVIDENCE_L0` / 생물학적 채택·실험 통과 판정 없음**.

[PRD](../../.codex/PRD.md)의 중심을 유지하면서, 2026-09-05 사용자의 “다른 가정이나 공리를 최대한 많이 만들어봐. 기본 리만메트릭, 뉴런은 점 기반” 요청에 따라 후보를 **17개 계열, 136개 항목**으로 넓혔다. 136개는 완성된 독립 이론 136개가 아니라 **조합하거나 경쟁시킬 수 있는 공리 후보**다. 일부는 알려진 수학적 구성과 생물 기전에 바탕을 두고, 일부는 새 경험 가정이다. 새롭다는 주장이나 실제 뇌에서 맞는다는 주장을 개수에 포함하지 않는다.

기존의 닫힌 균형 선형 회로, 공통 입력, 상수 계량에 한정하지 않는다. [막 회로·계량 식별 한계](고정뉴런_막회로_보류예측.md)와 [차동 전류 예측 실패](고정뉴런_차동전류_전달검증.md)는 보존하며, 새 공리를 붙여 과거 보류 판정을 소급해 바꾸지 않는다. 이번 작업은 후보 설계이며 새 생물자료 적합이나 다운로드는 하지 않았다.

## 1. 모든 후보가 지키는 핵심

**[정의]** 물리 공간의 열린 영역 또는 경계를 가진 영역을 $M\subset\mathbb R^3$, 뉴런 $i$의 고정 위치를 $p_i\in M$로 둔다. 뉴런은 점으로 표현하고 $\dot p_i=0$을 유지한다. 막전압·발화·수상돌기 특성·세포형·접촉 수는 그 점과 간선에 붙는 속성이다. 위치가 고정됐다는 말은 활동이나 연결이 고정됐다는 뜻이 아니다. 관측 위치의 오차와 실제 위치 이동도 구분한다.

위치 $x$의 접벡터를 $v\in T_xM$, 리만 메트릭을 $g_{x,t}$라 한다. 기본 조건은 $g(v,w)=g(w,v)$, $g(v,v)>0$ for $v\ne0$, 공간에 대한 $C^2$ 매끄러움이다. 각 시각과 조건에서 참인 리만 계량을 사용한다. 시간·이력에 의존할 수 있지만, 같은 시각의 $g$ 자체를 평가할 접벡터 $v$에 의존시켜 비이차형 비용으로 바꾸지는 않는다.

$$
ds^2=g_{ab}(x,t)\,dx^a dx^b,
\qquad \|v\|_g^2=g_{ab}v^av^b,
\qquad g(v,v)=g(-v,-v).
$$

마지막 등식 때문에 **축에 따른 비용 차이**와 **화살표의 정·역방향 차이**는 구분한다. 전자는 리만 메트릭에 넣고, 후자는 벡터장 $b$, 방향성 연결, 지연, 이온 구동력 등과 함께 표현할 수 있다. 이를 위해 리만 메트릭을 버릴 필요는 없다.

고정된 길이·시간·전압·전류 척도 $L_0,T_0,V_0,I_0$로 식을 무차원화한다. 표의 계량과 조절 계수는 특별한 단위를 적지 않으면 무차원이다. 저항·전도도·지연·발화율 같은 측정량은 먼저 정한 기준량으로 나눈다. 각 후보를 실제로 채택할 때 기준량과 유효 범위를 고정해야 한다.

## 2. 계량을 만드는 공통 틀

**[정의]** $g_0$는 고정된 배경 리만 메트릭이다. $\omega_r$는 공간 방향을 읽는 매끄러운 공벡터장, $q_r\ge0$는 계수다. $D$는 공벡터를 벡터로 보내는 대칭 양의 정부호 이동도 텐서다. $H$는 $g_0$에 대해 자기수반인 선형 연산자다. 표의 괄호는 다음 구성법을 가리킨다.

| 표기 | 구성 | 성립 조건과 직접 의미 |
|---|---|---|
| A: 비용 합성 | $g=g_0+\sum_r q_r\omega_r\otimes\omega_r$ | 매끄러운 비음수 계수이면 SPD; 해당 축의 추가 비용 |
| B: 이동도 역수 | $g=D^{-1}$ | $D$가 실제 관심 영역에서 SPD; 이동이 쉬운 축은 비용 감소 |
| C: 지수 변형 | $g(v,w)=g_0(e^Hv,w)$ | $H$가 매끄러운 자기수반 텐서이면 SPD; 단순 좌표별 행렬 지수와 구분 |
| D: 물리 공간으로의 pullback | $g=q^*h$ | $q:M\to N$은 관측·상태 특징으로 가는 명시적 사상, $h$는 그 공간의 계량; $q\in C^3,h\in C^2$, $Dq$의 rank 3 필요 |
| E: 국소 비용의 이차항 | $g_{ab}=\tfrac12\partial_{j^a}\partial_{j^b}\Phi_x(0)$ | $j\in T_xM$은 보정된 전류·수송 벡터; 해당 Hessian이 SPD이고 공간에 대해 $C^2$여야 함 |
| F: 국소 응답과 소모 | $g=Y^{-\top}QY^{-1}$ | 공벡터→벡터 응답 $Y$가 가역이고, 공벡터 공간의 전력 이차형 $Q^{ab}$가 SPD; 두 장의 공간 $C^2$와 동일 단위·좌표 규약 필요 |

**[정리: 구성의 지위]** A에서는 $g(v,v)=g_0(v,v)+\sum_rq_r\omega_r(v)^2>0$이고, B에서는 양의 정부호 역행렬이 양의 정부호다. C는 $g_0$ 정규직교 고유기저에서 양의 고유값 $e^{\lambda_r}$을 갖는다. D는 $g(v,v)=h(Dqv,Dqv)$이므로 $Dq$가 단사일 때에만 SPD다. E는 적힌 Hessian 조건을 별도로 검사해야 하며, F는 가역 변환의 합동식이므로 SPD다. □

구성 가능성은 뇌에서의 식별 증거가 아니다. $g_0$를 추가해 행렬을 SPD로 만들 수 있다는 사실로 자료가 세 방향을 식별했다고 하지 않는다. 일반 좌표변환에서 모든 텐서와 공벡터를 함께 변환한다. 유한 점 좌표를 비선형으로 바꾼 뒤 같은 행렬식에 다시 넣는 절차는 자동으로 공변적이지 않다.

## 3. 점과 공간의 표현 — A001–A008

여기서는 뉴런을 이동시키지 않고, 고정된 점의 주변을 어떤 공간 모형으로 읽을지 바꾼다.

| ID | 공리 후보 | 계량·모형에 들어가는 방식 | 구별할 관측·조건 |
|---|---|---|---|
| A001 | 세포체 중심이 유효 위치다 | $p_i$를 soma 중심으로 고정하고 그 주변에 국소 $g_i$를 배치 | 같은 세포의 전기 반응을 soma 거리로 예측할 수 있는가 |
| A002 | 고정점에 입·출력 방향 표지를 붙인다 | $p_i$는 하나이고 수상돌기·축삭의 방향 공벡터를 A에 별도 사용 | 같은 거리에서 입·출력 방향이 다른 쌍의 응답 차이 |
| A003 | 한 뉴런은 여러 전기 구획 속성을 가진 점이다 | 물리 점은 하나, 숨은 구획 전압·정전용량이 $q_r(t)$를 조절 | 단일 구획과 다중 구획의 보류 파형 비교 |
| A004 | 위치 오차가 계량 추정에 전파된다 | 참 $p_i$는 고정, 관측 $\tilde p_i=p_i+\epsilon_i$의 보정 분포를 둠 | 위치 재등록 오차로 계량의 축·고유값 불확실성을 계산 |
| A005 | 계량의 영향 범위가 세포마다 다르다 | 고정점 주변 평활 커널 $k_i(x)$의 폭을 세포형별로 다르게 둠 | 고정 폭·세포형별 폭의 거리별 예측 오차 비교 |
| A006 | 피질 층과 수직 방향이 기본 이방성 축이다 | 피질 표면에 접한 두 축과 깊이 축으로 $g_0$ 또는 A를 구성 | 층내·층간 자극에서 같은 길이의 비용 차이 |
| A007 | 고정된 해부학적 구역 사이에 매끄러운 전이층이 있다 | 구역별 SPD 계량을 평활 partition of unity로 연결 | 경계 근처 반응의 급변과 전이 폭 측정; 불연속 텐서는 그대로 리만장으로 쓰지 않음 |
| A008 | 뉴런 사이의 연속 계량장은 관측점의 보간 가설이다 | $g(p_i)$와 외부 측정에서 $C^2$ 장을 추정 | 보간에 쓰지 않은 위치의 전류·전위 예측; 점 자료만으로 보간이 유일하다고 하지 않음 |

## 4. 어떤 연결을 기본 관계로 삼는가 — A009–A016

공간을 정한 뒤에는 점 사이의 관계를 단일 가중 간선으로 제한할지 바꾼다.

| ID | 공리 후보 | 계량·모형에 들어가는 방식 | 구별할 관측·조건 |
|---|---|---|---|
| A009 | 연결의 존재와 효능은 별개 변수다 | 이진 접촉 $a_{ij}$와 양의 효능 $s_{ij}$를 분리해 $q_{ij}=a_{ij}s_{ij}$ | 접촉 수가 같은 쌍의 효능 차이와 보류 예측 |
| A010 | 양방향 연결은 두 개의 다른 간선이다 | $w_{ij}$와 $w_{ji}$를 별도로 보존하고 대칭·방향 성분을 나눔 | 양방향 자극의 응답 비대칭; $g$만으로 화살표를 복원하지 않음 |
| A011 | 한 세포쌍의 여러 접촉은 합산되지 않을 수 있다 | 간선에 접촉별 지연·포화·가소성 속성을 붙이고 반응을 합성 | 동일 총 접촉 수에서 시간 분산과 포화 차이 |
| A012 | 전기·흥분·억제 연결은 서로 다른 층이다 | 다중 연결망의 $D^{(r)}$ 또는 비용항을 역할별로 구성 | 기전별 차단·회복에서 어느 층의 예측이 사라지는가 |
| A013 | 세포쌍을 넘어서는 공동 입력 상호작용이 있다 | $w_{ij}$ 외에 삼자 항이 $q_r$를 조절; 계량 자체는 이차형 유지 | 두 입력을 함께 줄 때 단일 입력 합에서 벗어나는 반응 |
| A014 | 연결망의 순환 구조가 국소 전달을 조절한다 | 사이클 상태를 별도 변수로 두어 C 또는 흐름 $b$를 변형 | 같은 쌍별 강도에서 루프의 선택적 차단 효과 |
| A015 | 장거리 연결은 비국소 연산자로 남긴다 | 국소 $g$와 별도로 적분 커널 $K(x,y)$를 둠 | 짧은 국소 경로 모형으로 설명되지 않는 먼 위치의 조기 반응 |
| A016 | 안 보이는 뉴런도 고정점 네트워크에 포함된다 | 관측점과 잠재점을 나누고 소거된 회로의 유효 연산자를 계산 | 관측 영역을 넓힐 때 유효 연결이 어떻게 바뀌는가 |

## 5. 연결에서 메트릭으로 가는 법칙 — A017–A024

같은 연결 자료도 어떤 비용을 정의하는지에 따라 다른 계량을 만들 수 있다. 이 여덟 행은 특히 서로 경쟁하는 구성이다.

| ID | 공리 후보 | 계량·모형에 들어가는 방식 | 구별할 관측·조건 |
|---|---|---|---|
| A017 | 연결 방향의 전도도를 더한다 | B: $D=D_0+\sum_e c_e a_e\otimes a_e$, $a_e$는 방향 벡터, $c_e\ge0$ | 같은 전위 기울기에서 연결 강화가 해당 축의 전류를 늘리는가 |
| A018 | 연결 사용에 드는 비용을 더한다 | A: 사용 비용 $r_e$를 방향 공벡터의 계수로 둠 | 같은 수송량에서 연결 사용 증가가 독립 에너지 비용을 늘리는가; A017과 부호가 다를 수 있음 |
| A019 | 방향 분포의 두 번째 모멘트가 이동도를 정한다 | B: $D=D_0+\sum_e\pi_e a_e\otimes a_e$, $\pi_e$는 정규화된 사용률 | 총 활동량을 맞춘 뒤 방향 분포만 바꾼 반응 |
| A020 | 병목의 역전도도가 비용을 지배한다 | E: 경로별 저항 합과 병렬 분기를 반영한 최소 소모의 Hessian | 강한 간선 추가보다 병목 완화가 비용에 더 큰 영향을 주는가 |
| A021 | 공간 계량은 최소 소모 문제의 유효 텐서다 | E: 미시 전류 보존 조건 아래 비용을 최소화한 $\Phi_x(j)$ | 같은 총 투영전류의 여러 주입 패턴에서 최소 비용을 재현하는가 |
| A022 | 반응 텐서와 소모 텐서는 따로 측정한다 | F의 $Y$와 $Q$를 서로 다른 관측으로 추정 | 전류 반응만 맞는 후보가 독립 전력 측정도 맞는가 |
| A023 | 기전들은 계량의 로그 변형을 더한다 | C: $H=H_{\rm syn}+H_{\rm membrane}+H_{\rm glia}$ | 두 기전의 공동 개입이 단순 비용 합과 로그 변형 중 어느 쪽을 따르는가 |
| A024 | 하나의 생물 상태에도 목적별 계량이 여러 개다 | 같은 $P$에 전력 $g_E$, 지연 $g_T$, 판별 $g_I$를 별도로 둠 | 세 비용의 등고선·최적 경로가 일치하는지 측정; 단위가 다른 계량을 무근거로 합하지 않음 |

## 6. 방향과 실제 흐름 — A025–A032

메트릭을 유지하면서 화살표의 방향을 어디에 저장할지 바꾼다. 아래 식의 궤적은 신호·활동 분포의 전파를 뜻하며 뉴런의 물리적 이동이 아니다.

| ID | 공리 후보 | 계량·모형에 들어가는 방식 | 구별할 관측·조건 |
|---|---|---|---|
| A025 | 방향성은 추가 흐름장에 저장한다 | $\dot x=-\operatorname{grad}_g U+b$; $U$는 활동 전파 비용 퍼텐셜 | 같은 비용 계량 아래 전·후 방향의 도착시간 차이 |
| A026 | 방향성 응답은 국소 반대칭 텐서로 분리된다 | $Y=D+A$, $A^\top=-A$; 계량과 $A$를 함께 추정 | 세 독립 입력의 전류 벡터에서 대칭·반대칭 부분 분리 |

## 19. 보존량과 명시적 장 방정식 — A129–A136

앞의 후보가 어떤 기전을 넣을지 정했다면, 이 계열은 그 기전이 공간 전체에서 따르는 구체적인 법칙을 제안한다. $k$는 보정된 연결·활동 특징, $u$는 스칼라장, $H$는 $g_0$ 자기수반 텐서장이다. $f(k)$와 $B(k)$는 각각 스칼라·자기수반 텐서 구동항이다. $\lambda,\kappa>0$이며, 아래 미분 연산자에는 충분히 매끄러운 고정 $g_0$와 입력을 사용하고 해의 공간 $C^2$ 조건을 확인한다. $\Delta$는 비양의 스펙트럼을 갖는 Laplacian 규약이다.

| ID | 공리 후보 | 계량·모형에 들어가는 방식 | 구별할 관측·조건 |
|---|---|---|---|
| A129 | 방향 비용은 바뀌어도 계량 부피요소는 보존된다 | C에서 $\bar H=H-\operatorname{tr}(H)I/3$, $g(v,w)=g_0(e^{\bar H}v,w)$; $\det(g_0^{-1}g)=1$ | 세 고유값의 곱이 유지되는가; A086보다 강한 제약이며 조직의 물리적 부피 불변과는 구분 |
| A130 | 연결의 공간 영향은 타원형 장 방정식을 따른다 | $(\lambda-\Delta_{g_0})u=f(k)$, $g=e^{2u}g_0$; 경계조건 고정 | 국소 연결 교란 뒤 거리별 비용 변화가 정해진 감쇠 형태를 따르는가 |
| A131 | 계량 변화는 공간 확산과 시간 이완을 따른다 | $\partial_tH=\kappa\Delta^\nabla H+B(k)-\lambda H$, 구성 C; $\Delta^\nabla$는 자기수반성을 보존하는 연결 Laplacian | 교란 뒤 퍼짐의 거리·시간 곡선과 회복시간; 확산식에서 유한 전파속도를 주장하지 않음 |
| A132 | 장거리 영향은 분수 공간 연산자를 따른다 | $(\lambda+(-\Delta_{g_0})^s)u=f(k)$, $0<s<1$, $g=e^{2u}g_0$ | 연산자·경계를 고정한 뒤 A130과 원거리 반응의 감쇠 비교 |
| A133 | 계량은 하나의 볼록 퍼텐셜의 Hessian이다 | $g=\nabla_{g_0}^2\Phi\succ0$; $\Phi\in C^4$와 SPD 영역을 별도 요구 | 평탄한 기준의 아핀 좌표에서 $\partial_k g_{ij}=\partial_i g_{kj}$라는 추가 적분가능성 조건을 따르는가 |
| A134 | 신호 방향의 회전에는 별도 반대칭 2-form이 작용한다 | $\nabla^g_{\dot x}\dot x=F^\sharp\dot x-\operatorname{grad}_gU$, $g(F^\sharp v,w)=F(v,w)$ | $F(v,v)=0$인 순간 회전력과 실제 궤적의 대응; 뉴런 이동식이 아니며 시간 가변 $g$의 에너지 변화는 별도 계산 |
| A135 | 자극 주파수마다 소모 계량이 다르다 | $g_\omega=\operatorname{Re}(Y_\omega^{-\dagger}Q_\omega Y_\omega^{-1})$; 가역 복소 응답 $Y_\omega$, 공벡터 공간의 Hermitian SPD 전력 이차형 $Q_\omega$ | 공통 위상의 실수 전류진폭에 한정한 3차원 비용을 새 주파수에서 예측; 임의 상대 위상을 이 실수 계량 하나로 표현하지 않음 |
| A136 | 같은 현재 연결량에도 계량에 이력 고리가 남는다 | $g=e^{2u}g_0$, $\dot u=-\partial_u W(u;k)$, 매끄러운 이중우물 $W$ | 같은 $k$로 돌아와도 증가·감소 이력에 따라 다른 비용이 유지되는가; 초기조건·주행속도·관측시간 고정 |

A129의 행렬식 보존은 $\det e^{\bar H}=e^{\operatorname{tr}\bar H}=1$에서 나온다. A135에서는 실수 $v\ne0$에 대해 $v^\top g_\omega v=(Y_\omega^{-1}v)^\dagger Q_\omega(Y_\omega^{-1}v)>0$이므로 SPD다. 여기서 $\dagger$는 켤레전치다. 두 계산은 수학적 구성의 조건부 보장이며, 뇌가 해당 보존 법칙이나 주파수 법칙을 따른다는 증거는 아니다.

## 21. 이 후보들로 연구를 이어가는 순서

현재 자료와 가장 가까운 것은 P1·P2·P4·P5·P10이다. 이것은 생물학적 진실의 순위가 아니라 보유 입력으로 반증 가능한 정도의 분류다. 먼저 서로 다른 대표 묶음을 병렬로 설계하고, 같은 입력·같은 보류 조건에서 어떤 관측이 각 묶음을 구분하는지 정한다. 후보를 추가하는 동안 기존 양성·음성 판정은 바꾸지 않는다.

각 묶음을 실제로 채택하기 전에는 **어떤 물리량이 비용인지 → 그 양을 독립적으로 어떻게 재는지 → 어떤 항이 $g$와 흐름에 들어가는지 → 미관측·잡음 아래 무엇이 식별되는지 → 실패하면 어느 공리를 버리는지**를 적는다. 그래야 이름만 다른 후보가 아니라 서로 구별 가능한 이론이 된다.

이번에 완료한 것은 공리 후보의 확장이다. 실제 뇌가 이 공리들을 쓴다는 증거와 [PRD](../../.codex/PRD.md)의 전체 완료 조건은 아직 갖춰지지 않았다.
