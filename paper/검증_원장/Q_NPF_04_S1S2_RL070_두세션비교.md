# RL070 두 세션의 S2 대비

**RL070 run 29에서도 명목 S2 시험 자극−catch 대비가 양수였다.** 같은 마우스의 run 28과 방향은 같지만, 행동·보상을 분리한 인과효과나 독립 동물 간 재현으로 확정한 것은 아니다.

## 입력과 제외

다섯 번째 SessionLite 객체가 접두 3,094,579,299바이트까지 완전히 도착했다. 이 구간의 SHA-256은 계약에 저장했고 전체 파일은 수집 중이다. 서버 전체 원본과의 무결성 대조는 아직 하지 않았다.

run 29는 원래 279시행 중 263시행, S1 399세포·S2 284세포를 보존하고 있다. 기존 v2 규칙에 따라 galvo 시각이 비유한인 원래 인덱스 171, 248(0부터 셈)의 2시행을 집단 집계에서 제외했다. 유효 시행은 261개다. 별도 시각 보간이나 재정렬은 하지 않았다.

유효 자극 시각의 증가, S1/S2 상보 마스크, 직접 S2 표적 및 catch 표적 없음, 시행 내 일정한 표적 마스크, 행동 표지·원래 시행 인덱스·첫 핥기 대응과 선택 신호 창의 유한성을 검사했다. 이 검사는 광학 잡음·공통 입력·다른 행동의 부재를 증명하지 않는다.

## 동일 정의의 관측

기존 명목 전 창 `[−2,−0.5)`초와 후 창 `[1.5,3)`초를 사용했다. S2 세포별 후−전 평균을 세포 간 평균한 export 형광 척도다. 정확한 시행별 물리 시각은 복원되지 않았으며 [시간축 한계](Q_NPF_04_S1S2_프레임시간_민감도.md)가 적용된다. easy는 주 대비에서 제외했다.

| run 29 시행 종류 | 유효 수 | S2 평균 변화 | 반응 창의 lick 겹침 | 자동 보상 표지 |
|---|---:|---:|---:|---:|
| catch | 89 | +0.007837 | 4 | 0 |
| 시험 자극 | 88 | +0.024502 | 43 | 8 |
| easy | 84 | +0.024248 | 49 | 4 |

시험 자극−catch는 +0.016665다. 전후 신호 창을 함께 −1, +1프레임 이동하면 +0.016802, +0.016573으로 양수다. lick 창을 같은 명목 시간만큼 이동했을 때 시험 자극의 겹침은 44/88, 39/88이고 catch는 모두 4/89였다. 자동 보상 표지는 실제 물 전달 시각으로 취급하지 않았다.

[RL070 run 28](Q_NPF_04_S1S2_다른마우스_RL070_첫비교.md)의 대비는 +0.030999였으므로 두 세션의 방향은 같았다. 다만 이번 run 29는 catch와 시험 자극의 평균 변화가 모두 양수이며, run 28의 catch 평균은 음수였다. 대비 부호만으로 세션의 상태와 절대 신호 수준이 동일하다고 가정할 수 없다.

## 판정과 다음 조건

이번 질문에는 RL070의 다른 세션에서도 같은 정의의 양수 대비가 관측됐다는 답을 얻었다. 현재 분석 범위는 두 마우스의 다섯 세션이다. J064 세 세션의 대비는 음수·양수·음수였고 RL070 두 세션은 양수·양수였다. 이를 독립 표본 다섯 개의 다수결로 종합하지 않는다. 세포의 종단 동일성이나 세션 간 형광 척도의 동일성도 확보되지 않았다.

두 RL070 세션 모두 시험 자극에서 catch보다 lick 겹침이 많고 자동 보상 표지도 있다. 직접 전달·공통 입력·행동·보상의 기여는 여전히 미식별이다. 이 결과는 탐색적 범위고정 관측 `BIO_EVIDENCE_L1`이며 전체 뇌 구조나 안정적인 인과 전달 법칙의 확립은 아니다.

다음은 남은 마우스의 완전한 세션에 같은 정의를 적용하고 마우스별·세션별 결과를 분리해 비교하는 것이다. 전체 파일 무결성, 실제 프레임 시각과 보상 전달 시각의 가용성은 계속 별도 확인 조건으로 남는다.
