# Allen VC 진폭: 측정 정의와 적합 유효 범위

## 판정

pair121538의 고정 구간 평균 차이와 제작자 적합 진폭은 같은 양이 아니다. 특히 −55 mV에서는 관측 평균의 구간 차이가 +0.01975 pA인 반면, 저장 적합의 PSP 진폭은 −0.33250 pA다. 음수 적합 진폭을 구간 평균의 음수 반응이나 독립 연결 발견으로 바꾸어 읽으면 안 된다. 이는 **L0 측정 정의 감사**이며 뇌 전체 구조의 확정이 아니다.

## 입력과 고정 방법

[앞선 원파형 재현](Q_NPF_04_Allen_VC평균_원파형재현.md)이 통과한 mouse VisP L5 donor593646, pair121538의 두 VC 평균을 사용했다. 조건별 60개 반응 전부를 유지했다. 기존 small DB의 평균과 적합 매개변수를 읽고, 보유한 공개 수치 함수를 평가했다. 재다운로드·재적합·시간창 변경·반응 제외는 하지 않았다.

기존 대비는 발화 기준 `평균[1,5)ms − 평균[-8,-3)ms`다. 원전류에서 구한 개별 대비의 평균, 20 kHz 제작자 평균에서 구한 대비, 적합 성분의 대비를 분리했다. 원전류 평균과 제작자 평균의 대비에는 샘플 변환·정렬 방식 차이가 있으므로 두 계산을 동일 배열 연산으로 간주하지 않는다.

[제작자 평균 처리 소스](../../verify/Q-NPF-04/allen_synphys/qc_sources/avg_response_fit.py)는 자극 열 내 위치와 무관하게 반응들을 섞는다고 명시한다. 따라서 이 평균의 적합 진폭을 첫 자극의 연결 강도로 해석하기에도 제한이 있다. 수동 초기 지연의 ±100 µs 범위, 알려진 흥분성 VC 반응에 대한 음수 부호, 발현 시점 주변 가중치 3이 적합에 들어간다. 이 조건들이 관측에 근거한 선택이라는 점을 결과 해석에서 유지해야 한다.

## 수치 결과

모든 전류 단위는 pA이며 음수는 내향이다. 첫 자극은 각 조건 5개, 전체는 각 60개다.

| 측정량 | −70 mV | −55 mV |
|---|---:|---:|
| 원전류 첫 자극 대비 평균 | −1.46162 | −2.43737 |
| 원전류 전체 자극 대비 평균 | −0.42996 | +0.03059 |
| 제작자 평균 파형의 대비 | −0.42448 | +0.01975 |
| 저장 적합 전체 곡선의 대비 | −0.36395 | −0.19348 |
| 적합 PSP 성분의 대비 | −0.36509 | −0.19587 |
| 적합 지수 기준선 성분의 대비 | +0.00114 | +0.00239 |
| 관측−적합 잔차의 대비 | −0.06053 | +0.21323 |
| DB의 `fit_amp` | −0.48423 | −0.33250 |
| 저장 QC | 실패 | 통과 |

관측 대비는 적합 전체 대비와 잔차 대비의 합이다. −55 mV에서 +0.21323 pA의 잔차 대비 때문에 관측 구간의 부호가 음수 적합 곡선의 부호와 다르다. 이것은 정해 둔 구간에서의 분해이며, 곡선 전체에 대해 연결이 없다는 판정은 아니다. 이전 대조구간 기반 분류의 실패도 이번 계산으로 바뀌지 않는다.

## 누락 매개변수와 유효 범위

두 DB 행의 `fit_rise_power`는 NULL이다. [제작자 저장 루프](../../verify/Q-NPF-04/allen_synphys/source_snapshots/aisynphys__pipeline__multipatch__synapse.py)는 이 매개변수를 쓰지 않고, [공개 적합 함수](../../verify/Q-NPF-04/allen_synphys/source_snapshots/allen971__neuroanalysis__fitting__psp.py)는 2로 고정한다. 이번 계산은 해당 공개 판본의 값 2에 조건부다. 과거 제작 환경의 완전한 동일성을 주장하지 않는다.

같은 수치 소스는 `rise_time < rise_power × decay_tau`를 유효 조건으로 명시한다. −70 mV의 상승시간 6.06115 ms는 `2 × 1.74706 = 3.49413 ms`보다 커서 이 조건을 위반한다. 소스는 내부 비율을 0.99999로 제한하므로 계산은 유한하게 나오지만, 입력 `fit_amp`와 실제 계산 곡선의 정점이 달라진다. 코드로 평가한 극값은 −0.69943 pA, 시점은 발화 후 4.97401 ms다. DB 매개변수로부터 단순 계산한 정점 시점 7.54104 ms와 같지 않다. 이를 유효한 생물학적 상승시간·정점 진폭으로 해석하지 않는다.

−55 mV는 유효 조건을 만족하며 정점은 −0.33250 pA, 발화 후 3.36247 ms다. 그래도 수동 지연과 부호 조건부 적합이며 독립 연결 정답은 아니다. 적합 지연은 초기 지연에서 −70 mV는 −92.8646 µs, −55 mV는 +99.8357 µs 이동했다. 경계 근접만으로 오류나 인과성을 확정하지 않는다.

첫 구현은 누락 매개변수 검사에서 곡선 평가 전에 중단됐다. [실패 기록](../../verify/Q-NPF-04/allen_synphys/vc_amplitude_estimands_failure.json)을 보존하고, 위 공개 코드 근거를 명시한 별도 판본으로 계산했다.
