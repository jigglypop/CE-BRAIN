# Allen 시각피질 상층 E-E 비교 적격성

전체 목표는 실제 뇌의 연결 구조와 그 기전을 밝히는 것이다. 이번 질문은 기존 전자현미경 E-E 분석에 대응하는 Allen 전기생리 모집단의 크기와 평가 누락이다. 자료를 보유했다는 사실만으로 서로 다른 측정의 결과를 재현했다고 판단하지 않기 위해 이 분모를 먼저 확인했다.

## 범위와 결과

보유한 synphys r2.1 원본을 재사용했다. mouse·VisP·양쪽 세포의 비시냅스 기반 분류 ex·양쪽 target_layer가 2, 2/3, 3 중 하나인 쌍을 선택했다. 연결 유무를 보고 포함 범위를 넓히지 않았다. 이 층 표지는 전자현미경 세포 분류와 완전히 동일하다는 보장이 없다.

| 항목 | 수 |
|---|---:|
| 해당 세포쌍 전체 | 232 |
| 양방향 평가 완료 | 231 |
| 평가 미완료로 제외 | 1 |
| 양쪽 연결 없음 | 208 |
| 한쪽만 연결 | 20 |
| 양방향 연결 | 3 |
| 평가 완료 쌍을 포함한 실험 | 82 |
| 해당 절편 | 79 |

82개 실험 중 59개는 평가 완료 쌍이 하나뿐이다. 거리 누락은 없다. 절편 수를 독립 동물 수로 간주하지 않았다. 미평가 표지를 연결 없음으로 바꾸지 않았다.

## 판정과 다음 조건

분모와 관측 연결 수는 확인됐지만, 전자현미경에서 추정한 양방향 의존성의 안정적인 전이를 입증한 것은 아니다. 상호연결 3쌍을 여러 평가 묶음으로 나누면 대부분의 묶음에 사건이 없거나 극소수만 남으므로, 앞선 5분할 예측 결과와 같은 정밀도를 기대하기 어렵다. 이는 전이 가설의 반증이나 연결 기전의 부재를 뜻하지 않는다.

원래의 뇌 구조 규명 목표는 미완료다. 이번 계산은 비교 모집단 질문에 답했으며 생물 기전을 반증하지 않았다. 다음 설계에서는 동물 식별 정보와 검출·선택 과정을 확인하고, 이 모집단의 불확도를 유지해야 한다. 더 넓은 층·세포형을 사용한다면 별도 질문으로 명시해야 하며 상층 E-E 재현으로 합치지 않는다. 관측 표지의 기술은 BIO_EVIDENCE_L1 범위이고, 코드 일치 검사는 L0이며 인과사슬의 지지가 아니다.
