# 다른 마우스 RL070의 첫 S1/S2 비교

**두 번째 마우스 RL070 run 28에서 S2 시험 자극−catch 대비는 +0.030999였다.** 첫 마우스의 세션 간 부호 변동을 하나의 보편 방향으로 정리할 수 없으며, 이 양수 대비도 행동·보상을 분리한 직접 신경 전달 효과는 아니다.

## 입력과 동일 방법

네 번째 SessionLite 객체가 접두 2,403,981,976바이트까지 완전히 도착했다. 접두 SHA-256은 계약에 기록했으며 전체 파일은 계속 수집 중이다. 원격 전체 파일과의 무결성 대조는 아직 수행하지 않았다.

대상은 RL070 run 28이다. 원래 386시행 중 export에 보존된 375시행, S1 333세포·S2 259세포다. 이번에는 보존 시행의 galvo 시각이 모두 유한하고 순서대로 증가했다. 따라서 [세 번째 세션](Q_NPF_04_S1S2_세번째세션_시각누락과반응.md)에서 사용한 비유한 시각 제외 규칙에 따른 추가 제외는 0회다. 파일명이 `clock_filtered`인 것은 같은 v2 코드를 사용했기 때문이며, 실제 제외 수는 결과에 따로 기록했다.

S1/S2 마스크의 상보성, 직접 S2 표적 없음, catch 표적 없음, 시행 내 일정한 표적 마스크, 행동 표지와 원래 시행 인덱스의 대응, 첫 핥기와 원래 lick 배열의 일치가 검사됐다. 30Hz·420프레임이며 선택 창의 신호는 유한했다. 이 검사는 광학 잡음이나 다른 행동의 부재를 보장하지 않는다.

기존과 같은 명목 전 구간 `[−2,−0.5)`초, 후 구간 `[1.5,3)`초를 사용했다. S2 세포별 후−전 평균을 세포 간 평균한 export 형광 척도다. easy 150세포 자극은 주 대비에서 제외했다. [프레임 시간의 한계](Q_NPF_04_S1S2_프레임시간_민감도.md)는 그대로 적용된다. 다른 마우스의 첫 완전 세션이지만 사전 고정된 독립 확인시험으로 설계한 것은 아니므로 탐색적 비교로 보고한다.

## 관측

| 시행 종류 | 수 | S2 평균 변화 | 반응 창의 lick 겹침 | 자동 보상 표지 |
|---|---:|---:|---:|---:|
| catch | 125 | −0.019102 | 5 | 0 |
| 시험 자극 | 133 | +0.011897 | 47 | 24 |
| easy | 117 | +0.018315 | 52 | 12 |

시험 자극−catch는 +0.030999다. 전후 창을 함께 −1, +1프레임 이동하면 각각 +0.031554, +0.030211로 양수다. 같은 이동에서 시험 자극의 lick 겹침은 모두 47/133회, catch는 모두 5/125회였다. 명목 창에서 이는 각각 35.3%, 4.0%다.

자동 보상 표지는 시험 자극 24/133회, easy 12/117회에 있다. 보상 상태 표지이지 실제 물 전달 시각이 아니다. 보상이나 핥기가 없는 시행만 사후 선택한다고 직접 전달 효과가 자동 식별되는 것은 아니다. 개입 후 행동으로 조건화하는 문제를 별도로 다뤄야 한다.

첫 마우스 J064의 세 세션 대비는 −0.001081, +0.001270, −0.024400이었다. 이번 결과를 더해 현재 분석 단위는 **두 마우스의 네 세션**이다. 각 세션의 세포 구성과 형광 척도가 같다고 가정하지 않았고, 네 세션을 독립 동물 네 마리로 세거나 양수 세션을 재현 성공으로 선별하지 않았다.

## 판정과 다음 조건

이번 질문에는 다른 마우스의 한 세션에서 같은 정의의 양수 대비가 관찰됐다는 답을 얻었다. 첫 마우스에서 드러난 방향의 변동은 여전히 남고, 관측된 집단 대비의 크기나 부호만으로 흥분·억제 연결 구조를 판정할 수 없다. 직접 전달·공통 입력·행동·보상의 기여도 아직 분리되지 않았다.

현재 상한은 범위가 제한된 탐색적 관측 `BIO_EVIDENCE_L1`이다. 전체 뇌 구조와 보편적인 전달 법칙은 미확립이다. 다음은 RL070의 추가 세션과 남은 마우스 자료가 완전히 도착하면 같은 정의를 적용하는 것이다. 전체 파일 무결성과 실제 프레임·보상 시각의 확보 여부도 별도로 확인한다.
