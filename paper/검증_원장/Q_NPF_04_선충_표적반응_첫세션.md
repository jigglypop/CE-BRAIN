# 선충의 직접 표적·다른 표적 시행 반응

후속 정정: 첫 −2 이후 전체 제외는 이 분석의 보수적 자체 규칙이며, 저자의 필수 제외 규칙으로 단정할 수 없다. [음수 표지 재검토와 시간 분할 예측](Q_NPF_04_선충_표적정보_시간분할예측.md)에 근거와 새 판본을 기록했다. 아래 계산 결과와 원래 계약은 보존한다.

**보유 자료의 첫 두 세션에서 같은 세포가 직접 표적일 때의 평균 반응이 다른 세포가 표적일 때보다 큰 경우가 각각 12/14개와 25/30개였다.** 선택적 자극 자료로 진입하기 위한 초기 관측이며, 직접 신경 연결이나 유전자형 인과효과는 판정하지 않았다. 주장 상한은 `BIO_EVIDENCE_L1`이다.

## 저자 코드에서 확인한 입력 규칙

[이전 대응 점검](Q_NPF_04_선택자극_선충자료_대응점검.md) 이후 로컬 `pumpprobe`의 Git 객체를 확인했다. 작업 폴더는 비어 있었지만 코드 객체는 남아 있었다. 새 다운로드 없이 저자 저장소 판본 `1dbc5e0a2b609d54bc9b1c90c73d4e3bf183d3c7`에서 세 파일을 읽어 보존했다.

[저자 Funatlas 코드](https://github.com/leiferlab/pumpprobe/blob/1dbc5e0a2b609d54bc9b1c90c73d4e3bf183d3c7/pumpprobe/Funatlas.py)의 `export_to_txt`는 신호 배열을 그대로 저장하고 `arange(len(y))*Dt`를 시간으로, `i0s + shift_vols`를 자극 표본으로 저장한다. Python 0 기반 인덱스이며 표지를 자동으로 신호 열 수에 맞추는 단계는 없다. 따라서 앞서 발견한 세 세션의 표지 수 불일치는 아직 해결되지 않았다.

[저자 Fconn 코드](https://github.com/leiferlab/pumpprobe/blob/1dbc5e0a2b609d54bc9b1c90c73d4e3bf183d3c7/pumpprobe/Fconn.py)는 초기 대상 값을 −1로 두고, 기포 표지가 있는 자극부터 뒤의 대상을 −2로 설정한다. −3은 수동 주석의 보완 표지와 연결된다. 해당 코드에는 주석 루프의 `i`와 별개로 이전 루프 변수 `m`을 대상 대입에 사용하는 부분도 있으므로, 개별 −3 기록의 정확한 의미를 복구했다고 보지 않는다. 모든 음수는 이번 분석에서 제외했고, 첫 −2 이후도 제외했다. **음수 자극을 sham으로 취급하지 않았다.** 이 코드 판본을 실제 과거 export 실행 판본이라고 확정한 것은 아니다.

## 고정한 탐색 방법

WT에 해당하는 `exported_data/0`와 `exported_data_unc31/0`을 선택했다. 기존에 검토한 자료의 후속 탐색이며 새 독립 확인시험이 아니다. 원자료의 첫 행 일부와 메타데이터를 이미 본 상태임을 전제로, 전체 반응 계산 전에 입력·코드 해시와 방법을 계약에 저장했다. 실패 시 다른 세션으로 교체하지 않도록 했다.

각 자극의 전 −10초 이상 −2초 미만, 후 +2초 이상 +10초 미만의 평균을 비교했다. 전체 창이 기록 안에 있고, −10초 이상 +10초 미만에 다른 자극이 없는 시행만 사용했다. 세포별 두 창의 모든 표본이 유한하고 전 평균이 양수일 때 `(후 평균−전 평균)/전 평균`을 계산했다. 원래 export의 전처리된 형광을 사용했으며 발화율로 변환하지 않았다.

같은 세포에 대해 직접 표적 시행의 평균에서 다른 표적 시행의 평균을 뺐다. 양쪽에 적어도 한 유효 시행이 있는 세포만 비교했다. 한 번만 직접 자극된 세포도 있으므로 강한 반복성 증거가 아니다. 신호 행·열 수와 시간·표지 길이가 일치하는지, 자극 시각이 순서와 범위를 만족하는지도 확인했다. atlas 이름은 미검증 표지로 보존하고 이번 대비에는 세션 내부 열 인덱스만 사용했다.

| 자료·세션 | 남은 시행 | 비교 가능 세포 | 양의 대비 | 세포별 대비 중앙값 |
|---|---:|---:|---:|---:|
| exported_data · 0 | 15 | 14 | 12 | +0.22955 |
| exported_data_unc31 · 0 | 45 | 30 | 25 | +0.41973 |

단위는 무차원 ΔF/F 차이다. 세포 수를 독립 동물 수로 세지 않는다. 전 평균이 작으면 비율이 커질 수 있고, 상태·시간·광학적 영향과 전처리 차이가 남아 있다. 이 중앙값을 서로 빼서 유전자형 효과로 해석하지 않는다. 같은 세포 대조도 서로 다른 시점의 시행이므로 상태 교란을 제거하지 못한다.

## 판정과 다음 진행 조건

원래 질문 중 자극 대상에 따른 실제 반응 차이는 평가했다. 모든 비교 가능 세포에서 양의 대비가 나온다는 명제는 두 세션 모두 성립하지 않았다. 다수 세포의 양의 대비는 남았으나 이는 자극 충실도를 완전히 입증하거나 공통 입력과 시냅스 상호작용을 분리하지 않는다. 기존 UNC31 유효전파 실패 판정과 그 분할은 변경하지 않았다.

다음은 반복 자극이 충분한 세포에서 시간·자극 전 상태를 분리하고, 비표적 반응 예측을 비교하는 것이다. 직접 표적 반응을 선별 기준으로 사후 변경해 성공한 시행만 남기지 않는다. 다른 표적 시행을 sham으로 승격하지 않으며, 광학적 직접 영향과 다중 시냅스 경로를 구분하기 전에는 직접 연결을 주장하지 않는다. 전체 뇌 구조와 기전은 미확립이다.
