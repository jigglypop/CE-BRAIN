# S1/S2 첫 세션의 핥기 시간과 반응 창

**첫 세션의 S2 반응 창에는 행동 기록이 겹치며, 시험 자극과 catch의 겹침 비율도 다르다.** 따라서 기존 집단 평균 대비를 S1→S2 직접 전달 효과로 해석할 수 없다. 이는 전달이 없다는 반증은 아니다.

## 질문과 대응

[첫 세션 분석](Q_NPF_04_S1S2_첫세션_대응과반응.md)의 자극 후 +1.5초 이상 +3초 미만 창에 기록된 핥기가 있는지 점검했다. 대상은 같은 마우스 J064, run 10의 162시행이다. 분석 후 정한 기술 점검이며 독립 확인시험이 아니다. 기존 계약에 기록된 첫 완전 객체의 접두 구간 SHA-256과 현재 파일 구간이 일치했다. 전체 파일은 아직 수집 중이며 서버 원본과의 전체 해시 대조가 아니다.

`spiral_lick`에는 원래 173시행이 남아 있다. `nonnan_trials`로 162시행을 대응시켰고, 각 시행의 첫 핥기가 별도 `first_lick` 값과 전부 일치했다. 피클의 외부 함수를 실행하지 않고 허용된 숫자 스칼라와 배열만 해석했다.

공개 [Vape cacher](https://github.com/Packer-Lab/Vape/blob/a2e2a7ec94f6e7d24917f93f1452cad9a5ba8e92/utils/cacher.py)는 `B_to_A(spiral_start)`를 `get_binned_licks`에 전달한다. [시간 처리 함수](https://github.com/Packer-Lab/Vape/blob/a2e2a7ec94f6e7d24917f93f1452cad9a5ba8e92/utils/run_functions.py)는 각 구간의 lick에서 이 시작 시각을 빼고, [행동 입력 클래스](https://github.com/Packer-Lab/Vape/blob/a2e2a7ec94f6e7d24917f93f1452cad9a5ba8e92/utils/data_import.py)는 단위를 밀리초로 정의한다. Session 소스의 `galvo_ms`도 같은 시작점을 사용한다. 다만 실제 export를 만든 Vape 실행 판본은 확인되지 않았다. 아래 시간 해석은 확보한 공개 코드와 일치한다는 조건을 가진다.

## 관측

각 구간에서 하나 이상의 핥기가 기록된 시행 수다. 두 시간 열은 서로 배타적이지 않다.

| 시행 종류 | 전체 | 0–1.5초에 핥기 | 1.5–3초에 핥기 | 자동 보상 표지 |
|---|---:|---:|---:|---:|
| catch | 61 | 33 | 14 | 0 |
| 시험 자극 | 54 | 40 | 37 | 2 |
| easy | 47 | 46 | 35 | 0 |

기존 주 대비의 반응 창 겹침은 시험 자극 68.5%, catch 23.0%다. 기록된 전체 시행 구간에 핥기가 하나도 없는 경우는 각각 catch 13회, 시험 자극 4회, easy 1회다. 이 사실을 움직임이 없거나 보상이 없다는 뜻으로 사용하지 않는다. 세포 152개나 시행 162개를 독립 동물 수로 세지 않는다.

`autorewarded`는 자동 보상 상태 표지이며 물 전달의 실제 시각이 아니다. `pre_reward`와 `pre_rew_trials`는 별도의 보상 구간을 위한 필드라 시험 시행의 보상 시각으로 대체할 수 없다. 이 SessionLite 객체에서 시험 시행별 보상 전달 타임스탬프는 확보되지 않았다.

## 판정과 다음 조건

이번 질문에는 기록된 핥기와 반응 창이 겹친다는 답을 얻었다. 현재 대비가 행동을 분리한 직접 전달 효과라는 해석은 성립하지 않는다. 직접 전달·공통 입력·행동 관련 반응의 각 기여는 여전히 미식별이다. 핥기가 없는 시행만 사후 선택해도 자극의 영향을 받은 행동으로 조건화하는 문제가 있으므로 인과효과가 자동 식별되지 않는다.

현재 상한은 공개 시간 정의를 조건으로 한 한 세션의 기술 관측 `BIO_EVIDENCE_L1`이다. 전체 뇌 구조와 인과 기전은 미확립이다. 다음은 진행 중인 전체 수집의 무결성을 확인하고, 다른 마우스에 같은 창과 행동 겹침 정의를 적용하는 것이다. 보상 시각·실행 판본을 확인하기 전에는 직접 전달이나 행동 매개를 확정하지 않는다.
