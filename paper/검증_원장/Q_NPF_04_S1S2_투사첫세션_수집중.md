# S1–S2 첫 투사 세션 수집 시작

목록 순서의 첫 투사 세션 `2021-02-18_RL127.pkl`을 선택했다. 응답 헤더의 크기는 1,861,537,717바이트다. 자료의 신경 결과를 보고 선택한 것이 아니다. 다운로드가 진행 중이며 실제 반복 수·시계 구조·전체 무결성은 아직 확인하지 못했다.

파일 앞부분에서 피클 프로토콜 3과 `utils.interareal_analysis.interarealProcessing`, `interarealAnalysis` 객체 이름을 확인했다. 외부 함수를 실행하지 않는 기존 기호 판독기에 이 두 이름만 추가했다. 확인하지 않은 참조는 거부한다. [판독기](../../verify/Q-NPF-04/allen_synphys/mechanisms_symbolic_reader.py)의 기호 매핑과 알 수 없는 함수 참조 거부 검사는 통과했지만 전체 파일 호환성 검사는 미실행이다.

[다운로더](../../verify/Q-NPF-04/allen_synphys/mechanisms_download.py)는 중복 대상이 있으면 새 수집을 시작하지 않는다. 진행 파일을 원장에 등록했으며, 완료 시 응답 길이·기존 prefix 일치·로컬 SHA-256을 기록하도록 했다. 서버 독립 체크섬은 확보하지 못했다. 이 진행 기록은 완료 영수증을 대체하지 않는다.

다음에는 현재 다운로드 프로세스를 확인하고, 완성 파일에서 허용 참조와 객체 스키마를 검증한다. 실제 조건별 반복 수와 블록 순서는 그 뒤에 확인한다. 자료 준비 단계이며 생물학적 결론이나 뇌 구조 규명 완료가 아니다.
