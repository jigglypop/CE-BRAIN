# S1/S2 전체 자료 수집과 RL116 두 기록 비교

**다섯 마우스의 11세션 수집과 동일 명목 창의 탐색적 비교를 완료했다.** 마지막 RL116 run 33의 시험 자극−catch 대비는 −0.011531로, run 32의 −0.021514와 같은 음수였다. 전체 기록에서 공통 부호는 관측되지 않았으며 뇌의 인과 구조는 아직 미확립이다.

## 전체 파일 확인

공식 GIN 자료 파일 5,405,910,737바이트를 한 번의 다운로드로 수집했다. 로컬 SHA-256은 `67ac18b40a5a14d685aaf542a131edd195bf023097cc40fefea0648864020506`이다. 전체 파일을 다시 읽어 다운로드 영수증의 해시와 일치함을 확인했다. 안전한 기호 판독기로 pickle 종료와 뒤따르는 불필요한 바이트 없음, 예상한 다섯 마우스·11개 세션 식별자를 확인했다. 기존 접두 해시가 있는 12개 계약도 최종 파일과 모두 일치했다.

이는 로컬 파일과 다운로드·분석 기록의 일치 확인이다. 서버가 별도 SHA-256을 제공하지 않아 서버 체크섬 대조는 하지 못했다. 기존 계약·결과의 당시 수집 중이라는 기록은 보존한다. 마지막 결과의 `complete_file_verified: false`도 기존 v2 출력 그대로이며, 전체 파일 검증은 아래 별도 영수증을 참조한다. 수집 완료를 생물학적 증거의 승격으로 세지 않는다.

## 마지막 세션의 방법과 결과

RL116 run 33의 객체 끝은 접두 5,405,910,735바이트다. 원래 235시행 중 export에 남은 215시행, S1 267세포·S2 62세포를 분석했다. 보존 시행의 galvo 시각은 모두 유한하고 증가해 추가 제외는 없다. export 누락 20시행을 반응 없음으로 세지 않았다.

기존 v2를 변경하지 않고 명목 30Hz 전 창 `[−2,−0.5)`초와 후 창 `[1.5,3)`초에서 S2 세포별 후−전 평균을 구한 뒤 세포 간 평균했다. easy는 주 대비에서 제외했다. 표적·영역·시행·행동 표지·첫 핥기 대응과 선택 신호 유한성 검사를 통과했다. [실제 프레임 시각의 한계](Q_NPF_04_S1S2_프레임시간_민감도.md)는 유지된다.

| 종류 | 유효 시행 | S2 평균 변화 | 반응 창 핥기 겹침 | 자동 보상 표지 |
|---|---:|---:|---:|---:|
| catch | 70 | −0.008479 | 8 | 0 |
| 시험 자극 | 73 | −0.020011 | 9 | 8 |
| easy | 72 | −0.058746 | 5 | 5 |

전후 창을 함께 −1, 0, +1프레임 이동한 대비는 −0.010760, −0.011531, −0.012257이다. 세 창에서 음수지만 통계적 신뢰구간이나 독립 확인 실험은 아니다. [첫 RL116 기록](Q_NPF_04_S1S2_RL116_첫비교.md)과 부호는 같으나 세포 구성·시행 상태가 동일하지 않다. 핥기 겹침의 두 집단 비율이 가깝다고 행동과 보상이 통제된 것도 아니다.

## 현재 판정과 후속 질문

관측 부호는 J064 음수·양수·음수, RL070 양수·양수, RL117 음수·음수·양수, RL123 음수, RL116 음수·음수다. 동일 마우스의 세션을 독립 동물로 세거나 부호 다수결로 보편 기전을 판정하지 않는다. 이번 질문에는 RL116 두 기록 모두 음수 대비라는 답을 얻었다. 다만 통계적으로 확립된 세션·마우스 차이나 특정 생물 기전의 반증을 수행한 것은 아니다.

상한은 탐색적 범위고정 관측 `BIO_EVIDENCE_L1`이다. 직접 전달·공통 입력·행동·보상의 기여는 여전히 미식별이다. 다음 질문은 기록 내 시간 경과와 자극 전 상태를 고려해도 관측 대비가 유지되는지다. 이미 결과를 본 뒤의 후속 탐색으로 별도 분석 규칙을 고정하고, 세션·동물 단위를 보존하며 자극 이후 행동을 단순 회귀해 직접 인과효과라고 부르지 않는다. 실제 프레임·보상 시각 확보와 독립 인과 검증도 별도 과제로 남는다.
