# 생리 자료의 재기록 중복 경로와 제한된 가용성

공개 코드에서 재기록 표 내부의 중복이 남을 수 있는 결합 경로를 확인했다. 실제 중복 98개는 6개 기록에 집중돼 있다. 어느 충돌 행이 올바른지 확인된 것은 아니므로 원본과 기존 중단 판정을 보존했다. 이번 결과는 출처·가용성 `BIO_EVIDENCE_L0`이며 생리 특성의 효과는 적합하지 않았다.

## 공개 코드가 보여주는 경로

보유 Planert 자료의 `pipeline_repatch.m`은 각 재기록 표를 먼저 이어 붙인다. 이후 원래 연결 표에 이미 있는 synapse ID를 제외하고, 남은 재기록 표를 원래 표에 합친다. 이 경로에는 합쳐진 재기록 표 자체의 키 중복을 확인·해소하는 단계가 없다. `extract_connection_repatch.m`은 재기록 단계의 세포 표에서 연결 행을 구성한다.

이는 중복이 남을 수 있는 코드 경로의 확인이다. 그 코드가 공개 CSV를 생성한 정확한 역사적 실행이라는 증거나 각 행의 세션 대응은 아직 없다. 따라서 첫 행·마지막 행을 취하거나 양성 연결을 우선하는 규칙을 적용하지 않았다.

별도의 `tconnection_curate.m`에는 수동 peak 값으로 진폭을 교체하는 경로가 있다. 필요한 수동 교정 원장은 다운로드한 ZIP에 없다. 가공 표와 MATLAB 진폭이 다를 수 있는 추가 경로지만, 이것만으로 Peng TR 진폭 42개의 출처를 해결했다고 보지 않는다.

## 모호한 기록을 통째로 제외한 재고 조사

일부 중복 행만 골라 지우지 않고, 중복 방향쌍을 하나라도 포함한 6개 기록 전체를 가용성 조사에서 제외했다. 제외된 952행을 포함한 원자료는 그대로 보존했다. 이는 원본의 복구나 전체 자료 판정이 아니라 별도 제한 모집단의 재고 조사다.

| 항목 | 결과 |
|---|---:|
| 원 연결 표 | 10,784행 |
| 제외된 기록 / 행 | 6 / 952 |
| 남은 행 / 양방향 쌍 | 9,832 / 4,916 |
| 남은 양성 방향 | 1,503 |
| 단방향 연결쌍 | 1,175 |
| 양쪽 입력저항이 유한한 단방향 쌍 | 1,175 |
| 양쪽 피질 위치가 유한한 쌍 | 1,028 |
| 양쪽 rheobase가 유한한 쌍 | 1,057 |
| 위치·입력저항·rheobase가 모두 유한한 쌍 | 926 |
| 마지막 조건의 환자 표지 수 | 22 |

남은 모든 행의 두 세포가 같은 공개 세포 표에 직접 대응하며 환자·기록 표지도 일치했다. 방향쌍은 유일하고 반대 방향도 모두 있었다. 그러나 유한 값이 있다는 것만으로 품질 통과나 생리적 적격성을 보장하지 않는다.

## 다음 진행 조건

현재 세포 표의 `removal_boolean`, `resting_bool`, `access_bool`은 0과 1을 모두 포함한다. 특히 이름만 보고 1을 제거 또는 통과로 해석하면 안 된다. 다음에는 이 플래그를 만드는 코드와 논문 분석의 실제 선택 규칙을 확인한다. 입력저항·rheobase의 단위와 생리 측정 조건도 고정한 뒤에만 방향과의 관계를 적합한다.

이 제한 분석이 전체 자료의 중복 문제를 해소한 것은 아니다. 원 질문의 전체 표본을 되살리려면 기록 상태와 수동 교정 원장이 여전히 필요하다. 같은 연구 계보의 후속 자료이므로 독립 재현으로 합산하지 않는다.
