# Q-NPF-04 — 공간 모형의 선택 방식 분리와 고정 후보 평가

작성일: 2026-09-05. 기존 Minnie v1718의 23P 347세포를 기준으로 한 합성 모형 비교다. 생물학적 개입이나 독립 동물 검증이 아니다.

## 질문과 대조 설계

[이전 교정](Q_NPF_04_공간모형_교정과_반올림.md)에서 q=1.5와 1.55 사이에 보호 단계의 정수 선택 수가 달라짐을 확인했다. 이번에는 동일 공간 그래프 32개 각각에서 두 q와 세 가지 선택 방식을 비교했다. d=65, p=0.1 및 나머지 설정은 고정했다.

- **원래 방식:** 첫 6단계에서 선택 수를 결정적으로 반올림하고, 가중 비복원 추출한다.
- **확률 반올림:** 첫 6단계의 선택 수를 바닥값 또는 천장값으로 확률적으로 정한다. 그 평균은 후보 수로 제한한 목표 선택 수다. 가중 비복원 추출은 유지한다. 별도로 작성한 모형 변형이며 원본 코드를 수정하지 않았다.
- **모든 단계 Bernoulli:** 보호 단계를 0으로 설정한다. 정수 반올림뿐 아니라 행 안의 의존성과 선택 수의 분산도 바뀌므로 순수한 반올림만의 대조는 아니다.

각 공간 그래프를 여섯 분기에 그대로 재사용하고 확산용 난수를 같은 seed로 시작했다. 알고리즘마다 난수를 소비하는 방식은 다르므로 개별 연결에 같은 난수가 대응하는 것은 아니다. 총 192개 그래프를 만들었다. 파라미터 선택이나 상호연결 평가는 이 대조 계약에 포함하지 않았다.

## 같은 공간 그래프에서 나타난 연결 수 변화

| 선택 방식 | q=1.5 평균 연결 수 | q=1.55 평균 연결 수 | 같은 공간 그래프 안의 평균 증가 | 증가 평균의 Monte Carlo 표준오차 |
|---|---:|---:|---:|---:|
| 원래 방식 | 4,561.06 | 6,838.41 | 2,277.34 | 35.91 |
| 확률 반올림 | 5,602.72 | 5,877.56 | 274.84 | 38.74 |
| 모든 단계 Bernoulli | 2,467.34 | 2,724.56 | 257.22 | 24.12 |

확률 반올림의 증가량은 원래 방식보다 같은 공간 그래프에서 평균 2,002.5개 작았다. 이 차이의 Monte Carlo 표준오차는 51.05개다. 원래 방식의 큰 변화가 보호 단계의 선택 수 결정 방식에 강하게 의존함을 확인했다. 생물학적 효과 크기나 신뢰구간이 아니다. 다른 q 구간에서 항상 같은 현상이 난다는 증명도 아니다.

확률 반올림 q=1.5는 이 32개 표본에서 기존 다섯 기본 적합성 조건을 통과했다. 원래 방식 및 나머지 설정은 모두 통과하지 못했다. 모든 단계 Bernoulli는 연결 수가 크게 부족했다. 보호 단계를 단순 삭제하는 것과 선택 수만 확률화하는 것은 다른 변형이다.

## 고정 후보의 새 난수 표본 평가

위 결과를 본 뒤 확률 반올림 q=1.5를 고정하는 별도 계약을 만들고, 새 공간·확산 seed 64쌍으로 평가했다. 기존 20% 연결 수, 0.10 거리 비율 총변동거리, 25% 입력·출력 차수 표준편차, 고립 수 평균 차이 1개 기준을 바꾸지 않았다. 생물자료는 이미 본 같은 표본이므로 탐색적 후속 비교다.

| 항목 | 실제 관측 | 새 64개 생성 결과의 평균 |
|---|---:|---:|
| 방향성 연결 수 | 5,995 | 5,554.36 |
| 출력 차수 표준편차 | 10.2245 | 8.3023 |
| 입력 차수 표준편차 | 8.3579 | 10.4450 |
| 고립 세포 수 | 0 | 0.1563 |
| 거리 구간 비율 총변동거리 | 기준 | 0.04163 |

계약에 정한 평균값 기준은 모두 통과했다. 그러나 입력 차수 표준편차 상한 10.44736과 생성 평균 10.44502의 차이는 **0.00234**에 불과하다. 이 평균의 Monte Carlo 표준오차는 **0.06892**로 더 크다. 따라서 기대값 수준에서 적합성이 안정적으로 통과했다고 확정할 수 없다. 조건 통과를 모형 전체의 적합이나 생물학적 검증으로 승격하지 않는다.

계약에 따라 평균값 기준 통과 후 상호연결을 집계했다. 실제 221쌍, 생성 평균 134.1719쌍으로 차이는 +86.8281쌍이었다. 생성 범위는 110–166쌍, 평균의 Monte Carlo 표준오차는 1.6160쌍이다. 이 범위는 64개 생성값의 최솟값과 최댓값이며 생물학적 신뢰구간이 아니다. 꼬리 p값은 계산하지 않았다.

이 비교에서는 연결 수 자체가 여전히 약 7.35% 적고 차수 편차도 정확히 같지 않다. 따라서 +86.83을 앞선 입출력·거리 기대값 모형의 +52.02와 같은 조건부 잔차로 비교하지 않는다. 이 결과만으로 공간 구조 대안을 반증하거나 특정 뇌 기전을 확정할 수 없다.

## 판정과 다음 질문

이번에는 큰 연결 수 변화의 상당 부분이 생성기의 선택 수 결정 방식에 의존함을 분리했다. 확률 반올림 변형은 기본 특성의 평균에 가까워졌지만 적합성은 경계에 걸려 있고, 현재 조건에서 생성 상호연결은 관측보다 적었다. 재구성 오류·부피 경계·선정 편향은 보정하지 않았다.

다음은 저장된 생성 그래프마다 기존 입출력·거리 기대값 기준을 적용해, 기본 연결 수 차이와 그 기준을 넘는 잔차를 분리하는 것이다. 새 생성 파라미터를 상호연결 수에 맞추지 않는다. 전체 뇌 구조와 인과 기전은 미확립이다.

## 저장과 검증

192개 대조 그래프와 64개 평가 그래프를 데이터 원장에 합성 자료로 등록했다. 모든 그래프의 연결 목록·거리 구간·차수·고립 수·해시·root ID를 검사했다. 공간 그래프는 대조 32개와 평가 64개 모두 다시 생성해 일치함을 확인했다. 최종 그래프는 대조 첫 공간 그래프의 여섯 분기 및 평가 첫·마지막 그래프 두 개를 다시 생성해 일치함을 확인했다. 최종 그래프 전체를 재생성한 검사는 아니다. 평가 상호연결은 64개 모두 직접 세포쌍별 집계로 대조했다.
