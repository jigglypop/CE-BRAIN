# 긴 펄스의 고정 IPFX 발화 검출

저장한 24개 긴 펄스 파형을 IPFX 2.1.2의 고정 조건으로 검사했다. 명령이 0인 7기록에서는 발화 후보가 없었고, 직접 자극 17기록에서는 전극별 발화 후보 수가 달랐다. 이 결과는 알고리즘에 따른 관측이며, 독립 발화 정답 확인·역치전류 확정·세 기전 분리의 증거는 아니다.

## 검출 조건

Allen의 생리 분석은 IPFX에 발화 검출을 위임한다. 로컬에 IPFX가 없어 공식 배포 wheel 2.1.2만 받고, 기존 Python 환경에서 패키지 설치 없이 읽어 실행했다. PyPI가 제공한 SHA-256과 다운로드 파일을 대조하고 원장에 등록했다. 과거 r2.1 DB에 사용된 IPFX 판본은 확인되지 않았으므로 이번 결과를 원 DB 파이프라인의 완전한 재현이라고 부르지 않는다.

검출창은 명령 구간 0.05–1.05초, 저역 필터 10kHz, 상승 기울기 문턱 20V/s, 역치–정점 최대 간격 5ms, 최소 높이 2mV, 최소 정점 −30mV, 역치 비율 0.05, 시작 구간 추가 배제 0초로 고정했다. 입력 단위는 초·mV·pA다. DB 역치와 일치시키기 위한 조건 조정은 하지 않았다.

## 시행별 결과

표는 `전류 단계 pA / 발화 후보 수`다. 전류는 표시상 반올림했다. 전극 2·4·5는 기존 연결 분석의 세포 3·5·6에 대응하나, 기록 사이 세포 상태 불변은 별도 조건이다.

| 시행 | 전극 2 | 전극 4 | 전극 5 |
|---|---|---|---|
| 82 | 100 / 1 | 100 / 8* | 100 / 1 |
| 83 | 200 / 7 | 50 / 0 | 50 / 0 |
| 84 | 150 / 2 | 60 / 3 | 60 / 0 |
| 85 | 100 / 1 | 0 / 0 | 70 / 0 |
| 86 | 110 / 1 | 0 / 0 | 80 / 0 |
| 87 | 120 / 2 | 0 / 0 | 90 / 1 |
| 88 | 130 / 1 | 0 / 0 | 0 / 0 |
| 89 | 140 / 2 | 0 / 0 | 0 / 0 |

별표는 8후보 중 1개가 clipped로 표시됐다는 뜻이다. 이를 임의 삭제하지 않고 저장했다. 다른 후보에는 해당 표시가 없었다. clipped는 알고리즘의 파형 잘림 판정이지 전체 기록의 생물학적 품질 판정이 아니다.

전극 2는 가장 낮은 시험 전류 100pA에서도 후보가 있으므로 이 표만으로 역치를 찾았다고 말할 수 없다. 전극 4의 50/60pA, 전극 5의 80/90pA 사이에서 검출 유무가 바뀌지만 반복 확률·기록 상태·제작자 전체 전처리가 확인되지 않은 단회 대비다. 따라서 이를 확정된 역치 구간이나 DB 역치와의 모순으로 해석하지 않는다. 같은 명령의 반복 수와 전류 순서도 균일하지 않다.

## 검증과 다음 조건

24개 원본 추출 파일의 해시와 유한성을 확인했다. 평평한 대조 파형에서는 검출이 없었고, 모든 기록에서 파형과 검출창의 시간 원점을 함께 0.1초 옮겨도 후보 수와 상대 정점 시각이 보존됐다. 검사는 통과했다. 합성·수치 검사는 실제 spike 정답의 대체물이 아니다.

이제 자극 세기와 발화 후보를 연결할 수 있지만, 제작자 기록 QC·holding 및 bridge 처리·접근저항과 세포 상태가 남아 있다. 다음에는 해당 시행의 기록 메타데이터와 QC 근거를 확인한다. 조건이 충족되기 전에는 이번 최소 발화 전류를 시냅스 전달 기전의 고정 파라미터로 넣지 않는다.
