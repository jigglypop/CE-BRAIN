# ICMS98 catch: 시행 평균과 시행 내부 동반성

**적격 13개 unit 모두에서 시행별 평균을 제거한 뒤에도 양의 동반 활동이 남았다.** 같은 시간 구간의 다른 catch 시행을 대응시킨 값보다도 컸다. 이는 시행 평균 수준이나 반복되는 상대시간 패턴만으로 현재 관측을 설명하지 못한다는 범위 제한 결과다. 직접 신경 연결의 증거는 아니다.

## 같은 입력의 분해

[시행 경계 보존 검사](Q_NPF_04_ICMS98_catch_시행경계보존.md)의 ICMS98 2023-10-24 자료와 36개 catch, 21개 unit, 내부 trigger 규칙을 그대로 사용했다. 대상 unit을 제외한 집단 발화를 시행별로 smoothing하고 각 500ms 창의 내부 300ms만 평가했다. 대상 unit의 발화 수로 가중한 PC를 다음 두 성분으로 정확히 분해했다.

1. 시행 내부 집단 평균과 전체 집단 평균의 차이.
2. 각 시행 내부 평균을 제거한 집단 활동을 대상 발화 시각에서 평가한 값.

두 성분의 합은 이전 PC와 일치한다. 첫 성분은 trigger가 어떤 시행에 집중되는지와 전체 창·내부 창의 평균 차이를 함께 포함하므로 순수한 시행 간 공분산으로 부르지 않는다.

추가 대조에서는 대상 발화 시각은 유지하고, 집단 활동 곡선을 원래 100시행 구간 안의 다른 모든 catch 곡선의 평균으로 바꿨다. 자기 시행은 대조에서 제외했다. 같은 상대시간을 비교하므로 반복되는 시간 패턴을 일부 보존한다. 시행별 평균을 제거한 곡선에도 같은 대조를 적용했다. 새로운 시행·unit 필터나 유의성 검정은 추가하지 않았다.

## 결과

내부 발화 50개 이상이라는 이전 기준을 충족한 13개 unit의 기술적 요약이다. unit들이 같은 시행과 집단 활동을 공유하므로 13개를 독립 복제 수로 세지 않는다.

| 측정 | 양의 값인 unit | unit별 값의 중앙값(Hz) |
|---|---:|---:|
| 전체 PC | 13/13 | 76.307 |
| 시행 평균 성분 | 13/13 | 22.605 |
| 시행 내부 성분 | 13/13 | 56.526 |
| 같은 시행 PC − 다른 시행 대조 | 13/13 | 79.533 |
| 시행 평균 제거 후 같은 시행 − 다른 시행 | 13/13 | 63.752 |

표의 중앙값끼리는 더해지지 않는다. 합의 일치는 unit별 값에서 검사했다. 예를 들어 unit 0의 전체 PC 179.330Hz는 시행 평균 성분 49.179와 내부 성분 130.150의 합이다. unit 17에서는 각각 52.987, 29.937, 23.050Hz였다. 전체 21개 unit 결과를 저장했으며 기준 미달 unit을 0효과로 처리하지 않았다.

## 판정과 다음 조건

이번 관측은 같은 시행 안에서 상대적으로 빠르게 함께 변하는 집단 활동이 남는다는 결과다. 다른 시행 대조는 같은 구간 안의 상태·행동 차이를 모두 통제하지 못하며, 대상 발화와 집단 활동의 공통 입력도 제거하지 않는다. 분류·선택과 전처리의 영향이 여전히 가능하다.

특히 unit 간 중복 검출이나 동일한 전기적 사건이 여러 unit에 할당되는 경우도 확인해야 한다. 다음에는 정렬된 발화 시각의 정확한 일치·근접 중복과 waveform·채널 정보를 함께 검사해, 집단 동반성을 직접 회로 관계로 오인할 위험을 좁힌다. 중복이 없다 해도 직접 인과관계가 자동으로 성립하는 것은 아니다.

이 범위 제한 실자료 관측의 상한은 `BIO_EVIDENCE_L1`이다. 전체 뇌 인과 구조는 미확립이며 비과제군의 미해결 시간축 문제도 그대로다.
