# S1–S2 경로별 시간 반복의 표본 한계

공유 표적 경로를 전반·후반으로 나누면, 각 구간에서 test와 catch가 모두 두 번 이상 있는 경로는 전체 11개 세션에서 하나도 없었다. 현재 자료로 표적 경로별 반응의 시간 반복성을 안정적으로 확인하는 단계는 진행하지 않는다. 이는 효과가 없다는 판정이 아니라 해당 비교의 반복 표본 부족이다.

## 고정한 점검

각 세션 전체 보존 catch/test의 최초·최후 획득 시각 중점을 사용했다. 중점 이전을 전반, 이후를 후반으로 정하고 기존 배정 이력 제한과 공유 경로 집합을 유지했다. 반응값으로 경계나 경로를 선택하지 않았다. 초 단위 환산도 필요하지 않았다.

|---|---:|---:|---:|
| J064/10 | 19 | 3 | 0 |
| J064/11 | 22 | 1 | 0 |
| J064/14 | 27 | 3 | 0 |
| RL070/28 | 44 | 13 | 0 |
| RL070/29 | 34 | 6 | 0 |

네 칸은 전반 test·전반 catch·후반 test·후반 catch다. 2회라는 기준 자체가 충분한 검정력을 보장하지 않는다. 이번에는 그 최소 반복조차 없음을 확인했다. 각 칸 한 시행만 남는 경로로 효과 지도를 만들거나 유리한 분할을 찾지 않는다.

## 후속 자료로 전환

연구실의 별도 [S1S2_mechanisms 저장소](https://github.com/Packer-Lab/S1S2_mechanisms/tree/4a1b6b0210d4916656d962941be9bc308e9d8bf8)를 확인했다. 고정 판본 README는 [별도 데이터 저장소](https://gin.g-node.org/vdplasthijs/S1S2_mechanisms_data)를 안내한다. 파일 트리와 README만 확보했고 README의 Git blob 해시를 대조했다. 분석 환경 설치나 대용량 자료 다운로드는 아직 하지 않았다.

다음은 이 후보의 세션·마우스·개입 설계·반복 수를 확인해 기존 자료와 중복인지, 직접 경로 질문에 더 적합한지 판단하는 것이다. 저장소 이름만으로 독립 자료나 기전 검증으로 간주하지 않는다. 현재 경로의 표본 부족은 전체 연구의 중단 사유가 아니며, 뇌 구조 규명 목표는 미완료로 유지한다.
