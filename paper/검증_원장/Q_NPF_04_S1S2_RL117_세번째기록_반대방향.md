# RL117 세 번째 기록의 반대 방향

**RL117 run 30의 S2 시험 자극−catch 대비는 +0.003830이었다.** 앞선 run 26과 29의 음수 대비와 반대다. 동일 마우스에서 관측 대비의 부호가 일정하지 않았으며, 이를 연결의 흥분성·억제성 전환으로 해석할 수는 없다.

## 입력과 방법

여덟 번째 SessionLite 객체의 끝은 접두 4,433,868,897바이트다. 새 계약에 이 접두의 SHA-256과 기존 v2 코드 해시를 기록했다. 전체 파일은 수집 중이며 전체 원본 무결성 확인은 미완료다. 원래 220시행 중 export에 남은 192시행, S1 343세포·S2 186세포를 사용했다. galvo 시각이 유한하지 않은 원래 시행 인덱스 65(0부터 시작)를 기존 규칙으로 제외해 191시행을 집계했다. export 누락 28시행과 시각 제외 1시행을 반응 없음으로 세지 않았다.

기존 v2 코드를 변경하지 않고 명목 30Hz 전 창 `[−2,−0.5)`초와 후 창 `[1.5,3)`초에서 S2 세포별 후−전 평균을 구한 뒤 세포 간 평균했다. easy 자극은 주 대비에서 제외했다. S1/S2 상보 마스크, 직접 S2 표적 및 catch 표적 없음, 표적의 시행 내 불변성, 행동 표지·첫 핥기·시행 인덱스 대응, 유효 시각의 증가와 선택 신호 유한성 검사를 통과했다. [실제 프레임 시각의 한계](Q_NPF_04_S1S2_프레임시간_민감도.md)는 유지된다.

## 관측

| 종류 | 유효 시행 | S2 평균 변화 | 반응 창 핥기 겹침 | 자동 보상 표지 |
|---|---:|---:|---:|---:|
| catch | 60 | +0.002600 | 2 | 0 |
| 시험 자극 | 66 | +0.006431 | 23 | 10 |
| easy | 65 | +0.011087 | 33 | 10 |

전후 창을 함께 −1, 0, +1프레임 이동한 대비는 +0.003944, +0.003830, +0.003976이었다. 세 창에서 양수가 유지되지만 통계적 신뢰구간이나 독립 검증으로 해석하지 않는다. 시험 자극의 핥기 겹침은 23/66, catch는 2/60이다. 행동 차이와 자동 보상 표지가 남아 있고 실제 보상 전달 시각은 확인되지 않았다.

[앞선 두 기록](Q_NPF_04_S1S2_RL117_두세션비교.md)의 대비는 −0.018439, −0.020255였다. 현재 세 마우스의 여덟 세션에서 J064는 음수·양수·음수, RL070은 양수·양수, RL117은 음수·음수·양수다. 동일 마우스라도 세포 구성·형광 척도·행동 상태가 같다고 가정하지 않았고 같은 세포의 종단 등록도 확보하지 않았다.

## 해석과 다음 조건

이번 질문에는 RL117의 세 번째 기록에서 앞선 두 기록의 음수 방향이 유지되지 않았다는 답을 얻었다. ‘관측 대비 부호가 이 마우스의 모든 기록에서 같다’는 기술적 진술은 성립하지 않는다. 다만 통계적으로 확립된 세션 차이를 검정하거나 특정 생물 기전을 반증한 것은 아니다. 직접 전달·공통 입력·행동·보상 기여는 여전히 미식별이다.

주장 상한은 탐색적 범위고정 관측 `BIO_EVIDENCE_L1`이며 전체 뇌 구조는 미확립이다. 다음은 남은 마우스의 완성된 기록을 같은 방법으로 비교하는 것이다. 전체 파일 무결성, 실제 프레임·보상 시각과 독립 검증은 별도 조건으로 남는다.
