## 1. 완료한 잡음 입력과 실제 결측

앞선 깊이·횟수 검사에서는 작은 DB에 기록 테이블이 없어 잡음을 포함하지 못했다. 이번에는 진행 중이던 동일 수집을 끝내고, 세포 신원과 평균값을 검증한 뒤 적합했다. 이전 원장의 진행 중 표기는 당시 시점 기록으로 보존한다.

|---|---:|

| 평균 잡음을 계산할 수 있는 세포 | 8,300 |

| 잡음값이 유효한 쌍 | 25,683 |

**미수집 세포는 0개다.** 잡음이 없는 1,042세포는 수집 실패와 구별했다. 적합 코드는 완결 결과·완료 상태·journal·사용 블록 목록의 SHA-256과 전체 대상 ID 집합을 먼저 확인한다. 각 세포의 QC IC 목록에서 평균을 다시 계산해 저장 결과와 일치하는지도 검사했다. 어느 모형에서도 결측을 이유로 기존 쌍을 제거하지 않았다.

수집은 [Allen 공식 medium SQLite](https://allen-synphys.s3-us-west-2.amazonaws.com/synphys_r2.1_medium.sqlite)의 필요한 바이트만 기존 캐시에 보충했다. 전체 원격 크기는 11,125,997,568 bytes, ETag는 `d954cbad0d7c7b0002bf3a2879e40e90-1327`이다. 기존 193블록·12,648,448 bytes에서 최종 1,479블록·96,927,744 bytes가 됐고, 두 수집 호출에서 새로 받은 양은 합계 84,279,296 bytes다. 이 질문에서 접근한 블록 목록은 1,313개·86,048,768 bytes이며 전체 DB 복사본이 아니다. 최초 직렬화 오류와 수정 계보는 부모 원장에 보존했고, 재개한 session 93749는 종료 코드 0으로 완료됐다.

## 2. 잡음의 측정 의미

입력을 확보했더라도 그 값이 어떤 변동성을 측정했는지 구분해야 한다. 공식 [기록 스키마](https://github.com/AllenInstitute/aisynphys/blob/b187927abf1e8df46d11b47eeb88c8e2c76aee3c/aisynphys/database/schema/dataset.py)는 `baseline_noise_stdev`를 기록의 정상상태 구간 표준편차로 정의한다. [저장 파이프라인](../../verify/Q-NPF-04/allen_synphys/qc_sources/dataset_pipeline.py)은 recording 객체의 값을 저장한다. 현재 보유한 해당 생산 경로만으로 정확한 원시 시간창·필터·표본수를 복원하지는 못했다.

[공식 연결 분석 함수](https://github.com/AllenInstitute/aisynphys/blob/545a990ee171e6c0d23dd4bba413e1ccbf2f0853/aisynphys/connectivity.py)의 정의에 따라 postsynaptic 세포의 QC 통과 IC 기록이 두 개 이상일 때 표준편차들을 산술 평균했다. IC 값의 단위는 V다. 기록 길이·시행 수로 가중하지 않았고 holding·수집 시각·자극 프로토콜별로 나누지 않았다. 이 평균이 시냅스 판정 순간의 유효 잡음이라는 보장은 없다.

[QC 생산 코드](../../verify/Q-NPF-04/allen_synphys/qc_sources/pulse_qc.py)는 큰 기록 결함을 거르는 최소 기준이며, IC 잡음이 5 mV를 넘으면 실패로 처리한다. 접근저항이나 세포 건강의 완전한 교정이라는 뜻은 아니다. 별도의 [`avg_baseline_noise`](https://github.com/AllenInstitute/aisynphys/blob/b187927abf1e8df46d11b47eeb88c8e2c76aee3c/aisynphys/avg_response_fit.py)는 정렬·평균된 반응의 첫 7 ms 구간 변동성이다. 이번 기록 잡음 평균과 구별해야 하며, 두 값 모두 추가 가정 없이 독립 시행 평균의 표준오차로 대체할 수 없다.

| 유효한 8,300세포의 평균 IC 잡음 | µV |
|---|---:|
| 최소 | 48.295 |
| 1% 분위수 | 169.852 |
| 중앙값 | 595.120 |
| 99% 분위수 | 2,288.472 |
| 최대 | 4,811.064 |

최종 횟수와 QC 통과 여부는 관측 반응에 따라 달라졌을 가능성이 있고, 잡음의 크기도 세포 상태와 연관될 수 있다. 따라서 이번 변수는 **수집이 끝난 뒤 이용하는 기록 요약**이다. 잡음을 독립적으로 조작한 실험이나 검출 민감도의 교정값으로 해석하지 않는다.

## 3. 같은 고정점과 관측변수에서 비교한 메트릭 후보

이 측정 의미를 유지하면서 깊이·횟수 모형에 잡음 한 항과 결측 지시자를 추가했다. 실험마다 뉴런의 3D 위치를 고정했으며, 서로 다른 뇌를 하나의 물리 좌표계로 등록한 것은 아니다. 실험 간에 공통 예측 계수를 사용하는 조건부 모형이다. raw X·Y·Z를 실제 피질축으로 동일시하지 않는다.

세포 쌍의 변위를 $\delta=p_j-p_i=(\delta_x,\delta_y,\delta_z)$, 길이 기준을 $L_0=100\,\mu\mathrm m$라고 둔다. 이전과 같은 순서 있는 nonsynaptic 세포형·층 문맥을 $c$로, 기록 요약 벡터를 $z$로 쓴다. 관측 연결 표지 $Y$의 예측식은

$$
\operatorname{logit}P(Y=1\mid\delta,c,z)
=a+u_c+\theta^Tz-\rho\sqrt{(1-w)(\delta_x^2+\delta_y^2)/L_0^2+w\delta_z^2/L_0^2}
$$

다. $a$는 전체 절편, $u_c$는 문맥 편차, $\theta$는 기록 요약 계수, $\rho\ge0$는 거리 척도, $w\in[0,1]$은 Z와 XY 비용의 분배다. 직선 경로를 허용하는 공간 영역에서 마지막 항은 상수 계량

$$
g_w^{(Z)}=\frac{\rho^2}{L_0^2}\operatorname{diag}(1-w,1-w,w)
$$

의 거리와 같다. $\rho>0$, $0<w<1$이면 매끄럽고 대칭인 SPD이며, 성분 단위는 $\mu\mathrm m^{-2}$다. 실제 경계가 강제하는 우회 경로는 넣지 않았다. 좌표변환 $q=F(p)$의 Jacobian을 $J$라 하면 성분은 $J^{-T}gJ^{-1}$로 변환해야 한다. 이 후보의 상수·축 정렬 형태는 채택 조건이다.

$w=0$은 정확한 XY rank 2 경계, $w=1$은 Z만 남는 rank 1 경계이며 리만 SPD 후보와 구분한다. $w=1/2$는 등방점으로, 별도 등방식 $\gamma\|\delta\|/L_0$와 $\rho=\sqrt2\gamma$일 때 일치한다. X·Y 분리 대조는 같은 식에서 축만 바꾼다. 공간 메트릭의 대칭성은 그대로이며 연결 표지의 방향 차이를 메트릭만으로 표현하지 않는다.

관측 벡터는 깊이 평균/100 µm, 그 제곱, $\log(1+\min(n,800))$, $\log(\bar\sigma_V/1\,\mathrm V)$의 네 연속 항과 깊이·횟수·잡음 결측 지시자 세 개다. $n$ 선택과 깊이 범위는 부모 검사와 같다. 표준화는 학습 fold의 유효값만 사용한다. 문맥과 관측 계수의 ridge 강도는 각각 1이고, 거리 계수는 벌점 없이 비음수로 제한한다. 횟수 결측 지시자와 문맥의 중복으로 문맥 축소 방식도 달라질 수 있다는 부모 검사의 제한을 유지한다.

| 비교 모형 | 이번 처리 |
|---|---|
| 깊이+횟수, 거리 없음 / 등방 거리 | 부모의 고정 OOF 예측 재사용 |
| 깊이+횟수+잡음, 거리 없음 / 등방 거리 | 같은 분할에서 적합 |
| 잡음 포함 Z·X·Y 분리 | 각 축의 $w$를 학습 목적값으로만 선택 |
| 잡음 포함 XY / Z-only | Z 후보의 정확한 두 경계에서 적합 |

기존 [방향 프로파일 코드](../../verify/Q-NPF-04/fixed_points_metric/allen_hidden_axis_metric.py)의 고정 격자와 국소 구간 탐색을 재사용했다. 세 축×다섯 fold에서 총 647개 프로파일 점을 평가했다. 연속 전역 최적해의 증명은 아니며, 등방점과 두 경계를 항상 포함했다. 등방점의 보류 logits와 별도 등방 적합의 최대 차이는 $1.31\times10^{-6}$였다. 관측변수 처리·거리 척도의 구현 일치 확인이며 생물학적 재현성이 아니다.

## 4. 예측 결과와 방향별 판정

같은 쌍·donor 분할에서 평가한 결과는 다음과 같다. log loss와 Brier는 작을수록 좋다.

| 모형 | OOF log loss | Brier |
|---|---:|---:|
| 깊이+횟수, 거리 없음 | 0.285456 | 0.080028 |
| 깊이+횟수, 등방 거리 | 0.277058 | 0.078467 |
| 잡음 추가, 거리 없음 | 0.281506 | 0.079056 |
| 잡음 추가, 등방 거리 | **0.273248** | **0.077512** |
| 잡음 추가, Z 분리 | 0.273376 | 0.077556 |
| 잡음 추가, XY 경계 | 0.273279 | 0.077538 |
| 잡음 추가, Z-only 경계 | 0.281034 | 0.078929 |
| 잡음 추가, X 분리 | 0.273202 | 0.077508 |
| 잡음 추가, Y 분리 | 0.273229 | 0.077507 |

![기록 잡음·방향 비용의 동일 분할 비교](../../verify/Q-NPF-04/fixed_points_metric/allen_noise_axis_observation.png)

그림 C의 회색 선은 이전 **문맥만 포함한 Z 후보**, 주황색은 깊이·횟수·잡음을 모두 포함한 이번 후보다. 두 선의 차이를 잡음 하나의 효과로 귀속하지 않는다. 전체 비교는 이미 노출된 같은 개발 자료이며 새 외부 확인이 아니다.

다음 구간은 고정된 OOF 예측을 donor 단위로 2,000회 재표집한 쌍 가중 백분위 95% 구간이다. 재적합·전체 모형 선택 불확실성·다중 비교 보정을 포함하지 않는다. 차이는 `후보 − 비교`이며 음수가 개선이다.

| 후보 − 비교 | log loss 차이 | 재표집 구간 |
|---|---:|---|
| 잡음 포함 등방 − 잡음 없는 등방 | −0.003810 | [−0.005197, −0.002478] |
| 잡음 포함 등방 − 같은 관측변수의 거리 없음 | −0.008258 | [−0.010025, −0.006530] |
| Z 분리 − 등방 | +0.000128 | [−0.000021, +0.000277] |
| Z 분리 − XY 경계 | +0.000097 | [−0.000072, +0.000297] |
| X 분리 − 등방 | −0.000047 | [−0.000288, +0.000190] |
| Y 분리 − 등방 | −0.000020 | [−0.000232, +0.000184] |
| XY 경계 − 등방 | +0.000031 | [−0.000269, +0.000290] |
| Z-only 경계 − 등방 | +0.007786 | [+0.006046, +0.009527] |

잡음을 넣은 등방 모형은 잡음 없는 등방 모형보다 log loss를 약 1.38% 낮췄다. 같은 잡음 변수 안에서도 거리의 추가 예측 정보는 남았고, 다섯 fold 모두에서 거리 항이 개선했다. 잡음 추가 전후 거리 개선량의 변화는 +0.000141, 구간 [−0.000109, +0.000401]이었다. 이 값은 쌍 가중 기준에서 뚜렷하게 구별되지 않는다. 동일 donor 가중 변화는 +0.000658, 구간 [+0.000229, +0.001108]로, 가중 대상에 따른 차이도 보존한다.

**Z 분리는 log loss의 추가 이득이 미확립이며, Brier는 악화 방향이다.** 등방 대비 Brier 차이는 +0.00004383, 구간 [+0.00000625, +0.00008513]이었다. 두 지표를 모두 ‘차이 없음’으로 묶지 않는다. Z 분리의 log loss가 등방보다 낮은 fold는 2/5였고, 전체에서는 높았다. X·Y 분리의 작은 평균 개선도 구간이 0을 포함하므로 실제 축별 비용의 확인으로 채택하지 않는다.

| fold | Z 후보의 $w$ | $g_Z/g_{XY}=w/(1-w)$ | XY 경계와의 학습 벌점합 차이 |
|---:|---:|---:|---:|
| 0 | 0.004535 | 0.004556 | 0.000996 |
| 1 | 0.504582 | 1.018497 | 2.410156 |
| 2 | 0.379512 | 0.611634 | 1.434117 |
| 3 | 0.126806 | 0.145221 | 0.108286 |
| 4 | 0.250749 | 0.334666 | 0.661203 |

마지막 열은 `XY 경계의 학습 목적합 − 선택점의 학습 목적합`이다. 확률적 신뢰구간이나 경계 검정의 유의확률이 아니다. 다섯 Z 후보 모두 SPD 내부였지만 비율은 0.00456–1.01850으로 달랐고, 특히 fold 0의 XY 경계와 선택점은 학습 목적값 차이도 매우 작았다. 양의 작은 계수를 얻었다는 사실만으로 숨은 3D 비용을 식별했다고 하지 않는다.

## 5. 전체 뇌 메트릭에 남은 조건과 다음 경로

이번 결과는 기록 조건이 관측 연결 표지의 예측에 중요하다는 점을 보이지만, 실제 연결확률과 검출률을 분리하지는 못한다. [부모 원장의 관측식과 조건부 검사](고정뉴런_절단면깊이와_연결관측모형_검사.md)에 따르면 미지 민감도가 위치·상태에 의존할 수 있는 후보군에서는 서로 다른 SPD 비용이 같은 관측확률을 만들 수 있다. 잡음을 공변량으로 넣어도 독립 민감도 측정이 새로 생기는 것은 아니다.

따라서 현재의 공간 결과는 **선택된 표지에서의 거리 정보는 지지됨, 원 좌표 축별 메트릭의 추가 이득은 미확립**으로 정리한다. 등방 후보도 확률 비용을 표현한 조건부 모형이며 실제 개인별 메트릭의 복원이 아니다. XY 경계의 비슷한 성능이나 Z-only의 낮은 성능은 전체 뇌의 차원·연결 부재·해부학적 축에 관한 결론이 아니다.

다음에는 관측 방식이 다른 구조 입력과 연결해 이 한계를 구별한다. 데이터 원장에는 이미 같은 root ID의 3D 세포 위치와 방향 있는 EM 시냅스 행자료를 포함한 MICrONS/Minnie65 v1718 및 Pinky v185가 있다. 이들을 곧바로 정답이나 독립 donor 검증으로 간주하지 않는다. **동일 뉴런 위치·방향 접촉의 대응 → 좌표 단위·재구성 및 관측 경계 확인 → 정의한 구조 비용의 보류 예측과 방향 대조**를 먼저 수행할 수 있다. 이미 본 자료를 재사용하는 경우 개발 분석으로 표시하며, 두 판본이나 다른 표본을 섞어 하나의 뇌로 만들지 않는다.

전기 전달 경로에서는 실제 단자 전압·관측 필터·전도도와 구성에 쓰지 않은 방향별 비용의 독립 교정이 여전히 필요하다. [해마·호르몬 반응 평가](고정뉴런_해마호르몬_화학반응_평가.md)의 국소 호르몬·수용체 상태와 같은 고정 뉴런의 기능을 연결하는 요구도 유지한다. 이번 VisP 기록 잡음에서 호르몬 효과를 추정하지 않았다. 전체 PRD 목표는 미완료다.
