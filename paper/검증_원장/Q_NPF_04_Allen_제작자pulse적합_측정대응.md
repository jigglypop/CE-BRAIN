# 제작자 pulse별 적합값과 측정 정의

양성 연결 pair 104272의 시행 37–56에서 제작자 적합 240개를 찾고 원시 자극과 대응시켰다. 역필터링 기반 적합은 이전의 단순 고정 창 대비와 다른 양을 측정한다. 단순 대비가 불명확하다는 결과를 제작자의 연결 표지나 시냅스 진폭 추정이 실패했다는 뜻으로 확대하면 안 된다.

## 자료 대응

60기록의 기존 DB 대응과 240개 실제 명령 시각을 재사용했다. 각 pulse_response의 시냅스전 기록이 device 5인지, 표적 기록이 device 4인지, 실제 명령 시작과 한 표본 이내에서 맞는지 확인했다. 시행·pulse 키 240개가 모두 유일하게 대응됐으며 저장된 `ex_qc_pass`와 적합 행도 240개 모두 있었다. 기준선 ID는 서로 다른 240개다. 기준선 ID의 고유성이 생물학적 독립성을 뜻하지는 않는다.

medium DB의 기존 부분 캐시를 재사용하고 1,638,400바이트만 추가 조회했다. 원시 파형의 적합을 새로 실행한 것이 아니라 배포 DB의 적합값을 조회한 결과다. 확인한 코드 판본과 과거 DB 생성 환경의 완전한 동일성은 미확인이다.

## 측정량의 차이

확인한 [제작자 반응 코드](https://raw.githubusercontent.com/AllenInstitute/aisynphys/b187927abf1e8df46d11b47eeb88c8e2c76aee3c/aisynphys/pulse_response_strength.py)는 기존 synapse의 지연과 상승·감쇠 값을 사용한다. 직접 PSP 적합에는 부호 제약과 기준선 성분이 들어간다. 역필터링 경로는 IC에서 2 kHz 저역통과 후 고정 템플릿의 scale·offset을 계산하고 원래 진폭 단위로 환산한다. 각 경로는 별도 기준선에도 적용된다.

[파이프라인](https://raw.githubusercontent.com/AllenInstitute/aisynphys/b187927abf1e8df46d11b47eeb88c8e2c76aee3c/aisynphys/pipeline/multipatch/pulse_response.py)은 연결 표지가 있는 pair에 이러한 적합을 저장한다. 따라서 양성 적합값 자체를 독립적인 연결 발견의 증거로 삼지 않는다. 반면 기존 분석은 각 표적의 [2,8) ms−[−8,−3) ms 전압 평균 차이를 구한 뒤 양성 표적에서 음성 표적을 뺀 대비다. 필터·파형 가정·기준선·표적 수가 모두 다르다.

이 연결의 저장된 PSP 상승시간은 약 6.010 ms, 감쇠시간은 15.387 ms, 지연은 1.636 ms다. 이 값으로 현재 파형에 새 적합을 수행하거나 검출 창을 사후 변경하지 않았다.

## 판정과 다음 조건

이번에 확인한 것은 저장된 측정량의 차이와 같은 자극의 정확한 대응이다. 한 실험의 조건부 관측 수준이며 통합 CE 사슬이나 뇌 전체 구조의 등급을 올리지 않는다. 다음에는 pulse·기준선 추출 구간, 제작자 발화 정렬 시각, 파형 적합의 고정값을 원시 기록과 대조한다. 이 자료는 개발 자료로 유지하고, 새 측정 방식의 검증에는 별도 기록을 분리해야 한다. 기존 실패한 고정 창 결과는 보존한다.
