# S1–S2 후속 투사 자료의 설계 점검

후속 자료는 기존 11개 세션과 다른 마우스 표기를 가진 12개 파일이다. 투사 집단을 구분하는 조건이 있어 기존 표적 수 비교보다 경로 질문에 가깝다. 다만 로더는 조건별로 섞지 않은 블록 설계를 설명하므로 시간 경과와 조건 차이를 분리하는 검토가 필요하다. 새 생물학적 결과는 아직 없다.

## 목록과 조건

[데이터 안내](https://gin.g-node.org/vdplasthijs/S1S2_mechanisms_data)는 투사 실험 6개와 감각 실험 6개를 설명하며, 실제 폴더 목록도 각각 6개 파일을 포함한다.

- 투사 실험: RL127, RL128, RL129, RL130, RL131, RL132. 2021년 2–3월 표기. 조건은 S2 투사 S1 집단, 비투사 집단, sham이다.
- 감각 실험: RL093, RL099, RL101, RL103, RL108, RL109. 2020년 9–10월 표기. 조건은 감각 반응 집단, 무작위 집단, 수염 자극, sham이다.

기존 J064·RL070·RL117·RL123·RL116과 표기 중복은 없다. 동물 원장으로 개체 출처를 독립 검증한 것은 아니다. 공개 파일 이름만으로 모든 자료의 독립성을 확정하지 않는다.

## 설계와 측정상의 주의점

[고정 판본 로더](https://github.com/Packer-Lab/S1S2_mechanisms/blob/4a1b6b0210d4916656d962941be9bc308e9d8bf8/jupyter/thijs/decoding_analysis_vis.py)의 `create_data_objects` 주석은 조건당 100회, 조건을 섞지 않은 블록, 마지막 두 광자극 조건 순서의 실험별 교대를 설명한다. 이 주석이 각 투사 세션에 어떻게 적용됐는지는 실제 파일과 획득 기록으로 대조해야 한다.

로더는 `photostim_s/r`를 실험 유형에 따라 감각/무작위 또는 투사/비투사로 해석한다. `spont`는 sham으로 이름을 바꾼다. 로더 주석상 sham 표적 구성은 random과 같다고 설명하지만 실제 출력은 독립 확인되지 않았다. 조건 이름만으로 완벽한 대조를 가정하지 않는다.

표적 셀·좌표·영역 라벨과 시간축을 읽는 경로를 확인했다. 로더는 182개 시간점을 기대하고, 신경 세포 필터와 자극 아티팩트 구간을 적용한다. 이 조건은 이전 30 Hz·420프레임 자료와 다르므로 기존 시간창 인덱스를 그대로 적용하지 않는다.

## 확보 상태와 다음 단계

파일 목록·데이터 README·분석 예제·로더만 받았다. GitHub 예제와 로더는 고정 판본의 Git blob 해시를 대조했다. GIN 페이지는 로컬 해시로 보존했다. 신경 피클 본체는 아직 받지 않았고, 예제의 저장 출력은 현재 실행 결과로 취급하지 않는다.

[사전 점검 결과](../../verify/Q-NPF-04/allen_synphys/s1s2_mechanisms_preflight.json)에 12개 파일 경로·마우스 표기·보유 소스 해시를 남겼다. 목록 수와 기존 마우스 표기 중복 0을 검사했다. 다음은 투사 세션 한 개의 용량·직렬화 구조를 확인하고 안전 판독 경로를 준비한 뒤 실제 조건별 반복 수와 블록 순서를 확인하는 것이다. 설치 안내의 전체 환경을 실행하거나 외부 피클 함수를 직접 실행하지 않는다.

현재 단계는 자료 준비와 설계 검토이며 뇌 구조 규명은 미완료다. 블록 설계의 한계를 밝힌 뒤 투사 집단에 특이적인 전달이라는 질문을 검증할 수 있는 범위를 정한다.
