# MICrONS 반복 행동 상태와 회차 제외 민감도

## 이번 결과

반복 자극 60회의 행동을 정렬하니 7번째 회차에서 이동이 많았고, 9·10번째 회차에는 정렬 가능한 동공·눈 위치 값이 없었다. 그러나 이동이 많았던 7번째 회차를 제외해도 영역·거리 조건부 구조 대비는 **0.01823 → 0.01785**로 거의 변하지 않았다. 그 회차 하나가 기존 대비를 만든다는 설명은 이번 검사와 맞지 않는다.

이것은 행동 보정이나 인과 검정이 아니다. 앞서 [회차 교환 대조](Q_NPF_04_MICrONS_회차교환_구조대비.md)에서 관측 대비가 대조 분포와 뚜렷하게 구별되지 않았다는 한계도 그대로 남는다. 관측 차이의 부호와 특정 회차 의존성을 구분한다.

## 행동 자료의 실제 가용 범위

기존 6조건 × 10회 × 57시점, 총 3,420개 시점에 행동을 맞췄다. 원자료의 바로 이웃한 두 샘플이 모두 유한하고, 시간 간격이 해당 자료의 중앙 간격 3배 이내일 때만 선형 보간했다. 범위 밖 외삽이나 NaN 구간 연결은 하지 않았다. 이 기준은 행동값을 읽기 전에 기록했다.

| 정렬 변수 | 유효 시점 / 전체 | 회차별 주요 제한 |
|---|---:|---|
| 이동 속도 | 3,286 / 3,420 | 134개 시점은 긴 원샘플 간격으로 제외 |
| 동공 장·단반경 각각 | 2,635 / 3,420 | 9·10회차는 유효 시점 0 |
| 눈 위치 x·y 각각 | 2,635 / 3,420 | 9·10회차는 유효 시점 0 |
| 다섯 변수 모두 유효 | 2,595 / 3,420 | 완전 사례 분석의 가능한 시점 범위 |

긴 간격 기준은 속도 약 0.0394초, 눈·동공 약 0.1499초다. 시간 범위 밖 시점은 없지만, 범위 안에도 결측과 긴 샘플 간격이 있다. 각 시행에서 유효 비율 80%를 넘긴 시행은 속도 60/60, 눈·동공 각각 48/60이었다. 모든 시행 행과 결측 표지는 보존했다.

속도는 NWB의 conversion 0.01과 offset 0을 한 번 적용해 m/s로 변환했다. 회차 요약은 방향 상쇄를 피하도록 절대 속도의 평균이다. 7번째 회차는 약 **0.02806 m/s**였고, 나머지 회차는 약 **0.0000435–0.0001738 m/s**였다. 이는 행동 상태의 차이이며 생물학적 원인을 지정한 결과는 아니다.

동공·눈 위치의 뒤 5회 평균은 9·10회차가 빠진 관측값에만 기반한다. 앞 5회 평균과 같은 관측 범위인 것처럼 비교하지 않는다. 결측을 정지·정상 눈 상태로 해석하지 않는다.

## 모든 회차를 하나씩 제외한 결과

행동 결과를 확인한 후의 민감도 검사임을 명시했다. 특정 회차를 골라 기존 결과를 구제하지 않도록 1–10회차를 각각 한 번씩 제외했다. 매번 여섯 자극 조건 모두에서 같은 회차를 제외하고, 남은 9회 안에서 회차 제외 평균과 잔차를 다시 계산했다.

53개 전체·양의 촬영 지연 조건의 영역·거리 조건부 대비는 다음과 같다.

| 제외 회차 | 대비 |
|---|---:|
| 1 | 0.02052 |
| 2 | 0.01748 |
| 3 | 0.01556 |
| 4 | 0.01943 |
| 5 | 0.02356 |
| 6 | 0.01472 |
| 7 | 0.01785 |
| 8 | 0.01761 |
| 9 | 0.01470 |
| 10 | 0.02006 |

두 시간 처리와 등록 판본 차이 세포의 포함·제외를 함께 적용한 40개 결과는 모두 양수였고, 전체 범위는 0.01470–0.02432였다. 이 범위는 효과의 신뢰구간이나 회차 교환 대조를 통과했다는 증거가 아니다.

## 판정과 다음 행동

원래 질문에는 행동 상태가 회차별로 달라지고 관측 범위도 불완전하다는 답을 얻었다. 7번째 고이동 회차 하나만 제거하면 구조 대비가 사라진다는 설명은 지지되지 않았다. 여러 회차에 걸친 행동·공통 입력의 영향과 잔차 대비의 불확실성은 남아 있다.

다음에는 행동 자료가 있는 시점의 선택 효과와 같은 시점에서의 제한된 행동 회귀를 구분해야 한다. 행동 결측 때문에 표본이 바뀐 효과를 행동 제거 효과로 부르지 않는다. 관측된 행동만으로 모든 공통 원인을 통제했다고 주장하지 않는다. 통합 뇌 기전은 계속 L0/미확립이며, 이번 분석은 기존 L1 관측의 민감도와 입력 가용성을 점검한 것이다.
