# 고정 뉴런 전체 프로토콜과 동적 식별 입력

유형: 연구 검증 원장. 판본일: 2026-09-05. **지위: 전체 recording/command 채널 목록 확보·추가 IC 명령 확인 / `BIO_EVIDENCE_L0` 입력 적격성 / 생물학적 전도도·공간 계량 미확립.**

[시험 펄스 교정 가능성](고정뉴런_시험펄스_교정가능성.md)의 후속으로 같은 Allen experiment 2771, NWB `1552517188.758`의 전체 자극을 조사했다. 중심 device 4와 잎 1·2·5의 고정점 정의는 유지한다. 질문은 **공통 TP의 식별 공백을 보완할 독립 입력과 별도 측정이 실제 파일에 있는가**다.

`acquisition/timeseries`의 전체 89개 시행에서 새 작은 양·음 VC 자극은 발견하지 못했다. 별도 auxiliary TP의 모드까지 배제한 결과는 아니다. 추가 IC 기록에는 뉴런별 양의 단독 입력과, 여러 시행을 결합하면 일곱 방향을 이루는 역치 자극이 있다. **양의 독립 입력만으로도 선형 전달행렬의 대수적 식별은 가능하다.** 부호 반전은 선형성과 작동점 의존성을 검사하는 유용한 수단이며, 모든 식별 문제의 필수조건은 아니다. 따라서 음의 독립 자극이 추가로 없다는 이유만으로 연구를 닫지 않는다.

## 1. 실제 전체 채널 목록

`acquisition/timeseries`와 `stimulus/presentation`을 끝까지 조사했다. sweep 0–88 각각에 일곱 세포의 acquisition·command가 있으며, 총 **623쌍**이다. 모두 시작시각·50 kHz 표본률·표본 수가 대응하고, 누락된 짝이나 별도 미분류 노드는 없었다. 확인한 timeseries에는 세포당 전류 또는 전압 채널 하나와 대응 명령 하나가 있다. 이 범위에서 동시 별도 기준전극·막전압 보정 채널은 확인되지 않았다.

기존 [VC 검사](고정뉴런_전압고정_교차전류_반복성.md)의 0–9번이 `acquisition/timeseries`의 VC 시행 전부다. 그 명령은 약 70 mV·1.5 ms 독립 펄스와 공통 −10 mV TP였다. 나머지 IC 73개 시행(16–88)은 이번에 **명령 배열만** 직접 읽었다. 새 acquisition 반응 배열은 읽지 않았다. protocol 이름만 보고 자극 크기나 실제 발화 여부를 정하지 않았다.

## 2. 추가 IC의 실제 입력 방향

아래 진폭은 기준선에서 변한 **기록 명령 전류**다. 실제 주입 전류 교정값, 뉴런 막전압 변화, 발화 유무를 뜻하지 않는다. 시간은 실제 명령의 구간 분할에서 구했다.

| protocol | 양의 명령 범위 (pA) | 양의 펄스 길이 | 시행별 본 자극 rank | 여러 시행의 의미 |
|---|---:|---:|---:|---|
| FastRheo | 100–1,200 | 3 ms | 1 | 19개 진폭벡터를 합치면 rank 7 |
| Recovery 50 Hz | 281–2,008 | 3.00–3.02 ms | 7 | 세포별 순차 단독 펄스 |
| PulseTrain 20 Hz | 281–2,058 | 3.00–3.02 ms | 7 | 세포별 순차 단독 펄스 |
| PulseTrain 10 Hz | 360–2,058 | 3.00–3.02 ms | 7 | 세포별 순차 단독 펄스 |
| LP FastRheo | 50–600 | 1 s | 1 | 14개 진폭벡터를 합치면 rank 7 |
| If Curve | 84–1,176 | 0.5 s | 7 | 세포별 순차 단독 펄스, 두 6시행 블록 |

Recovery·PulseTrain·If Curve의 음의 명령은 전 세포에 동시에 주는 **−50 pA, 7.5–17.52 ms**의 공통 TP다. FastRheo와 LP FastRheo에는 음의 명령이 없다. 이 추가 기록에서 음의 세포별 단독 자극은 발견하지 못했다. 기존 TargetV 10–15의 별도 음의 입력을 없었던 것으로 취급하지는 않는다.

**시간창 해석 주의:** FastRheo의 본 자극은 **25–28 ms**다. 공통 TP를 피하려고 저장한 `after_50ms` 요약은 이 본 자극까지 제외하므로 rank 0이 나온다. 이를 무자극으로 해석하면 잘못이다. 원래 결과의 전체 명령 구간과 `all_time`은 보존돼 있고 rank 1을 확인한다. 본 표는 FastRheo에는 전체 시간, 나머지에는 실제 구간을 확인한 50 ms 이후 요약을 썼다.

여러 시행의 진폭벡터 rank 7은 중요한 긍정적 입력 조건이다. 같은 전달행렬을 공유한다면 시행들을 묶어 일곱 방향을 추정할 수 있다. 하지만 역치 탐색은 진폭과 활성 채널이 바뀌는 적응적 과정이며, 실제 막 상태·선형성·발화 전 구간의 안정성은 아직 검사하지 않았다. **시행별 rank 1을 전체 식별 불가능으로, 합친 rank 7을 실제 회로 식별 완료로 해석하지 않는다.**

## 3. 별도 저장된 시험 펄스

`/general/testpulse/ITC1600_Dev_0`에는 원장 요약과 별도로 `StoredTestPulses_*` dataset들이 있다. 제한적으로 확인한 이름은 0·1·10·100·1000·10000·10001·10002다. 번호의 크기만으로 정확한 전체 수나 시간 순서를 주장하지 않는다.

| 확인한 항목 | 실제 구조 |
|---|---|
| StoredTestPulses 0·1·10·100 | float32, 1,250×8, gzip |
| StoredTestPulses 1000·10000·10001·10002 | float32, 1,250×7, gzip |
| 부가 metadata 이름 | `IGORWaveNote`, `IGORWaveScaling`, `IGORWaveType`, `IGORWaveUnits` |
| 별도 stimsets | 자극 정의의 `SegWvType`, `WP`, `WPT` dataset들 |
| `stimulus/templates`, `acquisition/images` | 빈 group |

완료된 표적 조사에서는 이 파형의 **dataset 값과 속성 값을 읽지 않고 구조와 속성 이름만 저장했다.** 앞선 실패한 전체 순회 코드에는 속성 값을 읽는 경로가 있었지만 중간 결과를 저장하지 못해 개별 속성의 노출 범위는 확정하지 못한다. 두 코드 모두 TP dataset의 파형 값은 읽지 않는다. 현재 확인된 결과만으로는 열 순서·전류/전압 단위·clamp mode·UTC 시각·TP 평균 방식을 확정할 수 없다. 별도 TP 전체가 독립적인 전극 보정 실험이라고 단정하지 않고, 다음에는 시각·단위·headstage를 확인해 이미 찾은 원장 TP와 대응시켜야 한다.

이 보조 영역의 전체 순회는 추가 수집 8 MiB 한도에 도달해 중단됐다. 첫 표적 조회도 2 MiB 한도와 임시 group 참조의 iterator 오류로 결과를 쓰지 못했다. 캐시를 재사용하고 직접 경로 조회·group 참조 유지로 수정한 표적 조사는 완료했다. 표적별 상태와 시도 이력을 결과에 남겼다. **완료된 전체 acquisition/command 목록과, 일부만 조사한 auxiliary 영역의 범위는 다르다.** auxiliary 전체의 보정 채널 부재를 주장하지 않는다.

## 4. 독립 동적 입력이 해결할 수 있는 범위

**[조건부 수학]** 다음은 생물학적 확인이 아닌 이상적 단자 모형의 식별 정리다. 뉴런의 점·정체를 고정하고, 막용량 $C\succ0$, 막·접합 전도행렬 $G\succ0$, 전극 행렬 $E=\operatorname{diag}(R_s)+r_{\rm ref}\mathbf1\mathbf1^\top\succ0$를 둔다. 초기 상태에서의 증분이 0인 선형·시불변 회로를 가정하면

$$
C\dot v=i-Gv,\qquad i=E^{-1}(U-v),\qquad
H(s)=\left[(sC+G)^{-1}+E\right]^{-1}
$$

는 명령 $U$에서 전류 $i$로 가는 전체 전달행렬이다. 모든 독립 입력에 대한 이상적 $H(s)$가 정확히 알려지면

$$
E=\left[\lim_{s\to+\infty}H(s)\right]^{-1},\qquad
B(s)=\left[H(s)^{-1}-E\right]^{-1}=sC+G.
$$

따라서 $G=B(0)$, $C=[B(s_2)-B(s_1)]/(s_2-s_1)$로 유일하게 구한다. 세포가 둘 이상이면 비대각 $E_{ij}=r_{\rm ref}$, 대각에서 이를 뺀 값이 각 $R_{s,i}$다. 비대각 값이 모두 같은지, 저항이 양수인지는 해당 모형의 검사 조건이다. 이 정리는 **공통 TP의 반례가 모든 독립 입력의 영구적 불가능성을 뜻하지 않음**을 보여 준다.

적용 조건도 엄격하다. $C$가 특이하면 이 보장은 깨질 수 있고, 미지의 측정 필터가 있으면 실제 관측은 $F(s)H(s)$다. 막과 병렬인 기생용량은 총용량에 섞이며, 별도로 더해지는 명령측 용량전류는 고주파 극한을 바꾼다. 충분한 독립 방향, 같은 작동점, 전극·필터의 적합한 관측모형이 필요하다.

또한 **유한 대역이라는 사실만으로 구조적 비식별을 선언하지 않는다.** 선언한 유한차원 모형에서 연속 구간의 정확한 전달행렬은 이론상 유일성을 유지할 수 있다. 실제 유한 표본·잡음에서는 관측 대역 밖 시정수 때문에 복원이 불안정해질 수 있으므로 오차·민감도와 보류 파형 예측을 검사해야 한다. 위 VC 전달 정리를 이번 IC 파형에 그대로 대입하지 않고, IC에서는 주입 전류와 기록 전압의 관측식을 따로 써야 한다.

복원에 성공한 $G$도 먼저 선언한 단자 모형의 행렬이다. 숨은 회로와 직접 접합의 구별, 고정된 위치와 연결 효능을 공간 계량으로 보내는 사상, 구성에 쓰지 않은 방향별 비용 예측은 별도다. 실제 뇌 메트릭의 [PRD 완료 조건](../../.codex/PRD.md)은 남아 있다.

## 5. 자료 노출과 다음 검사

이전에 추출한 전체 numerical 원장에는 **0–88번 시행의 TP 또는 USER 응답·QC 요약**이 포함돼 있다. 이후 acquisition 원파형을 아직 읽지 않았더라도 완전히 미열람인 보류 자료로 취급하지 않는다. 새 모형 수정과 다음 같은 파일의 검사는 개발·적합성 확인으로 기록하고, 독립 비용 검증의 근거와 구분한다.

다음 유효 경로는 두 가지다. 첫째, 별도 StoredTestPulses의 **속성·시각·채널 대응 → 실제 TP 파형 → 전극·필터 관측모형**을 확인한다. 둘째, FastRheo·LP FastRheo의 **여러 독립 진폭벡터 → 발화 전 작은 반응·막 상태의 안정성 → IC 전달모형과 보류 파형 예측**을 검사한다. 입력 조건만으로 실패/성공을 결정하거나 단순히 자극의 양·음 유무만으로 판정하지 않는다. 어느 경로도 통과하지 않으면 그 이유를 남기고, 다른 고정점·측정 조건을 가진 실제 자료에서 후보를 구별해야 한다.
