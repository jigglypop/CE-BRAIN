# RL117의 두 S1/S2 기록 비교

**RL117 run 29의 S2 시험 자극−catch 대비는 −0.020255였다.** 첫 기록 run 26의 −0.018439와 같은 음수 방향이다. 같은 마우스의 반복 기록이므로 독립 동물의 재현으로 세지 않으며, 음수 대비만으로 억제성 연결이나 직접 전달을 확정하지 않는다.

## 자료와 계산

일곱 번째 SessionLite 객체가 접두 4,040,959,148바이트까지 완성된 것을 확인했다. 해당 접두의 SHA-256과 분석 코드 해시는 새 계약에 기록했다. 전체 파일은 아직 수집 중이다. 기존 v2 코드를 변경하지 않고 명목 30Hz 전 창 `[−2,−0.5)`초와 후 창 `[1.5,3)`초의 S2 세포별 평균 차이를 구한 뒤 세포 간 평균했다. easy 자극은 주 대비에서 제외했다.

원래 332시행 중 export에 남은 260시행, S1 280세포와 S2 108세포다. 기존 규칙에 따라 galvo 시각이 유한하지 않은 원래 시행 인덱스 140, 240, 299(0부터 시작)를 제외해 257시행을 집계했다. export에서 빠진 72시행과 추가 시각 제외 3시행을 반응 없음으로 간주하지 않았다. 저장 결과는 260시행의 값과 집계에 사용한 유효 마스크를 모두 보존한다.

S1/S2 상보 마스크, 직접 S2 표적과 catch 표적 없음, 시행 내 일정한 표적, 행동 표지·첫 핥기·원래 시행 인덱스 대응, 유효 시각의 증가, 선택 신호의 유한성 검사를 통과했다. [프레임 시각의 한계](Q_NPF_04_S1S2_프레임시간_민감도.md)는 그대로 적용된다. 명목 0은 정확한 자극 시작 시각이 아니다.

## 결과

| 종류 | 유효 시행 | S2 평균 변화 | 반응 창 핥기 겹침 | 자동 보상 표지 |
|---|---:|---:|---:|---:|
| catch | 85 | +0.010854 | 13 | 0 |
| 시험 자극 | 100 | −0.009401 | 8 | 13 |
| easy | 72 | −0.039942 | 5 | 9 |

전후 창을 함께 −1, 0, +1프레임 이동한 시험 자극−catch 대비는 각각 −0.020244, −0.020255, −0.019845였다. 세 창 모두 음수지만 이는 통계적 신뢰구간이나 독립 검증이 아니다.

[첫 RL117 기록](Q_NPF_04_S1S2_RL117_첫비교.md)의 명목 핥기 겹침은 catch 26/110, 시험 자극 30/119였다. 이번에는 catch 13/85, 시험 자극 8/100이다. 자동 보상 표지도 시험 자극에서 4/119에서 13/100으로 달랐다. 따라서 두 기록의 같은 대비 부호를 동일 행동·보상 상태의 결과로 해석할 수 없다. 자동 보상 표지는 실제 물 전달 시각이 아니다.

## 판정과 다음 조건

현재 세 마우스의 일곱 세션에서 J064는 음수·양수·음수, RL070은 양수·양수, RL117은 음수·음수다. 이번 질문에는 RL117의 두 번째 기록에서도 음수 대비가 관찰됐다는 답을 얻었다. 마우스 간 공통 부호는 관측되지 않았지만, 마우스 차이의 통계적 확립이나 보편 가설의 반증을 수행한 것은 아니다. 세포 구성과 형광 척도의 동일성, 같은 세포의 종단 대응도 확보되지 않았다.

주장 상한은 탐색적 범위고정 관측 `BIO_EVIDENCE_L1`이다. 직접 전달·공통 입력·행동·보상의 기여는 여전히 미식별이며 전체 뇌 구조는 미확립이다. 다음은 RL117의 남은 기록과 다른 마우스의 완성된 세션에 같은 방법을 적용하는 것이다. 전체 파일 무결성과 실제 프레임·보상 시각은 별도 확인 조건으로 남는다.
