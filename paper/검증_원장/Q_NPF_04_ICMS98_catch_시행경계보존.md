# ICMS98 실제 catch의 시행 경계 보존 비교

**시행 경계를 지킨 계산에서도 적격 13개 unit 모두 양의 PC가 남았다.** 같은 내부 발화만 사용하면 연결된 신호와 시행별로 처리한 신호의 PC가 일치했다. 따라서 앞선 합성 반례가 실제 자료의 모든 양의 결합도를 설명한다고 볼 수 없다.

## 질문과 자료

[연결 경계 합성 반례](Q_NPF_04_ICMS_결합도_연결경계_합성반례.md)에 이어, 원래 사건 시각과 바퀴 기록으로 창을 확인한 ICMS98 2023-10-24의 36개 catch를 재사용했다. 기존의 좋은 시행·응답 표지 없음·기록 범위·자극 중첩 규칙을 유지했다. 각 시행 시작 +0.8∼+1.3초의 500ms 창을 사용했다.

이 검사는 비과제군 저자 추정량의 직접 재현이 아니다. 모든 21개 unit을 사용하고 대상 unit을 제외한 집단 발화를 1ms bin으로 계산했다. 10ms Gaussian smoothing은 4표준편차에서 절단했다. 전체 시간 길이를 마지막 발화로 정하지 않고 36×500ms로 고정했으며, 모든 방식에서 같은 smoothing 전 집단 평균을 차감했다.

세 방식을 비교했다: 창들을 연결한 전체 유효 trigger, 같은 연결 신호에서 각 시행 내부 trigger만 사용한 값, 시행별 smoothing 후 같은 내부 trigger만 사용한 값이다. 내부 trigger는 500개 bin 중 index 100–399로, ±100ms 창이 시행 안에 들어오도록 했다. 비교 방향은 내부 발화가 50개 이상인 unit에서만 요약했다.

## 결과

21개 중 13개 unit이 내부 발화 50개 기준을 충족했다. 그 unit들의 연결 방식 trigger는 합계 3,554개, 시행 내부 trigger는 2,222개였다. 이 합계는 독립 표본 수가 아니다. 동일 집단 활동과 시행을 공유한다.

13개 모두 연결 전체 PC와 시행 내부 PC가 양수였다. 같은 내부 trigger를 사용하는 두 smoothing 방식의 값은 허용오차 내에서 일치했다. 이는 smoothing의 최대 영향 범위 40ms보다 내부 여유 100ms가 큰 설정과 일치한다.

반면 연결 전체와 시행 내부 PC 사이에는 값 차이가 있었고, 적격 unit의 최대 절대 차이는 약 16.780Hz였다. 예를 들어 unit 3은 160.361에서 177.140Hz, unit 14는 55.457에서 54.702Hz로 변했다. 이 차이에는 trigger 선택 차이가 섞이므로 전부를 경계 누출 편향으로 부르지 않는다. 기준 미달 8개 unit은 0효과로 처리하지 않았다.

## 해석과 다음 조건

원래 질문에 대해, 이 고정 catch 창의 양의 PC는 내부 경계 창을 제외해도 남았다. 합성 경계 반례는 가능한 실패 방식이고, 이번 결과는 해당 방식만으로 이 관측의 모든 양성을 설명할 수 없다는 제한이다. 두 결과는 모순되지 않는다.

남은 결합도는 공통 입력, 과제 상태, 시행별 발화율 변화, 실제 상호작용 등 여러 원인과 양립한다. 직접 연결·신호 전달 방향·학습 인과효과로 승격하지 않는다. 이 범위의 실제 발화 동반성 관측 상한은 `BIO_EVIDENCE_L1`이며 전체 뇌 인과 구조는 미확립이다.

다음에는 시행 경계를 보존한 대조로 같은 시행의 동반 활동이 시행별 평균 상태만으로 설명되는지 확인해야 한다. 대조는 구간을 무작정 연결하거나 동일 세포를 독립 표본으로 세지 않아야 한다. 그 전에는 양의 PC를 기전적 결합으로 해석하지 않는다.
