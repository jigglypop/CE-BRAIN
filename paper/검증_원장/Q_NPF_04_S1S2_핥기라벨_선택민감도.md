# S1–S2 핥기 라벨 선택 민감도

저자 로더의 라벨 변경 대상 중 기존 test–catch 비교에 포함된 test 48개를 제외해도, 11개 세션 모두 무보정·보정 계수의 부호는 바뀌지 않았다. 이 규칙만으로 세션별 반대 방향이 해소되지는 않는다. 다만 대비 크기는 달라진다. 이는 사후 행동 선택의 민감도이며 자극 총효과나 직접 전달 경로의 입증이 아니다. BIO_EVIDENCE_L1을 유지한다.

## 판정과 검증

행동에 따른 추가 선택을 하지 않은 집합을 주 분석으로 유지한다. ‘전체’는 기존 피클의 유한 시각 catch/test 집합을 뜻하며, 신경 기록이 없는 원래 시행까지 포함한 것은 아니다. 부호 유지가 모든 제외 규칙에 대한 강건성이나 통계적 확립을 뜻하지 않는다. 원래 빠진 275개 시행의 문제도 해결하지 않는다.

[계약](../../verify/Q-NPF-04/allen_synphys/rowland_lick_selection_contract.json)을 계산 전에 저장했다. [코드](../../verify/Q-NPF-04/allen_synphys/rowland_lick_selection.py)는 전체 집합 계수가 기존 결과와 일치하는지, 제외가 test에만 적용되는지, 총 48개인지 확인했다. 무보정 계수 변화는 제외 비율과 두 test 부분집합 평균 차이의 곱으로도 독립 대조했다. 모든 선형 모형은 rank·조건수·잔차화 검사를 통과했다. [결과](../../verify/Q-NPF-04/allen_synphys/rowland_lick_selection_result.json)에 인덱스와 정밀 수치를 보존했다.

뇌 구조 규명에는 아직 답하지 못했다. 이번 비교에서는 특정 핥기 라벨 선택이 방향 차이를 없앤다는 예상이 성립하지 않았다. 다음은 기록 누락에 대한 민감도와 배정 이력을 반영한 총효과 분석 가능성을 평가하는 것이다. 추가 회귀항이나 행동 선택을 직접 연결 증거로 승격하지 않는다.
