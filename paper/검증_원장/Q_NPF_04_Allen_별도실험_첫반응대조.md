# 별도 실험의 고정 선택과 첫 반응 대조

개발 실험 3337 밖에서 진폭과 무관한 ID 순서로 선택한 실험 3338, pair 104345의 첫 20개 IC 기록을 확인했다. 제작자의 역필터링 진폭에서 할당된 기준선 진폭을 뺀 값은 평균 +15.45 µV, 중앙값 +38.18 µV, 양수 12/20이었다. 다른 실험에서의 관측이지만 독립 동물 복제나 강한 연결 검증으로 해석하지 않는다.

## 선택 규칙

전체 목표인 뇌 구조·기전 규명을 위해, [측정법 수치 재현](Q_NPF_04_Allen_역필터링진폭_수치재현.md)에 사용한 20시행을 개발 자료로 남기고 별도 기록을 확인했다. 선택 전에 다음 규칙을 저장했다.

mouse VisP, 같은 프로젝트·내부액·외부액·32도 조건, 시냅스전 흥분성 분류와 양쪽 표적 L5, 알려진 흥분성 연결, 유효한 지연·상승·감쇠 값을 요구했다. 다른 slice이며 실험 ID가 3337보다 큰 후보 중 실험 ID와 pair ID가 가장 작은 하나를 택했다. 진폭이나 QC 점수로 순위를 매기지 않았다. 시냅스후 세포의 비시냅스성 흥분성 분류는 개발 pair에서 미확인이므로 이번 조건에도 새로 요구하지 않았다.

선택된 실험의 IC 기록 28개를 DB 시작 시각·기록 ID로 정렬해 첫 20개를 사용했다. 각 기록에서 시냅스전 자극 시작이 가장 빠른 응답 하나를 사용했다. 적합 진폭과 QC를 본 뒤 기록을 교체하지 않았다.

## 독립성 한계

| 항목 | 개발 자료 | 새 선택 |
|---|---|---|
| 실험 ID | 3337 | 3338 |
| 외부 ID | 1574292898.139 | 1574282818.996 |
| slice ID | 2869 | 2870 |
| pair ID | 104272 | 104345 |
| 표본 이름의 말미 | 499168.06.06 | 499168.09.06 |

실험 ID 순서는 시간 순서를 뜻하지 않는다. 두 표본 이름에 같은 `499168` 문자열이 있으므로 서로 다른 동물이라고 단정하지 않는다. 현재 확인 범위는 별도 실험·별도 절편이다. 제작자 파형 파라미터가 어떤 기록 전체에서 추정됐는지도 미확인이어서 엄밀한 독립 calibration holdout은 아니다. 알려진 양성 pair의 적합을 살피는 검사이므로 연결 발견의 눈가림 시험이 아니다.

## 관측 결과

선택된 20개는 모두 `Y4_SRecovery_50H_DA_0`이며 기록 시작 시각은 DB 기준 2019-11-20 13:50:13.904–13:56:02.710이다. 시냅스전·후 전극 외래키가 선택한 pair와 일치했다. 첫 반응 20개 모두 저장된 흥분성 QC를 통과했고 응답·기준선 역필터링 환산 진폭이 있었다.

| 지표 | 값 |
|---|---:|
| 사용 가능 / 선택 기록 | 20/20 |
| 응답−기준선 평균 | 15.45 µV |
| 응답−기준선 중앙값 | 38.18 µV |
| 차이 범위 | −347.27–294.84 µV |
| 양의 차이 | 12/20 |

단위는 이전 개발 자료의 두 표적 차이가 아니라, 선택한 양성 표적의 제작자 진폭과 해당 기준선의 차이다. 원시 적합을 이 새 실험에서 다시 계산한 결과는 아니다. 저장값 조회에는 기존 medium 범위 캐시를 재사용하고 3,145,728바이트를 추가 받았다.

## 판정과 다음 조건

첫 반응의 평균·중앙값은 양수지만 시행별 부호와 진폭은 섞인다. 이 한 실험의 조건부 관측은 `BIO_EVIDENCE_L1` 범위이며 반복 검토한 개발 자료에서 벗어났다는 이유로 상위 증거가 되지 않는다. 같은 양성 표지의 존재를 새로 입증하거나 반증한 것은 아니다.

다음에는 동물 단위 독립성을 확인하고, 반복 자극의 전체 기록을 사용할 경우 첫 20개 선택과 남은 기록의 역할을 구분해야 한다. 현재 작은 평균을 키우기 위해 새 pair나 좋은 기록으로 교체하지 않는다. 실제 뇌 구조·기전의 확인에는 독립 단위와 입력·상태·측정 대조를 갖춘 자료가 여전히 필요하다.
