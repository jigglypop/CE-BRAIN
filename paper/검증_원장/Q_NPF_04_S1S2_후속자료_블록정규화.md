# 후속 자료의 블록별 정규화

확보한 생성 코드에서 각 조건 블록의 전체 평균 형광을 분모로 사용하는 정규화를 확인했다. 조건 간 반응 크기를 비교하기 전에 분모 차이와 시간 분할의 정보 공유를 검토해야 한다. 실제 RL127의 전처리 재현은 파일 완성 후 수행한다.

`dfof2`는 각 세포에 대해 `(F − 블록 평균 F) / 블록 평균 F`를 계산한다. 호출부는 조건별 `self.frames`를 선택해 이 함수를 적용하고, 같은 블록의 정규화 전 형광도 `raw`에 저장한다. 이 `raw`는 이미 neuropil 계수 0.7을 적용한 형광이며 카메라 원시 영상은 아니다.

이후 시행 전 평균을 빼더라도 블록별 분모는 남는다. 같은 세포·같은 원래 형광 변화라도 조건별 블록 평균이 다르면 정규화 반응 크기가 달라질 수 있다. 또 전후반을 분리해 예측하더라도 블록 전체 평균으로 만든 입력은 후반 정보를 포함한다.

합성 사례에서 전반 원래 형광을 `[10,12]`로 같게 두고 후반만 바꿨다. 전체 평균이 11에서 21로 바뀌자 같은 전반 변화 2의 정규화 크기는 약 0.1818에서 0.0952로 달라졌다. 이는 실제 신경 효과가 아니라 함수 동작을 확인한 예다. [검사 결과](../../verify/Q-NPF-04/allen_synphys/mechanisms_normalization_audit.json)에 입력·출력·소스 해시를 보존했다.

다음에는 도착한 `raw`와 `dfof` 배열의 대응을 확인하고, 조건 간 공통 기준 또는 학습 구간만 사용하는 기준이 가능한지 판단한다. 조건별 정규화 수치만으로 투사 집단의 전달 강도를 비교하지 않는다. 같은 시계열을 여러 기준으로 바꾸는 검사를 독립 생물학적 복제로 세지 않는다. 다운로드는 기존 프로세스에서 계속 중이며 뇌 구조는 미확립이다.
