# ICMS101 첫 세션: 고정 비교의 두 번째 외부 적용

ICMS101에서도 고정한 시간 구간별 catch 차감 평균은 **모든 전류에서 음수**였다. 각 전류가 관측된 구간별 평균도 모두 음수였다. 그러나 12·13 µA에서는 unit 중앙값이 양수여서 평균 방향을 모든 세포의 반응으로 확대할 수 없다.

## 입력과 규칙

[외부 5마리 계약](../../verify/Q-NPF-04/allen_synphys/icms_external_first_sessions_contract.json)의 ICMS101 첫 세션 `2023-10-27`을 사용했다. 파일 77,202,806바이트를 획득하고 서버 SHA-256과 일치함을 확인했다. ICMS100에 사용한 분석 코드와 상위 계약의 해시가 동일한지 확인한 뒤 실행했다. 반응을 보고 세션·전류·창을 바꾸지 않았다.

400개 시행과 10개 unit이 있었다. 좋은 시행은 374개, 그중 catch는 39개다. 명목 자극 규격은 100 Hz·70펄스·0.7초로 계약과 일치했다. 전 −0.7~−0.2초, 후 +0.8~+1.3초 창은 모두 다른 자극과 겹치지 않았고 세션 길이 대리 범위 안이었다. unit별 연속 검출을 독립적으로 확인한 것은 아니다.

400개 시행을 네 등분하고 같은 구간 catch의 unit별 전후 변화를 뺐다. 각 전류의 관측 구간에 catch가 있어 모든 대비를 정의할 수 있었다. 좋은 시행을 기본으로, 전체 품질 시행도 보존했다.

## 누적 판정

[ICMS100](Q_NPF_04_ICMS_외부첫세션_ICMS100.md)과 ICMS101에서 사전에 정한 평균 방향이 관찰됐다. 두 동물 모두 평균과 unit별 방향이 항상 일치하지 않았다. 전류 집합과 행동·훈련 상태가 다르므로 단순히 합쳐 보편적인 용량 반응이나 균일한 억제 기전을 주장하지 않는다.

고정 외부 5마리 중 2마리 완료다. ICMS83·ICMS92·ICMS98은 미획득·미실행이며 전체 방향 확인은 아직 미완료다. 다음은 크기순으로 고정된 ICMS83 첫 세션을 같은 코드로 확인한다. 비교 불가나 방향 반례가 나오면 대상을 교체하지 않고 그대로 기록한다.

현재는 실제 기록의 범위 제한 `BIO_EVIDENCE_L1` 관측이다. 무작위 배정·직접 경로·행동 매개·영상 동일세포 연결의 한계는 남으며 전체 뇌 인과 기전은 미확립이다.
