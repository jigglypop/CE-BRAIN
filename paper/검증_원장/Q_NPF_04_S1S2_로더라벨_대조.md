# S1–S2 로더 라벨 변환 대조

## 결과

저자의 `LinearModel.too_sooner` 메서드를 대조했다. 이 메서드는 배열을 삭제하지 않고 `outcome`을 변경한다. hit 중 첫 핥기가 150ms 미만이거나 핥기 기록이 없으면 라벨을 바꾼다. 저장 배열의 문자열 길이가 4이므로 실제 결과는 `too_`다. 따라서 [직전 기록](Q_NPF_04_S1S2_전체시행_배정과제외.md)의 ‘제외 처리’는 이 단계에서는 정확히 **후속 분석에서 구분할 라벨 변경**을 뜻한다. 각 후속 분석의 필터까지 확인한 것은 아니다.

11개 세션에서 총 103개의 라벨이 바뀌었다. 첫 핥기 150ms 미만 97개와 핥기 기록이 없는 hit 6개다. 현재 유한 시각을 요구하는 test–catch 비교의 test 중 48개가 이 조건에 해당한다. 핥기 누락의 원인은 저자 주석과 별개로 독립 확인하지 못했다.

- [Subsets 고정 판본](https://github.com/Packer-Lab/Vape/blob/a2e2a7ec94f6e7d24917f93f1452cad9a5ba8e92/utils/subsets_analysis.py): Git blob `000cba1be708e502ab28c9c690c29ee9555dcfa9` 확인.

Subsets 코드는 시행 설명을 읽는 파서이며 배정 생성기가 아니다. 과제 이름 `opto_stim_scope_threeway`는 확인했지만, 이번 정확한 이름 웹 검색에서는 생성 코드를 찾지 못했다. 검색 실패는 코드가 공개되지 않았다는 증거가 아니다.

[대조 코드](../../verify/Q-NPF-04/allen_synphys/rowland_loader_audit.py)는 검토한 단일 메서드만 AST로 격리해 실행했다. 전체 로더나 피클 내부 함수를 실행하지 않았다. 149·150·151ms 경계와 누락 기록의 합성 사례를 검사하고, 실제 11개 세션에서 독립 조건식과 변경 인덱스가 일치함을 확인했다. [결과](../../verify/Q-NPF-04/allen_synphys/rowland_loader_audit_result.json)에 원래 시행 인덱스와 유형별 변경 수를 보존했다.

## 분석 결정

현재 총효과 탐색의 주 집합은 행동 결과로 추가 제외하지 않는다. 위 48개를 제외한 비교는 사후 행동 선택의 영향을 보는 민감도로만 해석한다. 이 선택을 논문 재현이나 더 정확한 인과 추정으로 부르지 않는다. 신경 기록이 없는 시행의 누락 가정과 배정 확률은 여전히 별도 문제다.

이번 결과는 자료 처리의 차이를 확인한 것으로 BIO_EVIDENCE_L1을 유지한다. 직접 연결과 전체 뇌 구조는 미확립이다. 다음에는 동일한 반응 요약을 재사용해 라벨 선택이 대비에 미치는 크기를 확인하고, 주 분석과 선택된 집합의 결과를 나란히 남긴다.
