# S1/S2 두 번째 세션의 반대 방향 대비

**같은 마우스 J064의 run 11에서 S2 시험 자극−catch 대비는 첫 세션과 반대 방향이었다.** 첫 세션의 음수 대비를 이 마우스의 안정적인 특징으로 일반화할 수 없다. 이는 S1→S2 전달 자체가 없다는 반증이나 흥분·억제 기전의 전환 증거가 아니다.

## 입력과 방법

공개 Rowland 자료의 두 번째 SessionLite 객체가 완전히 도착했음을 확인했다. 객체 종료까지 804,246,725바이트의 접두 구간 해시를 새 계약에 기록했다. 전체 파일은 계속 수집 중이며, 전체 서버 원본과의 무결성 대조는 아니다. 대상은 J064 run 11, 원래 176시행 중 보존된 166시행, S1 536세포·S2 252세포다. 모든 보존 시행에 행동 표지와 원래 시행 인덱스가 대응했다.

S1/S2 마스크는 상보적이며 S2 직접 표적과 catch 표적은 없었다. 표적 마스크는 시행 내 시간축에서 일정했다. 166시행 모두 별도 첫 핥기 값과 원래 lick 배열의 첫 값이 일치했다. 선택 신호 창은 유한하며 30Hz·420프레임, 전 240프레임·artifact gap 0의 구조다. 이 검사들이 실제 광학 잡음의 부재를 증명하지는 않는다.

[첫 세션](Q_NPF_04_S1S2_첫세션_대응과반응.md)과 같은 명목 전 구간 `[−2,−0.5)`초와 후 구간 `[1.5,3)`초를 사용했다. 세포별 후−전 평균을 S2 세포 간 평균한 export 형광 척도다. 150세포 easy 시행은 주 대비에서 제외했다. 첫 결과를 본 뒤 정한 탐색적 후속 비교이며 독립 확인시험이 아니다. [시간축 보완](Q_NPF_04_S1S2_프레임시간_민감도.md)에 따라 이 축은 정확한 시행별 물리 시각이 아니다.

## 관측

| 세션 | catch 수 | 시험 자극 수 | S2 시험 자극−catch | 시험 자극 lick 겹침 | catch lick 겹침 |
|---|---:|---:|---:|---:|---:|
| J064 run 10 | 61 | 54 | −0.001081 | 37/54 | 14/61 |
| J064 run 11 | 44 | 60 | +0.001270 | 36/60 | 11/44 |

run 11의 명목 창 평균은 catch −0.007009, 시험 자극 −0.005739다. 양수 대비는 시험 자극 평균 자체가 양수라는 뜻이 아니다. easy는 62시행이며 주 대비에 넣지 않았다. 자동 보상 표지는 시험 자극 2회, easy 1회였다. 보상 상태 표지는 실제 물 전달 시각으로 취급하지 않았다.

전후 신호 창을 함께 한 프레임 앞·뒤로 이동한 run 11 대비는 각각 +0.000695, +0.001394였다. 같은 이동에서 시험 자극의 lick 겹침은 36/60, 35/60이고 catch는 12/44, 10/44였다. 첫 세션 대비는 세 창 모두 음수였으므로 이번 부호 차이는 이 한 프레임 선택만으로 사라지지 않는다. 실제 frame clock 전체가 없으므로 이 점검을 모든 시간 오차에 대한 보장으로 확대하지 않는다.

## 판정

이번 질문에는 동일 정의의 두 번째 세션에서 대비 방향이 재현되지 않았다는 답을 얻었다. 같은 마우스 안에서도 이 집단 평균 대비의 부호가 달랐으며, 행동 겹침은 두 세션 모두 시험 자극에서 높았다. 이 자료만으로 어느 요인이 부호 차이를 만들었는지 식별하지 못했다. 효과 크기의 통계적 차이나 인과효과를 확정한 것은 아니다.

두 세션은 한 마우스의 반복 기록이다. 세포·시행·세션 수를 독립 동물 수로 세지 않고, 세션 간 같은 세포가 종단 등록됐다고 가정하지 않는다. 현재 상한은 제한된 탐색적 관측 `BIO_EVIDENCE_L1`이다. 전체 뇌 인과 구조와 직접 전달·공통 입력·행동 경로의 기여는 미확립이다.

다음은 수집을 유지하며 다른 마우스의 완전한 객체를 확인하고 동일 정의를 적용하는 것이다. 같은 마우스의 다음 기록은 세션 간 변동으로 별도 표시한다. 전체 파일 무결성과 실제 시간·보상 시각의 확보 여부는 계속 별도 조건으로 남는다.
