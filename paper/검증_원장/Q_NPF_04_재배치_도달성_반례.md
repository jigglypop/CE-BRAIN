# Q-NPF-04 — 재배치 방법의 도달성 반례

작성일: 2026-09-05. 지위: 계산 방법 감사, **BIO_EVIDENCE_L0**. 실제 뇌 구조의 새로운 관측이나 반증은 아니다.

## 질문과 판정

[120블록 연장](Q_NPF_04_MICrONS_재배치_연장.md)에서 평균의 시간 변화는 줄었지만, 기존 두 연결 교환이 허용 그래프 전체를 방문하는지는 미확인으로 남았다. 이번에는 네 노드의 자기 연결 없는 유향 그래프 4,096개를 전부 열거했다. 원래 교환 함수를 직접 호출하고, 연결 수·종류 조건이 같은 그래프들을 묶어 도달 가능한 집합과 상호연결 평균을 계산했다. 실제 자료를 추가 다운로드하지 않았다.

**기존 교환 방법은 일반적으로 허용 공간 전체를 탐색하지 못하며, 도달 가능한 부분에 따라 상호연결 평균도 달라질 수 있다.** 이는 계산 방법에 대한 반례다. 실제 1,348개 세포의 MICrONS 허용 공간이 분리됐거나 현재 추정값에 특정 크기의 편향이 있다는 증명은 아니다.

## 전수 검사

조건은 실행 전 별도 계약에 고정했다. 모든 경우에 노드별 들어오는 연결 수와 나가는 연결 수를 보존한다. 세포 종류는 노드 0·1과 2·3을 각각 같은 종류로 놓았다. 거리 조건 사례는 일직선 좌표 0, 40, 110, 250과 기존 거리 문턱 50, 100, 200, 400, 800을 사용했다. 합성 좌표이며 생물 측정값이 아니다.

| 추가 조건 | 같은 조건의 그래프 묶음 수 | 기존 교환으로 분리된 묶음 | 부분별 상호연결 평균이 다른 묶음 | 삼각 순환 반전 추가 후 분리된 묶음 |
|---|---:|---:|---:|---:|
| 없음 | 2,656 | 16 | 0 | 0 |
| 방향별 세포 종류 연결 수 | 3,312 | 260 | 124 | 62 |
| 방향별 세포 종류·거리 구간 연결 수 | 4,032 | 64 | 0 | 0 |

삼각 순환 반전은 세 노드의 단방향 순환 세 연결을 모두 뒤집는 이동이다. 역방향 연결이 이미 있거나 종류·거리별 개수가 바뀌면 허용하지 않았다. 두 이동 모두 모든 허용 전이에 대해 역전이의 존재와 조건 보존을 검사했다. 삼각 반전을 더해도 세포 종류 조건에서는 62개 묶음이 분리된다. 이번 네 노드 검사에서 그 부분별 평균 차이는 0이었지만, 큰 그래프에서도 같다는 보장은 없다.

## 직접 확인할 수 있는 반례

다음 세 그래프는 노드별 출력 수 (2, 1, 1, 0), 입력 수 (1, 1, 1, 1)이 같다. 종류 A={0,1}, B={2,3}의 방향별 연결 수도 A→A 1개, A→B 2개, B→A 1개로 같다.

| 그래프 | 연결 목록 | 상호연결 쌍 수 |
|---|---|---:|
| 85 | 0→1, 0→3, 1→2, 2→0 | 0 |
| 99 | 0→1, 0→2, 1→3, 2→0 | 1 |
| 142 | 0→2, 0→3, 1→0, 2→1 | 0 |

이 조건을 만족하는 그래프는 정확히 세 개다. 기존 교환으로 85와 99는 오갈 수 있지만 142는 고립된다. 각 도달 부분을 균등하게 방문한다고 해도 평균은 각각 1/2과 0이다. 전체 세 그래프를 균등하게 방문한 평균 1/3과 다르다. 반복을 무한히 늘리는 것만으로 이 차이가 사라지지는 않는다. 이 반례는 거리 조건을 추가하지 않은 경우에 해당한다.

## 기존 결과에 미치는 영향과 다음 단계

원 관측 그래프와 연결 수·종류·거리 조건이 같으면서 상호연결 수가 낮은 대체 그래프가 실제로 존재한다는 기존 결론은 유지된다. 그러나 경로 평균을 전체 조건부 기대값으로 간주하는 일반적 보장은 반증됐다. 기존 보고서는 그러한 보장을 주장하지 않았으며, 이번 반례로 그 한계가 구체화됐다.

다음에는 실제 MICrONS 조건에서 더 넓은 이동을 적용하고 시작 상태 및 이동 규칙에 따른 민감도를 비교해야 한다. 작은 반례가 해결됐다는 이유만으로 큰 공간의 연결성이나 균등성을 선언하지 않는다. 이 감사만으로 생물학적 초과 연결·인과 기전·전체 뇌 구조는 확립되지 않았다.
