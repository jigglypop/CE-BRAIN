# ICMS 집단 결합도의 구간 연결 경계: 합성 반례

**원래 시간에서 가까운 사건 쌍이 없어도 구간 연결 후 양의 결합도가 계산되는 합성 반례를 확인했다.** 이 결과는 실제 동물의 결합도가 모두 인공적이라는 주장이 아니다. 내부 연결 경계를 보존하지 않는 측정이 짧은 지연의 관계를 만들 수 있다는 계산상 한계다.

## 검사한 경로

[STPR 복원 검사](Q_NPF_04_ICMS_STPR_복원과시간비대칭.md)에 이어 보유 저자 코드의 `concat_segments_rebased`와 `compute_stpr_and_pc` 두 함수만 AST로 추출했다. 모듈 전체를 실행하지 않고 필요한 NumPy·Gaussian 함수만 제공했다. 코드와 입력 정의를 계산 전에 해시와 함께 저장했다.

구간 연결 함수는 선택한 구간 사이의 실제 공백을 제거한다. STPR 함수는 전체 연결 시계열의 양 끝만 확인하며 내부 연결 경계를 전달받지 않는다. smoothing과 원형 이동 대조도 연결된 시계열에서 수행한다.

## 합성 입력과 결과

10초마다 시작하는 1초 길이 구간 240개를 만들었다. 대상 unit은 짝수 구간 종료 5ms 전, 다른 unit은 다음 홀수 구간 시작 5ms 후에 발화하도록 했다. 이는 생물 실험이 아니라 경계가 정확히 알려진 입력이다.

| 항목 | 결과 |
|---|---:|
| 원래 시간의 대응 사건 간격 | 9.010초 |
| 연결된 시간의 대응 간격 | 10ms |
| 원래 ±100ms 안의 다른 unit 사건 쌍 | 0 |
| 대상 발화 수 | 120 |
| 저자 함수가 사용한 trigger 수 | 119 |
| 원래 구간 안에 ±100ms 창이 모두 들어가는 trigger 수 | 0 |
| 계산된 PC | +22.891 |
| 원형 이동으로 정규화한 PC | +44.298 |
| STPR 최고점 지연 | +10ms |

기본 1ms bin·10ms smoothing·±100ms 창, 200회 원형 이동, seed 0을 사용했다. 119개 trigger는 생산 코드의 최소 50개 조건도 넘는다. 반면 원래 구간 경계를 지키면 모든 대상 발화의 창이 경계에 걸리므로 결과는 ‘효과 0’이 아니라 `UNASSESSED_NO_VALID_TRIGGERS`다.

## 판정과 실제 자료의 한계

이번 반례는 양의 PC나 10ms 최고점이 있다는 사실만으로 원래 시간의 가까운 신경 상호작용을 보장할 수 없음을 보였다. 높은 원형 이동 정규화 값도 이 입력에서는 경계 연결로 생긴 동시성을 배제하지 못했다. 정규화의 통계적 유의성을 검정한 것은 아니다.

합성 예의 수치를 실제 903개 곡선의 편향 크기로 옮기지 않는다. 실제 자료에서 경계를 가로지른 trigger 수, 각 구간의 검출 상태와 경계 없는 결과는 저장된 평균 곡선만으로 복원되지 않는다. 기존 PC–STPR 내부 일치 결과는 유지되며, 그것이 원래 시간축의 타당성을 증명하지는 않는다.

등급은 `BIO_EVIDENCE_L0` 합성 계산 반례다. 전체 뇌 인과 구조는 미확립이다. 이 집단 결합도 경로를 기전 증거로 올리려면 원래 구간 정보를 보존한 계산, 경계별 smoothing 또는 경계 제외 규칙, 구간을 보존한 대조가 필요하다. 실제 구간별 입력이 없으면 이를 구현만 해 놓고 실자료 검증이 끝났다고 보고하지 않는다.

이로써 현재 비과제 요약만으로 직접 경로를 판정하는 시도에는 구체적인 측정 한계가 확인됐다. 후속 연구는 이 자료의 요약 검사를 계속 늘리는 대신, 원래 사건·구간이 보존된 자료에서 동일한 측정의 타당성을 확인하는 쪽으로 전환해야 한다.
