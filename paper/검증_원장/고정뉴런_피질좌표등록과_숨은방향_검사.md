# 고정 뉴런의 피질 좌표 등록과 숨은 방향 검사

문서 유형: 검증 원장(ledger). 작성일: 2026-09-06 KST. 판본: `allen-cortical-registration-audit-v1`.

**좌표 대응은 많은 실험에서 정밀하게 근사할 수 있었지만, 그 대응만으로 실제 3차원 피질 법선이나 공간 계량을 정할 수는 없었다.** 같은 마우스 VisP 세포의 3D 위치와 2D 이미지 위치를 대조했다. 공통 비교 표본 1,270개 실험·8,457개 세포에서 단순 XY similarity의 세포 보류 RMSE는 3.45 µm, 일반 3D affine은 9.74 µm였다. 첫 모형의 실험별 RMSE 중앙값은 0.177 µm였으나 큰 오차를 보이는 실험도 남았다.

| 판정 대상 | 상태 | 의미 |
|---|---|---|
| 같은 세포의 3D/2D 좌표 사상 | 개발 자료에서 계산 완료 | 위치·단위의 독립 교정은 아님 |
| 2D 단위 이상과 생성 코드의 관계 | 가능한 생성 경로를 확인 | 현재 snapshot이 실제 DB 생성 판본이라는 확인은 없음 |
| 저장 깊이의 국소 affine gradient | 일부 표본에서 식별·안정성 계산 가능 | 독립 측정한 실제 pia 법선은 아님 |
| 영상 사상에서 완전한 3D SPD 비용 복원 | 유일하지 않음 | 숨은 방향에 서로 다른 양의 비용을 둘 수 있음 |
| 새로운 연결 표지·전류·호르몬 endpoint | 이번 단계에서 미검사 | 이전 생물학적 판정은 보존 |

이번 산출물의 지위는 **`BIO_EVIDENCE_L0`인 좌표·생성 코드 검사와 조건부 수학**이다. 실제 관측 자료를 읽었다는 사실만으로 새로운 기전의 생물학적 지지를 부여하지 않는다.

## 1. 이번 단계가 필요한 이유

[직전 연결확률 검사](고정뉴런_구조거리와_연결확률_검사.md)는 3D 세포체 거리의 예측 정보를 확인했으나, 별도 2D 피질 좌표를 3D 방향과 섞지 않았다. [PRD](../../.codex/PRD.md)의 다음 요구는 고정한 점 위에서 방향별 기능과 메트릭을 연결하는 것이다. 따라서 이번 질문은 **같은 점의 이미지 대응이 얼마나 재현되며, 그 대응으로 어떤 방향까지 구별할 수 있는가**다.

뉴런 위치는 기존 기록에 고정했다. 연결 표지를 조회하거나 새 확률식을 적합하지 않았다. 세포 좌표를 이용한 등록 모형과 저장 깊이의 관측 일관성을 검사하고, 그 정보만으로 빠지는 3D 비용 성분을 수학적으로 구분했다. [대안 공리](고정뉴런_리만메트릭_대안공리_후보원장.md)의 A004(좌표 오차), A006(피질 방향), A024(목적별 계량)에 해당하는 선행 검사다.

## 2. 두 좌표 필드의 생성 경로

3D 위치와 2D 위치는 아래 두 입력 경로에서 저장된다. 현재 보유한 소스는 동일하게 고정된 `b187927abf1e8df46d11b47eeb88c8e2c76aee3c` 판본이며 모든 역사적 DB 행의 실제 생성 판본이라는 주장은 하지 않는다.

| 필드 | 확인한 생성 경로 | 남은 정보 |
|---|---|---|
| `cell.position` | `site.mosaic`의 세포 marker 위치를 읽고 DB에 저장 | 원 mosaic과 촬영·등록 변환을 이번에 확보하지 않음 |
| `cortical_cell_location.position` | LIMS 세포의 2D soma 좌표와 이미지 해상도로 계산 | DB 행에 이미지 해상도·3D 등록행렬이 없음 |
| `distance_to_pia` | 이미지 경계에서 계산한 깊이 요약 | 같은 세포의 독립적인 3D pia 표면 측정이 아님 |
| `pair.vertical_distance` | pre/post 2D 위치 차이와 평균 pia 방향으로 계산 | 이미지 평면 밖의 성분이 없음 |

3D marker의 읽기·DB 저장 경로는 [공식 data/experiment 코드](https://github.com/AllenInstitute/aisynphys/blob/b187927abf1e8df46d11b47eeb88c8e2c76aee3c/aisynphys/data/experiment.py#L738-L755)와 [공식 DB 생산 코드](https://github.com/AllenInstitute/aisynphys/blob/b187927abf1e8df46d11b47eeb88c8e2c76aee3c/aisynphys/pipeline/multipatch/experiment.py#L94-L108)에 있다. 2D 좌표·깊이는 [피질 좌표 생산 코드](https://github.com/AllenInstitute/aisynphys/blob/b187927abf1e8df46d11b47eeb88c8e2c76aee3c/aisynphys/pipeline/multipatch/cortical_location.py)와 [깊이 계산 코드](https://github.com/AllenInstitute/aisynphys/blob/b187927abf1e8df46d11b47eeb88c8e2c76aee3c/aisynphys/layer_depths.py)에 있다.

`cortical_site`에는 3D pia/wm 위치용 schema가 있지만 이번 SQLite의 전체 행 수는 **0**이다. 세포별 `pia_direction`은 깊이 계산 중 만들어지고 쌍 거리 계산에 쓰이지만 현재 DB의 해당 세포 위치 행에는 보존되지 않는다. 이 파이프라인은 `ignore_pia_wm=True`로 깊이 계산을 호출하므로 원 pia/wm 경계를 직접 측정한 값으로 해석하지 않는다.

두 필드의 생성 입구가 다르다는 사실은 측정 오차의 독립성을 증명하지 않는다. 앞선 이미지 정렬에 전체 세포가 쓰였을 가능성도 배제하지 못한다. 이후의 세포 보류는 **저장된 두 필드 사이 계산의 보류**이며 독립적인 새 영상의 검증이 아니다.

## 3. 단위 이상을 설명하는 코드 경로

직전 검사에서 발견한 큰 2D 값에는 구체적인 생성 경로 후보가 있다. 깊이 계산의 성공 분기는 LIMS 픽셀 좌표에 이미지 해상도를 곱하고, 결과 위치에 $10^{-6}$을 곱해 m로 저장한다. 반면 깊이 계산 결과가 없는 세포는 원 `soma_centers`를 그대로 `position`에 저장한다. 두 분기는 같은 단위 변환을 수행하지 않는다. 이 사실은 위 고정 판본 코드의 명시적 차이이며, 특정 DB 행의 역사적 실행 경로를 재현했다는 뜻은 아니다.

유효한 3D·2D 좌표가 함께 있는 10,503개 mouse VisP 세포 중, 저장 2D 좌표의 절대 성분이 명목상 **1 m를 넘는 세포는 140개**였다. 140개 모두 `distance_to_pia`가 없었다. 이 동반 관계는 실패 분기의 단위 변환 누락과 양립한다. 그러나 원 픽셀 좌표와 이미지별 해상도 없이는 각 행의 교정값을 확정할 수 없다. 따라서 단순히 $10^{-6}$을 곱해 복구하지 않았다.

위 1 m 기준은 생성 경로를 살펴보기 위한 표시이며 적합의 제거 기준으로 쓰지 않았다. 적합 범위는 다음 절의 실험 내 좌표 폭으로 따로 정했다. 원자료와 이전 연결 분석의 제외 규칙은 바꾸지 않았다.

## 5. 비교한 좌표 모형

[정의] $x\in\mathbb R^3$은 명목상 µm 단위의 원 세포 좌표, $u\in\mathbb R^2$는 같은 단위로 읽은 저장 이미지 좌표다. 행벡터 표기에서

$$
\widehat u=(x-\bar x)B+\bar u
$$

로 적합한다. $B$는 $3\times2$인 무차원 행렬, $\bar x$와 $\bar u$는 해당 학습 세포의 평균 위치다.

| 모형 | 제한 | 평행이동을 포함한 자유도 |
|---|---|---:|
| centroid | 모든 세포를 학습 이미지 중심으로 예측 | 2 |
| XY similarity | 원 XY의 회전/반사·공통 배율, z행은 0 | 4와 이산 반사 선택 |
| XY affine | 원 XY의 일반 선형변환, z행은 0 | 6 |
| XYZ affine | 3D의 일반 선형변환 | 8 |

XY similarity는 원 좌표의 XY 평면에 제한한 후보다. 모든 가능한 3D 기울기를 허용하는 scaled-orthographic projection을 최적화한 것은 아니다. 따라서 이 비교로 모든 3D 투영의 실패나 참 촬영축을 확정하지 않는다. 일반 affine은 전단과 방향별 배율을 흡수할 수 있으므로 적합이 좋아도 물리적 직교 투영이라고 자동 판정하지 않는다.

위치 오차는 저장 2D 위치와 예측값 사이 유클리드 거리다. 표의 세포 통합 RMSE는 8,457개 보류 세포에서 오차제곱을 평균한 뒤 제곱근을 취했다. 실험별 RMSE 중앙값과 구별한다. 1 µm·5 µm 요약 기준은 분포를 보여주는 문턱이며 독립적인 물리 정확성 통과 기준이 아니다.

## 7. 저장 깊이의 gradient와 실제 피질 법선

같은 좌표에서 저장된 깊이 $d_i$를

$$
d_i\approx a^T(x_i-\bar x)+\bar d
$$

로 근사했다. 여기서 $a$는 길이/길이 단위의 무차원 gradient다. 깊이가 모두 유한하고 각 보류 학습 집합의 3D rank가 충분한 1,221개 실험을 평가했다. 실험별 깊이 보류 RMSE 중앙값은 1.279 µm, 95 백분위는 12.561 µm였다. 각 실험의 전체 적합 gradient와 세포 하나씩을 뺀 gradient 사이 최대 각도는 중앙값 3.015°, 95 백분위 43.002°, 최대 178.510°였다. 이는 내부 안정성 진단이며 독립 방향 추정 오차나 신뢰구간이 아니다.

experiment 2771에서는 깊이 보류 RMSE 9.595 µm, 최대 gradient 각도 16.056°였다. 전체 적합 gradient는 약 $(0.1903,-0.7886,-0.2390)$, norm은 0.8457이었다. 이 수치는 선언한 affine 깊이 모형에서 계산 가능하지만 실제 pia의 독립적인 3D 법선으로 채택하지 않았다.

[조건부 수학] 열벡터 표기에서 영상 사상이 $u=B^Tx+b$이고 영상의 스칼라장이 $f(u)$이면, 그 합성 함수의 gradient는 $B\nabla_u f$다. 이것은 **이미지에서 정의한 함수의 공간 확장**이다. 실제 물리적 pia가 영상에서 소실되는 방향으로 변하면 그 성분을 포함하지 않는다. 독립적으로 교정된 물리 좌표와 표면 관측이 추가되어야 실제 법선으로 해석할 수 있다.

예를 들어 이미지 평면을 $z=0$으로 두면 $F_a(x,y,z)=y+az$인 모든 표면 함수는 그 평면에서 같은 $y$를 주지만 3D 법선 $(0,1,a)$는 서로 다르다. 이 반례는 영상 평면만으로 빠지는 표면 기울기를 설명한다. **현재 rank-3 세포 표본에서 선언한 affine 깊이 gradient 자체가 식별되지 않는다는 증명은 아니다.** 저장 깊이 모형의 식별성과 실제 해부학적 표면의 식별성은 다른 문제다.

## 8. 영상 사상이 남기는 3D 메트릭 자유도

[조건부 정리] $B$가 rank 2이고 $k$가 $B^Tk=0$을 만족하는 길이 1의 3D 벡터라고 하자. $L_0=100\,\mu\mathrm m$를 계산 단위로 두면

$$
g_0=BB^T/L_0^2
$$

는 영상 평면의 유클리드 비용을 끌어온 행렬이며 rank 2다. 따라서 이것만으로는 3차원 리만 메트릭의 SPD 조건을 충족하지 않는다. 그러나 임의의 $\lambda>0$에 대해

$$
g_\lambda=(BB^T+\lambda kk^T)/L_0^2
$$

는 상수 SPD 행렬이다. 증명. 0이 아닌 벡터 $v$에 대해

$$
L_0^2 v^Tg_\lambda v=\|B^Tv\|^2+\lambda(k^Tv)^2>0.
$$

두 항이 모두 0이면 $v$는 $B$의 열공간과 그 직교여공간 모두에 직교해야 하므로 0이다. 이는 가정과 모순이다. □

$g_\lambda$의 성분 단위는 $\mu\mathrm m^{-2}$이며 $v^Tg_\lambda v$는 무차원 비용이다. 서로 다른 $\lambda$는 같은 영상 좌표 사상을 그대로 두고 숨은 방향의 비용만 바꾼다. 따라서 영상 좌표 대응만으로 $\lambda$를 정할 수 없다. 단위·SPD 조건을 맞추어 후보를 만드는 일과 생물 비용을 식별하는 일은 구별된다.

계산 예에서 experiment 2771의 일반 affine 적합 행렬에 $\lambda=0.25$와 4를 넣었을 때 두 행렬의 최소 고유값은 각각 $2.5\times10^{-5}$와 $7.13\times10^{-5}\,\mu\mathrm m^{-2}$로 양수였다. 같은 고정 세포 쌍에 부여한 무차원 비용은 최대 0.519만큼 달라졌다. 이 실험의 등록 오차가 앞에서 확인됐으므로, 이 수치는 조건부 사상의 계산 예이며 실제 회로 비용의 판정은 아니다. 또한 **두 후보가 연결 표지·전류 예측까지 동일하다고 보인 것은 아니다.** 그 구별에 필요한 추가 관측이 연구의 다음 대상이다.
