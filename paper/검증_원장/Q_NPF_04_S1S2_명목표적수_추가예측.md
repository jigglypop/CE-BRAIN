# 명목 표적 수를 추가한 후반 예측

**기존 이진 자극 모형에 명목 표적 수의 선형항을 추가하면 2개 기록에서 개선되고 9개에서 악화됐다.** 개선은 RL070 run 28의 약 0.06%, RL123 run 22의 약 1.04%였다. 후자는 자극 정보를 쓰지 않는 기준 모형보다 여전히 나빴다. 단순한 표적 수 정보 누락을 보충하는 것으로 기존 예측 한계가 해소되지 않았다.

## 고정한 비교

[표적 입력 점검](Q_NPF_04_S1S2_명목표적과공간마스크.md)에서 추출한 명목 수와 [전반 학습·후반 예측](Q_NPF_04_S1S2_전반학습_후반예측.md)의 시행 분할을 그대로 사용했다. 다운로드·원신호 처리·분할 변경은 하지 않았다. 새 계약을 저장한 뒤 계산했다.

기존 모형은 절편·시간·S1 전 상태·S2 전 상태·시험 자극 여부를 사용한다. 새 모형은 여기에 명목 수 0·5·10·20·30·40·50의 선형항 하나를 추가한다. catch는 0이며, 이진 자극 여부와 명목 수를 함께 사용해 시험 시행 안의 수 변화도 표현한다. 표준화와 적합은 전반 학습 자료만 사용하고, 후반 자료로 조정하지 않았다. 공간 마스크 ROI 수는 사용하지 않았다.

두 모형은 같은 평가 시행에서 S2 후−전 평균을 예측한다. 예측량·명목 창·easy 및 시각 제외·10초 완충 구간은 기존과 같다. 전체 11세션의 수치·계수행렬 순위 조건을 통과했다. 학습에 명목 30 수준이 없던 J064 run 11도 원래대로 남겼다. 그 수준의 예측은 선형 함수 가정에 따른 보간이며 해당 수준의 직접 학습이 아니다.

## 평가 결과

양수는 상대 MSE 감소, 음수는 악화다. 두 열은 비교 기준이 다르다. 자극 정보 없는 기준 모형은 시간과 두 영역의 전 상태만 사용한다.

| 마우스 / run | 이진 자극 모형 대비 | 자극 정보 없는 모형 대비 |
|---|---:|---:|
| J064 / 10 | −0.19% | +0.01% |
| J064 / 11 | −3.13% | −3.50% |
| J064 / 14 | −4.19% | −17.63% |
| RL070 / 28 | +0.06% | +2.20% |
| RL070 / 29 | −0.44% | −4.48% |
| RL117 / 26 | −0.03% | +0.15% |
| RL117 / 29 | −0.19% | +7.64% |
| RL117 / 30 | −11.46% | −12.41% |
| RL123 / 22 | +1.04% | −6.85% |
| RL116 / 32 | −1.25% | +18.89% |
| RL116 / 33 | −0.56% | +4.52% |

RL116의 두 기록은 표적 수를 넣어도 자극 정보 없는 모형보다 나았지만, 기존 이진 모형보다 성능은 떨어졌다. RL117 run 30은 새 항을 넣었을 때 악화가 가장 컸다. 이를 표적 수의 생물학적 효과가 없다는 증거로 해석하지 않는다. 작은 학습 표본, 시간 외삽, 함수 형태의 부적합, 표적 구성 차이가 함께 영향을 줄 수 있다.

## 검증과 판정

원래 시행 인덱스로 표적 수를 연결하고, 양의 명목 수와 기존 시험 자극 표지가 일치하는지 검사했다. 새 계산에서 재현한 이진 모형의 예측값과 기존 평가값이 일치했다. 학습 전용 표준화의 합성 검사를 재사용했고, 저장한 새 예측값에서 전체·집단별 MSE 및 상대 오차 감소를 다시 계산했다. 기존 학습·평가 인덱스도 그대로인지 확인했다.

이번 질문에는 단일 선형 표적 수 항이 대부분 기록에서 기존 예측을 개선하지 않았다고 답할 수 있다. 이는 선택한 함수와 분할의 결과이며, 비선형 자극 반응이나 표적 identity의 기전을 반증한 것은 아니다. 이미 본 자료의 사후 탐색이고 예측 차이에 대한 독립 불확실성 검정도 하지 않았다. 두 개선 기록만 선택해 후속 확인 성공으로 세지 않는다.

명목 표적 수는 실제 활성 세포 수·광출력·동일한 표적 집합을 보장하지 않는다. 따라서 이 계수를 세포당 전달 강도로 읽을 수 없다. 상한은 탐색적 `BIO_EVIDENCE_L1`이며 전체 뇌 구조는 미확립이다. 새로운 항을 계속 추가하는 것만으로 독립 인과 증거가 생기지는 않는다. 다음에는 현재 자료에서 식별 가능한 경로와 빠진 실제 자극·행동 측정 정보를 구분하고, 그 한계를 직접 판별할 추가 증거를 찾아야 한다.
