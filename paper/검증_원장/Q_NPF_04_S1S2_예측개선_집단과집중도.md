# 자극 정보의 예측 개선은 어디에서 나오는가

**전체 후반 오차가 줄었던 RL117의 두 기록은 catch에서 개선되고 시험 자극에서는 악화됐다.** RL116의 두 기록은 두 집단 모두 개선했다. 개선이 가장 큰 상위 10% 평가 시행을 제외하면 기존 여섯 개선 중 RL116 run 32만 개선을 유지했다. 전체 예측 개선을 곧바로 자극 반응 전달의 예측으로 읽을 수 없다는 결과다.

## 질문과 고정한 계산

[전반 학습·후반 예측](Q_NPF_04_S1S2_전반학습_후반예측.md)의 학습 계수·평가 시행·예측값을 그대로 사용했다. 모형을 재적합하거나 분할을 바꾸지 않았다. 원래 시행 번호로 catch·시험 자극을 연결하고 각 집단의 MSE와 상대 오차 감소를 계산했다. 새 계약에 집단 분해와 두 영향 검사의 규칙을 고정한 뒤 실행했다.

첫 영향 검사는 평가 시행을 하나씩 제외하고 고정된 예측의 상대 오차 감소를 다시 계산한다. 둘째는 시행별 `기준 제곱오차−자극 추가 제곱오차`가 큰 순서로 `ceil(0.1 × 평가 시행 수)`개를 제외한다. 동률은 기존 시행 순서를 따른다. 두 검사는 평가 결과에 따른 민감도 진단이며 새 확인 성능이나 신뢰구간이 아니다. 제거된 시행의 원래 인덱스는 모두 보존했다.

## 집단별 결과

양수는 기준 모형 대비 오차 감소, 음수는 악화다. 집단별 비율은 각각의 기준 오차로 나눈 값이라 두 집단 비율의 단순 평균이 전체 비율과 같지 않다. 합쳐지는 양은 오차 제곱합의 개선량이다.

## 단일 시행과 집중도

단일 평가 시행 제외에서 J064 run 10의 개선율 범위는 −0.87%~+1.02%였다. 원래 악화였던 J064 run 11도 −0.70%~+0.79%로 부호가 바뀔 수 있었다. 다른 아홉 기록은 이 검사에서 전체 개선·악화의 부호를 유지했다. 특히 RL117 run 26의 최소 개선은 약 +0.0011%로 사실상 0에 가까워, 부호 유지만으로 강한 개선이라고 부르지 않는다.

상위 10% 개선 시행 제외에서 RL116 run 32는 +9.14% 개선을 유지했다. 다른 다섯 개선 기록은 악화로 바뀌었다. 이는 모든 기록에 동일하게 적용한 결과 기반 스트레스 검사다. 제거 시행을 이상치로 판정하거나 정식 제외 규칙으로 채택한 것이 아니다. 이 결과를 보고 RL116 run 32만 남겨 독립 재현이라고 주장하지 않는다.

## 검증과 현재 해석

각 평가 시행을 원 자료의 자극 표지에 연결했고 기존 시행별 오차 차이와 전체 개선율을 재현했다. 두 집단의 제곱오차 개선 합이 전체 개선과 일치하는지 검사했다. 단일 시행 제외는 직접 합계에서 해당 시행을 빼는 식으로 계산했으며, 대표 시행의 직접 재집계와도 비교했다.

이번 질문에는 일부 전체 개선이 catch 예측에서 나오고, 여러 개선이 높은 기여 시행에 민감하다고 답할 수 있다. 예측 개선의 존재만으로 S1 자극의 S2 전달을 식별하지 못한다. 표적·자극 강도 차이, 전 상태 분포 변화, 시간 외삽, 행동·보상 및 전처리의 영향은 여전히 남는다. 상한은 탐색적 `BIO_EVIDENCE_L1`이며 전체 뇌 구조는 미확립이다.

후속 분석은 개선 기록만 골라 반복하기보다 모든 세션의 자극 표적 수·강도 대응을 확인해 단순한 자극 유무 모형의 정보 누락을 점검할 수 있다. 같은 학습·평가 경계와 원본 기록을 유지하고, 독립 개입·실제 프레임·보상 시각의 부족은 별도로 다룬다.
