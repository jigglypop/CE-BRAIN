# 인간 연결 자료의 진폭 대응 점검

Peng 2024 공개 자료에서 송신·수신 세포 효과를 구분할 기록을 찾은 뒤, 진폭 정의와 원본 대응을 확인했다. 데이터와 코드 ZIP은 원장에 등록했으며 각각 공개 MD5와 일치한다. 코드 다운로드는 완료됐고 실행 중인 수집 작업은 없다.

CSV의 `avg_psp_amplitude`를 MATLAB `matrix.avg.psp.amplitude`와 환자·군집·채널 기준으로 대조했다. ER의 유한 값 1,046개는 모두 허용 오차 안에서 일치했다(최대 절대 차이 약 5e-10). 이 중 앞선 양수 조건을 통과한 값은 1,040개다. TR의 유한 값 118개 중 76개는 일치했지만 42개는 해당 MATLAB 항목이 결측이다. 이 42개를 잘못된 값으로 단정하거나 자동 삭제하지 않는다. 생성 경로 확인이 필요하다.

저자 코드 `code/plot/plot_prob_rec_cneighbour.m`의 101~114행은 해당 CSV 필드를 직접 그리며 축을 mV 단위로 표시한다. 이 근거에 따라 CSV 진폭은 mV로 읽는다. 파일 이름에 avg가 있다는 이유만으로 반복 시행 평균과 평균 파형 피크를 혼동하지 않는다.

`pipeline_motifs_er.m`은 이미 만들어진 CSV를 읽어 후속 분석을 한다. 이번 코드 검색에서 재기록·원시 연결 코드의 의미를 정의하는 전처리 구현은 아직 확인하지 못했다. 셀 표의 repatch 값은 ER 모두 1, TR은 336개가 1이고 1개가 2다. 각 코호트에서 군집·채널 키 중복은 없지만, 이것만으로 생물학적으로 같은 세포의 재기록 중복이 전혀 없다고 확정하지 않는다.

원본 연결 코드와 CSV 표지의 차이, ER 1,138개 대 논문 1,137개 차이는 미해결이다. 특히 원본 결측 32방향을 CSV가 비연결로 갖는 문제 때문에 모든 CSV 음성을 확실히 검사된 음성으로 승격하지 않는다. 강도 효과 추정에 앞서 그 반대방향 연결 상태가 분명한지 확인해야 한다.
