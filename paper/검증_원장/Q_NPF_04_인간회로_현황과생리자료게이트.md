# 인간 회로 구조 연구의 현재 판정과 생리 자료 게이트

현재 밝혀진 범위는 **부분 관측한 인간 국소 회로에서 위치와 다른 연결이 숨긴 연결의 방향·존재를 예측하는 데 제한된 정보를 준다**는 것이다. 이 정보가 연결 강도·양방향 결합·시간적 신호 전달까지 일관되게 설명한다는 근거는 없다. 따라서 뇌 전체 구조나 보편적 세포 역할 법칙을 밝혔다고 보고할 수 없다. 2026-09-05 갱신에서는 완료된 생리 비교와 Allen 고정 모형 적용을 반영하고, 다음 연구를 기전 구분 문제로 연결한다.

| 연결의 존재 자체를 숨겨도 이득이 있는가 | [Planert 양방향 가림](Q_NPF_04_연결존재_양방향가림.md): 2,060쌍·21명, 방향별 손실 0.402443 → 0.394401 | 같은 연구 계보의 제한적 예측 지지 |
| 두 방향의 결합 상태도 더 잘 예측하는가 | [결합 비교](Q_NPF_04_양방향결합_환자제외예측.md): 전체 이득 약 0.000092, 환자 균등·상호연결 오차는 악화 | 공통 의존성 계수의 일관된 추가 이득 미확립 |
| 계수를 고정해 다른 기관에 적용하면 어떤가 | [Allen 고정 적용](Q_NPF_04_Allen_고정모형_연결존재.md): 362쌍, 손실 0.332367 → 0.321439; 실제 양성 73방향 대비 약 110방향 예측 | 외부 적용 이득과 총수 과대추정 공존; 환자 단위 독립 복제 아님 |

이 표의 지지는 범위가 정해진 `BIO_EVIDENCE_L1` 관측·탐색을 뜻한다. 동일 신경 상태의 종단 변화, 기전 개입, 선택적 복원, 행동 매개는 평가하지 않았다. 이 결과를 원래 CE 출력-상대 계량의 인과사슬이나 Q-NPF-04 카드의 전체 사전조건 통과로 합산하지 않는다.

## 생리 자료 게이트의 처리 이력

보유한 Planert Figshare 판본 1에는 세포 표 1,560행과 연결 표 10,784행이 있다. 세포 표의 입력저항 `R_in`, rheobase `rheo`를 사용한 후속 비교는 완료됐다. 분류 결과 `etype`, UMAP와 연결 수에서 만든 방향성 값은 독립 생리 특징으로 사용하지 않았다.

새 가용성 계약은 정확한 공개 ID로 두 세포와 연결 표를 결합하고, 연결쌍 키가 유일할 것을 요구했다. 실행은 이 유일성 검사에서 중단됐다.

| 중복 감사 | 결과 |
|---|---:|
| 연결 표 행 수 | 10,784 |
| 고유 방향 세포쌍 키 | 10,684 |
| 중복된 방향 세포쌍 키 | 98 |
| 두 행인 중복 키 | 96 |
| 세 행인 중복 키 | 2 |
| 중복 행 사이 연결 표지가 다른 키 | 23 |

일부 중복은 행 번호만 다르지만 23개에서는 연결 유무와 진폭 등도 다르다. [repatch 코드 점검](Q_NPF_04_생리자료_재기록중복경로.md)에서 중복이 생길 수 있는 결합 경로를 확인했지만 각 행의 실제 생성 이력까지 복원하지는 못했다. 후속 분석은 첫·마지막 행을 임의 선택하지 않고 중복 키가 있는 6개 기록 전체를 제외하는 별도 표본으로 진행했다. 원 실패와 계약은 보존했다. 중복이 남은 전체 자료의 문제가 해결됐다는 뜻은 아니다.

생리 단위와 QC 플래그의 의미도 확인했다. 최종 단방향 생리 비교는 523쌍·22명이었고, 연결 존재 비교는 거리 결측을 추가 제외한 2,060쌍·21명이었다. 서로 다른 과제의 분모를 합산하지 않는다. Peng과 Planert는 같은 연구 계보여서 독립 복제로 세지 않는다.

Allen에서는 [공통 입력 362쌍](Q_NPF_04_Allen_결합예측입력_재고.md)을 확보했지만 [측정 정의](Q_NPF_04_Allen_측정정의대응.md)가 동일하지 않다. [직접 표본 ID 공개 조회](Q_NPF_04_Allen_표본외래키_공개조회.md)도 환자 연결을 제공하지 못했다. 따라서 절편을 환자로 세지 않았고, Allen 정답으로 재적합하는 대신 Planert 계수를 고정한 기술적 외부 적용을 수행했다.

## 전체 목표에 남은 증거

| 밝혀야 할 대상 | 현재 증거가 증명하지 못하는 부분 | 필요한 판별 근거 |
|---|---|---|
| 실제 연결 구조 | 부분 표본에서 확률이 좋아져도 전체 연결 행렬은 복원되지 않음 | 독립 정답 회로에서 가림 범위를 고정한 구조 복원 평가 |
| 전달 기전 | 연결 존재·평균 진폭만으로 효능·지연·내재 이득이 구분되지 않음 | 같은 세포쌍의 반복 자극·응답 파형, 시간 기준과 자극 세기·QC, 기전별 식별 검증 |
| 구조 변화의 원인 | 횡단 관측은 변화의 원인을 판정하지 못함 | 동일 단위 종단 대응, 선택적 개입·대조·복원과 관측 오차 모형 |
| 행동·미래 출력과의 관계 | 현재 연결 예측은 행동 분포나 출력-상대 계량을 측정하지 않음 | 같은 preparation에서 신경 상태·출력·행동의 대응 및 독립 예측 |
| 뇌 전체로의 일반화 | 수술 조직의 제한 영역·층·세포형 결과임 | 종·영역·세포형·상태별 명시된 운반 가정과 독립 검증 |

이 표는 사용자의 전체 목표가 아직 완료되지 않았음을 점검하는 기준이다. 현재 L1 구성요소 결과를 더해 통합 인과사슬의 등급을 올리지 않는다. 원 Q-NPF-04 카드의 P1–P8 역시 이번 연결 구조 점수로 통과 처리하지 않는다.

## 다음 판별 질문

다음 질문은 **같은 세포쌍의 자극–응답에서 전달 효능과 지연, 내재 흥분성의 영향을 실제로 구분할 수 있는가**다. 이를 위해 보유 자료 원장에서 반복 시행·자극 타이밍·세포쌍 대응·관측 파형을 확인한다. 이미 조사한 동일 자료의 API 조회를 반복하거나, 같은 연결 표에서 유리한 특징·분할을 계속 탐색하는 것을 새 독립 증거로 세지 않는다.

진행 조건은 실제 측정 채널과 대응 키가 있어야 한다는 것이다. 하나가 없으면 누락된 기전의 영향은 미식별로 기록한다. 준비되면 먼저 관측 모형에서 세 기전이 구별되는지 검사하고, 그 후 분리된 시행에서 예측을 평가한다. 내재 이득을 독립적으로 측정·개입하지 않은 자료에서 세 채널 모두를 식별했다고 주장하지 않는다. 기존 자료가 특정 질문에 부적격이라는 판정을 공개 자료 전체의 재검토·다운로드 금지로 확대하지 않는다.
