# 시행 상관을 고려한 S1/S2 대비의 근사 불확실성

**시간·자극 전 상태 보정 계수의 근사 구간은 네 기록에서 모든 상관 범위 설정에 걸쳐 0을 포함했다.** J064 run 10·11, RL117 run 30, RL116 run 33이다. 나머지 일곱 기록은 이번 설정에서 0을 제외했다. 이는 모형 가정 아래의 탐색적 불확실성 계산이며 인과 연결의 확정이나 독립 확인 실험이 아니다.

## 자료와 분석 규칙

[자극 전 상태 보정 분석](Q_NPF_04_S1S2_시간과자극전상태_보정.md)의 시행별 값을 재사용했다. 무보정·시간만 보정·시간과 S1/S2 전 상태 보정이라는 세 모형과 원래 시행 제외 규칙을 유지했다. 모든 결과를 이미 본 뒤의 후속 탐색이며, 새 계약에 공분산 식·상관 범위·구간 계산·한계를 고정한 뒤 계산했다.

일반 HAC 구현은 등간격 단일 시계열을 가정하고 Bartlett 가중치를 기본으로 사용한다. 이 조건은 [statsmodels 공식 문서](https://www.statsmodels.org/stable/generated/statsmodels.stats.sandwich_covariance.cov_hac.html)에 명시돼 있다. 여기서는 실제 초 단위 간격이 일정하지 않으므로 원래 시행 번호의 거리를 사용하는 별도 근사로 제한했다. 설치되지 않은 statsmodels를 실행한 결과라고 주장하지 않는다.

원래 시행 인덱스 차이가 `d`이면 가중치는 `max(1−d/(L+1),0)`이다. `L`은 0·5·10·20을 모두 사용했다. easy·시각 누락·export 누락으로 빠진 시행 사이의 간격을 압축하지 않았다. 빠진 위치의 추정식 기여가 0인 격자와 같은 계산이며, 해당 시행의 생물 신호가 0이라는 뜻은 아니다.

각 시행의 설명변수와 최소제곱 잔차의 곱으로 sandwich 공분산을 계산하고 `n/(n−k)`를 곱했다. `n`은 유효 catch·시험 자극 수, `k`는 모형 계수 수다. 구간은 계수 ± 정규분포 97.5% 분위수 × 표준오차다. 모형의 안정성과 충분히 약한 의존 등의 가정 아래 점별 근사 95% 구간이며, 이 자료에서 실제 95% 포함률을 검증하지 않았다. 33개 모형과 네 범위의 다중비교를 보정한 동시 구간도 아니다.

## 검증과 후속 조건

모든 점추정 계수는 기존 결과와 `1e-12` 안에서 일치했다. 합성 예제로 `L=0`과 HC1 식의 일치, 비연속 원래 인덱스 사이의 간격 보존, 0 기여를 채운 원래 시행 격자의 lag 합과 직접 가중행렬 식의 일치를 검사했다. 모든 공분산 행렬의 대칭성과 수치 허용오차 안의 양의 준정부호성도 확인했다. 계산 검사는 구간의 실제 포함률 검증이 아니다.

이미 관측한 전후반 차이는 일정한 모형·오차 구조 가정을 의심하게 한다. 비선형 시간 변화, 20시행보다 긴 의존, 불규칙한 실제 시간, 선택·측정오차·전처리·행동·보상 교란은 남는다. 같은 마우스의 반복 세션을 독립 동물로 묶어 추론하지 않았다. 상한은 탐색적 범위고정 관측 `BIO_EVIDENCE_L1`이며 전체 뇌 구조는 미확립이다.

이번에는 불확실성을 고려해도 모든 기록에 공통된 방향을 주장할 수 없다는 상태를 구체화했다. 다음에는 앞 구간에서만 적합한 모형이 뒤 구간 반응을 예측하는지, 자극 표지를 추가한 모형이 전 상태·시간만의 모형보다 나은지 평가할 수 있다. 이미 본 자료의 후속 검증이므로 독립 확인자료로 승격하지 않는다. 실제 선택적 개입·보상 시각·프레임 시각의 부족은 별도 과제로 남는다.
