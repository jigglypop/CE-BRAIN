# 후속 투사 자료의 전처리 확인 조건

RL127 다운로드를 기다리는 동안 보유한 생성 소스를 검토했다. 조건 이름과 저장 배열을 그대로 측정 사실로 읽으면 안 되는 분기를 확인했다. 이번 결과는 소스 검토와 합성 검사이며 실제 세션의 생물학적 결과가 아니다.

## sham 분기

`interarealProcessing.addShamPhotostim`은 `spont.naparm_path == 'none'`이면 다른 자극 블록인 `photostim_r`의 시작 프레임·자극 길이·표적 정보 등을 자발 활동 객체에 복사한다. 따라서 상위 로더가 이 객체를 sham으로 부른다는 사실만으로 실제 광학 대조 시행을 수행했다고 확정할 수 없다.

이 분기는 원래 `naparm_path` 값도 덮어쓴다. 완료 객체에서 경로나 시각이 같다는 확인만으로는 실제 대조와 복사된 메타데이터를 구별할 수 없다. RL127에 이 분기가 적용됐다고 단정하지 않으며, 원래 획득 파일·기록 또는 추가 구분 정보가 필요하다.

## 기저선과 시각 대응

`_baselineFluTrial`은 시행 전 구간 평균을 빼고 자극 아티팩트 구간을 0으로 채운다. 이 0은 신경 무반응의 관측값이 아니다. 기존 자료의 프레임 인덱스를 새 배열에 그대로 적용하지 않으며, 아티팩트 구간을 반응 요약에서 분리한다.

`_makeFluTrials`는 길이가 맞는 시행만 배열에 붙인다. 불완전 시행은 빠질 수 있으므로 최종 시행 수가 자극 시각 목록의 길이와 같다는 가정을 먼저 두지 않는다. 각 배열과 이벤트의 대응을 확인해야 한다.

[검사 코드](../../verify/Q-NPF-04/allen_synphys/mechanisms_preprocessing_audit.py)는 검토한 기저선 메서드만 격리해 합성 배열에 적용했다. 기저선 평균 제거, 아티팩트 0 채움, 이후 프레임 값, 입력 배열 보존을 확인했다. [결과](../../verify/Q-NPF-04/allen_synphys/mechanisms_preprocessing_audit_result.json)에 소스 해시와 확인해야 할 필드를 남겼다. 전체 소스 모듈이나 외부 피클 함수를 실행하지 않았다.

다음은 진행 중인 다운로드가 완료되면 객체 스키마를 확인하는 것이다. 역사적 실행 판본과 실제 sham의 성격이 확인되기 전에는 투사·비투사 대비를 직접 경로의 인과효과로 승격하지 않는다. 뇌 구조 규명 목표는 미완료다.
