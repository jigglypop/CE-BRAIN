# 명목 표적 수와 공간 마스크의 구분

**유효 시험 자극 922시행 모두에서 공간 마스크에 잡힌 기록 ROI 수가 명목 표적 수보다 많았다.** 이는 곧바로 자극 오류나 추가 세포의 실제 활성화를 뜻하지 않는다. 두 변수는 의미가 다르며 실제 활성 세포 수로 바꿔 읽을 수 없다. 또한 J064 run 11은 명목 30개 자극이 학습 구간에는 없고 평가 구간에 7회 있었다.

## 출처와 방법

기존 전체 파일을 재사용해 `trial_subsets`, `photostim`, `is_target`과 원래 시행 번호를 읽었다. 앞선 예측의 학습·평가·시각 제외·easy 제외를 유지했다. 원래 시행 번호로 기존 분석의 유효 시행을 연결하고 명목 수준별 표본 수와 고정된 예측 오차를 집계했다. 모형 재적합은 하지 않았다.

보관한 [저자 Session 코드](../../data/external/cortical_propagation_2023/author_Session.py)는 `trial_subsets`로 catch 0, 시험 자극 5~50, easy 150을 구분한다. `is_target`은 `GetTargets` 결과를 프레임마다 반복한 마스크다. 보관한 [Vape 코드](../../data/external/cortical_propagation_2023/vape_run_functions.py)의 `GetTargets`는 자극 위치 주변 원형 마스크와 각 ROI 픽셀의 겹침 여부를 사용한다. 반경은 코드에서 15µm로 표기하지만 좌표 환산에 저자의 불확실성 주석이 있고, 실제 export 생성 당시 판본과 이 보관 판본의 일치도 확정하지 못했다. 이 값을 검증된 광학 유효 반경으로 채택하지 않았다.

따라서 공간 마스크에 해당하는 ROI 수와 명목으로 지정한 표적 수를 따로 보고한다. 마스크 양성은 실제 광출력·활성화·직접 연결의 측정값이 아니다. 기존의 ‘직접 S2 표적 없음’ 검사도 저장 마스크에서 S2 양성이 없다는 범위이며, 실제 S2 직접 광학 효과가 없다는 독립 실험 증명으로 확대하지 않는다.

모든 세션의 유효 분석 시행에는 catch와 명목 5·10·20·30·40·50 수준이 있었다. catch 마스크 수는 모두 0이다. 아래는 시험 자극 중 두 끝 수준의 마스크 양성 ROI 범위다. 나머지 수준별 결과도 JSON에 보존했다.

## 기존 예측의 학습 범위

J064 run 11은 명목 30 수준의 학습 시행이 0회, 평가 시행이 7회다. 나머지 세션은 평가의 모든 명목 수준이 학습에도 있었지만 표본이 매우 적은 수준이 있었다. 예를 들어 J064 run 10의 명목 5와 20은 학습에 각각 1회, RL117 run 30의 명목 50도 학습에 1회였다. 수준이 한 번 등장했다는 것만으로 충분한 학습이나 동일 표적 구성을 보장하지 않는다.

앞선 모형은 자극 유무만 사용했으므로 명목 30이 빠져도 이진 변수 자체가 학습에서 빠진 것은 아니다. 따라서 기존 실행 오류가 아니라, 표적 수별 관계로 해석하거나 세부 수준을 추가할 때 고려할 제한이다. 이번 결과를 보고 평가 시행을 제거하거나 학습·평가 경계를 바꾸지 않았다.

## 검증과 다음 조건

catch·easy 표지와 명목 수준의 대응, catch 및 S2 마스크 양성 없음, 기존 분석의 시행별 자극 표지 일치를 확인했다. 수준별 평가 MSE를 평가 수로 가중해 합치면 기존 전체 MSE가 복원되는지도 검사했다. 새 계약·코드·결과에는 원 자료와 참조 코드의 해시를 기록했다.

이번 질문에는 명목 표적 수와 공간 마스크 ROI 수가 서로 다른 값이고, 세부 수준의 학습 범위에도 빈틈이 있다는 답을 얻었다. 스키마 해석은 `BIO_EVIDENCE_L0`, 기존 생물 자료의 범위고정 예측 분해는 탐색적 `L1`이며 인과 구조는 미확립이다. 명목 수를 실제 활성 세포 수로 사용하는 해석은 정당화되지 않는다.

다음은 기존 분할을 유지한 채 명목 표적 수를 연속 공변량으로 추가해 이진 표지 모형의 정보 누락을 탐색할 수 있다. 이는 표적 수와 반응의 함수 형태를 가정하는 새 모형이며, 부족한 수준을 사후 보충한 독립 검증으로 부르지 않는다. 광학 마스크와 실제 활성화의 대응, 표적 identity·광출력·실제 프레임 및 보상 시각은 별도 확인 대상으로 남는다.
