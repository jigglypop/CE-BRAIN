# Song 기록의 세포별 연결 수와 상호연결

원래 목표인 뇌 연결 구조 규명을 위해, 관측된 상호연결이 세포마다 보내고 받는 연결 수로 어느 정도 제한되는지 확인했다. 이전 날짜 예측과는 다른 질문이다. 회귀모형의 주변확률 오차를 그대로 둔 채 의존성 계수만 해석하지 않기 위해, 이번에는 기록별로 가능한 그래프를 모두 열거했다.

Song 공개 표의 816개 기록은 각각 2~4개 세포를 포함한다. 각 기록의 세포별 입력·출력 연결 수를 그대로 보존하고 자기연결이 없는 모든 단순 유향 그래프를 열거했다. 해당 그래프들을 같은 확률로 보는 수학적 참조를 사용했다. 문자열에 없는 고립 세포는 필요한 수만큼 익명 노드로 보충했으며 실제 채널 ID를 추정했다고 주장하지 않는다.

| 항목 | 값 |
|---|---:|
| 관측 상호연결 | 218쌍 |
| 조건부 참조 기대값 | 205.380952쌍 |
| 관측−기대 | 12.619048쌍 |
| 기록별 최소값의 합 | 191쌍 |
| 기록별 최대값의 합 | 225쌍 |
| 상호연결 수가 변할 수 있는 기록 | 29개 |
| 상호연결 수가 조건만으로 고정되는 기록 | 787개 |

따라서 세포별 연결 수를 고정한 참조에서도 양의 잔차는 남는다. 하지만 대부분의 기록은 가능한 상호연결 수가 하나뿐이다. 이 고정성은 작은 기록과 강한 조건의 결과이며, 기대값이 관측에 가까워졌다고 해서 실제 생물 기전이 설명됐다는 뜻은 아니다. 고정해 버린 연결 수 자체의 생물학적 형성 과정도 이 검사로 판별하지 않는다.

원래 질문에는 세포별 연결 수가 상호연결 통계의 해석을 크게 제한한다는 답을 얻었다. 추가 구조를 판별할 여지는 29개 기록에 있으며, 그 기록의 잔차와 선택 조건을 다음에 확인해야 한다. 조건부 참조의 균등 가정은 실제 생성 과정으로 입증되지 않았다. 같은 동물의 상관과 거리·검출 과정도 미확인이라 독립 기록을 가정한 곱분포 유의확률은 계산하지 않았다. 뇌 구조 전체나 CE 인과기전은 미확립이며 관측 해석은 BIO_EVIDENCE_L1 상한이다.
