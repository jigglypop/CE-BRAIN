# 인간 연결 자료의 전처리 출처 추적

Planert 등의 후속 공개 코드에서 원시 연결 코드와 최종 표지의 관계를 확인했다. 다만 이 코드의 공개 시점과 기존 Peng 자료의 생성 시점은 다르며, TR 진폭 42개의 대응은 아직 해결되지 않았다. 이번 결과는 출처·준비 단계 `BIO_EVIDENCE_L0`이며 생물학적 endpoint를 추가 평가하지 않았다.

## 확보 자료와 확인 범위

[원 논문의 데이터·코드 안내](https://www.nature.com/articles/s41593-025-02134-7)는 가공 자료와 분석 코드를 [Figshare 28184126](https://doi.org/10.6084/m9.figshare.28184126)에 공개한다. 원시 인간 참여자 자료는 공개 배포하지 않는다고 명시한다. 여기서 말하는 원시 자료와 기존에 받은 MATLAB 가공 행렬을 구별한다.

데이터 원장을 먼저 검색한 뒤 미보유 파일 `humandata.zip` 1,956,326바이트를 받았다. Figshare 판본 1의 게시 MD5 `845ef00b5eb3aa15b2d74a619b7e334e`와 일치했다. SHA-256은 `6b0d7244dec5c665a88d0d1828ae842d084bb737a6df9f86561d53d8564c4bfd`이며, `planert2025-human`으로 원장에 등록했다.

| 확인 항목 | 결과 | 해석 상한 |
|---|---|---|
| `extract_matrix.m`의 최종 연결 표지 | 원시 코드가 1 또는 1.2일 때 참 | 해당 공개 코드의 변환 규칙 |
| 원시 코드 NaN | 위 비교식은 거짓 | 최종 0이 되는 경로는 설명하지만 실제 검사 완료나 음성 판정의 품질은 보장하지 않음 |
| `matrix.avg` | `ephys_import.avgsweep`에서 채움 | 생성 경로를 확인했으며 원시 파형을 재처리한 것은 아님 |
| `matrix2` | `ephys_import2`와 첫 import의 결합 필터 사용 | 기존 `matrix`와 교체 가능한 진폭이라고 가정하지 않음 |
| 새 연결 표 | 10,784행, 203기록, 23개 환자 표지, 유한 진폭 1,467개 | 기존 표와 동일 포함 기준으로 간주하지 않음 |
| 기존 ER/TR 세포 ID와 정확한 일치 | 각각 0개 | 공개된 명시적 대응표 없이 같은 세포로 병합하지 않음 |

후속 표는 다른 가명 형식을 사용한다. 생리 값이나 공간 좌표를 이용해 참여자의 가명을 역추적하지 않았다. 동일 연구 계보의 가공 표이므로 새 독립 표본이라고 세지 않는다.

## 판정과 다음 진행 조건

원래 질문인 TR 진폭 42개에 대해서는 아직 답하지 못했다. 대신 코드 1·1.2와 최종 연결 표지의 관계를 추측 없이 읽을 수 있는 공개 근거를 확보했다. 이 후속 코드가 기존 공개 ZIP을 실제로 생성한 정확한 판본이라는 증거는 없으므로 역사적 실행을 확정하지 않는다.

TR의 해당 진폭을 독립 비교에 사용하는 단계는 보류한다. 다음 안전한 경로는 이미 보유한 다른 기관 자료에서 인간 세포·연결·진폭·양방향 검사 조건의 가용성을 확인하는 것이다. 이때도 동일 환자·동일 연구 표본을 독립 복제로 중복 계산하지 않는다. 진폭 대응이 해결되지 않았다는 이유로 연결 표지에 근거한 별도 구조 질문 전체를 금지하지 않는다.
