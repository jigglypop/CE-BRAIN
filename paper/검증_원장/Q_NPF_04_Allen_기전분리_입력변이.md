# 반복 자극 자료의 기전 분리 입력 점검

기존 Allen 한 실험의 시행 37–56은 같은 세기의 자극에서 spike 후보가 하나씩 나온 반복 자료다. 명령과 spike 사이 시각 변이는 존재하지만 자극 세기별 흥분성 곡선이나 선택적 기전 개입은 없다. 이 20시행에서 효능·전달 지연·내재 이득의 세 채널이 분리됐다고 보고하지 않는다.

## 재사용한 근거와 범위

[원본 시행 대응](Q_NPF_04_Allen_원본시행_대응.md)과 [명령 대조](Q_NPF_04_Allen_자극명령_대조확인.md)가 이미 세포·채널·시행과 자극/기록 시작의 대응을 확인했다. 이번에는 저장된 명령 가장자리와 upstream 검출기의 최대 상승 기울기 시각만 재사용했다. 후세포 진폭을 새로 적합하거나 결과에 따라 시간창을 바꾸지 않았다. 새 다운로드도 없었다.

이 실험은 작은 평균 반응을 진단하려고 의도적으로 고른 사례다. 무작위 대표 표본이나 여러 동물의 검증이 아니다. 이번 spike는 기록과 검출기로 얻은 후보이며 독립적인 spike 정답과 비교한 것은 아니다.

## 결과

| 항목 | 20시행 결과 |
|---|---:|
| 명령 높이 | 모두 약 2,000pA |
| 명령 지속시간 | 모두 1.51ms |
| 검출된 spike 후보 | 매 시행 1개 |
| 명령 시작 → 최대 상승 기울기 | 1.085–1.305ms |
| 위 시각 차이의 표본 표준편차 | 0.074712ms |
| 시행 번호에 대한 선형 변화 | −0.009436ms/시행 |
| 선형 변화를 뺀 잔차 RMS | 0.048396ms |
| 명령 표본 간격 | 0.010ms |

시각 차이의 전체 폭 0.220ms는 표본 간격 하나보다 크다. 그러나 이것만으로 명령에 맞춘 누화와 spike에 맞춘 반응을 분리할 수 있다는 뜻은 아니다. 표본 간격은 시각 추정 오차가 아니며, 잔차 RMS도 측정 잡음의 독립 추정치가 아니다. 선형 변화는 기술적 요약이다. 이를 실제 흥분성 변화나 생물학적 추세로 확정하지 않는다.

명령 높이와 지속시간에는 이번 추출값 기준 변이가 없었다. 따라서 이 구간은 서로 다른 입력 세기에서 발화 확률·횟수가 달라지는 자료를 제공하지 않는다. 충분히 강한 고정 자극에서 한 번씩 발화했다는 사실은 역치나 이득이 같다는 증거도 아니다. 명령에서 spike까지의 시간은 전세포 유발 과정이며, 이를 두 세포 사이의 전달 지연으로 대체하지 않는다.

## 판정과 다음 조건

현재 확보한 것은 조건을 확인한 반복 자극과 제한된 시각 변이다. 세 채널 식별 게이트는 통과하지 않았다. 이 결과는 시냅스 연결 자체를 반증하지 않으며, 같은 자료의 평균 반응 결과도 덮어쓰지 않는다.

다음에는 **같은 실험·같은 세포의 독립적인 내재 생리 자극 구간이 보유 자료에 있는지**를 확인한다. 자극 세기와 holding current, 세포 대응, 기록 품질을 확인한 뒤에만 흥분성 측정과 연결 반응의 결합 가능성을 평가한다. 없어도 다른 세포나 다른 시점의 값을 같은 상태의 측정으로 붙이지 않는다. 후세포 반응에서 효능·지연을 분리하려면 별도의 관측 모형과 시각 오차·대조 조건도 필요하다.
