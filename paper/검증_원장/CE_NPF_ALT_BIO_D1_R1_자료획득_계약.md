# CE-NPF 대체 생물자료 D1/R1 자료획득 계약

## 지위

- 판본: `ALT_BIO_D1_R1_SOURCE_v1`
- 상태: **자료획득 계약 고정, 생물학 endpoint 미개봉**
- 계보: Loewenstein 및 AIND BCI E1과 다른 독립 계보다. 이 결과를 기존 Stage 번호의 통과로 세지 않는다.
- 이 문서는 다운로드와 source/schema 검사만 허가한다. 다운로드 성공은 가설 결과가 아니다.

## 목표 정렬

- 최종 목표: 뇌의 국소 표현기하와 가소성 메커니즘을 생물학 자료로 제약하고, 뉴런의 고정된 “의미” 주장을 검증 가능한 형태로 재구성한다.
- 이번 하위 목표: 서로 보완적인 두 공개 자료의 정본 파일을 고정하고 실제 분석 가능한 스키마인지 판정한다.
- 필요한 이유: 한 공개 자료가 발달기 동일세포, 직접 개입, 물리 연결, 행동을 모두 포함하지 않으므로 서로 다른 판별축을 섞지 않고 확보해야 한다.
- 이탈 위험: 동일세포 추적을 의미 고정으로, 광자극 반응을 물리 시냅스 가중치나 전도속도로 승격하는 해석을 금지한다.

## 고정 질문

### D1 — 발달 중 세포 연속성과 기능 표현

Track2p의 P7--P14 생쥐 동일세포 종단자료로 다음 질문만 연다.

> 같은 물리 뉴런으로 추적된 세포가 유지되는 동안 활동--행동 관계와 집단 표현기하는 발달일에 따라 변하는가?

이는 “뉴런은 태어날 때 의미를 가지며 청소년기에 고정된다”를 직접 검사하지 않는다. 대신 그 문장을 다음의 분리 가능한 주장으로 재구성할 자료인지 판정한다.

1. 세포 연속성: 같은 행 인덱스가 날짜를 넘어 같은 물리 세포를 가리킨다.
2. 기능 안정성: 세포별 활동--운동/각성 결합과 집단기하가 날짜를 넘어 보존된다.
3. 기능 가소성: 세포 연속성이 유지되어도 2가 체계적으로 변할 수 있다.

### R1 — 개입에 따른 유효 전파와 시간척도

Randi et al.의 단일뉴런 광자극--전뇌 반응 자료와 `unc-31` 자료로 다음 질문만 연다.

> 자극원별 유효 반응 강도와 시간척도가 국소 집단기하를 정의하며, dense-core-vesicle 방출 결손에서 그 기하가 달라지는가?

여기서 “유효 전파”는 직접·간접·extrasynaptic 경로를 모두 포함한다. 물리 시냅스 가중치, 축삭 전도속도, 같은 개체의 구조적 재배선을 식별하지 않는다.

## 정본 파일

- Track2p: Zenodo record `17091226`, DOI `10.5281/zenodo.17091226`, CC BY 4.0.
- Randi: OSF node `e2syt`; OSF node의 license 필드가 비어 있으므로 원파일은 로컬 내부 분석에만 사용하고 재배포하지 않는다.
- 정확한 URL, byte 수, provider checksum과 로컬 경로는 각각 `track2p_zenodo_17091226_source_lock.tsv`와 `randi_2023_osf_e2syt_source_lock.tsv`가 정본이다.

## Source gate

### Track2p

1. 세 파일의 byte 수와 MD5가 source lock과 일치해야 한다.
2. `data.zip` 중앙 디렉터리와 모든 구성원의 CRC 검사가 통과해야 한다.
3. 정확히 6개 subject 폴더가 있어야 하고, 각 subject에 날짜가 다른 session이 최소 6개 있어야 한다.
4. 날짜별 Suite2p 활동 배열과 행동 `motion_energy_glob.npy`가 존재해야 한다.
5. 한 subject 안에서 날짜별 추적세포 행 수가 같아야 한다.

### Randi

1. 두 archive의 byte 수와 SHA-256이 source lock과 일치해야 한다.
2. 두 tar archive가 손상 없이 열려야 한다.
3. WT와 `unc-31`을 구분하는 동물/recording 식별자, 자극원, 수신세포, 반응 trace 또는 kernel, 시간축을 복구할 수 있어야 한다.

하나라도 실패하면 biological endpoint를 열지 않고 해당 lane을 `SOURCE_BLOCKED`로 닫는다.

## 다음 게이트

- Source gate 통과 후에만 동물 단위 개발/holdout 분할, metric 후보, 음성대조, 중단조건을 담은 별도 분석 계약을 고정한다.
- 현재 단계에서 허용되는 행동은 다운로드, checksum, archive 무결성, 파일명/shape/dtype/key inventory뿐이다.
- 활동값의 효과크기, genotype 차이, 발달 추세, 행동 상관은 아직 계산하지 않는다.
