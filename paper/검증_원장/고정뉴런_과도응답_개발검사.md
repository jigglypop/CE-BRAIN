# 고정 뉴런의 직선 추세 제거와 과도 응답 개발 검사

유형: 연구 검증 원장. 판본일: 2026-09-05. **지위: 사후 개발 검사 실패 / 실제 파형 관측은 `BIO_EVIDENCE_L1`, 공간 메트릭은 미확립.**

[PRD](../../.codex/PRD.md)의 고정 뉴런·리만 메트릭 목표에 따라, [전기 연결 별 모양 검사](고정뉴런_전기연결_별모양_검증.md)에서 실패한 긴 시간창의 전압 차이를 다시 살폈다. 질문은 **직선 형태의 기준선 변동을 제거하고 막 충전의 시간 응답을 넣으면, 같은 고정점의 다른 시행을 더 잘 예측하는가**다. 이미 읽은 sweep 10–12만 재사용했다. 새 독립 확인으로 세지 않으며, 이전 판정을 수정하지 않는다.

결과는 개발 기준 미통과다. 두 시행으로 나머지 시행을 예측했을 때, 열두 교차 방향의 RMSE는 전류 효과를 0으로 둔 예측의 **1.0172배·0.9885배·0.9941배**였다. 요구한 0.8배 이하를 세 번 모두 충족하지 못했다. sweep 13–15의 응답은 읽지 않았다.

## 1. 고정점·가정·계량과의 관계

실험은 Allen Synphys experiment 2771, 외부 ID `1552517188.758`다. 네 점은 중심 device 4(cell 15834), 잎 device 1(15832), 2(15833), 5(15835)이며, 같은 세포 좌표를 유지한다. 위치·수동 전기 연결 표지는 앞선 원장의 것을 그대로 사용한다.

이번 조합은 [136개 대안 공리](고정뉴런_리만메트릭_대안공리_후보원장.md)의 **A037 전극 경계, A059 막 정전용량, A113 관측 연산자**에 해당하는 측정모형을 구체화한다. 추가한 가정은 다음과 같다.

| 가정 | 모형에 들어가는 위치 | 판정 범위 |
|---|---|---|
| 짧은 기록의 오프셋·직선 추세는 교란항으로 취급할 수 있다 | 고정 선형 변환으로 제거 | 곡선형 기준선이나 공통 신경 입력은 제거되지 않음 |
| 자기응답은 즉시항과 한 개의 RC 시간상수로 근사된다 | 전류에 대한 자기 전압 파형 | 전극·회로 효과가 섞인 유효 계수이며 막 상수 교정이 아님 |
| 약한 세포 간 전달은 두 RC 필터를 차례로 통과한다 | 자극·표적의 시간상수와 교차 gain | 정확한 결합망의 전달함수라고 하지 않음 |
| 작은 입력 범위에서는 계수가 시행 사이에 일정하다 | 두 학습 시행에서 정한 계수로 다른 시행 예측 | 이번 개발 검사에서 충분한 예측력을 얻지 못함 |

**[동기]** 수동 막 회로는 전류를 누설 저항과 막 정전용량으로 나누어 $C\dot V+(V-V_{\rm rest})/R=I$로 기술한다. 시간상수는 $\tau=RC$다. 이 식의 출발점은 [저자 공개 교재 Neuronal Dynamics 1.3절](https://neuronaldynamics.epfl.ch/online/Ch1.S3.html)에 설명되어 있다. 실제 기록이 이 근사를 만족하는지는 별도 질문이다.

**[미완성]** 교정된 연결 전도도 $c_e$를 얻으면, 고정점 변위 $d_e=p_j-p_i$로 구성하는 이동도 후보 $K=\sum_e c_e d_e d_e^\top$와 그 역수 계량 등을 비교할 수 있다. 이번 분석의 교차 계수는 MΩ 단위의 **전류 명령 → 측정 전압 전달 gain**이다. 이를 $c_e$에 대입하거나 SPD로 보정해 계량을 만들지 않았다. 관측모형의 예측 가능성을 먼저 검사하는 단계이므로 PRD에서 벗어난 별도 목표가 아니다.

## 2. 무엇을 관측하고 제거했는가

| 항목 | 고정한 내용 |
|---|---|
| 개발 자료 | 이미 본 sweep 10, 11, 12 |
| 미개봉 응답 | sweep 13, 14, 15; 명령·메타데이터만 기존에 알려짐 |
| 시간 구간 | 각 1초 전류 펄스 시작 기준 −0.3~+1.2초, 기존 acquisition read 범위 안 |
| 샘플 | 50 kHz 원전압을 250개씩 평균한 5 ms bin |
| 전환부 제외 | 시작 0초·종료 1초로부터 bin 중심 거리 5 ms 이하 제외; 남은 296개 bin |
| 단위 | 원 ADC의 conversion·offset 적용 후 mV, 명령은 pA; pA×MΩ/1000 = mV |
| 경계·품질 | 이전 검사에서 동일 구간의 명령 분리·작은 신호·발화·기준선 변화 조건을 통과한 세 시행만 사용 |
| 새 다운로드 | 0 byte; 등록된 1,247개 raw block 중 134개를 해시 확인하며 재사용 |

**[정의]** 남은 bin의 시간 벡터를 $t$, 상수열과 시간열을 묶은 행렬을 $X=[\mathbf1,t]$라 둔다. 전압 벡터 $v$와 예측 벡터 $\hat v$ 모두에 같은 변환을 적용한다.

\[
Q=I-X(X^\top X)^{-1}X^\top,
\qquad y=Qv,
\qquad \hat y=Q\hat v.
\]

**[정리]** $Q(\alpha\mathbf1+\beta t)=0$이므로 오프셋과 직선 추세는 이 평가에서 사라진다. 구현은 이 식과 같은 최소제곱 투영을 사용한다. 다만 $Qt^2\ne0$이며, 실제 곡선형 변동은 남는다. □

보류된 파형 전체에도 고정 $Q$를 적용한다. 따라서 이것은 **변환된 출력의 예측**이다. 원전압의 미래값을 기준선까지 예측하거나, 기준선의 생물학적 원인을 분리했다고 말할 수 없다. 실제 전류 효과의 상수·직선 성분도 함께 제거되므로 필터를 통과한 부분에만 판정이 적용된다.

## 3. 학습과 예측

**[정의]** $u(t)=\mathbf1_{0\le t<1}$은 1초 사각 명령이다. $h_\tau$는 $u$에 대한 1차 RC의 응답, $h_{\tau_s,\tau_j}$는 두 RC를 직렬로 통과한 응답이다. 모든 파형은 정확한 5 ms 구간 평균으로 계산한다.

자기응답에는

\[
\hat v_{ss}^{(k)}(t)
=\frac{I_s^{(k)}}{1000}\{a_su(t)+b_sh_{\tau_s}(t)\}
\]

를 사용한다. $I_s^{(k)}$는 시행 $k$에서 source $s$에 넣은 pA 명령이고, $a_s,b_s$는 MΩ 단위다. 각 fold의 **두 학습 시행만으로** 공통 $a_s,b_s,\tau_s$를 정한다. 시간상수 후보는 5·10·20·40·80·160 ms다. 즉시항 $a_s$에는 잔여 series/bridge 효과가 섞일 수 있어 부호를 제한하지 않는다. 수동 RC 해석의 다음 진행 조건에는 $b_s>0$을 요구한다.

서로 다른 표적 $j$, source $s$의 응답은

\[
\hat v_{js}^{(k)}(t)
=\frac{I_s^{(k)}}{1000}z_{js}h_{\tau_s,\tau_j}(t)
\]

로 예측한다. 교차 gain $z_{js}$는 두 학습 시행에서 적합하며, 방향별로 따로 두고 부호를 강제로 양수로 만들지 않는다. 따라서 이 단계의 gain은 수동 전기 연결의 채택값이 아니다. 비교군은 같은 자료·투영·학습 방식으로 맞춘 **즉시 사각응답**이다.

**[조건부 산출]** 두 RC의 단위 계단 응답은 $t\ge0$에서

\[
F(t)=1-\frac{\tau_s e^{-t/\tau_s}-\tau_j e^{-t/\tau_j}}{\tau_s-\tau_j}
\]

이고, 두 시간상수가 같으면 $F(t)=1-(1+t/\tau)e^{-t/\tau}$다. 1초 펄스에는 $F(t)-F(t-1)$을 쓴다. 이 식은 약한 결합 근사 아래의 후보이며, 결합된 회로의 고유모드를 모두 표현하지 않는다.

10번을 제외한 11·12번, 11번을 제외한 10·12번, 12번을 제외한 10·11번으로 각각 학습했다. 제외한 시행의 자기응답으로 시간상수를 갱신하지 않는다. 보류 명령만 예측 함수에 넣으며, 보류 전압은 마지막 오차 계산에서 사용한다. 모든 기록을 이미 본 뒤 세운 모형이므로 이 세 fold를 **새로운 독립 보류 검증**이라고 부르지 않는다.

다음 자료를 여는 개발 기준은 세 fold **각각**에서 (1) 모든 자기 느린 계수 양수, (2) 열두 교차 방향 전체의 RMSE/영예측 RMSE ≤0.8, (3) 수동 연결 표지가 있는 여섯 직접 방향의 같은 비율 ≤0.8이다. bin 수나 방향 수를 독립 동물 표본 수로 세지 않고 p값을 만들지 않았다.

앞선 긴 시간창 결과와 이번 비율을 직접 개선율로 비교할 수 없다. 이번에는 관측 변환, 학습 시행, 평가 대상이 달라졌다.

## 5. 남은 식별 한계와 다음 조건

계측 누화가 같은 명령·필터 응답을 만들면 교차 gain만으로 생물학적 결합과 구별되지 않는다. 직선 추세 제거 역시 곡선형 drift나 배경 시냅스 활동을 해결하지 않는다. 세포 위치의 세 방향 rank와 전기 연결 표지가 있어도 이 문제는 남는다.

다음에는 같은 실험의 **이미 확보된 VC 프로토콜 메타데이터와 전압 명령**에서 독립 입력이 있는지 먼저 확인할 수 있다. 입력 세포와 표적의 유지전압·기록 모드가 함께 변하는지, 각 명령 방향을 분리할 수 있는지, 교정 가능한 전극·막 경계 정보가 있는지를 확인한 뒤 분석의 적격성을 판단한다. 공통 명령만 있으면 다방향 전도도 식별로 진행하지 않는다. 응답을 보기 전에 무엇을 예측할지 정한다.

13–15번 큰 IC 응답은 이번 실패에 맞춰 열지 않는다. 향후 다른 질문에 사용하려면 진폭·전체 펄스 자기전압 변화·작동점·회복 조건과 부적격 처리법을 먼저 정해야 한다. 이번 결정은 해당 자료의 모든 후속 연구를 금지하는 뜻이 아니다.
