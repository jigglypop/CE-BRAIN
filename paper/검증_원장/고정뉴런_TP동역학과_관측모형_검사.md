# 고정 뉴런 TP 동역학과 관측모형 검사

유형: 연구 검증 원장. 판본일: 2026-09-06. **지위: 실제 TP 전환·종료 후 전류 관측은 `BIO_EVIDENCE_L1`, 모형·모드 검사는 개발 단계, 실제 전극·막·접합 전도도와 공간 리만 메트릭은 미확립.**

[저장 TP 대응 검사](고정뉴런_저장TP대응과_공통입력_식별.md)에서 확인한 열 개×일곱 채널의 실제 전류를 재사용했다. **명목 10 ms를 실제 삽입 명령에서 확인한 10.02 ms 후보로 바꾸면 종료 예측 오차가 크게 줄었지만, 선택한 필터 포함 후보의 전체 반복 기준은 통과하지 못했다.** 뒤쪽 네 기록에는 device 7의 큰 종료 후 안쪽 방향 전류도 있었다. 공통 입력의 일곱 동적 모드를 안정적으로 관측했다는 근거가 없어 회로 역산을 실행하지 않았다.

## 1. 고정한 점과 관측 전제

대상은 Allen experiment 2771의 device 0·1·2·4·5·6·7이며, 공간 구성의 네 점은 1·2·4·5다. 위치·정체를 고정한 채 전극, 막, 필터와 전류의 관계를 검사한다. 위치 고정은 막 상태나 측정 장치의 응답이 같다는 가정이 아니다.

이전 조건부 식별 정리는 대각 막용량 $C\succ0$, 대칭 전도행렬 $G\succ0$, 명시한 전극 저항 행렬 $E\succ0$와 이상적인 관측을 전제했다. 공통 계단 크기 $u$로 나눈 총전류를 $f(t)=\mathbf1^\top I(t)/u$라 하면 이 모형에서는

$$
f(t)=f_\infty+\sum_k a_k e^{-\lambda_k t},\qquad
f_\infty>0,\quad a_k\ge0,\quad\lambda_k>0.
$$

즉 계단 직후부터 총전류는 증가하지 않는 완전 단조 함수다. 조건을 확인하려면 $B=C^{-1/2}(G+E^{-1})C^{-1/2}$, $b=C^{-1/2}E^{-1}\mathbf1$를 두고, $B$의 정규직교 고유벡터 $q_k$와 고유값 $\lambda_k$에 대해 $a_k=(q_k^\top b)^2/\lambda_k$임을 사용하면 된다. 이 부호 조건은 **총전류**에 관한 것이며 개별 채널의 모든 지수계수가 양수라는 뜻은 아니다.

실제 기록에서 안쪽 방향 전류를 양수로 표시하면, 명목 시작 후 0.04→0.06 ms 사이 총전류가 기준선 표준편차의 약 133–179배 증가했다. 이것은 독립 표본에 근거한 통계적 유의도 배수가 아닌 변화량/기준선 척도의 비다. 기록을 명목 계단에 대한 이상적 직접 관측으로 대입할 수 없음을 보여 준다. 실제 명령의 유한 상승, 시각 정렬, 필터와 기생전류를 먼저 확인해야 하며, 연결 부재의 증거가 아니다.

기존 acquisition 메타데이터에는 LPF 10 kHz, 직렬 저항 보상 Off, whole-cell compensation Off가 있다. 그러나 **별도 StoredTestPulses의 속성에는 그 시점의 필터·보상 설정이 직접 붙어 있지 않다.** 이를 별도 TP의 독립 교정값으로 고정하지 않았다.

## 2. 시작 부분 적합과 종료·반복 예측

모든 파형은 이전 단계에서 이미 노출됐다. 이번 분석과 그 수정은 개발 검사이며 생물학적 독립 보류 검증으로 세지 않는다. 아래 sweep 번호는 대응하는 acquisition 번호를 사용한 TP 표지다.

| 항목 | 계산 기준 |
|---|---|
| 앞 시간 블록 | TP 0·1의 시작 반응 적합 → 2·3·4 평가 |
| 뒤 시간 블록 | TP 5·6의 시작 반응 적합 → 7·8·9 평가 |
| 블록 의미 | 시간상 묶음; 저장 TP의 실제 holding 전압 구분은 미확인 |
| 기준선 | 파형 5.90–7.40 ms, 양 끝 포함 76표본 |
| 적합 구간 | 명목 시작 후 0–9.98 ms, 종료 부분 사용 안 함 |
| 종료 평가 구간 | 파형 17.50–24.98 ms; 감도검사에서도 창 유지 |
| 필터 후보 | 동일한 1차 저역통과 두 개의 직렬 합성, 모든 채널에 공통 |
| 유효 필터 시정수 / 지연 | 0.002–0.08 ms / 0–0.06 ms |
| 모드 수 | 공통 지수 시정수 1–7개, 채널별 계수는 부호 자유 |
| 최초 지수 시정수 범위 | 0.1–100 ms |
| 척도 | 학습 기준선의 채널별 표준편차, 최소 1 pA |
| 모드 선택 | 학습 평균 잔차가 학습 차이/2 RMS의 1.25배 이하인 최소 차수 |
| 반복 판정 | 시작·종료 각각: 공동 RMSE/척도 ≤2, 최대 채널 RMSE/척도 ≤3, RMSE/영예측 ≤0.2 |

학습 차이/2는 반복이 독립·동일분포 잡음일 때 평균의 잡음 규모에 대응한다. 실제로는 작동점 변화·drift도 포함하므로 순수 측정잡음이나 신뢰구간으로 해석하지 않는다. 결과의 `whitened`·`noise` 필드는 채널 표준편차로 나눈 수치이며 시간 상관을 제거한 통계적 whitening이 아니다.

유효 필터의 라플라스 전달을 $F(s)=(1+s\tau_f)^{-2}$, 필터에 넣는 계단 반응을 $c_\infty+\sum_k c_k e^{-t/\tau_k}$로 두었다. $\tau_f$는 필터 시정수, $\tau_k$는 관측 과도응답의 후보 시정수, $c_k$는 채널별 전류 계수다. 이를 필터링하고 지연시킨 계단 반응을 $s(t)$라고 쓰면, 길이 $T$인 펄스의 예측은

$$
y_T(t)=s(t)-s(t-T),\qquad s(t)=0\ \text{for}\ t<0
$$

이다. 전체 계가 선형·시불변이면 필터가 있어도 이 식은 성립한다. 종료 반응을 시작 반응의 단순 음수로 놓지는 않았다. 원래 계단 반응이 종료 전 충분히 정상상태에 도달하지 않으면 그런 반전은 부정확하다.

앞·뒤 블록 모두 최초 선택 차수는 2였다. 명목 $T=10$ ms에서 앞 블록 후속 종료 RMSE는 26.753·26.777·27.060 pA, 뒤 블록은 191.784·258.297·242.676 pA였다. 두 블록 모두 전체 기준을 통과하지 못했다. 후속 기록을 모드 선택에 사용하지 않았으며, 비교용 전체 학습 평균 파형은 종료부까지 사용한다는 정보 차이를 결과에 명시했다.

## 3. 한 표본의 길이 차이를 분리한 검사

최초 실패를 살펴보니, [기존 실제 VC 명령 결과](../../verify/Q-NPF-04/fixed_points_metric/electrical_star_vc_inputs_result.json)의 삽입 TP는 70채널 모두 **7.50–17.52 ms, 즉 10.02 ms**였다. 원장 명목값 10 ms와 한 표본 차이다. 별도 저장 TP의 DAC 자체는 읽은 자료에 없으므로 그 길이를 측정했다고 하지 않는다.

별도 TP의 시작·종료 직후 첫 0.2 ms 안의 극값 간격도 70채널 중 66개가 10.02 ms, 두 개가 10.00 ms, 두 개가 10.04 ms였다. 극값 간격만으로 명령 길이와 같은 전환 커널을 증명할 수는 없지만, 10.02 ms 후보를 검사할 근거가 된다.

극·필터·계수·지연을 재적합하지 않고, 같은 최초 2모드 적합에서 길이만 바꿨다.

| 평가 TP | 명목 10.00 ms 종료 RMSE | 10.02 ms 후보 종료 RMSE |
|---|---:|---:|
| 2 | 26.753 pA | 16.479 pA |
| 3 | 26.777 pA | 15.817 pA |
| 4 | 27.060 pA | 16.216 pA |
| 7 | 191.784 pA | 190.648 pA |
| 8 | 258.297 pA | 257.424 pA |
| 9 | 242.676 pA | 241.761 pA |

앞 블록의 상당한 오차는 한 표본 길이 차이와 관련됐다. 이 개선을 생물학적 전극 교정이나 독립 검증 성공으로 세지 않는다. 고정된 평가 기준은 여전히 통과하지 못했다. 따라서 최초 실패를 막·연결 자체의 반증으로 확대하지 않는다.

![TP 전환, 길이 감도, 종료 후 사건과 모드 검사](../../verify/Q-NPF-04/fixed_points_metric/electrical_star_tp_dynamics.png)

그림 B는 적합을 바꾸지 않은 길이 감도검사다. 그림 C의 사건은 실제 기록이며 원인은 분류하지 않았다. 그림 D는 반복 변동 대비 차분 반응의 특이값으로, 내부 뉴런 차원이나 통계적 신뢰구간을 표시하지 않는다.

## 4. 빠른 시정수 경계와 높은 차수의 불안정성

최초 적합에서 필터 시정수는 두 블록 모두 하한 0.002 ms에 걸렸고, 앞 블록의 빠른 과도응답도 하한 0.1 ms였다. 이 상태에서 실제 필터나 막 시정수를 찾았다고 해석하지 않았다. 후속 개발에서는 지수 시정수 하한을 0.004 ms로 넓히고, 길이를 10.02 ms 후보로 두었다. 데이터 분할·적합 구간·선택 규칙은 유지했다.

필터 극과 과도응답 극이 일치할 때의 제거 가능한 특이점도 해석적 극한으로 계산했다. 두 시정수가 $\tau$로 같으면 해당 필터링된 지수 성분은 $\tfrac12(t/\tau)^2e^{-t/\tau}$다. 이를 수치적으로 검사했다.

| 넓힌 후보의 결과 | 앞 블록 | 뒤 블록 |
|---|---:|---:|
| 선택 차수 | 2 | 2 |
| 선택 시정수 | 약 0.0685·0.8331 ms | 약 0.1129·1.0884 ms |
| 선택 필터 시정수 | 0.002 ms 하한 | 0.002 ms 하한 |
| 후속 시작 RMSE 범위 | 15.440–16.761 pA | 13.429–15.271 pA |
| 후속 종료 RMSE 범위 | 16.194–17.052 pA | 190.648–257.424 pA |
| 전체 후속 기준 | 실패 | 실패 |

차수를 높이면 학습 평균 잔차는 줄었지만, 겹치거나 가까운 극들이 생겼고 설계행렬 조건수는 최대 약 $3.1\times10^8$이었다. 7모드의 학습 RMSE/채널 척도는 약 0.892·0.760까지 줄었어도 실제 일곱 막 모드의 식별을 뜻하지 않는다. 선택한 저차 후보의 실패를 모든 높은 차수 후보나 모든 선형 회로의 실패로 바꾸어 부르지 않는다. 필터·과도응답의 분리와 실제 매개변수는 여전히 미확립이다.

## 5. 종료 후 큰 전류와 안정적인 모드 수

종료 예측의 큰 오차를 설명하기 위해, 명목 17.80 ms 이후 기준선 대비 안쪽 방향 전류가 500 pA를 넘는 구간을 사후 기술했다. 문턱은 이미 본 실패 파형을 정리하는 기준이며 사전 사건 검출기나 발화 판정기가 아니다.

| 대응 TP | 채널 | 최대 안쪽 방향 전류 변화 | 최대 시각 |
|---|---|---:|---:|
| 5 | device 7 | 2.457 nA | 18.26 ms |
| 7 | device 7 | 3.231 nA | 18.14 ms |
| 8 | device 7 | 3.136 nA | 18.10 ms |
| 9 | device 7 | 3.007 nA | 18.12 ms |

8·9번에는 뒤에 추가 큰 파형도 보인다. 이 기록만으로 발화, Na 전류, 공간 고정 실패, 장치 현상, 직접 시냅스 연결 중 무엇인지 확정하지 않는다. 네 대상 점만의 종료 오차는 더 작지만, device 7을 빼는 것만으로 외부 경계 영향이 없거나 닫힌 네 점 회로가 됐다고 볼 수 없다.

조건부 공통 입력 식별에 필요한 동적 모드도 검사했다. 0.1 ms 평균 후 시작 0.2–9.7 ms 구간에서 인접 시간 차분을 구했다. 두 학습 기록의 평균 차분을 신호, 차이의 절반을 반복 변동으로 두고, 신호의 각 특이값이 변동 행렬의 최대 특이값의 3배를 넘는지 보았다. 이 문턱은 재현 가능한 기술 기준이며 차원의 신뢰구간이 아니다.

| 차분 모드 검사 | 앞 학습 0·1 | 뒤 학습 5·6 |
|---|---:|---:|
| 문턱을 넘은 특이값 수 | 1 | 1 |
| 첫 특이값 / 변동 최대 특이값 | 5.372 | 6.984 |
| 일곱째 특이값 / 변동 최대 특이값 | 0.488 | 0.646 |

현재 관측에서 **일곱 개의 안정적인 동적 방향은 확인되지 않았다.** 내부 차원이 정확히 1이라는 뜻은 아니다. 필터·채널별 장치 응답이 겉보기 모드를 만들 수도 있고, 잡음과 반복 상태 변화가 실제 작은 모드를 가릴 수도 있다.

원파형의 rank만 세면 정상상태 벡터 때문에 오판할 수도 있다. 정확한 예로 $E=I$, $C=\operatorname{diag}(1,2)$, $G=\operatorname{diag}(1,3)$에서는 공통 계단 전류가 $(1/2,3/4)^\top+(1/2,1/4)^\top e^{-2t}$이다. 원파형 rank는 2지만 차분·미분 궤적 rank는 1이다. 관련 테스트는 이 반례를 포함한다.

## 6. 판정과 다음 진행 조건

이번 결과는 **기록 TP를 이상적 초기 전류로 바로 대입할 수 없고, 길이·필터·종료 후 사건·반복 변동을 반영해야 한다**는 근거다. 지정한 후보의 전체 예측 기준과 일곱 모드의 실용적 관측 조건을 확보하지 못했으므로, $E,C,G$의 유일 역산이나 공간 계량을 계산하지 않았다. 고정점 가설 자체나 모든 공통 입력 식별 경로의 실패를 뜻하지 않는다.

다음 유효 질문은 **저장 TP의 실제 명령·필터·보상 계보를 더 직접적으로 확보할 수 있는지**, 또는 **같은 실제 세포에서 종료 후 사건과 동시 전류의 관계를 외부 경계·능동 막 후보와 구별할 수 있는지**다. 사건을 외생적인 독립 주입으로 간주하지 않고, 그 후보가 예측하는 채널·시각 관계와 경쟁 설명을 명시해야 한다. 실제 교정과 반복 예측이 확보된 뒤에도 고정 위치의 연결·전도도에서 리만 메트릭으로 가는 사상, 구성에 쓰지 않은 방향별 비용 예측이 남는다. [PRD](../../.codex/PRD.md)의 전체 목표는 미완료다.
