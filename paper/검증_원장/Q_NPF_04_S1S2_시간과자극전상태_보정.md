# 시간과 자극 전 상태를 고려한 S1/S2 대비

**시간만 선형 보정했을 때는 11세션의 대비 부호가 유지됐지만, 자극 전 S1·S2 평균 신호까지 보정하자 두 작은 양수 대비가 음수로 바뀌었다.** J064 run 11은 +0.001270에서 −0.003174, RL117 run 30은 +0.003830에서 −0.000578로 변했다. 무보정 부호가 전 상태를 다루는 방식에 민감한 기록이 있다는 결과다. 직접 전달·억제성 연결 또는 인과효과를 식별한 결과는 아니다.

## 질문과 고정한 비교

[전체 11세션의 무보정 결과](Q_NPF_04_S1S2_전체수집과_RL116_두세션.md)를 본 뒤 진행한 후속 탐색이다. 다운로드를 반복하지 않고 원장에 등록한 전체 파일을 재사용했다. 이번 질문은 기록 중 시간과 자극 전 관측 상태를 고려해도 기존 S2 대비가 유지되는가이다. 코드·자료·기존 결과 해시와 세 모형을 새 계약에 기록한 뒤 계산했다. 독립 확인자료나 생물 기전의 사전 예측으로 간주하지 않는다.

세션별로 기존 시각 제외 규칙을 유지하고 catch와 시험 자극 시행만 사용했다. easy는 제외했다. 반응값은 기존과 같은 명목 30Hz의 전 창 `[−2,−0.5)`초와 후 창 `[1.5,3)`초에서 구한 S2 세포별 후−전 평균의 세포 간 평균이다. 자극 전 공변량은 각 영역의 전 창 평균이며, 시간은 첫 분석 시행부터의 galvo 경과 초다.

같은 시행에서 다음 세 선형 모형의 시험 자극 계수를 모두 보고한다. 절편을 포함하고 시간·신호 공변량은 해당 세션 분석 시행에서 표준화했다.

1. 무보정: 자극 표지만 사용한다. 기존 시험 자극−catch 평균 대비와 같다.
2. 시간 보정: 경과 시간을 선형 항으로 추가한다.
3. 시간·전 상태 보정: 경과 시간과 자극 전 S1·S2 평균을 추가한다.

자극 이후 핥기·보상·성공 여부를 보정 변수로 넣지 않았다. 계수는 세션별 선형 투영의 조건부 관측 대비이며 인과효과가 아니다. 모형별 표본 선택이나 유리한 부호의 모형 선택은 하지 않았다.

시간·전 상태를 넣은 선형 모형에서는 J064와 RL117의 모든 기록이 음수가 되고, RL070의 두 기록은 양수를 유지했다. 그러나 세션 간 생물학적 차이를 확립하는 추론은 하지 않았다. 특히 RL117 run 30의 보정 계수는 0에 가까우며, 신뢰구간 없이 확실한 음수 반응이라고 부를 수 없다.

## 검증과 해석의 한계

전체 11세션에서 무보정 계수가 기존 결과와 허용오차 `1e-12` 안에서 일치했다. 알려진 계수를 가진 합성 예제, 최소제곱과 잔차화 계산의 일치, S2 전 값을 보정할 때 후 값과 후−전 값의 시험 계수 일치도 확인했다. 시간·전 상태 보정 모형의 계수행렬 순위는 모두 5, 조건수는 약 3.15–7.22였다. 수치적인 순위 부족은 없었지만 인과적 식별이나 공통 지지를 보장하는 검사는 아니다.

원 연구의 비무작위성, 미측정 행동·보상·이력, 비선형 시간 변화, 전 상태 측정오차, 전처리의 시간 혼입, 세포 구성 차이는 제거하지 못했다. 독립 확인자료는 없으며 표준오차나 유의성은 아직 계산하지 않았다. 11세션을 11개의 독립 동물로 취급하거나 마우스 간 평균 계수로 합치지 않았다.

이번 질문에는 단순한 시간항만으로는 부호가 바뀌지 않고, 전 상태를 포함한 선형 보정에서 두 기록의 부호가 바뀐다고 답할 수 있다. 기존의 작은 양수 대비를 그대로 고정된 연결 특성으로 읽는 해석은 지지할 수 없다. 어떤 생물 기전이 원인인지는 미식별이며, 증거 상한은 탐색적 `BIO_EVIDENCE_L1`, 전체 뇌 구조는 미확립이다.

다음은 연속 시행의 의존성을 고려한 불확실성 평가나 시간 분할로 계수가 특정 기록 구간에 의존하는지 확인하는 것이다. 추가 보정을 인과 식별의 대체물로 삼지 않으며 실제 프레임 시각·보상 시각·독립 개입 대조의 부족은 별도로 다룬다.
