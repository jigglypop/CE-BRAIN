# Q-NPF-04 — 연결을 가린 공통 이웃 예측

작성일: 2026-09-05. 같은 Minnie 23P 347세포의 내부 5분할 예측이다. 새 동물·종단 자료·독립 생물학적 확인 표본은 아니다.

## 질문과 정보 차단

[공통 이웃에 따른 잔차](Q_NPF_04_공통이웃_연결문맥.md)에서 공통 입력이 많은 세포쌍이 후속 후보로 나왔다. 이번에는 공통 입력 정보가 세포별 효과와 거리 정보에 더해 가린 연결을 예측하는지 확인했다.

가능한 60,031개 세포쌍을 결과와 무관한 고정 난수로 균등에 가깝게 5분할했다. 한 세포쌍의 양방향은 항상 함께 가렸다. 각 분할에서 평가 연결을 모두 제거한 학습 그래프를 먼저 만들고 그 그래프에서만 공통 입력·출력을 계산했다. 가린 부위를 음성 학습 사례로 쓰지 않았으며 학습 손실은 학습 마스크에 있는 방향만 사용했다. 전체 120,062개 방향이 평가에 한 번씩 포함된다.

기준모형은 절편·발신 세포 효과·수신 세포 효과·기존 거리 여섯 구간이다. 공통 입력만 추가, 공통 출력만 추가, 둘 다 추가한 모형을 함께 고정했다. 이웃 특징은 `log(1+개수)`이며 학습 방향들에서 계산한 평균·표준편차로 표준화했다. 절편을 제외한 모든 계수에 고정 ridge 벌점을 적용했다. 검증 결과에 따라 벌점이나 특징을 다시 고르지 않았다.

이는 이전의 정확한 기대 여백 적합과 다른 정규화 예측 모형이다. 세포 효과는 학습 연결에서만 추정한다. 평가 정답을 이용한 차수 특징을 만들지 않았다.

## 방향성 연결 예측 결과

로그손실과 Brier 점수는 작을수록 좋다. 표는 가린 방향 수로 가중한 전체 평가 평균이다.

| 모형 | 방향성 로그손실 | 기준 대비 변화 | 방향성 Brier 점수 |
|---|---:|---:|---:|
| 세포 효과+거리 | 0.18750196 | 기준 | 0.04630770 |
| 공통 입력 추가 | 0.18753352 | +0.00003155 | 0.04631208 |
| 공통 출력 추가 | 0.18751062 | +0.00000866 | 0.04630896 |
| 둘 다 추가 | 0.18754211 | +0.00004015 | 0.04631334 |

사전에 정한 주 평가인 방향성 로그손실에서 세 추가 모형의 평균 개선은 없었다. 공통 입력 추가는 5분할 모두에서 기준보다 손실이 조금 컸다. 공통 출력 및 둘 다 추가는 분할별 방향이 섞였다. 차이는 작으며 분할들은 학습 자료와 세포를 공유한다. 이를 독립 반복 실험이나 유의성 검정으로 해석하지 않는다.

## 상호연결에 관한 부 평가

각 모형의 양방향 예측 확률을 곱해 상호연결 확률을 계산했다. 이는 학습 그래프와 계수를 조건으로 양방향을 독립으로 보는 예측이다.

| 모형 | 상호연결 로그손실 | 상호연결 예측 수 합 |
|---|---:|---:|
| 기준 | 0.02245234 | 168.35 |
| 공통 입력 추가 | 0.02246184 | 168.21 |
| 공통 출력 추가 | 0.02243881 | 168.67 |
| 둘 다 추가 | 0.02244840 | 168.52 |

실제 평가 상호연결은 총 221쌍이다. 공통 출력 또는 둘 다 추가한 모형은 이 부 평가 로그손실에서 아주 작은 평균 개선이 있었으나, 예측 수 부족을 해소하지는 못했다. 부 평가의 작은 개선을 주 평가 실패 대신 채택하지 않는다.

## 판정과 다음 질문

**이번 고정된 선형 예측 형태와 내부 분할에서는 공통 입력 정보의 추가 예측 이득을 확인하지 못했다.** 앞서 공통 입력 4개 이상 집단에서 관측한 잔차와 양립하는 결과다. 그 집단별 요약이 세포 효과·거리 외의 일반적인 방향성 예측 이득을 보장하지는 않는다.

동시에 공통 입력의 생물학적 역할을 반증한 것도 아니다. 특징을 하나의 계수로 넣은 형태, 숨긴 연결 때문에 일부 공통 이웃도 사라진 점, 고정 벌점, 기존 표본을 이미 본 탐색이라는 제한이 있다. 내부 평가를 L2 종단·독립 예측 증거로 승격하지 않는다.

다음에는 양방향을 독립으로 곱하는 가정 자체를 점검할 수 있다. 공통 입력이 개별 방향성 연결보다 두 방향의 공동 발생에 관계하는지 구분하려면, 같은 가림 규칙을 유지한 공동 확률모형과의 비교가 필요하다. 모형 형태를 바꾸면 별도 탐색으로 기록한다. 전체 뇌 구조와 인과 기전은 미확립이다.

## 수치 검사와 저장

첫 L-BFGS 적합은 종료 메시지와 별개로 정한 기울기 오차 기준을 충족하지 못해 전체 비교를 해석하지 않았다. [첫 계약](../../verify/Q-NPF-04/allen_synphys/masked_neighbor_prediction_contract.json)과 [결과](../../verify/Q-NPF-04/allen_synphys/masked_neighbor_prediction_result.json)는 보존했다. 동일 목적함수에 Newton 보정을 추가한 [후속 계약](../../verify/Q-NPF-04/allen_synphys/masked_neighbor_prediction_polished_contract.json)에서 벌점·분할·특징·오차 기준을 유지했다. 20개 적합 모두 기울기 오차 0.00001 이하를 통과했다.

별도 검사는 5분할 각각에서 평가 정답을 모두 뒤집어도 학습 입력과 특징이 그대로임을 확인했다. 모든 세포쌍의 공통 이웃 수를 비트 집합으로 대조하고, 저장된 20개 적합의 기울기·예측·평가 지표를 다시 계산했다. 평가 방향이 한 번씩만 포함됨도 확인했다. 대표 모형 하나는 다시 적합했다. 독립 재계산한 최대 기울기 오차는 약 1.60×10⁻¹⁰이었다.
