# 독립 개입 후보: ICMS 기록의 실제 입력 확인

MICrONS 관측의 거리·회차·공유 세포 민감도 이후, 실제 자극과 신경·행동 기록을 함께 가진 자료로 조사 범위를 옮겼다. 보유 원장부터 확인했고, 로컬에 그림 요약만 있던 ICMS 자료의 공개 NWB 표본을 확보했다. **입력 확보와 스키마 확인까지 완료했으며 생물학적 결과는 아직 계산하지 않았다.**

## 보유 후보와 선택 이유

[기존 재고](../../verify/Q-NPF-03/local_data_inventory.md)는 특정 계량 endpoint를 위한 과거 감사다. 그 문서의 다운로드 금지와 표본 문턱을 새로운 모든 질문에 적용하지 않았다. 과거 판정은 그대로 보존했다.

| 후보 | 보유 근거와 이번 질문의 한계 |
|---|---|
| Randi 선충 단일뉴런 자극 | 원자료가 있으나 고정 개체의 급성 반응이며 행동 endpoint가 없다. 기존 unc-31 분석은 별도 계보로 보존한다. |
| Plitt/Kaganovsky Stx3 | 조작과 동일 ROI 종단 지도가 있지만 기존 arm별 trial 충분성 계약은 실패했다. 이번에 그 문턱을 완화하거나 재실행하지 않았다. |
| Hattori OFC | 기존 감사에서 영상·개입 코호트가 분리돼 동일개체 신경 매개 결합을 할 수 없었다. |
| ICMS 학습 | 로컬 그림 요약 외에 공식 코드가 처리된 신경 기록을 안내했다. 실제 자극·신경·행동 시각을 확인할 후보로 선택했다. |

생쥐 V1 단일뉴런 광자극 논문도 확인했으나 해당 논문의 자료 공개 문구는 저자 요청 방식이다. 저자에게 메시지를 보내지는 않았다. [Chettih와 Harvey 원문](https://www.nature.com/articles/s41586-019-0997-6)

ICMS는 단일 시냅스 선택적 조작과 다르며 S1 자료다. MICrONS V1 구조 연결의 직접 복제나 같은 세포의 개입 검증으로 취급하지 않는다. [공식 코드](https://github.com/XieLuanLab/icms-activation-plasticity)

## 획득 범위와 무결성

DANDI `001868`, 고정 판본 `0.260715.2016`의 메타데이터와 파일 목록 5페이지를 받았다. 고유 asset 85개, 총 7,504,049,197바이트다. 메타데이터는 12마리·85세션, 과제 학습 6마리와 수동 대조 6마리를 기술한다. 아직 동물별 실제 입력을 전수 검사한 것은 아니다. [고정 데이터 판본](https://dandiarchive.org/dandiset/001868/0.260715.2016)

파일명에 행동·전기생리·영상을 모두 표시한 후보 중 크기가 가장 작은 파일을 스키마 표본으로 골랐다. 반응값을 보기 전에 파일 크기로 선택했으며 대표 표본이나 확인용 holdout으로 주장하지 않는다.

- 파일: `sub-ICMS93_ses-2023-10-06_behavior+ecephys+ophys.nwb`
- asset: `e55c2085-e364-494b-a081-4c218f404ded`
- 크기: 31,957,441바이트
- SHA-256: `843e8cfabc9d4e8c8413f3c7f3e3046f47976e83328f98c9144f1e0b26993187`

서버 asset 메타데이터의 크기와 SHA-256을 대조해 일치한 뒤 임시 파일을 완성 파일로 옮겼다. 이미 받은 메타데이터는 재사용했다. 최초 메타데이터 읽기의 Windows 문자 인코딩 오류는 UTF-8 지정으로 수정했으며 같은 파일을 다시 받지 않았다.

| 항목 | 실제 파일 값 |
|---|---|
| 행동 시행 | 204개; `is_good_trial` 참 201개 |
| 자극 전류별 시행 | 0·3·4·5·6·7 µA에 각각 20·13·38·64·48·21개 |
| 전기 자극 이벤트 | 184개; 시각·채널·전류·주파수·펄스 수·폭·trial index 필드 있음 |
| 전기생리 | 33개 unit, spike time 173,237개; 수용 표지 모두 참 |
| 제공 세포형 표지 | interneuron 9개, pyramidal 24개; 독립 조직학 판정 여부는 미확인 |
| 영상 | ΔF/F 배열 36,154 × 1,101 ROI, 분할 마스크와 원본 ROI ID 필드 있음 |
| 영상 명목 시계 | 시작 0초, 약 30.124716 Hz |
| 처리된 바퀴 기록 | 시작 0초, 1,000 Hz |

0 µA 시행을 대조로 쓸 수 있는지는 시행 정의·순서·무작위화·시각 대응을 더 확인해야 한다. 필드 존재만으로 적절한 sham이나 무작위 배정을 단정하지 않는다. 전기생리 unit과 영상 ROI가 같은 세포인지, 세션 간 ROI ID가 지속되는지도 아직 확인하지 않았다.

영상에는 중요한 결측 경계가 있다. 100프레임마다 선택한 362 × 1,101 표본에서 유한값은 8,808/398,562개, 약 2.21%였다. 표본 내 비상수 열은 1,101개였지만 이는 연속 유효 기록을 뜻하지 않는다. 전체 결측률이나 유효 블록 길이를 이 표본 비율로 대신하지 않는다.
