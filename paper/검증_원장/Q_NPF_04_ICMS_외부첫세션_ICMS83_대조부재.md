# ICMS83 첫 세션: catch 부재로 고정 대비 정의 불가

**ICMS83의 고정 첫 세션에는 0 µA catch 시행이 없다.** 따라서 시간 구간별 catch를 빼는 외부 검증 대비는 모든 전류에서 정의할 수 없다. 이를 음의 결과나 양의 결과로 세지 않고, 다른 세션으로 대체하지 않는다.

## 입력 확인

[외부 5마리 계약](../../verify/Q-NPF-04/allen_synphys/icms_external_first_sessions_contract.json)이 지정한 `2023-07-20` 세션을 사용했다. 103,939,513바이트 파일을 확보하고 서버 크기·SHA-256 일치를 확인했다. ICMS100·ICMS101에 사용한 코드와 해시가 동일한 상태에서 실행했다.

5개 unit, 480개 시행이 있었다. 모든 시행의 품질 표지가 참이고, 100 Hz·70펄스·0.7초 자극 규격은 계약과 일치했다. 고정 전후 창의 다른 자극 중첩이나 세션 길이 대리 범위 위반도 없었다. 하지만 대조 부재가 별도의 필수 입력 실패다.

| 전류(µA) | 시행 수 | 같은 구간 catch 차감 |
|---|---:|---|
| 0 | 0 | 대조 없음 |
| 4 | 80 | 정의 불가 |
| 5 | 80 | 정의 불가 |
| 6 | 80 | 정의 불가 |
| 7 | 80 | 정의 불가 |
| 8 | 80 | 정의 불가 |
| 9 | 40 | 정의 불가 |
| 10 | 40 | 정의 불가 |

좋은 시행과 전체 품질 민감도 모두 같은 상태다. 계산 가능한 일부 시간 구간도 없었다. 결측 catch를 0으로 채우거나 ICMS93·다른 동물의 catch를 가져오지 않았다. 원 발화 count와 시행 정보는 보존했으므로 다른 질문의 자료 사용까지 금지한 것은 아니다.

## 외부 검증의 현재 상태

- ICMS100: 고정 대비 정의됨, 모든 관측 전류의 평균 음수.
- ICMS101: 고정 대비 정의됨, 모든 관측 전류의 평균 음수.
- ICMS83: 대조 부재로 전류별 대비 전부 정의 불가.
- ICMS92·ICMS98: 아직 미획득·미실행.

계약은 비교 불가 동물이나 전류가 있으면 5마리 전체 방향 확인을 인정하지 않도록 정했다. 따라서 **고정된 5마리 전체 확인 조건은 충족되지 않는다.** 이는 음의 평균 방향 가설의 생물학적 반증과 다르며, 필요한 비교가 관측되지 않은 상태다. 두 완료 동물의 관측 사실은 그대로 유지한다.

남은 ICMS92·ICMS98도 원래 지정된 첫 세션을 같은 규칙으로 검사해 전체 범위를 마무리한다. 대조가 있는 다른 세션을 조사하는 것은 별도 질문과 선택 규칙이 필요한 후속 작업이며 이번 검증의 대체 성공으로 세지 않는다. 전체 뇌 인과 기전 목표는 여전히 미확립이다.
