# S1/S2 대비의 시간 구간 의존성

**시간·자극 전 상태를 보정한 뒤에도 J064의 두 기록은 전반과 후반의 대비 부호가 달랐다.** 연속 시간의 4분의 1 구간을 하나씩 제외하면 이 두 기록과 RL117 run 30에서 부호가 바뀌었다. 작은 전체 기록 계수를 고정된 연결 특성으로 해석하기 어렵다는 근거가 추가됐다.

## 질문과 방법

[직전 보정 분석](Q_NPF_04_S1S2_시간과자극전상태_보정.md)의 시행별 값을 재사용했다. 다운로드나 전처리를 반복하지 않았다. 전체 11세션을 이미 본 뒤의 탐색이며, 새 계약에 시간 분할·제외·최소 표본과 보고 규칙을 고정한 다음 계산했다.

각 세션에서 첫 유효 catch·시험 자극 시행부터 마지막 시행까지의 galvo 경과 시간을 반으로 나눴다. 전반과 후반에서 별도로 적합했다. 같은 시간 범위를 4등분하고 각 구간을 차례로 제외한 네 번의 적합도 수행했다. 따라서 시간 길이를 나눈 것이며 시행 수가 같은 구간은 아니다. 경계는 왼쪽 포함·오른쪽 제외이고 마지막 끝점은 마지막 구간에 포함했다.

모든 부분집합에서 무보정·시간만 보정·시간과 S1/S2 전 상태 보정 모형을 다시 적합하고 공변량도 다시 표준화했다. 각 집단 최소 6시행을 요구했다. 원래 시각 제외와 easy 제외, 명목 전후 창은 유지했다. 전체 77개 부분집합과 각각의 세 모형에서 표본·수치 조건을 통과했다. 분할 결과를 보고 제외 구간이나 표본을 바꾸지 않았다.

## 시간·전 상태 보정 결과

마지막 열은 네 번의 구간 제외 계수 중 최솟값과 최댓값이다. **신뢰구간이나 표준오차가 아니다.** 전체 세 모형과 각 부분집합의 집단별 시행 수는 결과 파일에 보존했다.

J064 run 10과 11은 전후반 부호가 반대다. 이 두 기록은 무보정과 시간만 보정한 모형에서도 전반 양수·후반 음수였다. RL117 run 30은 시간·전 상태 보정의 두 반분 모두 음수지만, 마지막 4분의 1 구간을 제외하면 +0.004734가 됐다. 서로 별도로 적합한 반분 계수의 평균이 전체 계수와 같을 필요는 없다.

나머지 여덟 기록은 이번 반분·구간 제외 조건에서 시간·전 상태 보정 부호가 유지됐다. 이는 정한 분할에서의 기술적 안정성이다. 예를 들어 RL116 run 33은 부호를 유지하면서도 전반 −0.031661, 후반 −0.011597로 크기가 달랐다. 부호 유지가 시간 불변성이나 통계적 유의성을 뜻하지 않는다.

## 검증과 현재 판정

합성 시간 배열로 경계 포함 규칙을 검사했다. 각 실제 세션에서 두 반분이 전체 시행을 겹침 없이 덮고, 네 제외 구간이 각 시행을 정확히 한 번씩 제외하는지 확인했다. 전체 시행 적합은 기존 세 모형의 계수와 `1e-12` 이내에서 일치했다. 적합마다 기존 최소제곱·잔차화 계수 일치 검사를 사용했다.

이번 질문에는 세 기록의 보정 부호가 시간 구간 선택에 민감하다고 답할 수 있다. 두 기록은 전후반에서도 반대였다. 그러나 시간과 함께 행동·이전 자극 이력·표본 구성도 변하므로 어떤 요인이 원인인지 분리하지 못했다. 별도 적합은 독립 예측시험이 아니며, 자기상관을 제거하거나 통계적 불확실성을 추정한 검사도 아니다.

생물 기전의 반증이나 직접 전달·억제성 연결은 미식별이다. 상한은 탐색적 범위고정 관측 `BIO_EVIDENCE_L1`이며 전체 뇌 구조는 미확립이다. 11세션을 11독립 동물로 세지 않았다. 다음에는 연속 시행 의존성과 관측된 시간 변화에 대한 가정을 명시한 불확실성 평가가 필요하다. 실제 프레임·보상 시각과 선택적 개입 대조의 부족도 계속 남는다.
