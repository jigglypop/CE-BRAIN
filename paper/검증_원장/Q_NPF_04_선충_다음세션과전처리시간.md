# 선충 다음 세션의 예측과 전처리 시간 방향

**동일 모형을 WT 세션 9에 적용했을 때 오차 감소는 0.085%였고, 평가 자극 하나를 제외하면 부호가 뒤집히는 경우가 있었다.** 세션 6의 오차 증가와 함께 보면 일관된 표적 정보의 예측 이득을 확인하지 못했다. 전체 뇌 인과 구조는 미확립이다.

## 다음 세션 결과

[이전 시간 분할 비교](Q_NPF_04_선충_표적정보_시간분할예측.md)에서 이미 메타데이터로 적격성이 확인된 다음 세션 9를 사용했다. 상태·시간 입력, ridge 계수 10, 표적 잔차 보정 분모의 +5, 시간 창, 직접 표적 제외와 세포 적격성 기준을 그대로 유지했다. 별도 코드·계약·결과로 저장했으며 원래 세션 6의 봉인은 수정하지 않았다. 각 세션의 앞부분에서 따로 적합하므로 세션 6의 계수 자체를 세션 9로 옮긴 시험은 아니다.

| 항목 | 세션 6 | 세션 9 |
|---|---:|---:|
| 평가 비표적 세포 | 93 | 136 |
| 지원되는 평가 자극 | 6 | 5 |
| 기준 모형 오차 | 1.752395 | 2.751966 |
| 표적 보정 모형 오차 | 1.806283 | 2.749627 |
| 상대 오차 감소율 | −3.075% | +0.085% |
| 개선 세포 | 38 | 68 |

오차는 학습 반응 표준편차로 나눈 제곱오차의 세포 내 평균을 세포 간 평균한 값이다. 세션 9의 양성 표시는 단지 미리 정한 `표적 모형 오차 < 기준 오차` 조건을 뜻하며, 유의성·실용성·인과효과의 통과가 아니다. 136개 세포는 같은 다섯 자극에 반응하므로 136개의 독립 개입 복제가 아니다.

세션 9 평가 자극을 하나씩 제외하고 재적합 없이 집계하면 오차 감소율은 약 −0.210%~+0.444%였다. 자극 43을 제외하면 음수가 된다. 따라서 작은 평균 이득을 견고한 방향성으로 해석하지 않는다. 이 추가 점검은 결과를 본 뒤 수행한 민감도이며 새로운 확인시험이 아니다.

## 전처리 출처 확인

로컬 Git의 export 실행 스크립트는 `remove_spikes=True`, `photobl_appl=True`, `smooth_mode='sg_causal'`, 창 13·차수 1을 설정하고 전처리된 신호를 내보낸다. 이 코드와 연결되는 [저자 Signal 소스](https://github.com/leiferlab/wormdatamodel/blob/532d9b65d62e899fb29d2e8ab69a0c22f2889cc2/wormdatamodel/signal/signal.py)를 필요한 파일 하나만 받아 판본·해시를 기록했다. 원자료 재다운로드는 없었다.

그 판본에서는 결측 보간이 나중의 유효 표본을 사용할 수 있고, 큰 신호 제거는 전체 기록 평균·표준편차를 사용한다. 광퇴색 보정도 전체 시간축과 신호를 적합한다. 따라서 인과적 평활화라는 이름 하나만으로 전체 전처리가 과거 정보만 사용한다고 볼 수 없다.

실제 export 당시 사용한 라이브러리 판본, 저장된 객체의 전처리 상태와 실행 로그는 확인되지 않았다. 이 소스 조사는 미래 정보 유입 경로가 존재함을 보여주지만, 현재 export에서 유입된 양이나 그것이 오차를 바꾼 방향을 측정한 것은 아니다. 이번 회귀의 학습·평가 분리를 전체 입력 처리의 시간 분리로 확대하지 않는다. 결과 상한은 과거 기록의 탐색 관측 `BIO_EVIDENCE_L1`이며 `L2`는 미확립이다.

## 다음 행동

현재 모형의 반복 적용만으로 구조 발견을 주장할 수 없다는 질문에는 답했다. 표적별 단순 보정의 일관된 이득은 확립되지 않았고, 생물학적 상호작용의 존재 가능성은 남아 있다. 다음은 이미 보유한 OSF 목록의 `raw_extracted_data` 폴더 또는 `exported_data_full.tar.gz`에서 같은 세션의 전처리 전 신호·결측 표지·세포 대응을 확인하는 것이다. 같은 세션의 입력이 연결되면 미래 표본을 사용하지 않는 전처리로 다시 비교할 수 있다. 입력을 복구하기 전에 작은 양성 결과에 맞춰 모형을 조정하지 않는다.
