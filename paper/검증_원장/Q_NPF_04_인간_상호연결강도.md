# 인간 피질 상호연결과 강도: 세포 효과를 고려한 관측

간질 수술 ER 표본의 검출된 연결에서, 송신·수신 세포별 차이를 고려한 상호연결의 로그 진폭 계수는 0.52491, 지수값은 1.69030이었다. 이 대비를 식별할 수 있는 자료는 21개 기록·11명 환자의 261개 방향이다. 전체 뇌의 연결 법칙이나 인과 효과를 확립한 결과는 아니다. 주장 상한은 이 표본과 모형에 한정한 `BIO_EVIDENCE_L1` 관측이다.

## 질문과 자료

최종 목표는 뇌 회로의 구조와 기능 관계를 밝히는 것이다. 이번 질문은 상호연결 여부와 시냅스 진폭의 관계가 단순한 송신·수신 세포 차이를 고려해도 남는지다. 이는 연결 개수의 패턴과 연결 강도의 패턴을 구별하는 데 필요하다. CE 추가항이나 작동 기전은 이번 회귀에서 시험하지 않았다.

[데이터 원장](../../ledger/data_registry.md)의 `peng2024-human`, `zenodo10891892-v1` 자료를 재사용했다. 원본 ZIP의 SHA-256은 실행 계약과 검증 영수증에서 확인했다. ER만 분석하며, TR의 진폭 42개는 원본 대응이 미해결이라 제외한다. 기존 [진폭 대응 감사](Q_NPF_04_인간자료_진폭대응.md)와 별개의 조건부 분석이다.

모형은 기록마다 `log(진폭 mV) = 송신 세포 효과 + 수신 세포 효과 + beta × 상호연결 + 잔차`다. 진폭이 유한한 양수이고 저자 연결 표지가 양성인 방향만 사용했다. 역방향 연결 표지로 상호연결 여부를 정의한다. 검출되지 않은 연결의 강도를 0으로 대입하지 않는다. 세포 효과는 이 자료에서 추정한 통계적 차이이며 생물학적 원인의 분리는 아니다.

## 결과와 검증

| 항목 | 저자 공개 표 | 양방향 원시 코드가 유한한 경우 |
|---|---:|---:|
| 사용 가능한 양성 진폭 방향 | 1,040 | 1,037 |
| 대비가 식별되는 기록 / 환자 | 21 / 11 | 21 / 11 |
| 정보 있는 기록의 방향 수 | 261 | 261 |
| 동일 기록에서 기록별 절편만 고려한 강도비 | 0.99633 | 0.99633 |
| 송신·수신 효과를 고려한 exp(beta) | 1.69030 | 1.69030 |
| 환자 한 명씩 제외한 exp(beta) 범위 | 1.42717–1.95826 | 1.42717–1.95826 |
| 양의 계수 기여를 보인 환자 | 8 / 11 | 8 / 11 |

두 분기의 정보 있는 기록과 기여는 동일했다. 원시 결측을 제외해도 결과가 같다는 것은 이 제한된 제외 규칙에 대한 민감도 결과다. 유한 코드가 검사 품질을 보장하거나 모든 누락 편향을 제거한다는 뜻은 아니다.

강도비 1.69는 로그 진폭 모형의 조건부 계수를 지수화한 값이다. 전체 연결의 산술 평균이 69% 크다는 해석은 성립하지 않는다. 조정 전후에는 모형과 가중 방식이 바뀌므로, 두 수치의 차이만으로 특정 세포 특성이 관계를 숨겼다고 확정할 수 없다. 환자 제외 범위는 신뢰구간이나 독립 복제가 아니다.

원 계산은 세포 효과를 제거한 잔차로 계수를 구했다. 별도 검증에서는 원 CSV에서 전체 설계행렬을 다시 구성해 한 번에 최소제곱을 풀었다. 261행·244열, 계수행렬 rank 210에서 beta가 0.524905846623815로 일치했다. 정규방정식의 최대 잔차는 7.13e-14였다. 송신·수신 개별 계수에는 중복 자유도가 있지만 이번 상호연결 대비는 식별된다. 이 검증은 산술 검증이며 생물학적 재현이 아니다.

## 판정과 다음 조건

- **원래 질문:** 이 표본의 정보 있는 기록에서는 세포 효과를 고려한 양의 관계가 남는다. 실제 진폭 endpoint를 평가했다.
- **배제된 설명의 범위:** 이번 모형에서 송신·수신의 가산 효과만으로 관측 로그 진폭 대비가 정확히 사라지지는 않는다. 통계적 유의성이나 인과 가설 기각은 주장하지 않는다.
- **남은 설명:** 거리, 층 내 위치, 절편 손상, 검출·진폭 누락, 환자 구성과 비가산 상호작용이 관계에 기여할 수 있다. 수술 표본에서 건강한 인간 전체로 일반화하지 않는다.
- **출처 한계:** ER 원시 코드 결측 32방향의 처리 근거, 논문과 공개 표 사이 양성 연결 1개 차이는 미해결이다. 기존 판정이나 원자료를 덮어쓰지 않았다.
- **다음 진행 조건:** 거리 변수가 같은 방향에 대응하고 단위·누락이 확인되면, 동일 기록에서 거리 효과를 추가한 민감도 분석을 별도로 고정한다. 현재 자료를 이미 보았으므로 후속 분석은 탐색이며 독립 확인으로 부르지 않는다.
