# DEPRECATED — spatial rank test is not a Pattern-Jet temporal validation

이 파일의 이전 rank-1/rank-2 region 실험은 사용자의 Pattern-Jet 가설과 다른 대상을 계산했다.

**2026-10-02 판정: Pattern-Jet의 증거로 사용하지 않는다.**

이유:
- 공간 region rank를 검사했다.
- x_t → Δ_1(t) → Δ_2(t)의 시간 이력 상태를 만들지 않았다.
- 현재값이 같은데 과거가 다른 상태를 구별하지 않았다.
- 미래 신경상태에 대한 held-out 예측을 검사하지 않았다.

과거 결과 파일과 코드는 개발 이력 보존 목적으로 남기지만 active evidence에서 제외한다.

현재 유효한 직접 시험은 TEMPORAL_JET_TEST.md와 temporal_jet_test.py다.
