# Pattern-Jet 실데이터 검증 — 2026-10-02

## 판정

**후보식의 두 필요조건은 실제 측정에서 지지되지만, `K>1` 시냅스 내부 이력 캐스케이드와
무한고차원 극한 자체는 아직 직접 검증되지 않았다.**

따라서 현재 판정은 **후보 유지 / 전체 생물학 검증 보류**다.

## 1. 전역 스칼라 하나로 충분한가 — 실패

Bergmann et al. 2026의 저자 공개 처리 KC calcium CSV를 고정 blob으로 읽고,
31°C ctrl 평균에서 TRPA 평균을 예측하는 7개 냄새 위치 leave-one-out을 다시 계산했다.

| 모델 | RMSE | MAE |
|---|---:|---:|
| global gain | 0.15140972 | 0.13211048 |
| global affine | 0.13599335 | 0.10526619 |
| local gain | 0.05407891 | 0.04114580 |
| **local affine** | **0.04325579** | **0.03148494** |

local affine은 global affine보다 RMSE가
**68.19% 낮다.**

이 결과는 **하나의 전역 스칼라 반응관계가 이 KC 처리자료를 설명하기에 부족하고,
영역/구획별 상태가 필요하다는 실데이터 증거**다.

하지만 이것을 바로 `앞 시냅스 delta`의 직접 측정이라고 부르지는 않는다.
정적 군 평균 자료이므로 시간 이력을 식별하지 못한다.

## 2. 현재 입력만으로 상태가 결정되는가 — 실제 동물자료와 모순

Sun et al. 저자 저장소의 Figure 4j notebook에 들어 있는 11마리 가공값을 그대로 사용했다.

- Pre-R2 평균 정규화 분리시점: **0.409773411**
- Pre-R1 평균: **0.589953590**
- Pre-R2가 먼저 분리: **8/11**
- 반대: **3/11**
- paired t-test: **p=0.04405412**
- exact two-sided sign test: **p=0.22656250**

과제의 공유 감각 구간에서 현재 관측만의 결정론적 함수 \(z=f(o_t)\)라면
Near/Far가 같은 현재 관측을 가질 때 같은 상태를 내므로 문맥별 분리를 만들 수 없다.
실제 해마 집단표현은 학습과 함께 공유 감각 구간을 분리한다.

따라서 **현재값 외에 과거 문맥을 보존하는 상태가 필요하다는 방향은 실제 동물자료에서 지지된다.**

다만 paired t-test와 exact sign test의 결론 강도가 같지 않으며,
이 자료만으로 `K=2`, `K=8`, 분수차수 같은 수치를 고를 수 없다.

## 3. Pattern-Jet 전체가 검증됐나 — 아직 아니다

현재 실제자료가 지지하는 것은 다음 두 가지다.

1. 하나의 전역 스칼라 상태만으로는 부족하다.
2. 현재 감각만으로는 동일 감각의 문맥별 신경상태를 설명할 수 없다.

아직 직접 검증되지 않은 것은 다음이다.

- 하나의 실제 시냅스/말단에 독립적인 다중 시간모드 \(u_1,\ldots,u_K\)가 있는가.
- `K>1`이 같은 파라미터 예산의 `K=1`보다 **새 동물/세션** 예측을 개선하는가.
- \(\Delta_{e,k}=u_{e,k-1}-u_{e,k}\)가 실제 가소성 변화량을 예측하는가.
- \(K\to\infty\) 극한을 생물학적 실체로 볼 수 있는가.

Kropf et al. 2026은 실제 초파리 KC 집단이 서로 다른 지연에 최대반응하는 시간기저를 만들고,
강화 시점에 활성인 KC→MBON 가중치가 선택적으로 감소한다는 독립적인 실험 근거를 제공한다.
이는 Pattern-Jet의 **시간기저+국소 저장** 방향과 가깝지만 정확한 내부 캐스케이드 식을 측정한 것은 아니다.

Davidson et al. 2023의 bouton별 가소성 이질성은 전역 뉴런 상태보다 국소 상태의 필요성을 지지하지만,
단순한 pairing 전 시간 프로파일만으로 plasticity를 충분히 예측할 수 없었다는 제한도 남긴다.

## 4. 다음 직접 검증 기준

다음 데이터에서는 실행 전에 아래를 고정해야 한다.

- `K ∈ {1,2,4,8,16}`, 로그 간격 \(\tau_k\)
- train animal/session에서만 readout 적합
- held-out animal/session에서 RMSE 또는 log-likelihood 비교
- `K=1` 대비 `K>1`의 개선
- 같은 자유도/유효 파라미터 예산 대조
- history shuffle 대조
- 현재 activity만 쓰는 대조
- 개선이 없으면 Pattern-Jet의 고차원 저장 가설은 **실패**로 판정

이번 결과는 그 직접 시험 전의 **실데이터 필요조건 검증**이다.
