# CE-BRAIN 기존 결과 검증·선별 판정서

**2026-09-16 · 기준 커밋 `22b2251be2b12af3ae1e3806290e8283d6321c4d`**

## 판정

새 식을 만들지 않고, 실행 가능한 첨부 3개를 재검산했다. 기존 연구의 강한 비교 기준과 음성 결과를 다시 대조했고, FR1의 입력 소유권 결함 한 건을 재현·수정했다. 수정은 복사본의 두 줄뿐이다.

현재 남기는 것은 **계산 부품과 범위를 제한한 관측·합성 실험 기록**이다. 검토한 자료에서 **실제 전체 MaleCNS의 발화·학습·보행·신체 피드백을 함께 재현했다는 합격 판정은 없다.** 새 생물학 표본·새 신경 모형은 0개다.

‘전부’라는 요청에 맞춰 미확인 연구 묶음도 선별 원장에서 빠뜨리지 않고 미검증으로 격리했다. 그러나 전체 저장소·모든 Library ZIP의 내용·전량 생물 자료를 모두 실행해 검증 완료했다는 뜻은 아니다. 실행 범위와 기록 검토 범위는 아래 및 `evidence/access_and_coverage.json`에서 분리한다. 누락·미실행은 오답 또는 반증으로 계산하지 않는다.

## 2. 확인한 코드 결함과 처리

`ce_cns_fr1/core.py`의 생성자는 호출자가 전달한 CSC 배열·행렬과 저장 공간을 공유했다. 입력을 바꾸면 검증된 전이는 바뀌지만 VNC 효능 미분의 평균 캐시는 그대로 남았다.

서로 다른 CSC 타입 두 경우에서 동일하게, 여전히 비음수이고 열합이 1인 입력 변경을 했을 때 캐시 차이가 0.3이 되었고 `first-hit tangent conservation failed`가 발생했다. 원래 119개 테스트에는 이 변경 순서가 없었다.

수정은 Q와 E 구성에 `copy=True`를 지정한 두 줄이다. 새 식·가중치 학습·뉴런 동역학을 추가하지 않았다. 수정 뒤 입력 변경이 연산자에 전파되지 않고, 121개 검사가 통과했으며 원래 64조건 결과의 주요 수치가 정확히 같았다. `git apply --check` 및 적용된 core 바이트의 일치도 확인했다.

**한계:** 연산자 내부의 공개 `op.Q`, `op.E`를 직접 수정하는 API는 지원하지 않는다. 이 패치는 그 직접 변경을 막는 불변 객체 구현이 아니며, 호출자 소유 입력과의 공유만 고친다. 희소 배열을 소유하기 위한 추가 복사 비용이 든다. 전체 크기 메모리 벤치마크는 이번에 하지 않았다. 기존 `BrainRuntime`의 snapshot·Dale 문제도 고친 것이 아니다.

원본 ZIP 세 개는 해시가 그대로이며, 원격 GitHub와 봉인 결과는 수정하지 않았다. 패치는 `patches/fr1_input_ownership.patch`, 반례·통과 로그는 `evidence/alias_effect_*.json`, `ownership_*.xml`에 있다.

## 3. 성능 주장 선별

### 구조가 기능을 일반적으로 예측한다 — 주장 축소

CGU4의 type 보류 NLL 개선 11.6958%는 그대로다. 그러나 이름 계열 보류는 3.5373%, 정규화 출처 보류는 **1.0308% 악화**다. 결합모형을 사용해도 같은 출처 보류의 강한 기준선 대비 개선은 0.3623%다. 같은 숫자를 내는 출처/계열 합동 분할은 독립 확인으로 중복 계산하지 않는다.

카탈로그 안의 연관은 보존하지만, 새로운 출처의 기능을 견고하게 예측한다거나 CE가 우월하다는 주장은 현재 채택에서 뺀다. 통계적 유의성이나 독립 동물 검증을 새로 만들어 넣지 않았다. [CGU4]

### 재생 최적화가 가장 좋다 — 강한 기준선 앞에서 제외

ARTC1의 MSE는 joint 0.611563, greedy 0.751006, direct-slow 0.491424다. **탐욕 대비 18.5675% 감소하지만, 직접 느린 쓰기 대비 24.4470% 크다.** 직접 쓰기가 불가능한 별도 생물학적 제약 문제에까지 일반화해 열등하다고 결론내리는 것은 아니다. 이 프로토콜에서의 탐욕 대비 개선만 남긴다. [ARTC1]

### 수면 특수성·위상 정렬 우위 — 현재 모델에서는 인정하지 않음

수면 검증 v2의 조건이 같은 각성 대조는 24개 시드 모두 bitwise 동일했다. 정렬 정확도 95.913%, 창 이동 96.029%로 차이는 −0.116%p, paired 95% 구간은 −0.362~+0.145%p다. 동일 총량의 일정 게이트도 비슷하거나 더 좋았다. 재생으로 느린 가중치를 남기는 합성 예시는 보존하지만 수면 고유 기전·특별한 위상 우위의 증거로 쓰지 않는다. 생물학적 수면이 무의미하다는 판정이 아니다. [SLEEP]

### 자원 경쟁만으로 한쪽 기억이 반드시 남는다 — 고정계 주장은 제외

RGM3의 고정 친화도·동일 연결은 대칭 평형에 수렴한 기록이 있다. 뒤에 추가한 협동 포착은 탐색적 후보이며, 그것으로 최초 음성 결과를 덮지 않는다. 물질 보존 계산과 실측 분자·호르몬 기전을 구분해 남긴다. [RGM3]

### 2/2 행동 일치 — CE 성과에서 제외

BIO_MATCH와 CGU5는 같은 DNa02/DNg13 두 유형의 공개 표와 이미 알려진 기능을 재사용했다. 해부학적 다수 출력 쪽 2/2의 정합성 자체는 지우지 않는다. 다만 이 휴리스틱은 CE가 없어도 계산되며 사례와 규칙도 결과를 알고 골랐으므로, 독립 예측 성공률로 세지 않는다.

사후에 붙인 ‘모든 유형에 공통 부호’, ‘DNg13에 고정 운동 방향’이라는 두 단순 해석의 실패도 FR1의 실제 오예측은 아니었다. 원래 모델에 없던 readout이므로 CE 성공·실패 점수에서 모두 뺀다. 실제 생리 관측을 만족해야 한다는 제약 사례로만 보존한다. [BIO-MATCH, CGU5]

## 4. 실제 관측을 무시하지 않되 범위를 바꾸지 않는다

**HPI1:** 원저 노트북의 33개 요약값과 저장소 전사값을 대조했다. 평균 Pre-R2 0.40977341, Pre-R1 0.58995359이고 순서가 반대인 동물은 3/11이다. paired t 검정 p=0.044054, 정확 부호검정 p=0.226563을 재계산했다. 이들은 서로 다른 가정/대상을 검사하므로 모순으로 읽지 않는다. 11마리의 가공 자료에서 본 차이만 남기고 모든 개체의 순서, 해마 주소 기전, 원칼슘영상 적합의 증거로 늘리지 않는다. [HPI-AUTHOR, HPI1]

**MaleCNS 이력:** 전체 이력을 넣어 원형을 복원한 것은 조건부 계산 증거로 보존한다. 짧은 lag 1/2/4/8의 signed 축약에서는 음의 분포가 기록돼 있으므로 유효 확률 모형으로 채택하지 않는다. lag15의 매우 작은 오차도 같은 원형에서 커널을 산출한 항등식 검사이지 미래 생리 기록의 정확도가 아니다. [M-OBS]

**CCEP:** README에 기록된 DISC2R의 거리 항을 이용한 관측 kernel 예측의 양성 결과는 별도로 남긴다. 그것을 뇌의 실제 리만 계량·의식·MaleCNS 행동의 증명으로 바꾸지 않는다. 이번 환자 원자료 재실행은 없고, 기존 문서의 73/74명 충돌도 해결하지 않았으므로 인원·표본 적합성까지 재검증 완료했다고 하지 않는다. [CE-README, KNOWN-DEBT]

**Allen 공간 rank:** 기존 부채 원장이 초기 세 점 rank 3을 중심화 반올림 오류로 교정하고 rank 2 기록을 가리킨다. 최초 rank 3 주장만 검증된 사실 목록에서 제외한다. 이 판정은 현 저장소 교정 기록에 근거하며 원자료 새 계산은 아니다. [KNOWN-DEBT]

## 5. 미검증을 성공이나 반증으로 바꾸지 않는다

전량 MaleCNS 캐시, 지정 자극의 정량 발화·다리 시계열, 전체 `BrainRuntime`/Rust/CUDA 검증은 이번에 실행하지 못했다. CGU 5개 별도 ZIP은 Library에서 보이지만 도구가 허가된 원본 바이트 경로를 제공하지 않았다. 다른 PatternLibrary·BCV·FMC·HPI2·RGM2 ZIP의 목록을 찾은 것을 그 내용을 실행한 것으로 세지 않았다.

따라서 이 항목들은 **채택 대기인 미검증 항목**이다. 원본을 삭제하지 않고 선별 목록에서 별도로 격리한다. 프랙탈·무한차원·의식·물리 상수와 뇌의 동일성도 검토한 자료만으로 확정하지 않는다. CE 전체의 반증이라는 판정도 내리지 않는다.

## 7. 채택 경계

원자료를 지우거나 새로운 후보식을 만들어 기존 실패를 덮는 방식으로 정리하지 않았다. 실제 신경·행동 모델로의 채택을 판정하는 데에는 동일 관측 단위의 예측과 데이터, 정의된 held-out 조건, 강한 기준선, 추가 파라미터·계산 비용, 원 코드·입력의 재현 가능성이 필요하다. 이것은 새 신경 가설이 아니라 증거를 분류하는 조건이다.

이번 선별 결과의 실행 핵심은 **수정된 FR1 계산 부품과 검증 장부**다. 생물학적 완성 모델이 아니라는 경계는 그대로다. 실제 관측에 관한 제한된 양성·음성 기록 모두 남겼고, 검토되지 않은 항목의 빈칸을 새 식이나 성공 점수로 채우지 않았다.

## 출처와 재현

출처 키와 고정 경로는 `sources.json`, 세부 결정은 `selection.json`, 실행 범위는 `evidence/access_and_coverage.json`에 있다. `inputs/`의 세 원본 ZIP은 바이트 그대로 보존했다. 새 패키지의 `MANIFEST.json`은 이 선별 패키지만 검사하며, 수정본에 옛 FR1 manifest를 적용하지 않는다.

로컬 복사본으로 실행 검사를 다시 하는 방법은 `README_KO.md`를 따른다. 소프트웨어 검사·집계 산술 재계산을 재현할 수 있지만, 이 패키지에는 전체 MaleCNS 원자료나 행동 원시 시계열이 들어 있지 않다.
