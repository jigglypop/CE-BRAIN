# CE-BRAIN: 단일 SPD 계량을 유지한 실제 KC 반응 예측부의 후속 수정

**2026-09-19 · 직전 리만 모델과 직접 비교 · 동일 공개 가공 측정의 후향 개발**

## 1. 결과

직접 비교 대상은 `CE_BRAIN_RIEMANN_IMPROVEMENT_20260919`다. 과거 비리만 회귀식으로 비교 기준을 되돌리지 않았다. 원본 ZIP을 별도 폴더에서 실행해 직전 네 평가값을 재현했다.

수정 모델은 네 기존 평가에서 RMSE와 MAE를 모두 낮췄다. 이는 수치 적분·반올림 오차보다 큰 직접 계산 차이다. 하지만 생물학적 모집단의 유의한 개선이나 전체 신경계의 완성을 입증하는 통계는 아니다. 236개 설정과 기존 분할 점수를 검토한 후 선택했으므로 기존 패널은 개발 자료다.

| 평가 | 직전 SPD RMSE | 수정 RMSE | 직전 MAE | 수정 MAE |
|---|---:|---:|---:|---:|
| 냄새 한 조건 보류 | 0.03705364 | **0.03635965** | 0.02655048 | **0.02577739** |
| 냄새 두 조건 보류 | 0.04029088 | **0.03962268** | 0.02857139 | **0.02803103** |

한 조건 보류의 감소는 RMSE **1.873%**, MAE **2.912%**다. 최대 절대오차는 **0.11994804→0.10112156**, **15.696%** 감소했다. 두 조건 보류의 최대 절대오차는 거의 같으므로 최대오차 개선을 모든 평가에 일반화하지 않는다.

숫자의 단위는 원저의 가공 칼슘 반응 단위다. 퍼센트포인트·발화 정확도·신경계 규명률이 아니다. 원래 입력은 같은 냄새의 대조군 칼슘 평균이고 목표는 처리군 평균이며, 이 문제 정의를 바꾸지 않았다.

## 2. 실제로 변경한 부분

### 영역별 크기에 맞춘 공통 결합

직전 기초 이동도는 유형별 대각 성분과 균일 공통 성분이었다. 이번에는 같은 차원의 SPD 구조를 유지하면서 공통 성분의 방향을 **훈련 대조군의 영역별 반응 크기**에서 정했다.

\[
L=\operatorname{diag}(d_{s(c)})+\rho vv^T\succ0,\qquad
v_c=\frac{\sqrt{\overline{\phi(x_c)}_{train}}}{\sqrt{\sum_j\overline{\phi(x_j)}_{train}}}.
\]

이 v는 훈련 입력만 사용한다. 보류 처리군이나 보류 입력을 사용해 방향을 선택하지 않는다. 추가 생리 파라미터나 실제 APL 연결강도를 추정한 값은 아니다. 생물학적 근거는 원저에서 지역/유형별 반응 변화가 다르고 흥분 감소와 억제 감소가 상쇄된다는 관측이다. 그 관측이 이 정확한 v 공식을 유도하지는 않는다. [S1]

### 국소 차이는 남기되 가지 사이 보정 차이를 약하게 제한

기존 α–β, α′–β′ 묶음을 유지하고, 보정 과정의 구획별 오프셋 b에 아래 비용을 추가했다.

\[
\lambda_b n\left[(b_\alpha-b_\beta)^2+(b_{\alpha'}-b_{\beta'})^2\right],\quad\lambda_b=0.06.
\]

같다는 등식을 강제하지 않는다. 실제 보정값은 다를 수 있다. 별도 말단 상태나 뉴런을 추가한 것이 아니라, 이미 존재하던 기준 결합의 과도한 차이를 억제하는 추정 제약이다. b는 보정 중의 임시 좌표이며 추론 모델에 별도 상태로 저장하지 않는다.

### 기존 입력 척도와 SPD 보정의 크기도 다시 비교

최종 설정은 입력 지수 0.625, 측정오차 가중 지수 2.5, 공통 결합 정규화 3.0, SPD 접공간 보정 스텝 0.2다. 직전 값은 각각 0.75, 2.0, 1.0, 0.1이었다. 처음 탐색에서는 0.75를 고정했고 이후 탐색 단계에서 입력 척도까지 비교했다. 각 단계의 모든 결과가 저장돼 있다.

**이 숫자들은 개발 자료에서 선택한 설정이지 생물학적으로 측정된 상수가 아니다.** 가중 지수 2.5는 통상적인 Gaussian 우도보다 강한 가중이다. 정확한 오차변수 추정이나 확률 보정 완료라고 부르지 않는다. 분산 바닥, 공분산 근사 개선, robust loss, 추가 국소 기울기/쌍 결합도 탐색했지만 최종 구현에서는 사용하지 않았다.

## 3. 보존한 리만 계산과 실제 모델 상태

\[
G=G^T\succ0,\qquad
G=\begin{bmatrix}L^{-1}&-L^{-1}b\\-b^TL^{-1}&1+b^TL^{-1}b\end{bmatrix},
\]
\[
\widehat y=G_{yy}^{-1}\left(\phi(x)-G_{yr}\right),\qquad\phi(x)=x^{0.625}.
\]

이것은 기존과 같은 에너지의 고유 최소점이다. 저장되는 영속 상태 필드는 `metric` 하나다. 고정/선택 설정은 별도 `config`에 남으므로 모델의 모든 정보가 텐서 28개 원소에만 있다는 과장은 하지 않는다. 기초 계량 적합은 이동도 5개와 기준 결합 6개를 쓰며, 최종 7×7 SPD 텐서는 대칭 고유 원소 28개를 저장한다. 접공간 보정 뒤에도 원래 11계수 부분족에 남는다고 보장하지 않는다.

SPD 보정은 기존과 동일한 로그·지수 절차다.

\[
T=\frac1n\sum_j\log(G^{-1/2}G_{-j}G^{-1/2}),\qquad
G_{new}=G^{1/2}\exp(-0.2T)G^{1/2}.
\]

G_-j는 훈련조건 하나를 빼고 적합한 계량이다. 새 입력/출력표를 추론 때 저장하거나 여러 예측기를 선택하는 방식이 아니다.

**차원은 기존과 같은 여섯 관측 영역 + 한 기준 좌표다. 이것이 일곱 뉴런인 것은 아니다.** 실제 뉴런 위치·시간 동역학·말단 기억·곡률을 이번에 복원한 결과가 아니다. 상수 SPD 관측 모델은 affine 응답과 대수적으로 연결되며, 그 사실을 감추지 않는다. 업데이트와 예측을 같은 SPD 상태에서 실행했다는 계산 결과와 실제 신경 리만 기전의 식별은 별개다.

## 4. 설정을 고정한 뒤 추가한 기록 분할

초기 프로토콜에서 seed 2026091900–2026091931을 고정했다. 후보를 고른 뒤 설정과 코드의 SHA-256을 저장했고, 그 이후 32개 분할을 열었다. `selection_freeze.json`과 최종 검산에서 설정·핵심 코드가 이후 바뀌지 않았음을 확인했다.

| 추가 32분할의 전체 예측 | 직전 SPD | 수정 |
|---|---:|---:|
| RMSE | 0.12496038 | **0.12141653** |
| MAE | 0.09047749 | **0.08880693** |

RMSE가 낮은 분할은 17/32, MAE는 18/32, 둘 다 낮은 분할은 **16/32**다. 완료된 쌍은 32/32이고 오류로 누락한 분할은 없다.

32개는 새로운 동물 실험이 아니다. 같은 가공 기록을 새로운 난수 분할로 재사용했고, 각 영역·그룹 안에서 일곱 냄새 전체 기록 벡터를 나눴다. 영역과 그룹 사이 실제 동물/반구 대응을 모른다. 따라서 집단 정확도의 신뢰구간, p값, 독립 animal-disjoint 검증을 주장하지 않는다. 종합 오차는 개선됐지만 모든 기록 분할에 일관되게 우월한 결과는 아니다.

## 6. 원자료·재현·계산 검산

원자료는 저자의 `all KC values.csv`이며 직전 사용자 패키지의 같은 바이트를 재사용했다. 17,682바이트, Git blob `965d7e038fa23ba4226cda865d8802157f0d18c8`, SHA256 `5733b69eda14e5c557e784e96da917091877dc86a3a4a9c6026eae2520c8765a`를 확인했다. 유효값 1,540개, 완전한 일곱 조건 벡터 220개, 음수 39개를 그대로 보존했다. 220은 독립 동물 수가 아니다. 음수 원기록과 결측을 고치거나 가짜 생물 값을 생성하지 않았다.

| 계산 검사 | 결과 |
|---|---:|
| 저장·복원 후 예측 차이 | 0 |
| 직접 선형계와 Cholesky 풀이 최대 차이 | 1.67e-16 |
| 실제 8적합의 독립 정규방정식 대조 | 5.29e-14 |

좌표 공변성 검사는 고정된 힘을 텐서 규칙대로 바꾸었을 때의 계산이다. 전체 전처리·정규화 목적함수가 모든 임의 좌표변환에 불변이라는 뜻은 아니다. 주 네 평가 계량의 최소 고유값은 0.515935, 최대 조건수는 88.624다. 원본 UnifiedMetricCore의 기본 고유값 제한 [0.25,4]를 이 관측좌표에 적용했다고 주장하지 않는다.

새 출력 폴더에서 네 평가를 재실행해 결과 JSON, 예측 CSV, 최종 모델 JSON이 바이트 단위로 같았다. 추가 32분할을 전체 두 번 다시 실행한 것은 아니다. 탐색 작업은 실행 시간 제한에서 중단되면 이미 완료된 설정부터 이어 갔고, 완료/실패 로그를 보존했다. 검산의 조건 수는 생물 표본 수가 아니다.

## 7. 전달 범위

실행 가능한 후속 모델을 `results/selected/model.json`에 고정했다. 기존 리만 모델보다 낮은 오차가 실제로 나온 범위는 위의 조건부 가공 칼슘 예측이다. 뉴런 동역학의 완성, 장기기억 법칙의 규명, 새 동물의 전류/발화/행동 예측, 전체 MaleCNS, 물리적 시공간의 곡률 확인으로 확대하지 않는다.

원격 GitHub와 정식 생물 검증 완료 원장을 변경하지 않았다. 원본 ZIP도 변경하지 않았다. 추론에는 저장된 SPD 텐서와 config만 필요하며, 계수 재학습을 하지 않는다.
