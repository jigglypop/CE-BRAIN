# CE-BRAIN: 고정 노드·공통 연결 기억으로 시간별 생물 반응을 제약하기

2026-09-18 · 생물 문헌에서 얻은 구조 제약 + 기존 시간모형의 소스 재검토 + 실행 가능한 조건부 확장

## 결론

기본 아이디어를 **노드 고정 → 입력에 따른 시간상태 → 국소 연결 기억 → 같은 연결로 회상 → 관측에서 유도되는 기능적 기하**로 유지했다. 약물별 평균을 다시 조절하는 대신, 기존 시간표현의 냄새–시간 분리 가정을 풀고, 하나의 고정된 동역학과 하나의 연결 기억으로 여러 냄새의 반응을 계산하는 모듈을 만들었다.

Kropf et al. (2026)의 공개 초록과 출판사 요약은 냄새에 따른 KC 집단의 시간표현, 동시 활동 중인 KC→MBON 연결의 도파민 의존 약화, 서로 다른 냄새에 대해 학습된 지연에서 나타나는 신경·행동 반응을 보고한다. 이 관측 구조가 이번 확장의 동기다. **이 논문의 개별 KC/MBON 원시 곡선이나 행동 시행은 취득하지 않았다.** 따라서 새 생물 예측 정확도는 계산하지 않았고, 공식 생물 검증 완료 식은 추가하지 않았다. [S1]

기존 생물 평균값 예측의 잔차도 그대로다. 이전 보고서의 DA EPSC 오차 3.14%포인트와 PPR 오차 18.18%포인트를 이번 소프트웨어 시간실험으로 줄였다고 하지 않는다. 이번에는 이전 시간 부분함수와 일부 확률 읽기만 재사용·재검산했다. 전체 약물 적합, 해마 학습, MaleCNS, Rust/CUDA 통합은 실행하지 않았다. [P1–P3]

Kropf 연구의 초록만으로 **동일 세포의 모든 냄새별 지연 차이**를 정량 확인했다고 하지는 않는다. 초록에 있는 odor-specific delays는 기존의 모든 분리형 표현을 논리적으로 반증하기에 충분하지 않다. 이번에는 그 관측을 수용할 수 있는 더 일반적인 구조를 후보로 구현했다. 원자료에서 추가 자유도가 필요한지는 별도 판정이다.

기초 원리 자체가 새로 발견된 것도 아니다. 신경 집단의 시간표현과 가소성 읽기라는 원저의 설명을 CE의 고정 노드 아이디어와 대조해 계산 계약으로 정리한 것이다. 원저가 아래의 순환 그래프, 80노드, 시간상수 또는 로지스틱 학습식을 입증했다고 주장하지 않는다.

## 2. 기존 시간모형에서 제한한 것

원본 `model.py:dynamic_population()`은 네 단계 필터에 대응하는 노드별 시간파형을 만들었다. 냄새별로는 파형에 0/1 마스크를 곱했다.

\[
x_i^{(a)}(t)=b_i^{(a)}f_i(t).
\]

노드마다 f_i가 다르므로 전체 집단이 시간 rank 1인 것은 아니다. 서로 다른 활성 집합으로 냄새별 집단 지연을 만들 수도 있다. 그러나 **고정된 하나의 노드 i에서는 두 냄새의 비영 반응이 같은 파형의 배율**이다. 해당 노드의 냄새×시간 행렬은 rank 1 이하이며, 두 냄새가 그 노드를 모두 활성화하면 최대 시점은 같다.

80개 노드에서 이 성질을 확인하고, 기존 합성 학습의 억압 정점 2.89초와 8.05초를 재현했다. 2초와 6초의 훈련 시각은 이전 코드의 시험 설정이다. **Kropf 논문의 실험 시각으로 전사하지 않았다.**

## 3. 새 시간상태: 노드·회로·입력 투영은 고정하고 궤적이 달라진다

일반 표기는

\[
\dot x=F x+B u(t),\qquad
\tau_e\dot e=x-e
\]

이다. 이번 실행은 그중 **초기 감각 충격 입력**의 제한형이다.

\[
x^{(a)}(t)=e^{Ft}B u_a,
\qquad
 e^{(a)}(t)=\frac1{\tau_e}\int_0^t e^{-(t-s)/\tau_e}x^{(a)}(s)\,ds.
\]

모든 냄새가 같은 F와 B를 사용한다. 냄새별 새 그래프, 지연표, 출력 정답 함수를 만들지 않는다. 이미 정한 감각 벡터 u_a만 달라진다. 미래 보상 시각을 x나 e 계산의 입력으로 넣지 않는다. 학습 시점에 실제로 도착한 조절 이벤트가 현재 흔적을 포착한다.

실행 모듈은 양의 선형 상태 축약이다. F는 비음수 비대각 성분과 엄격히 음의 열합을 가져 안정성이 보장되는 제한된 클래스다. 막전위·이온통로·실제 축삭전도를 복원한 것이 아니다. 음의 억제 연결을 포함한 일반 생물 회로를 그대로 처리하는 구현도 아니다.

### 계산용 그래프의 정확한 지위

80노드 순환 전달 그래프 F=κ(P−I)−λI, 두 고정 감각 입력 위치를 사용했다. 이는 **소프트웨어 fixture**다. 초파리 KC 사이가 이 순환망으로 연결됐다는 가설이나 실제 커넥톰이 아니다. κ=4/s, λ=.05/s, τ_e=.25s, p0=.35, 사건 학습이득20은 미측정 가정이며, 이번 탐색은 사후적이다.

## 4. 기억은 같은 국소 연결 상태에 쓴다

입력 노드 i와 출력 j 사이의 고정 연결 마스크를 A_ji, 유효 방출 부위수×한 번의 전류 기여를 qbar_ji라고 한다. 학습 기억 m_ji가 방출확률을 바꾼다.

\[
p_{ji}=\sigma(\operatorname{logit}p_{ji,0}+m_{ji}).
\]

짧은 억압 유도 이벤트의 제한형을 다음처럼 실행했다.

\[
\boxed{m_{ji}^{+}=m_{ji}^{-}-\eta A_{ji}d_j e_i(T).}
\]

위첨자 +/-는 이 문단에서 사건 직후/직전이며 LTP/LTD 부호가 아니다. d_j는 해당 출력 구획의 비음수 유효 조절 강도다. d_j=0, e_i(T)=0 또는 A_ji=0이면 새 억압을 쓰지 않는다. 차단이 기존 기억을 즉시 삭제하는 것은 아니다. 현재 구현은 짧은 사건과 사건 중 기억 감쇠를 무시하는 특수형이며, 도파민 농도→d_j 변환을 유도한 것은 아니다.

서로 다른 초기 감각 상태에서 두 학습 에피소드를 계산하지만 **m은 하나를 계속 사용한다.** 회상 시에는 같은 m에서 두 입력을 모두 읽는다. 강화 시각 정답이나 냄새 이름은 읽기 함수의 인자가 아니다.

기존 분 단위 생화학 가정은 유지한다:

\[
\dot m^-_{ji}=\eta_D e_i g_{PKA}\frac{A}{K_A+A}-m^-_{ji}/\tau_D,
\quad \dot U_{ji}=\eta_P[z_i-\theta]_+-U_{ji}/\tau_{ret},
\quad \tau_{expr}\dot X_{ji}=U_{ji}-X_{ji}.
\]

실제 기억으로 X−m^-를 공급하는 연결은 이 표기의 일반화다. **그 전체 화학–집단 모형을 새로 적합하거나 전부 실행한 것은 아니다.** 이번 사건 모듈은 그 안의 짧은 LTD 특수형이다. 초 단위 입력 궤적, 밀리초/초 단위 eligibility, 분 단위 유도·발현의 시간상수를 같은 파라미터로 합치지 않는다. 기존 600초 발현 상수도 생물에서 선택된 상수로 승격하지 않는다. [P1]

## 5. 새 자유함수 대신 동일 연결에서 나오는 시간별 반응식

현재 선형 평균 출력 proxy는

\[
y_j^{(b)}(t)=\sum_i A_{ji}\bar q_{ji}p_{ji}x_i^{(b)}(t)
\]

다. 출력의 물리적 단위는 x와 qbar의 보정에 달려 있다. 지금 수치의 y는 실제 발화수·칼슘·EPSC를 동일시한 측정값이 아니다. 각각에 대한 관측기가 필요하다.

학습 전후 차이는 정확히

\[
\boxed{\Delta y_j^{(b)}(t)=\sum_i A_{ji}\bar q_{ji}x_i^{(b)}(t)\{p_{ji}^{before}-p_{ji}^{after}\}.}
\]

한 작은 억압 이벤트에서 d_j=1이라면,

\[
\boxed{
\frac{\partial\Delta y_j^{(b)}(t)}{\partial\eta}\bigg|_{\eta=0}
=\sum_i A_{ji}\bar q_{ji}p_{ji}(1-p_{ji})
x_i^{(b)}(t)e_i^{(a)}(T).
}
\]

이 식은 **학습 당시 흔적과 지금 회상 활동이 같은 실제 연결에서 얼마나 겹치는가**다. 시간 억압곡선을 별도로 맞춘 커널이 아니다. 계수가 같은 p에서 나오므로 첫 반응, 다른 냄새 전이, 시간별 감소를 각각 독립적으로 고를 수 없다. 같은 시점의 활동과 흔적이 같다는 추가 조건이 없는 한 시간 커널의 대칭성이나 PSD를 강제하지 않는다.

균일한 가중치·균일한 학습 감소·이진 활성 집합의 특수형에서는 기존 d_B=q_overlap d_A가 돌아온다. 인공 200부위 배열에서 .8×.33=.264를 복원했다. 이는 이전 생물 집계 비교의 새로운 독립 성공이 아니라, 새 식이 기존 제한형을 포함하는지에 대한 검사다.

## 6. 기존 두 펄스 확률모형과도 같은 p를 사용했다

새 연결 기억으로 얻은 p를 기존 `release.py`에 직접 입력했다. 시험에서는 지정한 12개 부위의 동일 p로 첫/두 방출 공동분포, 평균, 공분산을 계산했다. 별도의 확률 예측기나 자유 PPR 보정값을 붙이지 않았다.

두 펄스는 초기 소포 점유·부위 독립성·회복에 관한 기존 제한 가정을 그대로 가진다. 이 연동은 원시 시행 자료에 대한 적합이 아니다. 12개 부위, 촉진계수, 미회복 확률 .1은 소프트웨어 예제이며 생물 표본과 무관하다.

## 7. 위상과 기능적 공간은 같은 계산에서 유도된다

C(m)_ji=A_ji qbar_ji p_ji(m)라 쓰면, 고정된 기억 상태에서 선형 전달함수는

\[
\boxed{H_m(\omega)=C(m)(i\omega I-F)^{-1}B.}
\]

위상은 H_m의 복소 위상이며 새로운 자유 위상변수를 학습하지 않는다. 입력별 경로의 혼합이 달라질 때 출력 위상이 달라질 수 있으나, 모든 가중치 변화가 반드시 위상을 바꾼다고 가정하지 않는다. 이 식은 동역학이 해당 선형 축약에 해당할 때의 관계다.

독립적으로 주어진 양의 정부호 측정 잡음 Σ를 사용한 관측 구별 가능성은

\[
d_m^2(x,x')=(x-x')^T C(m)^T\Sigma^{-1}C(m)(x-x')
\]

로 정의할 수 있다. 현재 C가 full-column-rank라는 보장이 없으므로 이것은 일반적으로 **반거리와 양의 준정부호 형식**이다. 실제 뇌의 리만 계량이나 물리적 시공간을 식별한 것이 아니다.

연결을 약화하면 모든 상태 사이의 거리가 줄어든다는 주장도 하지 않는다. C=(.35,.35)→(.175,.35)인 계산 반례에서 (1,0)과 (0,1)의 출력 거리는 0→.175로 늘지만, (1,0)과 (0,0)은 .35→.175로 줄어든다. 따라서 기본 아이디어의 정확한 표현은 **같은 노드의 연결 변화가 어떤 상태는 구별하고 다른 상태는 가까워지게 하는 기능적 재구성**이다.

고정된 F,B와 연결 마스크의 해시는 학습 전후 일치했다. 조절되지 않은 두 번째 출력은 변하지 않았고, 없는 연결은 학습되지 않았다. 전체 후보의 의미는 시간과 문맥에 맞게 읽을 수 있는 **유한한 공유 상태공간**이지 무한차원 뇌의 증거가 아니다.

- 기존 시간 부분함수의 2.89/8.05초 정점 재현. 원본 화학 적합을 모두 재실행한 것은 아님.

- 국소 시간커널을 작은 gain의 중앙 유한차분과 대조.
- 기존 공유연결 일반화식으로의 축약과 전후 출력 차이 항등식 대조.
- 인과적 prefix, 입력 소유권 복사, 유효 확률, 국소 조절, 연결·노드 수 불변 검사.
- 같은 p의 두 펄스 공동확률을 전수 합산한 모멘트와 대조.
- 전달함수를 유한시간 행렬 적분 및 충분히 감쇠된 꼬리와 대조. 이는 독립 생리 실험이 아니다.

최초 실행은 원본 모듈을 동적으로 불러올 때 sys.modules 등록 누락으로 중단됐다. 등록을 추가했고 모형과 통과 기준은 바꾸지 않았다. 기록은 `evidence/import_failure.json`에 있다. 기존 결과 폴더는 덮어쓰지 않았다.

## 10. 채택과 다음 판정의 경계

**보존:** 고정 노드, 기존 gamma 시냅스 후보와 잔차, 국소 활동–조절 결합, 유도/발현 분리 후보, p와 Q·소포 상태의 구분, 같은 상태에서의 확률 읽기.

**추가한 개발 후보:** 공통 F,B가 생성하는 입력별 시간상태, 하나의 연결 기억, 거기서 유도된 비대칭 시간 겹침 커널과 출력 전달함수. 원래 분리형 모형은 반드시 비교 기준으로 유지한다.

**채택하지 않은 주장:** 80노드 순환망이 KC 해부학이라는 해석, Kropf의 원곡선/실험시간을 맞혔다는 주장, APL 억제 구현 완료, 기존 18.18%포인트 PPR 잔차 해소, 해마 해시·의식·실제 시공간 증명, 전체 MaleCNS 또는 전체 생물학 모형의 완성.

실제 생물자료에서 판정하려면 학습 전 KC 시간반응으로 표현을 먼저 제한하고, 한 냄새·지연에서 학습 계수를 고정한 다음, 다른 냄새·지연의 **사용하지 않은 MBON 파형**을 같은 기억상태에서 예측해야 한다. 행동은 별도 고정 readout이 있어야 비교한다. KC 칼슘, MBON 발화, EPSC를 같은 관측값으로 변환하지 않는다. 분리형 기준과 새 후보의 원자료 held-out 오차·계산비용·개체 간 재현을 비교하기 전에는 공식 생물 검증으로 올리지 않는다.

Kropf의 공개 요약을 읽었으나 원시 파형과 사용할 수 있는 수치 자료를 확보하지 못했다. Yamada의 데이터 가용성은 합리적 요청에 따른 공유로 명시돼 있다. 이번에 저자에게 연락하거나 자료를 수령한 것은 아니다. 다음 데이터가 없다고 합성 숫자를 생물행으로 바꾸지 않았다. [S1,S2]
