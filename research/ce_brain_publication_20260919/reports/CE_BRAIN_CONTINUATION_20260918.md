# CE-BRAIN: 생물 제약으로 후보를 줄이고, 조건부 계산식만 검산

2026-09-18 · 후속 식 탐색 · 원격 게시 없음

## 결과

직전 OCT→MCH 참조 코드를 실제로 다시 실행해 26.4% 예측을 재현했다. 새로 생물 관측값을 맞힌 것은 아니다. 이번에는 논문에서 확인한 제약과 후보식의 필연적 예측을 대조하고, 시간별 가중 읽기와 강화·억압 경쟁의 정확해를 독립 수치 계산으로 검산했다.

**생물 예측식의 신규 승격은 0개다.** 새 정량 생물 평가자료를 확보하지 못했으므로, 조건부 수학 정합성과 문헌상 정성적 양립성을 독립 생물 예측 검증으로 올리지 않았다. 그 대신 다음 후보의 구조를 더 엄격하게 제한하는 결과를 남겼다. `promotion_gate.py`가 미충족 요건이 있는 후보를 게시 가능 목록에서 제외한다.

## 2. 정확히 검산한 유한 억압·시간별 읽기식

다음은 가정 아래의 항등식이지 새 생물 법칙이 아니다.

- 노드 수와 연결 인덱스는 고정한다.
- 읽기 활동 x_bi(t)와 초기 연결 효능 w_i는 비음수다.
- 학습 중 누적 억압량 U_i=integral L_i(s) ds≥0는 무차원이다. L_i의 단위는 1/시간이다.
- 읽기 활동과 관측 연산은 학습 전후 동일하고, 출력은 y_b(t)=sum_i w_i x_bi(t)인 선형 유효 입력이다.
- 실제 EPSC·발화·칼슘 중 무엇에 이 관측식을 연결할지는 별도로 검증해야 한다.

순수 LTD 미분식 dw_i/ds=−L_i(s)w_i의 정확해는

    w_i^+ = w_i^- exp(−U_i).

따라서 읽기 반응의 감소량과 감소율은

    Δy_b(t) = sum_i w_i^- x_bi(t) [1−exp(−U_i)],

    d_b(t) = Δy_b(t) / sum_i w_i^- x_bi(t),   분모>0.

감소율은 세포별 감소 1−exp(−U_i)의 가중 평균이다. 이에 따라 0≤d_b(t)≤1이다. 동일 기여 이진 지지집합과 균일 억압을 추가하면 기존 d_B=q_(B←A)d_A가 정확히 돌아온다. 작은 억압만을 가정한 선형화가 아니다.

이번 확장의 핵심은 고정된 세포 인덱스 위에서도 x_bi(t)가 세포별로 다르게 변할 수 있도록 남긴 점이다. x와 U를 관측에서 식별한 것은 아니므로, 이 식을 쓰기만 하면 실제 시간 곡선을 예측하게 되는 것은 아니다.

### 독립 검사

64개의 무작위 비음수 계산 fixture에서 전후 가중치의 직접 합과 위 감소식을 비교했다. 최대 차이는 4.44×10^−16이었다. 같은 fixture에서 약한 억압 근사의 오차 경계

    0 ≤ sum_i w_i x_i U_i − Δy ≤ (1/2) sum_i w_i x_i U_i²

와 노드 재명명 불변성을 검사했다. 증명은 z≥0에서 0≤z−(1−exp(−z))≤z²/2를 항별로 합하면 된다.

이 64개는 소프트웨어 검사 입력 수이며 생물 표본 수가 아니다.

### 한 평균값은 연결별 억압을 식별하지 못한다

동일 가중치 두 연결에서 훈련 읽기 A=(1,1)를 사용한다. 잔존 효능이 (0.2,0.8)인 경우와 (0.5,0.5)인 경우 모두 A의 감소는 50%다. 그러나 읽기 B=(1,0)에서는 각각 80%와 50%가 된다.

이 반례를 실제로 실행했다. 따라서 한 평균 억압량을 맞춘 것을 전체 연결 학습법의 검증으로 승격하지 않는다.

## 3. 하나의 공통 시간파형으로는 상대적 억압 구간을 만들 수 없다

고정된 냄새에 대해 모든 활동이 x_i(t)=a_i f(t)이고, 읽기 중 가중치는 고정이라고 하자. 학습 조건 s마다 억압량 U_i(s)는 달라도 된다. 그러면

    Δy(t,s)=f(t) sum_i a_i w_i [1−exp(−U_i(s))].

따라서 학습 조건별 감소 곡선은 모두 f(t)의 배수다. f(t)>0인 시간 구간에서 감소율 Δy/y_pre는 시간에 무관하다. 시간×학습조건 감소행렬의 rank는 최대 1이다.

이 결과는 정확한 대수식이다. 서로 다른 조건에서 임의로 억압을 강하게 하더라도, 이 제한형은 상대적으로 특정 시간만 눌리는 새로운 구간을 만들 수 없다. 비선형 읽기, 학습으로 변하는 활동, 세포별로 다른 시간파형을 허용하면 이 제한의 가정 밖이다.

16개의 계산 fixture에서 이 제한을 확인했다. 제2/제1 특잇값 비의 최대는 1.81×10^−16, 시간별 감소율 범위 최대는 6.66×10^−16이었다. 원신경 데이터의 차원을 추정한 수치가 아니다.

비교용으로 서로 다른 시간파형을 가진 고정 노드 4개의 합성 예를 만들었을 때는, 두 학습 조건의 감소 정점이 각각 지정한 3초와 5초에 나타났다. 이 시각과 파형은 검사용 임의 입력이므로 생물 예측 성공률에 넣지 않았다.

## 4. 강화·억압 경쟁식의 정확한 시간 전파

이것은 기존 경쟁 후보의 정확해를 검산한 결과다. P(t),L(t)≥0가 주어진 외생 유효율이고 w_max>0일 때

    dw/dt = P(t)(w_max−w)−L(t)w.

R(t)=integral_0^t[P(u)+L(u)]du로 두면

    w(T)=a(T)w(0)+b(T),
    a(T)=exp(−R(T)),
    b(T)=w_max integral_0^T P(s) exp(−[R(T)−R(s)]) ds.

0≤b(T)≤w_max[1−a(T)]이므로 초기 0≤w(0)≤w_max가 보존된다. 실제 P,L가 w에 의존한다면 이 식은 경로를 알고 있는 경우의 조건부 표현일 뿐, 그 경로까지 독립적으로 해결해 주지는 않는다.

시간에 따라 실제로 변하는 양의 P,L 함수 24개에서, 적분식과 독립 DOP853 풀이를 대조했다. 최대 최종 효능 차이는 5.61×10^−12였다. 시간상수·분자 속도를 실측에서 추정한 수치가 아니다.

### 학습 사건의 순서가 남는 정확식

순수 억압 연산 D_a(w)=a w와 순수 강화 연산 P_b(w)=b w+(1−b)w_max, 0<a,b≤1에 대해

    P_b(D_a(w))−D_a(P_b(w))=(1−a)(1−b)w_max.

64개의 fixture에서 최대 대수식 차이는 1.11×10^−16이었다. 초기 w와 상관없이 두 연산은 일반적으로 교환하지 않는다. 이는 '강화와 억압의 순서가 연결 상태에 남을 수 있다'는 계산 성질이지, 어떤 생물 자극이 어떤 a,b를 만드는지 이미 규명했다는 뜻은 아니다. 이 식은 새 분자 메커니즘도, 양자역학적 주장도 아니다.

## 6. 재현과 접근 범위

    python verify_equations.py
    python promotion_gate.py

기존 코드의 사본은 inputs/ 아래에 보존했다. 원본 ZIP의 SHA256을 SOURCES.json에 보존한다. 원래 첨부와 원격 GitHub는 수정하지 않았다. 새 코드의 독립 폴더 실행과 결과 동일성은 results/reproduction_receipt.json에 있다.

직접 외부 다운로드는 이 환경의 DNS/다운로드 오류로 실패했다. 공개 웹에서 확인한 본문/초록을 관측 제약으로 쓰되, 원자료 파일이나 그림 데이터가 들어 있다고 주장하지 않았다. 새로운 생물 수치 자료가 없으므로 새 생물 예측오차·상관·생물학 일치율은 계산하지 않았다.
