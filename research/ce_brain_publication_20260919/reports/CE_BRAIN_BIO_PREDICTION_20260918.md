# CE-BRAIN: 생물 요약값을 이용한 국소 학습 전이 예측

2026-09-18 · 후향적 계산 · 한 개의 집계 관측량 · 새로운 독립 참조 구현

## 결과

훈련 냄새의 반응 감소 0.80과 비훈련 냄새 기준 KC 겹침 0.33을 입력하여, 비훈련 냄새의 감소를 **0.264(26.4%)**로 계산했다. 논문이 보고한 대응 평균은 **0.27, SEM 0.071**이므로 평균 간 차이는 **−0.6%포인트**다. 대상은 Hige et al. 2015의 OCT 훈련 후 MCH에 대한 MBON-γ1pedc 발화 반응이다. 입력과 출처 위치는 `observations.json`에 보존했다. [S1]

이 계산에서 비교 대상 0.27을 계수 추정에 사용하지 않았다. 하지만 이미 출판된 결과를 읽은 뒤 수행한 후향적 비교다. 데이터 분할을 동반한 맹검, 신규 개체 예측, 최초 생물 기전 발견이 아니다. 동일한 선행 연구가 이미 표현 겹침과 학습 간섭의 관계를 해석한다. 그 관계를 CE 후보의 제한된 계산 모형으로 명시하고 수치 대조한 것이다. [S1]

## 1. CE의 어느 부분을 검사했나

제공된 버섯체 문서는 활동 흔적과 조절신호에 따른 유계 효능 갱신, 쓰기 흔적과 읽기 활동의 구별을 제안한다. 이번에는 그중 **강화 경로를 제외한 국소 LTD 제한형**만 별도 구현했다. γ4 수용체 경쟁식 전체를 γ1pedc에 그대로 이식한 결과가 아니다. 원본 `candidate_v2.py`의 바이트를 취득하거나 원본 코드를 실행한 것도 아니다. [S2]

수학적 상태와 갱신은 다음이다.

```
e_i'(t) = -e_i(t)/tau + x_i(t)
w_i_after = w_i_before * exp(-alpha * E_i)
y_B = sum_i x_Bi * w_i
```

`E_i`는 학습 때 해당 연결에 남은 유효 흔적이다. 가중치가 양수이고 학습량이 음수가 아니면 갱신 뒤에도 양수이며 증가하지 않는다. 이 지수 갱신을 사용하여 강한 억압을 약한 학습의 1차 근사로 계산하지 않았다.

다음 관측 대응은 **이번 참조 모형의 가정**이다. 실제 전류·발화 모델을 측정에서 식별한 것이 아니다.

- 냄새별 활동 집합은 고정된 이진 지지집합이다.
- 한 냄새에 반응하는 KC의 출력 기여는 동일하다.
- 훈련 냄새에 속하는 연결들은 같은 비율로 약화되고, 다른 연결은 그대로다.
- 출력 발화수는 이 유효 입력 합에 선형으로 대응한다.

특히 KC의 단순 개수 겹침이 γ1pedc에 대한 시냅스 가중 겹침과 같다는 것은 미검증이다.

## 2. 국소 전이식의 정확한 유도

훈련 냄새의 활동 집합을 A, 읽기 냄새의 집합을 B라 하자. A의 모든 연결이 `1-d_A`배가 되면, B의 반응 중 A와 겹치는 부분만 같은 비율로 줄어든다. 동일 기여 가정에서

```
y_B_after / y_B_before = 1 - |A∩B|/|B| * d_A

d_B = q_(B←A) * d_A
```

따라서 `q=0.33`, `d_A=0.80`으로 `d_B=0.264`를 얻는다. q의 분모는 **읽는 냄새 B**다. 반대 방향의 겹침률 0.30을 여기 넣지 않는다.

이는 `d_A`가 작아야만 성립하는 근사가 아니다. 다만 동일한 활동·기여·약화라는 가정이 정확해야 한다. 이 식에는 실제 신호의 푸리에 위상이나 축삭 지연을 추정하는 기능이 없다.

### 최소 대조

| 모형 | 비훈련 냄새 예측 감소 | 보고 평균과 절대 차이 |
|---|---:|---:|
| 학습이 전혀 전이되지 않음 | 0% | 27.0%포인트 |
| 전체 출력에 동일 이득 변화 | 80% | 53.0%포인트 |
| 고정 지지집합의 국소 전이 | 26.4% | 0.6%포인트 |

이는 한 집계 관측량에서 계산한 잔차이며 통계적 우월성 검정이 아니다. 복잡한 경쟁 모형이나 최선의 학습 기준선까지 이겼다는 결과도 아니다.

### 가중치 가정의 반례

검사용 고정 지지집합에서 겹치는 KC의 읽기 기여만 두 배로 만들면, 개수 겹침은 0.33이어도 유효 가중 겹침은 `66/(66+67)`로 바뀐다. 같은 80% 약화에서 비훈련 감소는 **39.699%**가 된다. `predict.py`가 이 반례도 검사한다. 이것은 합성 수학 fixture이지 실제 KC 집단을 복원한 데이터가 아니다.

따라서 26.4%의 근접만으로 실제 가중치나 유일한 기전을 알아냈다고 할 수 없다.

## 3. 시간 구조: 실제 일정, 가정한 세포 입력

논문의 외부 일정은 1초 냄새, 네 개의 1ms 빛 자극이며 시작시각은 0.2/0.7/1.2/1.7초다. 단일 빛 자극은 0.8초에 제시된다. 이것을 곧바로 측정된 KC 발화나 도파민 농도 파형으로 간주하지 않는다. [S1]

시간 계산의 가정은 냄새 동안 단위 활동 `x=1`, 그 밖에는 0, 빛 자극마다 같은 단위 면적의 유효 조절 이벤트라는 것이다. 처음의 흔적은 0이다. 이 경우

```
e_tau(t) = tau * (1-exp(-t/tau))                       0<t<=1
e_tau(t) = tau * (1-exp(-1/tau))*exp(-(t-1)/tau)       t>1
```

이고, 네 자극의 노출은 정확히

```
S4(tau) = e(.2)+e(.7)+e(1.2)+e(1.7)
        = tau * [2-exp(-1.2/tau)-exp(-1.7/tau)].
```

`kappa*S4=−log(0.2)`로 네 자극의 훈련 감소를 고정한다. 시간상수 tau는 목표 데이터에 맞추지 않는다. 단일 자극의 조건부 예측은

```
d_A,1(t) = 1 - 0.2 ** [e_tau(t)/S4(tau)]
d_B,1(t) = 0.33 * d_A,1(t)
```

이다. 여기의 0.80 역시 가중치 자체의 측정값이 아니라 선형 출력 가정 아래의 보정 입력이다.

### 시간상수를 정하지 않아도 남는 범위

0.8초 단일 이벤트의 노출비 r은 모든 양의 tau에서

```
0.8/2.9 < r < 1/2
```

이며 양 끝은 tau→무한대와 tau→0의 극한이다. 따라서

**조건부 비훈련 반응 감소: 11.8313%에서 18.2420% 사이.**

이 범위는 생물 신뢰구간이 아니다. 특정 입력·관측 가정과 미식별 tau가 만드는 수학적 예측 범위다. 시간 순서를 무시하고 사건당 같은 곱셈 변화를 주는 단순 횟수 모형은 네 번에서 한 번으로 바꿀 때 **10.9316%**를 예측한다. 어느 쪽이 실제 단일 자극 데이터를 이겼는지는 이번에 판정하지 않았다.

논문의 단일 자극 CS− 요약값은 별도 격리했다. 본문만으로 해당 냄새·농도·코호트와 지금의 q=0.33이 대응하는지 충분히 확인하지 못했고, 보충그림 S6를 취득하지 못했기 때문이다. 이 숫자에 가깝다는 이유로 tau를 선택하거나 두 번째 예측 성공으로 계산하지 않는다.

네 개의 빛 자극이 모두 냄새보다 앞선 역순 일정에서는 이 제한 모형의 흔적 노출이 0이다. 반면 횟수만 센 모형은 순서를 구별하지 않는다. 논문은 역순의 유의한 변화를 검출하지 않았다고 보고한다. 그 사실을 실제 효과가 정확히 0이라는 수치 정답이나 등가성 검정으로 변환하지 않는다. [S1]

## 4. 다음 측정에서 틀릴 수 있는 예측

모든 아래 항목은 **미측정 조건부 예측**이다.

### 같은 연결 지지집합의 전이 비율

가정이 유지되면 같은 냄새쌍의 어떤 약화량에서도 `d_B(t)/d_A(t)=0.33`이다. 지연에 따라 이 비율이 체계적으로 바뀌면 고정 지지집합·동일 기여·동일 흔적·선형 읽기 가정 중 일부를 수정해야 한다. 이것이 일반적인 모든 국소 학습 규칙의 반증은 아니다.

### 냄새 종료 뒤의 지연 곡선

단일 자극의 훈련 반응에서 `H(t)=-log(1-d_A(t))`라 두면, t>1초에서

```
H(t) = constant * exp(-(t-1)/tau)
```

이다. 등간격 세 시점 `t1,t2,t3`에서는 `H(t2)^2 = H(t1)*H(t3)`가 강제된다. 첫 두 생물 관측을 얻은 다음에는 별도 재적합 없이

```
d_A(t3) = 1 - exp(-H(t2)^2/H(t1))
```

로 세 번째를 예측할 수 있다. 감소량이 0 또는 1에 매우 가까우면 이 변환은 불안정하므로 원시 반응의 불확실성을 먼저 반영해야 한다. 현재는 그 세 측정값이 없어서 성공을 주장하지 않는다.

### 분해능을 보이는 예시

네 자극 보정값은 같아도 tau=0.1초와 tau=1초가 만드는 미래 곡선은 다르다. 예를 들어 1.2초 단일 자극에 대한 비훈련 감소는 각각 약 3.405%와 13.949%다. 이는 어느 tau가 맞다는 주장이 아니라 지연 측정이 무엇을 구별하는지 보이는 계산이다. 모든 고정 그리드는 `results/results.json`에 남겼다.

## 5. 검증·분모·접근 범위

원저의 전후 평균 발화수로 만든 비율과 원저가 별도로 보고한 정규화 감소의 평균은 같지 않다. 이번 비교에서는 후자를 목표로 사용한다. 개별 기록을 얻지 못했으므로 개인별 분모와 공분산을 역으로 생성하지 않았다. [S1]

`predict.py`는 흔적 적분과 독립 수치적분, 직접 합과 닫힌 노출식, 고정 지지집합 계산, 유한 폭 펄스의 독립 ODE 등을 검사한다. **291개 수치 assertion 조건 통과**는 생물 표본 수가 아니다. 유한 1ms 펄스를 같은 면적으로 처리한 민감도 계산과 이상적 이벤트 계산의 최대 차이는 고정 tau 그리드에서 약 **0.002733%포인트**다. 이 계산이 실제 빛→도파민 응답 변환의 정확성을 보장하지 않는다.

주 검증에서는 독립 ODE 대비 최종 가중치 차이 최대 약 **2.23×10^-13**이 확인됐다. 소스와 입력 해시는 결과 JSON에 있다. 별도 폴더 재실행 및 목표값 변경 시 예측 불변성 검사는 `reproduction_receipt.json`에 기록한다.

PDF의 파싱된 본문은 읽었지만 화면 렌더링·바이너리 취득은 실패했다. 도표 좌표를 수동 추정하거나 OCR로 데이터를 생성하지 않았다. 생물학 원시 시계열, 새로운 초파리, MaleCNS, γ4 수용체 개입, CE 전체 런타임은 실행하지 않았다. GitHub도 변경하지 않았다.

## 판정

**범위를 제한한 생물 요약값 예측 비교 한 건을 확보했다.** 고정 노드·국소 약화·겹치는 표현이라는 최소 모형은 이번 관측 평균과 근접했다. 시간 흔적은 외부 실험 일정에 적용하여 계산 가능한 다음 예측으로 정리했지만, 시간·푸리에 위상·축삭 지연에 대한 생물 검증 합격은 아직 아니다.
