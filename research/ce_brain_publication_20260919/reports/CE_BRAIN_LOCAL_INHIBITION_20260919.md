# CE-BRAIN: 고정 노드에서 말단별 학습 흔적과 국소 억제를 연결

**2026-09-19 · 개발 후보 · 공개 생물학적 정성 제약 + 실행 검산**

## 결론

기존의 고정 KC 집단과 연결 기억을 보존하고, **뉴런당 하나의 학습 흔적을 모든 출력에 공유하던 부분을 연결 구획별 흔적으로 바꿨다.** 억제 신호가 발생하는 위치와 그 억제로 영향을 받는 하류 경로를 분리했다. 입력부 억제는 여러 축삭 구획에 영향을 줄 수 있고, 말단 억제는 해당 구획의 전달·학습 흔적을 더 강하게 바꿀 수 있다.

이번 선택은 ‘완전 균일한 전역 억제’나 ‘하류 전달을 전혀 고려하지 않는 국소 억제’만을 유일한 구조로 쓰지 않는 것이다. **국소 상태 + 상류에서 하류로 이어지는 영향**을 개발 구조로 남긴다. 반면 정확한 억제 함수·공간상수·시간상수는 아직 생물학적으로 선택되지 않았다. 두 다른 함수가 같은 정성 제약을 만족하면서 서로 다른 반응 크기를 낸다는 반례를 보존했다.

신규 생물학 원시·수치 파일은 0개다. 새로운 생물 RMSE, 성공률, PPR 오차 개선은 계산하지 않았다. 기존 γ 시냅스의 DA 잔차 3.14145%p(EPSC), 18.17713%p(PPR)는 이전 기록으로 유지하며 이번에 원 실험 적합을 재실행한 것은 아니다.

## 1. 생물 관측과 이번 추론을 분리

Amin 등의 연구는 한 APL 뉴런 안의 반응과 KC 억제가 공간적으로 균일하지 않으며, 국소 자극 부근에서 억제가 더 강해짐을 보고했다. KC 수상돌기 입력부인 calyx를 억제하면 축삭 반응까지 영향을 받을 수 있다. 축삭을 억제했을 때 관측되는 더 넓은 약한 효과의 기전은 완전히 결정되지 않았다. 이 때문에 ‘APL의 국소 신호’와 ‘영향을 받는 KC 범위’를 동일시하지 않는다. [S1]

저자 답변은 calyx와 엽에서 측정한 것이 서로 다른 근위·원위 뉴런이 아니라, 같은 KC 집단의 수상돌기·축삭이라는 점도 명확히 한다. [S1R]

Davidson 등의 연구에서는 DAN이 활성화된 구획의 전달물질 방출 억압과 축삭 묶음 전체의 칼슘 변화가 일대일로 대응하지 않았고, 개별 bouton의 칼슘 변화도 이질적이었다. 따라서 전체 칼슘을 같은 뉴런의 모든 말단의 학습 상태나 방출확률로 복사하지 않는다. [S2]

**이번 모델링 추론:** 같은 뉴런이라도 연결 구획의 유효 활동과 학습 흔적을 서로 다르게 허용해야 한다. 그러나 관측이 아래의 유리함수형 gate, 수동 4구획 회로, 정확한 시간상수를 유일하게 증명하지는 않는다. 이 실험에서 직접 측정하지 않은 ‘학습 중 APL 억제가 나중 기억을 얼마나 줄인다’는 수치도 새 생물 정답으로 만들지 않는다.

## 2. 보존한 기본 아이디어와 실제 구현 차이

부모 패키지의 `FixedPopulation`은 80개 노드의 고정 전달행렬 F와 두 감각 입력의 고정 투영 B를 사용한다. 이는 실제 KC 해부학이 아닌 코드 검사 회로다. 이번에는 그 두 배열과 두 출력의 연결 마스크, 학습 이득을 대조 조건 간 동일하게 두었다. 원본 `fixed_graph.py`는 바이트 그대로 복사했다. [P1]

부모의 `FixedReadout.train_event`는 `trace.shape == (N,)`를 받아 출력별로 broadcast했다. 새 `LocalMemory.train_event`는 `trace.shape == (C,N)`를 요구한다. 예를 들어 출력 구획 하나의 유효 활동이 완전히 0이면, 다른 구획의 활동만으로 그곳에 기억을 쓰지 않는다. 단, 억제 전의 흔적이 남아 있으면 해당 흔적이 감쇠할 때까지 쓰기가 가능하다. ‘현재 활동 0’과 ‘남아 있는 과거 흔적 0’을 구별한다.

KC 노드 수는 그대로지만 계산 상태·비용이 같은 것은 아니다. 최소 표현에서 흔적은 N개에서 C×N개로 늘고, APL 역할을 표현하는 4개 구획 상태가 추가된다. 4구획은 4개의 APL 뉴런이 아니라 하나의 억제 뉴런 내부를 표현하는 가정이다. 실제 실행 메모리/속도 우위는 측정하지 않았다. 두 축삭 출력의 대칭 장난감 배치는 모든 KC 유형, 특히 γ의 실제 분지 구조를 나타내지 않는다.

## 3. 수정한 식

### 3.1 국소 억제의 전달

고정 구획 그래프의 라플라시안을 L_A라고 두면,

\[
\tau_A\dot a=-(\ell I+\kappa L_A)a+s(t),\quad \ell>0,\ \kappa\ge0.
\]

이는 음이 아닌 입력을 받는 수동 누설·확산 모형이다. 새 함수는 고정 그래프 위에서 동작하며 신호가 필요할 때 노드를 생성하지 않는다. 입력 s는 현재 실행에서는 **외부의 국소 자극**이다. KC→APL 피드백이나 완전한 억제 폐회로를 이번에 구현한 것은 아니다.

정상상태는 a*=(ell I+kappa L_A)^(-1)s이고, 대칭 비음수 연결에서는 행렬이 양의 정부호다. 수동 전달의 이차 에너지는 음의 되먹임과 누설로 감소한다. 이 안정성은 이 선형 부분모형에 한하며 뇌 전체 안정성 증명이 아니다.

저자 코드는 자극 자체의 퍼짐과 경로 거리에 따른 감쇠를 별도로 다룬다. 이번 단위 구획 연결은 그 해부학이나 추정 공간상수를 복제하지 않는다. [S3]

### 3.2 입력부 억제와 말단 억제

부모 회로가 생성하는 억제 전의 활동을 x_i^0(t), 수상돌기 구획을 d, 출력 구획을 c라고 한다.

\[
\boxed{\widetilde x_{ci}(t)=x_i^0(t)g_d(a_d(t))g_c(a_c(t)).}
\]

이번 두 gate 후보는

\[
g_c(a)=\frac1{1+\gamma_c a},\qquad
 g_c(a)=e^{-\gamma_c a}.
\]

둘 다 양의 억제 강도에서 단조 감소하고 g(0)=1이다. 첫 식은 유효 shunt에서 동기를 얻은 근사다. 둘 중 어느 함수가 실제 calcium·발화·방출량을 정량적으로 나타내는지는 확인하지 않았다. x̃는 **전달과 학습에 관련된 정규화 활동 proxy**이지 측정된 GCaMP 또는 막전위 자체가 아니다. 입력부/말단의 순간적 곱셈은 빠른 gate 근사이며 밀리초 전도 지연을 새로 예측하지 않는다.

### 3.3 구획별 흔적과 동일 연결 기억

\[
\boxed{\tau_e\dot e_{ci}=\widetilde x_{ci}-e_{ci}.}
\]

짧은 LTD 유도 사건에서

\[
\boxed{m_{ci}^{+}=m_{ci}^{-}-\eta A_{ci}D_c e_{ci}(T),}
\qquad
\boxed{p_{ci}=\sigma(\operatorname{logit}p_{ci,0}+m_{ci}).}
\]

위 ±는 사건 직전·직후를 뜻한다. 기존의 강화 상태 기호와 혼동하지 않는다. D_c는 고정한 유효 조절 입력이다. 이 코드의 사건식은 짧은 억압 특수형이며, 원래의 PKA 경로·분 단위 U→X 발현·LTP를 새로 적분하지 않는다. 그 계산부는 원본 후보로 보존한다.

읽기는

\[
\boxed{y_c(t)=\sum_i A_{ci}\overline Q_{ci}p_{ci}\widetilde x_{ci}(t).}
\]

동일한 p를 시간반응과 학습 효과에 사용한다. 억제가 없는 경우에는 부모의 활동·읽기식으로 돌아가고, 모든 구획의 e가 같으면 부모의 학습 사건과 정확히 같다. 첫 조건은 출력 계산에서, 둘째는 동일 입력 흔적을 준 사건 연산에서 실제 대조했다. 새 선형보간 흔적을 부모의 행렬지수 흔적과 모든 시점에서 같다고 주장하지 않는다.

## 4. 같은 식에서 나오는 두 가지 구별 가능한 예측

### 4.1 학습 때만 억제하고, 시험 때는 억제를 제거

같은 감각 입력·초기 흔적·조절신호를 사용하고 억제가 보상성 흥분을 만들지 않는 가정에서 x̃_inh≤x̃_control이면 인과적 양의 흔적 필터에 의해 e_inh≤e_control이다. 그러면

\[
m_{inh}^{+}\ge m_{control}^{+},\quad p_{inh}\ge p_{control}.
\]

억제가 없는 동일 시험 입력으로 읽으면

\[
\boxed{y_{inh\ during\ learning}^{test}\ge y_{control}^{test}.}
\]

즉 이 제한형에서는 학습 중 억제가 강했던 경로의 후기 LTD가 더 작다. **실제 APL 조작에서 도파민, 다른 피드백, 가소성 경로까지 변하면 이 조건부 예측을 그대로 적용할 수 없다.** 이 결과는 이번 자료에서 미리 맞힌 실험값이 아니다.

### 4.2 시험 때만 억제하고, 새 학습 입력은 주지 않음

m을 그대로 둔 채 x̃만 줄이면 즉시 반응은 낮아진다. 그러나 읽기 연산은 m을 변경하지 않는다. 억제를 제거하고 같은 조건으로 읽으면 원래 반응으로 돌아온다. **일시적인 전달 억제를 기억 삭제 또는 연결 제거로 기록하지 않는다.**

따라서 ‘낮은 현재 반응’ 하나만으로 기억이 더 강한지, 소실됐는지 판단할 수 없다. 이 구분은 원래의 연결 기억 아이디어를 유지하면서 관측 해석을 정확하게 만든다.

### 4.3 국소 학습–읽기 커널

작은 사건의 읽기 감소에 대해

\[
\left.\frac{\partial\Delta y_c(t)}{\partial\eta}\right|_{0}
= D_c\sum_i A_{ci}\overline Q_{ci}p_{ci}(1-p_{ci})
 \widetilde x_{ci}(t)e_{ci}(T).
\]

동일 뉴런이라는 이유만으로 두 구획의 학습·읽기 겹침을 같게 강제하지 않는다. 코드의 작은 사건 커널은 D_c=1에 대한 값을 반환한다. 12개 비영 기억 조건에서 독립 중앙차분과 대조했다.

## 5. 실제 실행 — 아래는 전부 코드 검사 수치

기존 80개 KC의 F,B와 입력을 그대로 사용했다. 두 출력에 같은 유효 조절 사건을 2초에 가하고, 이후 억제를 없앤 동일 입력으로 2초 시점의 출력을 읽었다. 자극 위치를 calyx/vertical/horizontal로 부르지만 실험의 실제 공간 길이나 강도를 가져온 것은 아니다. 모형 시간·이득은 고정한 가정이다.

| 학습 중 억제 위치 | shunt: 출력 V의 후기 감소 | shunt: 출력 H의 후기 감소 |
|---|---:|---:|
| 없음 | 70.6269% | 70.6269% |
| 입력부 calyx | 24.0460% | 24.0460% |
| V 구획 | 24.0460% | 68.1009% |
| H 구획 | 68.1009% | 24.0460% |

억제함수를 exponential로 바꾸면 입력부 억제의 후기 감소는 4.8618%가 된다. 둘 다 정성 방향은 같지만 크기가 크게 다르다. **24.0460% 또는 4.8618%를 생물 예측 정확도로 보고하지 않는다.** 이것이 수치 자료 없이 gate를 유일하게 선택할 수 없는 직접 반례다.

같은 총량의 APL 자극으로 비교한 세 제한형에서, 완전 균일 전역 모형은 자극 위치가 달라도 공간 반응 모양이 같다. 엄격한 무확산 국소-only 모형은 calyx를 억제해도 연결된 축삭 출력을 변화시키지 못한다. 국소+상류 전달형은 두 종류의 영향을 모두 표현한다. 유한 퍼짐을 가진 모든 국소 모형이나 전역 억제 기여 일반을 반증한 것은 아니다. 실제 distal 억제의 기전과 강도는 여전히 미결이다.

## 6. 수치 검산과 재현 범위

`run.py`의 32개 검사 그룹은 모두 통과했다. 숫자는 생물학 표본 수가 아니다.

| 검사 | 최대 차이 |
|---|---:|

추가로 인과적 prefix, 비음수 신호·확률, 입력 저장공간 소유, 고정 행렬 해시, 미연결 부위 불변, 무조절 입력의 무학습, 구획 벡터 대신 뉴런 벡터를 잘못 넣는 경우의 거부를 검사했다. 순간 활동이 꺼져도 과거 흔적이 남는 경우는 별도로 읽어야 한다.

`reference_parent/run.py`는 출처 보존용이며 이번에 전체 실행하지 않았다. 기존 약물 8개/16개 적합, 확률 방출 공동분포 전체, 전체 Rust/CUDA/MaleCNS도 재실행하지 않았다. 현재 실행 코드는 NumPy/SciPy 독립 연구 모듈이다.

## 7. 자료 획득의 실제 경계

eLife의 그림 수치 파일이 공개돼 있고 저자 저장소에 .mat/.csv와 경로 감쇠 코드가 있음을 확인했다. 그러나 이 환경의 CDN/출판사 다운로드는 DNS 또는 접근 오류로 실패했다. GitHub 연결도 바이너리 .mat를 UTF-8 자료로 읽는 요청을 거부했다. 따라서 raw/는 비어 있으며 데이터를 대체하는 가짜 관측행을 만들지 않았다. 경로가 존재한다는 사실을 바이너리를 읽거나 원자료 분석을 끝낸 것으로 세지 않는다.

원시 calcium 영상을 가져온 것도, xlsx 표의 평균/개체값을 읽은 것도 아니다. 공개 HTML 검색 색인의 본문과 저자 답변을 이용해 정성 구조를 검토했다. PDF를 그래프로 수치화하지 않았다. 실패 기록은 evidence/downloads.json 및 evidence/access_scope.json에 있다.
