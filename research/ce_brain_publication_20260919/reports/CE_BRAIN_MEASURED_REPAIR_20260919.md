# CE-BRAIN: 실측 예측기 수정과 성과 범위의 정정

2026-09-19 · 같은 공개 KC 측정 자료의 후향 재분석

## 판정

기존의 미검증 가지 관계식을 뇌 원리 규명의 진전으로 제시한 것은 요청한 완성 기준을 충족하지 못한다. 그 관계를 새 성과 목록에 추가하지 않는다. 실제 수치가 개선됐던 회귀 관측식과 별도의 합성 회로가 같은 검증을 통과한 것처럼 합치지 않는다.

이번 수정은 **실측 칼슘 관측값을 예측하는 추정 절차**다. 고정 노드·국소 연결 기억이라는 연구 방향은 유지하지만, 새로운 뉴런이나 기억 변수를 추가하지 않았고 신경 동역학 코어를 수정하거나 통합 재실행하지 않았다. 수정된 예측기의 RMSE를 신경망 전체의 성능으로 사용하지 않는다.

31°C 사전가열 자료의 냄새 한 조건 보류에서, 추정 방법 선택까지 내부에서 수행한 RMSE가 0.04010733 → 0.03939941로 1.76507% 감소했다. 감소 폭은 작다. MAE는 0.02970687 → 0.02982565로 소폭 악화했다. 최대 절대 잔차 0.12022402는 그대로다. 모든 점이나 지표를 개선한 결과가 아니다.

**현재 이 생물학적 동역학식을 완성·검증했다는 판정은 내리지 않는다.** 이 전달본에서 완료한 것은 관측 예측기 수정, 실제 데이터 보류 비교, 실패한 탐색의 보존 및 재현이다.

## 1. 입력과 예측 대상

원본은 Bergmann et al. (2026), *Conflicting adaptations in an inhibitory feedback circuit*, DOI 10.1113/JP290394의 저자 GitHub 저장소에 공개된 `CorrelationAnalysis/all KC values.csv`다. 사용자가 전달한 직전 패키지에서 같은 바이트를 읽었다.

- 고정 원본 Git blob: `965d7e038fa23ba4226cda865d8802157f0d18c8`.
- SHA-256: `5733b69eda14e5c557e784e96da917091877dc86a3a4a9c6026eae2520c8765a`.
- 17,682바이트, 1,540개 유효 가공 측정값, 220개 완전한 일곱 자극 벡터.
- 음수 39개를 유지했고 결측·음수값을 임의로 보간하거나 잘라내지 않았다.
- 220은 고유 동물 수가 아니다. 영역·유전자형 간 동일한 슬롯 번호를 같은 개체로 연결하지 않았다.

입력은 같은 영역·자극의 **대조군 평균 칼슘 반응**, 목표는 **처리군 평균 칼슘 반응**이다. 입력 칼슘값 자체를 냄새 분자나 전기 입력에서 예측하는 문제는 아니다. 자극 순서의 화학명 대응은 독립 확인되지 않았으므로 위치 1–7을 유지했다.

새 동물·원시 영상·독립 실험 데이터는 추가되지 않았다. Dataset S1의 공개 존재는 원저에서 확인했지만 다운로드는 실패했다. 원본 CSV를 대체하거나 가짜 원시 파형을 생성하지 않았다.

## 2. 실제 수정한 계산

출력의 기본 형태는 직전 모델과 같다.

    Y_hat[c,o] = slope[type(c)] * X[c,o] + intercept[c]

Calyx·gamma는 별도 기울기, alpha/beta와 alphaprime/betaprime는 각각 공통 기울기를 사용한다. 31c에서는 기울기 네 개와 지역 절편 여섯 개, 총 열 개다. 22c에서는 기존 네 기울기 배율식을 유지한다. 이 공유는 예측용 정규화 제약이며 해부학적 등식으로 주장하지 않는다.

변경한 것은 관측 오차를 처리하는 방법이다. 먼저 해당 훈련 자극에서만 기존 OLS 기울기 k0를 계산한다. 이후 동일 훈련 자료의 측정 SEM을 이용해

    variance[c,o] = SEM_y[c,o]^2 + k0[c]^2 * SEM_x[c,o]^2

를 만들고, 그 역수로 가중 최소제곱을 한 번 수행한다. 1e-10의 수치 안정화 항은 고정되어 있으며 추가 잡음 모수로 적합하지 않았다.

이는 입력과 목표 양쪽의 표본 변동성을 반영하는 **두 단계 대각 오차전파 가중법**이다. 완전한 errors-in-variables 우도나 개체별 공분산을 알아낸 모형은 아니다. 대조군과 처리군의 독립성 및 대각 공분산을 작업 가정으로 사용한다.

외부에서 제외한 자극은 계수 적합과 추정법 선택에 모두 넣지 않는다. 남은 자극 안에서 OLS와 대각 가중법을 다시 비교해 하나를 고른다. 따라서 가중법이 항상 이긴다고 미리 강제하지 않는다. 냄새 조건·세포마다 새 상태를 추가하지 않는다.

## 3. 실제 보류 점수

| 평가 | 기존 추정 절차 | 수정 절차 |
|---|---:|---:|
| 31c: 한 자극 보류, RMSE | 0.04010733 | 0.03939941 |
| 31c: 두 자극 보류, RMSE | 0.04275535 | 0.04217201 |
| 31c: 한 자극 보류, MAE | 0.02970687 | 0.02982565 |
| 31c: 기록 집합 1→2 및 자극 보류, RMSE | 0.06764384 | 0.06764384 |
| 31c: 기록 집합 2→1 및 자극 보류, RMSE | 0.07714325 | 0.07635373 |

이 표는 동일한 원본 자료에 동일한 분할을 적용한 직접 계산이다. 기록 집합은 영역·그룹 안의 슬롯 홀짝으로 분할했다. 실제 동물·반구 ID가 없으므로 동물 단위 독립 평가라고 부르지 않는다.

31c 한 자극 보류의 영역별 RMSE:

| 영역 | 기존 | 수정 |
|---|---:|---:|
| Calyx | 0.03286806 | 0.03396588 |
| gamma | 0.01398571 | 0.01331686 |
| beta | 0.03638345 | 0.03785256 |
| betaprime | 0.03330192 | 0.03242490 |
| alpha | 0.01955600 | 0.01907476 |
| alphaprime | 0.07456856 | 0.07165770 |

alpha′ 오차는 0.07456856 → 0.07165770으로 줄었으나 여전히 가장 크다. Calyx와 beta 등 일부 영역은 악화했다.

22c에서는 기존 OLS 모형의 한/두 자극 보류 RMSE 0.03644697/0.03686593을 유지한다. 수정 절차를 무조건 적용하면 한 자극은 같았지만 두 자극은 0.03729197로 악화했고, 기록 분리 한 방향도 0.11013053 → 0.11184783으로 악화했다. 따라서 이 절차를 모든 온도 이력에 공통으로 승격하지 않는다. 이 조건 구분은 이번 후향적 결과에 근거한 개발 결정이며 새로운 외부 검증이 아니다.

## 4. 좋게 보인 초기 점수와 실패한 탐색

대각 가중법을 고정한 점수는 0.03889251이고, 자동 공분산 축소를 사용한 점수는 0.03710353이었다. 그러나 이는 추정 방법 선택까지 포함한 점수와 다르다. 공분산 축소율을 여러 후보에서 내부 선택한 절차는 0.04177986으로 악화했다. 넓은 공분산 탐색을 최종 절차로 채택하지 않았다.

첫 탐색에는 계수의 부드러운 공유, 측정 오차 가중, 포화·거듭제곱 변환, 비가열 기준 정보를 추가하는 방식, 입력 저차원 축약 등이 포함됐다. 결과를 읽고 후보 범위를 줄였으므로 이번 전체 연구가 맹검이라는 주장은 하지 않는다. `evidence/exploration_actual.json`, `exploration_cov.json`, `robust_actual.json`, `nested_simple.json`에 불리한 결과도 전부 남겼다. 22c 정보를 추가하는 모형은 입력 정보가 더 많으므로 동일 입력의 주 성능 개선으로 사용하지 않았다.

이번 선택은 작은 같은 자료에서 얻은 탐색적 개선이다. 일반화 성공률, 신경계 규명률, 생물학적 완성도로 변환하지 않는다.

## 6. 계산 검증

독립적인 가중 중심화 공식과 행렬 풀이의 최대 차이는 3.77475828373e-15이다. 바깥 보류 목표를 크게 바꿔도 적합 계수·내부 선택이 그대로인지 14개 실제 분할에서 검사했다. 원본 음수·결측·벡터 수를 확인했고 원본 배열을 바꾸지 않았다. 다른 출력 폴더에서 전체 분석을 다시 수행해 평가 JSON, 예측 CSV, 두 모델 JSON의 바이트가 일치했다.

소프트웨어 검사 수는 생물학 표본 수가 아니다. 기존 신경 동역학·말단 기억·전체 MaleCNS를 이번에 재실행하거나 검증한 것은 아니다. 기존 EPSC/PPR 잔차 18.18%포인트는 해결되지 않았다.

## 7. 최종 반영 범위

- 수정: 실제 칼슘 관측 예측기의 추정법 및 검증·선택 절차.
- 유지: 고정 노드·말단별 연결 기억이라는 연구 방향과 원본 코드. 이번에 새 생리 상태는 추가하지 않았다.
- 철회: 미검증 관계식을 새 생물학적 성과로 제시하는 해석; 회귀 RMSE를 별도 회로의 성능으로 사용하는 해석.
- 미달성: 입력 자극에서 신경 상태·발화·행동을 함께 예측하는 완성된 생물학적 동역학식.

정식 생물 검증 원장, GitHub, 사용자 원본 ZIP은 변경하지 않았다. 미래의 조건부 관계를 새 성과로 덧붙이지 않는다.
