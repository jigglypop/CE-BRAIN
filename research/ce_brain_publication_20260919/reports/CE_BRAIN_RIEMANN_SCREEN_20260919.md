# CE-BRAIN: 리만 가정을 유지한 계량 후보의 실측 선별 — 이번 판정은 미채택

2026-09-19 · 기존 공개 KC 가공 측정의 후향적 재분석

## 판정

**이번 후보들은 주 평가의 명확한 개선 기준을 충족하지 못했다. 신규 생물학적 채택식은 없다.** 일부 낮은 점수만 골라 성공으로 바꾸지 않았다. 원래 CE-BRAIN의 리만 계량 가정이나 코어를 폐기한 것은 아니며, 실패한 수치 후보를 원본에 덧붙이지 않는다.

이번에는 연결 기억과 분리된 회귀 보정만 수행한 것이 아니라 SPD 계량이 직접 유한 반응 연산을 정하는 축약모형을 계산했다. 그러나 이것은 **여섯 관측 영역 좌표의 정적·국소 선형반응 검사**다. 원본 `UnifiedMetricCore`, 80-neuron 동역학, 말단 기억, 전체 MaleCNS를 통합 실행한 것이 아니다. 여섯 관측영역을 여섯 실제 뉴런이라고 부르지 않는다. 이 단계의 좋은 점수만으로도 전체 신경 기전이나 곡률이 검증되는 것은 아니다.

## 1. 유지한 원래 전제

연결된 GitHub에서 다음 원문을 확인했다.

`jigglypop/CE-BRAIN`, commit `22b2251be2b12af3ae1e3806290e8283d6321c4d`,
`reality_stone/python/reality_stone/clarus/unified_metric.py`.

원문은 고정된 유한 점/그래프에서 노드별 SPD tensor를 의미 상태로 사용한다. 원문의 선언도 finite local quadratic lengths와 metric-graph readout을 continuum geodesic, curvature, biological evidence와 구별한다.

보존한 수학적 조건은

\[
g=g^T\succ0,\qquad ds^2=dq^Tg\,dq
\]

이다. 계량을 회귀 결과 뒤에 이름만 붙이는 대신, 이번 제한된 검사는 주어진 좌표의 응답을 SPD tensor의 선형계 풀이로 계산했다. 원본의 default eigenvalue bounds 0.25–4에 해당하는 별도 민감도 검사도 수행했다. 좌표계 변경 뒤 다시 고정 수치범위로 clipping하는 것이 일반 affine covariance를 보존한다는 주장은 하지 않는다.

## 2. 계산한 후보의 정확한 범위

두 조건의 중심화된 관측 상태를 연결하는 검사식은

\[
G_1(y-\bar y)=G_0(x-\bar x),\qquad G_0,G_1\succ0
\]

였다. 이는 공통 generalized input을 두 조건에서 유지한다고 추가 가정한 정상 선형반응 축약이다. 실제 자극→뉴런 과거상태→발화의 완성된 방정식으로 취급하지 않는다. \(\bar x,\bar y\)는 훈련 자료의 관측 기준값이지 새 신경 기억이 아니다. 중심값을 두지 않는 \(y=G^{-1}x\) 제한형도 후속 대조로 검사했다.

1차 검사는 **42개 수치 설정**이다. 설정 수는 생물학 표본 수가 아니다.

- 고정된 가지 쌍 좌표에서 공통/차이 방향의 이동도를 가진 SPD 스펙트럼형: 4개 고정 각도 × 5개 수축 강도 = 20개.
- 억제 되먹임에서 동기를 얻은 \(G_0=I+V\operatorname{diag}(r_0)V^T\), \(G_1=\operatorname{diag}(d)+V\operatorname{diag}(r_1)V^T\) : 3개 support × 4개 수축 강도 = 12개. \(d>0,r_0,r_1\ge0\). support와 대칭성은 검사 가정이지 원저가 측정한 연결/전도도가 아니다.
- 반응 이동도 자체를 SPD로 제한한 희소 pair/star형: 2개 support × 5개 수축 강도 = 10개. 희소 이동도와 희소 실제 시냅스는 같은 대상이 아니다.

계량의 역행렬과 모든 예측에 동일한 계수를 사용했다. 비대칭 신경 전달 전체가 대칭 SPD 상태만으로 정해진다는 주장을 하지 않는다. 모든 모델은 constant-chart tangent reduction이며, 위치 의존 곡률을 계산한 것은 아니다.

## 3. 자료·평가

원본은 기존 첨부 패키지의 `all_KC_values.csv`다.

- 저자: Bergmann et al. (2026), DOI 10.1113/JP290394.
- Git blob: `965d7e038fa23ba4226cda865d8802157f0d18c8`.
- SHA256: `5733b69eda14e5c557e784e96da917091877dc86a3a4a9c6026eae2520c8765a`.
- 17,682 bytes; 1,540개 유효 가공 측정; 완전한 7조건 벡터 220개.
- 음수 39개 보존. 결측 보간·가짜 동물 생성 없음.

같은 코호트의 대조군 칼슘 평균을 입력으로 받고 처리군 평균을 예측한다. 입력 평균 자체를 냄새 분자에서 예측한 것은 아니다. 한 냄새 조건을 모든 영역에서 함께 제외한다. 개별 동물/반구 대응이 없어 기록 슬롯 분할을 fly-disjoint라고 부르지 않는다.

비교 기준은 직전 제공된 nested OLS/대각가중 선택 절차이다. 31°C 한 조건 보류 RMSE 0.039399413064, MAE 0.029825648491를 정확히 재현했다.

원래 자료와 앞선 결과를 알고 개발했다. 이번 전체 연구는 외부 사전등록 또는 맹검이 아니다. 후보 및 수축값의 외부 제외와 연구자의 사전 지식은 다르다.

명확한 개선의 작업 기준은 **RMSE와 MAE 각각 5% 이상 감소, 두 조건 보류와 기록 분리에서도 개선 확인**으로 기록했다. 5%는 이번 작업용 기준이지 생물학적 유의성이나 사용자 지정 수치가 아니다. 이 기준은 새 동물의 통계적 확증을 대신하지 않는다. 31°C가 주 평가이며 22°C의 좋은 숫자로 주 평가의 실패를 덮지 않는다.

## 6. 22°C의 유리한 결과도 숨기지 않되, 전체 성공으로 바꾸지 않는다

같은 평가의 비가열 자료에서 중심화된 pair 계량 특수형은 한 조건 RMSE 0.02694471, 두 조건 0.02826911로 작아졌다. 그러나 기록 분리를 포함하면 0.11018403 / 0.12017508이었고, 기존 배율 기준의 0.11013053 / 0.11695794보다 모두 나빴다. 처리군의 평균 기준값 차이를 잘 맞춘 것을 동물 밖 일반화로 바꾸지 않는다.

중심값을 없애고 순수 계량 반응만 남긴 6계수 제한형도 검사했다.

| 22°C 평가 | 기존 4계수 공유 배율 RMSE | 순수 계량형, 내부 수축 선택 RMSE |
|---|---:|---:|
| 한 조건 보류 | 0.03644697 | 0.03177526 |
| 두 조건 보류 | 0.03686593 | 0.03246530 |
| 기록 집합 1→2 + 조건 보류 | 0.11013053 | 0.10291398 |
| 기록 집합 2→1 + 조건 보류 | 0.11695794 | 0.11402695 |

이는 검사한 22°C 조건에서의 부분적 수치 개선이다. 다만 한 조건 MAE 감소는 약 4.991%로 작업 기준인 5%에 미달하고, 7개 적합 중 6개가 이동도 최소 고유값에 걸렸다. 가장 큰 계량 조건수는 약 77,644다. 따라서 숫자만 보고 큰 이방성을 실제 신경 기하로 확정하지 않는다.

원본 fixed-chart 안정화 범위에 맞춰 metric eigenvalue를 0.25–4로 제한한 순수 계량형에서는 한 조건 RMSE 0.03228693, MAE 0.02750463이었다. 기록 분리 RMSE는 0.10430592 / 0.11477530이었다. 부분적 감소는 유지되지만, 31°C에서는 RMSE 0.04599525, MAE 0.03647490으로 주 기준보다 나쁘다.

**따라서 22°C 제한형의 부분 결과는 보존하고, 요청한 전체 생물학적 개선을 달성한 식으로는 채택하지 않는다.** 동일 계수 수의 독립 affine, 더 자유로운 pair 회귀, 두 가지 틀린 쌍짓기 대조도 전부 `additional_equal_parameter_controls.json`에 있다. 좋은 점수의 출처를 실제 시냅스 기전으로 바꾸지 않는다.

## 7. 원 가정과 수치검사의 경계

- SPD 조건은 유지했다. 보정된 metric을 일반 affine chart change로 변환했을 때 quadratic length와 반응도 함께 변환되는지를 검사했다.
- 해당 covariance 검사는 고정된 tensor/readout의 성질이다. 학습 prior 또는 고유값 clipping까지 좌표 불변이라는 주장이 아니다.
- 양의 정부호 행렬을 적합했다는 사실은 실제 뇌의 계량·차원·곡률을 식별했다는 뜻이 아니다.
- 데이터는 static processed calcium group means이므로 신경 시간 동역학, 과거 기억 갱신, 실제 전기적 위상을 여기서 관측했다고 하지 않는다.
- 원본 리만 코어·말단 기억·연합학습 모델·원시 데이터·원격 GitHub는 수정하지 않았다.
- 기존 γ KC→MBON EPSC/PPR 잔차 18.18%포인트도 해결되지 않았다.

## 8. 재현 검사

- 원본 데이터 Git/SHA256 일치 및 이전 첨부 ZIP 11개 해시 불변 확인.
- 기존 기준 절차 재실행 차이 0.
- 1차 최저 pair 후보의 7개 보류 분할 전량 재실행 차이 0.
- 원 metric 안정화 범위의 14개 실제 적합: affine-chart 반응 차이 최대 9.99e-16, quadratic length 차이 최대 1.07e-14, shared-force solve 잔차 최대 5.00e-16.
- 보류 목표를 바꿔도 train-only 순수 계량 적합이 바뀌지 않는 14개 검사 통과.
- 최초 배포용 소스 추출에서 main-guard 문자열을 잘못 잘라 SyntaxError가 났다. import bootstrap만 수정하고 같은 식/수치 설정을 재실행했다. 생물 모델의 변화나 새 성공으로 세지 않았다.

검사 개수는 생물 표본 수가 아니다. 42설정 전체와 모든 보조 평가를 두 번 실행했다고 주장하지 않는다. 원형 probe와 이 배포본의 주 계산을 실행했고, 전달 검사는 위에 명시한 범위다.
