# CE-HPI1: 논문의 학습 과제에서 생성한 문맥 분리와 생물 측정의 비교

**실행일 2026-09-17 · 후향적, 과제 대응 현상 재현 실험**

## 결론

CE-BRAIN HPI1의 고정 방출·전이 학습 모형을 논문에 명시된 실제 과제 구조로 실행했다. 모델이 생성한 문맥 분리 순서를 저자의 11마리 생쥐 측정 요약과 비교했다. 코드 내부 항등식이나 다른 연구자의 모형 결과만 다시 계산한 작업은 아니다.

선택한 800상태 모형의 32회 초기화 중 **23회에서 두 사전보상 구간이 모두 분리되고 Pre-R2가 먼저 분리**됐다. 2회는 반대 순서, 7회는 주어진 학습 예산 안에서 두 구간의 분리를 완료하지 못했다. 동물 자료는 해당 세 범주가 8, 3, 0이다.

**판정: 알려진 문맥 분리 현상의 부분 재현. 원칼슘 신호·개별 뉴런·생물학적 학습 기전의 검증 완료는 아니다.** 두 구간을 모두 분리한 결과와 한 구간만 분리한 결과를 합쳐 '생물학 일치율'로 세지 않는다.

## 1. 이번에 실제로 실행한 모형

기반은 CE-BRAIN `HPI1/predictive_core.py`의 clone-emission HMM이다. HMM과 EM은 기존 알고리즘이다. 새로운 CE 고유의 뇌 법칙을 발명했다는 주장은 하지 않는다.

- 노드/감각 대응은 학습 동안 고정된다. 감각 8종에 각 100개 숨은 슬롯을 둔 판본은 800상태다. **숨은 상태 수는 실제 뉴런 수가 아니다.**
- 바뀌는 것은 상태 간 전이확률이다. 내부 문맥 정답, 정답 상태 번호, 동물의 상관/학습 시점은 학습기에 주지 않았다.
- 학습은 완료된 경험 묶음의 forward–backward 기대 전이 횟수와 행 정규화다. 추론과 반응 측정에는 causal forward 상태만 사용했다.
- 100슬롯은 해당 논문의 CSCG 설정을 가져온 것이다. 단일물리 상수나 실제 세포당 복제 수가 아니다.
- CE의 Gamma 초기화와 논문의 uniform 초기화를 별도 비교했다. 기존 HPI1의 prefix/suffix로 정답 상태 구조를 구성하는 initializer는 사용하지 않았다.

관측 기호로 블록화한 NumPy/Numba 구현이다. 작은 독립 dense HMM과 경로 완전 열거로 계산의 동등성을 검사했다. 전체 CE 런타임, Rust, MaleCNS의 실행으로 표현하지 않는다.

## 2. 입력과 학습 계약

논문 Methods 및 저자 코드에 제시된 26기호 trial을 사용했다.

```text
Near: 1 1 1 1 1 1  2 2 2 2  1 1 1  4 6  1 1 1  5 5  1 1  7 0 0 0
Far:  1 1 1 1 1 1  3 3 3 3  1 1 1  4 4  1 1 1  5 6  1 1  7 0 0 0
```

1은 모호한 공통 감각, 2/3은 trial을 구분하는 단서, 4/5는 두 보상 위치의 시각 기호, 6은 공통 물 보상이다. 이 기호화는 저자 모델에서 온 과제 표현이다. 동물 각 개체의 실제 trial 순서, 속도, 형광 기록을 입력한 것은 아니다.

각 실행은 **50묶음 × 20회 갱신**, 묶음당 무작위 Near/Far 20trial이다. 같은 묶음의 반복 갱신을 독립 경험 20배로 세지 않는다. 최대 1,000회 갱신은 이번 계산 예산이며 동물의 1,000일/1,000trial과 동일하지 않다.

주 비교는 seed 200–215에서 개발하고 216–231에서 추가 검사했다. 추가 seed는 새로운 초기화의 재현 검사이지 새로운 동물 검증 자료가 아니다. 논문 측정값을 이미 알고 시작한 후향적 실험이며 외부 사전등록은 아니다.

## 3. 생물학과 비교한 관측 항목

실측 기준은 논문 Figure 4j의 공개된 11마리 × 3개 분리 시점 요약이다. 해당 수치의 Pre-R2, Pre-R1 순서는 다음과 같다.

| 생물 측정 요약 | 값 |
|---|---:|
| 두 구간이 모두 분리된 공개 동물 수 | 11 |
| Pre-R2가 먼저 분리 | 8 |
| Pre-R1이 먼저 분리 | 3 |
| Pre-R2 평균 정규화 분리 시점 | 0.409773411 |
| Pre-R1 평균 정규화 분리 시점 | 0.589953590 |

원고의 핵심 현상은 **동일 감각 구간의 문맥 표현이 학습으로 분리되고, 다수 동물에서 먼 보상 직전 구간의 분리가 먼저 나타난다**는 것이다. 모델에 이 순서를 목표 손실로 넣지 않았다.

모형에서는 Near와 Far를 인식하는 forward 상태 벡터의 Pearson 상관을 측정했다. 사전보상 구간의 상관이 0.3 아래로 처음 내려가는 시점을 기록했다. 학습 전 두 감각에 서로 다른 직교 상태를 강제 배정하지 않는다.

### 관측 대응의 한계

**forward 잠재상태 확률은 칼슘 형광이 아니다.** 이번 비교는 과제에 대응시킨 문맥 분리 현상과 순서의 비교다. 개별 세포에 대한 모델–신경 대응, 형광 관측기, 동물 원자료 전처리를 추정하지 않았다.

초기 pilot에서는 회색 구간의 세 위치를 읽었다. 저자의 RNN 분석 노트북을 확인한 뒤 사전보상 네 위치 `[10:14]`, `[15:19]`의 대각 상관을 주 readout으로 기록하고, 세 회색 위치는 민감도 분석으로 함께 보존했다. 학습 배열은 바뀌지 않았으며, 동일 16 seed에서 전이 배열이 완전히 같은지 검사했다.

대형 CSCG 노트북은 도구 제한으로 읽지 못했다. 따라서 **전체 저자 CSCG 또는 동물 분석 파이프라인을 완전 복제했다고 주장하지 않는다.** 상관을 추출하는 집계·시간 원점의 차이가 남아 있으므로 절대 상관 오차/분리 시간 오차를 정식 신경 예측 정확도로 부르지 않는다.

## 4. 실제 결과: 미완료를 별도 범주로 유지

| 대상 | 실행/동물 수 | 두 구간 분리 + R2 먼저 | 두 구간 분리 + R1 먼저 | 두 구간 분리 미완료 |
|---|---:|---:|---:|---:|
| 저자 공개 동물 요약 | 11 | 8 | 3 | 0 |
| 128상태, 전체 경험 학습 | 16 | 0 | 0 | 16 |
| 800상태, 한 단계 뒤 정보만 학습 | 16 | 0 | 0 | 16 |
| 800상태, CE Gamma 초기화 + 전체 경험 학습 | 32 | 16 | 4 | 12 |
| **800상태, uniform 초기화 + 전체 경험 학습** | **32** | **23** | **2** | **7** |

작은 상태 풀에서 큰 상태 풀로 옮기며 상태 수와 매개변수가 증가했다. 성능 개선을 동일 계산/메모리 비용의 우위로 주장하지 않는다. 상태 수 100이 최소 필요조건이라는 결론도 아니다.

한 단계 신용할당 대조는 같은 상태 수와 입력을 쓰지만, 전이 기대횟수 계산에 먼 미래의 관측을 포함하지 않는다. 이 대조의 실패는 **검사한 이 모형/설정/예산에서** 충분하지 않다는 결과이지, 모든 국소 학습 규칙의 불가능성 증명이 아니다.

### 초기화 변경과 추가 실행

개발 seed 16개에서 uniform의 두 구간 분리 완료는 13/16, Gamma는 11/16이었다. 독립된 trial 배열의 보상 예측도 uniform이 더 좋았다. 그래서 uniform 후보를 추가 seed 실행 전에 기록했다 (`selection_before_uniform_fresh.json`).

추가 16개에서는 uniform이 **12회 두 구간 분리 + R2 선행**, 4회 미완료였다. Gamma 추가 16개는 7회 R2 선행, 2회 반대, 7회 미완료였다. 이때 학습 조건과 기준은 다시 조절하지 않았다.

### 비율 하나로 성공을 주장하지 않는다

23/32=71.875%와 8/11=72.727%는 비슷해 보인다. 그러나 동물의 반대 순서는 3/11인 반면 모형에서는 2/32이고, 7/32가 미완료다. **두 비율의 근접은 전체 분포 일치나 71.875%의 신경 예측 정확도가 아니다.**

`biological_comparison_final.json`에는 우측 검열된 교차 시점의 순서/시간차 범위도 있다. 주 판정은 이 부분 순서를 완료한 생물 현상과 섞지 않고 위 세 범주로 한다.

## 5. 과제 수행 결과는 별도 점수

학습된 전이를 고정한 뒤 새 순서로 배열한 익숙한 Near/Far 40trial에서, 각 두 보상 위치의 다음 물 보상 발생 여부를 80번 읽었다. 정답은 점수 계산에만 사용했다. 새로운 기호·길이·과제로의 일반화 시험은 아니다.

| 모델 | 평균 보상 예측 일치 | Brier 오차 |
|---|---:|---:|
| 128상태 전체 경험 | 54.6875% | 0.239921875 |
| 800상태 한 단계 신용 | 50.0000% | 0.278540666 |
| 800상태 Gamma 전체 경험 | 91.4063% | 0.048710937 |
| **800상태 uniform 전체 경험** | **94.5313%** | **0.027968750** |

**94.5313%는 모델의 합성 과제 예측값이지 동물의 핥기 행동이나 신경 발화와의 일치율이 아니다.** 미사용 자료는 학습한 과제 템플릿의 새로운 trial 순서이며, 개체/과제 밖 일반화가 아니다.

## 6. 아직 맞지 않는 시간차를 숫자로 남긴다

학습 시계의 단순 배수 영향을 줄이기 위해 `(t_R1-t_R2)/(t_R1+t_R2)`를 보조 지표로 계산했다. 출발시점 이동과 관측 정의 차이는 제거되지 않으며, 생리적 초/일 단위 예측도 아니다.

| 비교 | 평균 지표 | 분모/주의 |
|---|---:|---|
| 동물 | 0.133614 | 11마리 모두 시점 있음 |
| uniform 모형 | 0.327971 | 두 구간 교차를 완료한 **25/32만**; 나머지 7은 별도 미완료 |
| 차이 | +0.194357 | 탐색적 진단; 정식 신경 예측 오차 아님 |

모형은 완료된 경우 두 구간의 분리를 평균적으로 더 멀리 벌렸다. 이것을 지우려고 동물 값에 맞춘 시간 축 재설정이나 관측 잡음을 넣지 않았다. 일치 여부를 닫으려면 원신경 관측기/학습 시작점을 맞추고 분포 전체를 비교해야 한다.

## 7. 이번 결과로 남길 알고리즘

**고정된 감각-상태 슬롯 + 완료된 경험을 되짚는 전이 학습 + 현재까지의 감각만 쓰는 추론**을 다음 문맥 학습 구현 후보로 유지한다. 이는 CE-HPI1 내부의 기존 HMM 계산을 생물학 과제 구조에 적용한 구현 결과다.

현재 결과는 완성된 문자열을 미리 등록한 AC 검색이 아니다. 그렇다고 AC나 PS 자료구조의 생물학적 역할을 이번에 반증한 것도 아니다. 그 알고리즘은 본 실험 비교군에 없다.

모형이 R2를 먼저 분리하는 이유에 대한 해석은, R2 이전에는 R1에서의 보상/무보상이라는 최근 경험도 이용할 수 있지만 R1 이전은 더 앞선 단서 문맥을 구분해야 한다는 것이다. 이는 과제 구조와 모형에 대한 기전 가설이며, 뇌가 동일한 backward message를 생물학적으로 계산한다는 직접 증거는 아니다.

앞으로 줄여야 할 구체적인 잔차는 **7/32의 불완전 분리, 반대 순서 개체의 부족, 분리 시간차의 과장**이다. 이를 평균 점수나 관측 변환으로 숨기지 않고 주된 수정 대상으로 둔다.

## 8. 재현성과 전달 범위

정식 비교 96개 초기화의 전이 배열·학습 곡선·입력 seed·오류 기록을 보존했다. 별도 pilot과 초기 세 위치 readout 실행은 정식 96개에 중복 합산하지 않았다.

독립 dense HMM 24조건, 잠재 경로 완전 열거 8조건, forward 인과성과 Pearson 관측기 8조건을 검사했다. 최대 차이는 약 8.33e-16, 미래 입력을 붙이기 전 prefix 반응 차이는 0이었다. 이 검사들은 소프트웨어 검사일 뿐 동물 표본이 아니다.

`reproduce.py`는 새 출력 폴더에 선택 후보를 다시 학습시켜 패키지의 예측·전이와 비교한다. `--mode full`은 96개 정식 실행을 대상으로 한다. 시간 측정치(elapsed)는 동일성 검사의 대상이 아니다.

원격 GitHub, 사용자 원본 ZIP, MaleCNS 원자료는 변경하지 않았다. **전체 MaleCNS 실행과 생리·행동 재현은 이 결과에 포함되지 않는다.** 이번 모델은 해마 과제의 알고리즘 수준 후보이며, 초파리 커넥톰의 근거로 합산하지 않는다.
