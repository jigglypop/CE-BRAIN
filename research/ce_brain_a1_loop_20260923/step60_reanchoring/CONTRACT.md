# A1 60단계 — 다운 상태가 지운 방향은 업 상태 동안 되돌아오는가, 잃어버려지는가 (사전등록)

작성: 2026-09-25. 이 분석으로는 실제 자료를 계산하지 않았다. 합성 두 경우로 함수를 확인했다.
- 상류가 방향을 붙잡고 0.3초 뒤 되돌림: 초기 −0.02, 후기 1.0 → R1.
- 잃어버림: 초기 −0.01, 후기 −0.02 → R2.

## 왜

- 57단계: 다운 상태를 건너면 피질 범프 위치가 지워진다(ρ −0.03).
- 59단계: 업 상태 내내 약하게 흔들린다.
- 시상 버스트 모형(IFB, Smith 외 2000)을 넣으려면 먼저 가려야 할 것이 있다. **잠 동안 방향을 붙잡는 끌개가 어디에 있는가.**
  - 상류(뇌간 생성기)가 잠에도 방향을 붙잡고 있다면, 다운 상태 직후 흩어진 피질 범프가 업 상태가 이어지면서 **원래 방향으로 돌아와야** 한다.
  - 방향 자체를 잃었다면, 새 위치에 머문다. 58단계 모형(피질 고리 재설정)의 예측이 이쪽이다.

## 방법

- 57·59단계 기준을 그대로 쓴다: 100 ms 칸, 활동 ≥ 4(반쪽마다 ≥ 2), 침묵 ≤ 1. 집우리 논렘만 쓴다.
- 틈새: 침묵 1–5칸(0.1–0.5초)이다. 앞에 활동 칸 t₀가 있어야 한다.
- 틈새 뒤 칸: t_d = 틈새 뒤 첫 칸 + d − 1, d = 1..10(0.1–1.0초). 새 침묵 칸이 나오기 전까지, 그리고 t_d가 활동 칸일 때만 센다.
- ρ(t₀, t_d)는 반쪽 교차 지속도다(20회 분할). 분모는 **쌍별**(t₀와 t_d의 같은 칸 일치도 기하평균)로 둔다. 59단계 사후 보정과 같다.
- 부류: 초기 d = 1–2, 후기 d = 5–10.

## 판정 (생쥐 31마리)

| 기준 | 내용 |
|---|---|
| R1 되돌아옴 | ρ_후기 > ρ_초기 + 0.15 **그리고** ρ_후기 > 0.2인 세션 ≥ 70% (부류별 쌍 ≥ 30) |
| R2 잃어버림 | ρ_후기 ≤ 0.1 **그리고** ρ_초기 ≤ 0.1인 세션 ≥ 70% |

- R1이면 `HEADING_REIMPOSED_FROM_UPSTREAM`, R2이면 `HEADING_LOST`, 둘 다 아니면 `INTERMEDIATE`다.
- 참조: 58단계 모형 생쥐 5마리(같은 씨앗·σ·GAIN)에 같은 분석을 한다.

**사전 예측.**
- 생쥐: `HEADING_LOST`. 약 60% 확신이다. 어둠·잠에서는 바깥 기준점이 없고, Peyrache 2015도 논렘에서 덩어리가 빨리 돈다고 보고한다.
- 모형 참조: `HEADING_LOST`.
