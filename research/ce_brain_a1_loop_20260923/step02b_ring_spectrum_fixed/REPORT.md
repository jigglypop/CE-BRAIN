# A1 반복 2b단계 결과 — 판정: A1_RING_MEMORY_ATTRACTOR_SUPPORTED

자유 동역학 모수 없이 실제 가중치 행렬(148 뉴런, 입력 정규화 부호 행렬)의 스펙트럼만으로 판정했다.

| 판정 | 입력 정규화 (판정용) | 원 시냅스 수 (보고) |
|---|---|---|
| S1 선도 비균일 모드의 1차 조화 비율 | 0.992 | 0.933 |
| S2 퇴화쌍 | 0.6312 / 0.6303, span의 cos/sin R² 0.985 | 588 / 570, R² 0.947 |
| S3 PEN 좌우 불균형의 회전 비율 ρ | **0.996** | 0.994 |

- $Q=\tilde B^\top\Gamma WB\approx\begin{pmatrix}0.0046&-0.0391\0.0413&0.0003\end{pmatrix}$로, 거의 순수한 2차원 회전 생성자다.
- 쌍대 기저 오차는 $2.6\times10^{-15}$이다.

**기억 복구 쪽 보고값 (판정 제외).**
- **균일 모드 비:** $\lambda_0/\lambda_1$ = **1.28** (원자료 1.24). 이 148개 뉴런만으로는 이득을 올릴 때 균일 모드가 기억 모드보다 먼저 불안정해진다. 1단계에서 끌개가 0/144였던 원인으로 가장 유력하다. 기억 끌개가 성립하려면 균일 모드를 누르는 외부 전역 억제가 필요하다는 예측이 된다.
- **모양 복원 속도:** 1차 쌍을 한계 안정에 두면 2차 조화의 선형 복원 속도는 0.27/τ다. 봉우리 모양이 흐트러져도 약 3.7τ 안에 되돌아온다는 예측이다.
- **회전 속도:** PEN 구동 1단위당 0.064 rad/τ.

**해석 (L0).**
- 방향 고리 배선 자체가 원 위의 기억 끌개(퇴화 1차 조화쌍)를 담는다.
- 방향성 이동(PEN)은 그 끌개 안에서 순수 회전으로 작용한다. A1의 $L_g$와 $S_k$가 가중치 수준에서 분리되어 있다.
- 활동 자료로 한 검증은 아니다.

**다음.** EB의 전역 억제원(ring/ER 계열)을 넣으면 $\lambda_0/\lambda_1<1$이 되는지 사전등록한다. 되면 1단계 동역학을 다시 실행한다.
