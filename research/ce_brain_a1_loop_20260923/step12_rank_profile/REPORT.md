# A1 12단계 (사후 발견) — 신경계의 계수 윤곽: 압축과 확장이 번갈아 온다

**질문 (사용자).** 뇌와 신경삭이 스테이블 디퓨전처럼 계수를 낮췄다가 다시 올리는가?

**방법.**
- 슈퍼클래스로 단계를 나눈다.
- 단계 사이 시냅스 행렬의 열을 입력 비율로 정규화한다.
- 제곱 프로베니우스 에너지의 90%를 담는 계수(rank90)를 잰다.
- 대조는 같은 행렬에서 시냅스의 수신 쪽 끝점을 섞은 것이다.
- 상위 600개 특이값만 계산했으므로, 엔트로피 유효 계수는 상한에 막혀 해석하지 않는다.

## 뉴런 수 윤곽 (뇌→몸 경로)

| 단계 | 뉴런 | 변화 |
|---|---:|---|
| 뇌 감각 뉴런 | 10,966 | |
| 시엽 내재 | 89,403 | ×8 확장 |
| 시각 투사 | 9,764 | ÷9 압축 |
| 중앙뇌 내재 | 32,164 | ×3.3 확장 |
| **하강 뉴런(DN)** | **1,314** | **÷24 압축 (목 병목)** |
| VNC 내재 | 13,161 | ×10 확장 |
| 운동뉴런 | 815 | ÷16 압축 |

역방향 경로는 상승 뉴런 1,846개다.

## 연결 행렬의 rank90 (대조 대비)

| 경로 | 행×열 | rank90 | 섞은 대조 |
|---|---|---:|---:|
| 시각 투사 → 중앙뇌 | 9,342×18,132 | 493 | 600 초과 |
| 중앙뇌 → DN | 19,719×1,308 | **386** | 600 초과 |
| DN → VNC | 1,305×12,791 | **364** | 600 초과 |
| VNC → 운동뉴런 | 10,830×708 | 243 | 388 |
| 상승 → 중앙뇌 | 1,839×18,343 | 282 | 600 초과 |
| **ALPN → KC** | 314×3,812 | **158** | **152** (무작위와 같음) |
| **KC → MBON** | 4,063×97 | **30** | **60** |

## 발견 (사후, 역증명 필요)

1. **모래시계가 여러 겹 쌓여 있다.** 뉴런 수는 확장(시엽, 중앙뇌, VNC)과 압축(시각 투사, DN, 운동뉴런)을 번갈아 한다.
2. **목 신경삭은 약 360–390차원의 잠재 통로다.**
   - 뇌 약 13만 개와 VNC 약 1.3만 개를 잇는 DN 1,314개의 실효 계수가 rank90 386(입력 쪽)과 364(출력 쪽)다.
   - 섞은 대조보다 뚜렷이 낮다.
3. **버섯체는 "무작위 확장 → 구조화 압축"이다.**
   - PN→KC 계수는 무작위와 같다. 이는 무작위 수렴 문헌(Caron et al. 2013)과 맞는다.
   - KC→MBON은 대조의 절반(30)으로 압축된다.
   - 11단계의 "KC만 고차원"과 한 그림으로 맞는다.

## 스테이블 디퓨전 대응 (가설)

| SD | 신경계 후보 |
|---|---|
| VAE 인코더 (압축) | 시엽 → 시각 투사, 중앙뇌 → DN |
| 잠재 공간과 노이즈 제거 U-Net | 중앙뇌의 저차원 끌개들(고리·면). A1의 $-L_gx$ 복구가 점수 함수 방향의 노이즈 제거에 해당한다 |
| 조건 입력 (텍스트) | 단서·맥락, A1의 $u_k(t)S_k$ |
| VAE 디코더 (확장) | DN → VNC → 운동뉴런 |
| (SD에 없음) 무작위 확장 + 학습된 읽기 | 버섯체 PN→KC→MBON (커널 기계에 가깝다) |

## 한계

- 연결 행렬의 계수는 활동 표상의 차원이 아니다.
- 되먹임 고리가 많은 재귀망을 피드포워드 단계로 잘랐다.
- 슈퍼클래스 경계는 거칠다.
- 대조는 행 합만 보존한다.
