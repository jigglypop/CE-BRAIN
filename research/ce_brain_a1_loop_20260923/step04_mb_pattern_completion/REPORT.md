# A1 반복 4단계 결과 — 판정: KC_PATTERN_COMPLETION_NOT_SUPPORTED (기준 60%, 관측 56%)

KC→KC 결합이 PN(냄새) 입력 유사도를 따르는지, 세포체 거리를 통제한 부분 Spearman 상관으로 검사했다. 순열 대조는 같은 아형·반구 안에서 입력 벡터를 섞은 것이다.

| 아형 | 좌 $\rho_p$ (p) | 우 $\rho_p$ (p) |
|---|---|---|
| KCab-s | **0.155** (0.005) | **0.159** (0.005) |
| KCab-m | **0.072** (0.005) | **0.058** (0.005) |
| KCab-c | 0.007 (0.110) | 0.020 (0.015) |
| KCg-m | **0.031** (0.005) | **0.035** (0.005) |
| KCg-d (PN 입력 KC 14/19) | 0.127 (0.114) | 0.026 (0.408) |
| KCa'b'-ap1 | **0.068** (0.005) | 0.022 (0.090) |
| KCa'b'-ap2 | **0.067** (0.005) | **0.040** (0.005) |
| KCa'b'-m | 0.044 (0.015) | 0.034 (0.065) |

p = 0.005는 순열 200회에서 가능한 최솟값이다.

## 판정

- 통과 단위는 9/16 = 56.25%로, 기준 60%에 미달한다. $\rho_p$ 중앙값은 0.042다.
- 판정은 `KC_PATTERN_COMPLETION_NOT_SUPPORTED`다.

## 사후 관찰 (사전등록 아님)

- **부호 일관성:** 16/16 단위 모두 $\rho_p>0$이다. 무작위 부호라면 확률은 $2^{-16}\approx1.5\times10^{-5}$다.
- **거리 교란 없음:** 거리를 통제하기 전과 후의 상관이 거의 같다. 가까운 KC끼리 더 결합하는 경향(결합–거리 상관 −0.03~−0.17)은 입력 유사도 효과를 설명하지 않는다.
- **대칭성:** KC→KC 반대칭 에너지 비율은 0.134로, 대부분 대칭이다(A1의 $L_g$ 형태).

## 해석 (L0)

- KC→KC 결합은 약하지만 일관되게 냄새 입력이 비슷한 KC를 묶는 대칭 결합이다.
- 효과가 작고(ρ 약 0.03–0.16) 사전 기준에 미달했다. "패턴 완성 연산자"로 채택하지 않는다.
- 기억 복구의 주 경로는 따로 찾아야 한다. 후보는 MBON→DAN 되먹임과 APL 전역 억제다.
