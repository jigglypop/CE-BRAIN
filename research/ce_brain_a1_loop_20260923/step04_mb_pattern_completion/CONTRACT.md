# A1 반복 4단계 — MB 연합 기억: KC→KC 결합은 패턴 완성 연산자인가

작성: 2026-09-23, 실행 전 고정. 계획 (3)에 해당한다.

**질문.** 기억 복구(부분 단서 → 전체 패턴)에는 대칭 결합 $L_g$가 입력이 비슷한 뉴런을 서로 묶어야 한다. KC 엽 입력의 대부분(γ엽 71%)은 KC→KC다. 이 결합이 **같은 냄새 입력(PN 사구체)을 공유하는 KC끼리 더 강한지** 본다.

## 측정 (MaleCNS `neuron-graph-v1`, 모든 ROI의 시냅스 수)

- **KC:** `type`이 `KC`로 시작하는 뉴런, 반구는 `somaSide`로 나눈다. PN은 `class == "ALPN"` 686개(유형 181개)다.
- **입력 유사도:** KC마다 PN→KC 시냅스를 PN 유형(사구체)별로 합한 벡터를 만든다. 두 KC의 코사인 유사도가 입력 유사도다. PN 입력이 0인 KC는 제외한다.
- **결합:** $c_{ij}=w_{ij}+w_{ji}$ (KC→KC 시냅스 수).
- **교란 통제:** 세포체 거리 $d_{ij}$ (`somaLocation`).
- **검사 단위:** 같은 KC 아형·같은 반구 안의 모든 쌍. 그 반구에 90개 이상 있는 아형만 쓴다.
- **통계량:** 순위 변환 후 $d$ 순위에 선형 회귀한 잔차끼리의 부분 Spearman 상관 $\rho_p(s,c\mid d)$.
- **순열 대조:** 같은 아형·반구 안에서 KC의 입력 벡터만 섞는다(결합과 거리는 고정). 200회, $p=(1+\#\{\rho_{\rm null}\ge\rho_{\rm obs}\})/201$.

## 판정

- **K1 (단위별):** 아형-반구 단위마다 $\rho_p>0$이고 $p<0.01$이면 통과다.
- **K2 (종합):** 검사한 단위의 60% 이상이 통과하고, 단위별 $\rho_p$ 중앙값 > 0이어야 한다.

**보고:** 거리 통제 없는 Spearman 상관, 결합–거리 상관, KC→KC 반대칭 에너지 비율(대칭성)을 함께 적는다.

**종합:** K2 통과 → "KC→KC 결합은 입력(냄새) 유사도를 따르는 대칭 연산자다. 패턴 완성, 곧 기억 복구 연산자의 구조적 조건을 만족한다(L0)". 실패하면 KC→KC는 입력 유사도와 무관한 결합(예: 동기화·공간 근접)으로 기록한다.
