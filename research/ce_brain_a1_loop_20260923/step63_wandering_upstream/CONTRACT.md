# A1 63단계 — 논렘에서 머리방향 체계 전체가 떠도는가: 떠도는 상류 모형 (사전등록)

작성: 2026-09-25. 짧은 세션으로 끝까지 도는지만 확인했다. 결과 값은 출력하지 않았다.

## 왜

- 62단계: 상류가 방향을 붙잡고 중계만 흔들리면, 흔드는 입력이 원래 방향으로 되돌리는 입력이기도 하다. 그래서 생쥐의 조합을 만들 수 없었다(업 흔들림 0.68이면서 재출현 0.08).
- 남은 가장 단순한 설명: **논렘에서는 상류(뇌간 생성기) 자체가 떠돈다.**
  - 피질은 다운 상태마다 지워진 뒤, 떠도는 상류 쪽으로 약하게 끌려간다.
  - 그러면 흔들림은 상류의 떠돎에서 오고, 원래 방향의 흔적은 상류가 1초 안에 아직 다 멀어지지 않은 만큼만 남는다.
- 문헌: Peyrache 2015에 따르면 논렘에서 시상 ADn 덩어리도 빨리 돈다.

## 모형 (고정)

- 62단계와 같고, 한 가지만 다르다: 논렘에서 생성기 방향이 확산 D_NREM(rad²/s)의 **무작위 걷기**이고, 중계는 추가 떨림 없이 그것을 전한다.
- 깸: 생성기 D_W = −ln(0.977)/0.3, 중계 세기 1. 탐색: 머리방향.
- 58단계 고리·일정·σ·GAIN·스파이크 생성은 그대로다.

## 맞춤 (2개 값 ↔ 생쥐 2개 수치)

- A_NREM ∈ {0.1, 0.2, 0.4, 0.8} × D_NREM ∈ {1, 2, 4, 8} rad²/s, 씨앗 630.
- 최소화 대상: (후기 재출현 − 0.084)² + (업 후기 붙잡기 − 0.683)². 생쥐 값은 62단계 결과에서 가져온다(같은 추정기).

## 예측 (씨앗 631–635 중앙값)

| 기준 | 내용 | 생쥐 |
|---|---|---|
| P1 초기화 | 재출현 초기 ≤ 0.15 | 0.031 |
| P2 업 초기 흔들림 | 업 초기 ∈ [0.3, 0.65] | 0.467 |
| P3 논렘 흩어짐 | 논렘 0.3초 ρ ∈ [0.15, 0.5] | 0.319 |
| P4 재출현 곡선 **높이** | d 1–10에서 평균 \|모형 − 생쥐\| ≤ 0.05 (62단계의 척도 무관 기준을 고침) | 0.02 → 0.10 |
| P5 구조 유지 | 고리 지표 논렘/깸 ∈ [0.8, 1.2] | 0.98 |
| P6 깸 붙잡기 | 깸 0.3초 ρ ≥ 0.9 | 0.977 |

- 모두 맞으면 `FREE_RUNNING_UPSTREAM_EXPLAINS_NREM`, 아니면 `FREE_RUNNING_UPSTREAM_PARTIAL`이다(맞은 것을 적는다).
- 보고: 맞춘 D_NREM / D_W(깸 대비 논렘 확산 배수). Peyrache는 논렘이 "훨씬 빠르다"고 보고했다.

**사전 예측.**
- 맞춤이 62단계보다 잘 된다. D_NREM ≈ 2–4, A_NREM 중간.
- P1 통과: 다운 직후에는 피질이 무작위로 선다.
- P4 통과: 흔적이 천천히 오른다.
- P2·P3 불확실.
- P5·P6 통과.

## 해석 한계

- 상류의 떠돎은 가정한 무작위 걷기다(기전 없음).
- 맞춘 값 두 개가 있고, 격자가 거칠다(4 × 4).
- 파리 16단위 고리를 쓴다.
- L4 근거가 아니다.
