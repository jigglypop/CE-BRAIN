# A1 16단계 — EPG 배선 다양체는 위상적으로 고리인가 (사전등록)

작성: 2026-09-23. 실제 자료로 지속 호몰로지를 계산하기 전에 고정한다.

**질문(사용자).** "위상인가? 위상적으로" — 15단계 F4 실패의 원인은 반지름 균일성(CV)이었다. CV는 계량 성질이고 위상 성질이 아니다. 핵심 주장인 고정 뉴런이 접은 원(S¹, PB→EB 차수 2 감김)은 위상 명제다. 그래서 두 개체의 EPG를 위상 기준으로 다시 잰다.

**이미 본 것.**
- 15단계 사후 진단에서 FlyWire EPG의 MDS 반지름과 각도 범위를 보았다.
- 지속 호몰로지는 실제 자료로 계산한 적이 없다.

## 방법

1. **거리.** 11단계와 같은 단위 연결 윤곽(입력·출력 행 정규화, √2로 나눔) 사이의 현 거리를 쓴다. 현 거리는 11단계 각거리의 단조 함수라서 Vietoris–Rips 여과가 같다. 중심화한 Gram 행렬의 PCA 좌표로 계산한다.
2. **H1 지속성.** ripser(maxdim 1)로 가장 긴 H1 수명 ℓ1과 두 번째 수명 ℓ2를 구한다.
3. **대조.** PCA 스펙트럼이 같은(2차 모멘트 동일, 구멍 없음) 가우스 점구름이다. EPG·보고 유형은 500회, 전체 훑기는 100회 뽑는다. 시드는 20260923이다.
4. **고리 판정.** ℓ1 > 대조 최장 수명의 95% 분위이고, ℓ1 ≥ 2·ℓ2이다.

**합성 보정.** `calibrate.py`, sha256 `a248cc7d…aeb`, n=23, 잡음 20차원, 각 20회, 실제 자료 전에 실행했다.

## 판정

- **T0 방법 대조.** MaleCNS EPG 좌·우가 모두 고리 판정을 통과한다. 실패하면 `METHOD_CONTROL_FAILED`다.
- **T1 재현.** FlyWire EPG 좌·우가 모두 고리 판정을 통과한다.
- **T2 특이성.** EPG를 뺀 뉴런 15–40개인 전체 유형×반구 가운데 고리 판정 통과 비율이 두 자료 모두 ≤ 20%다. 이는 합성 원판 위양성의 상한이다.

**종합:** T0 ∧ T1 ∧ T2 → `EPG_TOPOLOGICAL_RING_REPLICATED`.

**보고(판정 아님).**
- PEN_a, PEN_b, PEG, Delta7, ER4d의 좌·우 결과.
- 상위 분류별 통과율.
- 윤곽이 0인 뉴런이 있어 건너뛴 단위 수.

**해석 한계 (미리 적음).**
- H1 고리는 "배선 유사도의 모양이 원"이라는 위상 명제일 뿐이다. 두 개체 사이에서 고리 위 **순서(위상각)**가 같은지는 FlyWire에 사구체 표지가 없어 검사하지 않는다.
- 동역학·개입 결론(L4)은 쓰지 않는다.
