# A1 62단계 — 약하고 흔들리는 상류 끌어당김 하나로 논렘의 관측들이 함께 나오는가 (사전등록)

작성: 2026-09-25. 짧은 세션으로 끝까지 도는지만 확인했다(1,220초 모사 24초). 결과 값은 출력하지 않았다.

## 왜

- 생쥐 논렘에서 확인한 관측은 다음과 같다.
  - 다운 상태가 방향을 지운다(57).
  - 업 상태 내내 흔들리고, 시작 직후가 가장 심하다(59).
  - 지워진 방향이 1초에 걸쳐 희미하게 돌아온다(60).
- 58단계의 잠의 식은 지움만 만든다.
- 61단계의 시냅스 촉진은 즉시 재수립을 만들어 기각되었다.
- 문헌 값의 IFB 시상 중계에 방향을 붙잡는 뇌간을 붙이면, 업 시작의 반동 버스트가 방향에 맞춰져 역시 즉시 재수립을 만든다. 또 Peyrache 2015는 논렘에서 시상(ADn) 덩어리도 빨리 돈다고 보고한다. 그래서 IFB를 직접 넣는 대신 추상적인 가설을 검사한다.
- 가설: **뇌간 생성기는 방향을 붙잡고, 논렘 중계는 그것을 약하고 흔들리게 전한다.** 이 한 가지 확장으로 세 관측이 함께 나오는가.

## 모형 (고정)

- 58단계 고리와 일정은 그대로다: Kim 국소, 16단위, τ 20 ms, dt 1 ms, σ 0.2, 구동 켜짐/꺼짐.
- **생성기 방향 θ_g.**
  - 탐색: 머리방향.
  - 집우리 깸: D_W = −ln(0.977)/0.3 rad²/s의 무작위 걷기. 생쥐 깸 ρ(0.3초)에서 정했다.
  - 논렘: 붙잡힘(D = 0).
- **중계된 방향 ψ = θ_g + η.** η는 OU 과정(τ 0.1초, 표준편차 S)이다. 깸은 S = 0, 논렘은 S = S_NREM이다.
- **중계 입력.** 단위 k에 a·exp(4(cos(ψ − φ_k) − 1))를 준다.
  - 깸: a = 1(탐색 단서 진폭).
  - 논렘 업: a = A_NREM.
  - 논렘 다운: a = 0.

## 맞춤 (2개 값 ↔ 생쥐 2개 수치)

- A_NREM ∈ {0.05, 0.1, 0.2, 0.4} × S_NREM ∈ {30°, 60°, 90°}. 시뮬레이션 세션 1개(씨앗 620)씩 돌린다.
- 최소화 대상: (후기 재출현 − 생쥐)² + (업 상태 후기 붙잡기 − 생쥐)².
- 생쥐 값은 이 코드가 같은 추정기로 31마리에서 다시 계산한다.
- 추정기는 쌍별 분모의 반쪽 교차 ρ다.
  - 재출현: 60단계(d 1–10, 초기 1–2, 후기 5–10).
  - 업 상태 붙잡기: 59단계 부류(초기 1–3칸, 중간 4–6칸, 후기 ≥ 7칸)의 연속 0.2초 쌍.
