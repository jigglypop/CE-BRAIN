# A1 반복 9단계 — 7단계 조합 실패의 진단: hΔB 입력 헤딩과 축삭 위상의 정렬·덮음

작성: 2026-09-23, 실행 전 고정. 다운로드는 없다.

**배경.** 7단계에서 헤딩이 한 바퀴 돌 때 hΔB 출력 위상은 0.23바퀴만 돌았다. 8단계에서 FB 위상 좌표는 검증됐다(가지돌기–축삭 194.5°). 선형 개체군 벡터가 헤딩과 함께 회전하려면 두 조건이 필요하다.
- (i) hΔB 축삭 위상이 원을 덮는다.
- (ii) 각 hΔB의 입력 선호 헤딩 $\beta_h$와 축삭 위상 $\psi_h$의 차이가 뉴런마다 일정하다.

## 측정

- **hΔB 구획:** 8단계와 같은 2-평균 분리를 쓴다(출력이 많은 덩어리가 축삭). 각 위상 $\psi_{\rm axon}$과 $\psi_{\rm dend}$는 8단계와 같은 척도다.
- **입력 선호 헤딩:** PFNd·PFNv 시냅스를 가중치로 $\beta=\arg\sum_iw_{ih}e^{i\varphi_i}$를 구한다($\varphi_i$는 E1 각). 전체 입력으로 $\beta_{\rm all}$을 구하고, 시냅스 위치가 가지돌기 덩어리인 것만으로 $\beta_{\rm dend}$, 축삭 덩어리인 것만으로 $\beta_{\rm axon}$을 구한다.

## 판정 (진단)

- **Q1 덮음:** $|\overline{e^{i\psi_{\rm axon}}}|\le0.3$ (19개 축삭 위상이 원을 고르게 덮는다).
- **Q2 정렬:** $\delta_h=\mathrm{wrap}(\psi_{\rm axon}-\beta_{\rm all})$의 원형 집중도 $R\ge0.7$.
- **Q3 구획별 일관성:** $\mathrm{wrap}(\psi_{\rm axon}-\beta_{\rm dend})$와 $\mathrm{wrap}(\psi_{\rm axon}-\beta_{\rm axon})$ 각각 $R\ge0.7$. 두 평균 오프셋의 차이를 보고한다(문헌 기전이면 약 180° 차이가 예상된다).

**해석 규칙 (미리 고정).**
- Q1이 실패하면 7단계 실패는 덮음 부족(부채꼴·19개 표본) 때문이다.
- Q2는 실패하고 Q3는 통과하면, 두 구획 입력이 서로 다른 오프셋으로 더해져 상쇄된 것이다. 선형 모형에 구획별 부호나 오프셋이 필요하다는 뜻이다.
- Q3도 실패하면 PFN→hΔB 가중치가 깨끗한 위상자 사상이 아니다.
