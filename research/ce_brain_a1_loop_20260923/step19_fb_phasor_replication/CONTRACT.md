# A1 19단계 — FB 네 위상자 기하를 표지·좌표 없이 두 개체에서 재현 (사전등록)

작성: 2026-09-23. FlyWire의 PFN·hΔB 자료는 계산하지 않은 상태에서 고정한다.

**왜.** A2(조합이 능력을 만든다)의 구조 기저는 10단계 C2′다: PFN→hΔB 사상이 약 90° 간격의 네 위상자이고, 앞쪽 쌍과 뒤쪽 쌍이 179° 차이다. 이 결과는 MaleCNS의 PB 사구체 표지와 FB 시냅스 좌표를 썼다. FlyWire에는 둘 다 없다.

## 방법 (표지·좌표 없음)

1. **헤딩 위상.** 17단계의 표지 없는 고리 쌍에서 기본 148/151 뉴런의 복소 좌표 z를 얻는다. Δ7은 −z로 둔다. PFN i의 헤딩 위상은 α_i = arg Σ_j w[PFN_i ← j]·z_j다.
2. **집단.** PFNd·PFNv × 세포체 좌·우로 dL, dR, vL, vR을 만든다. MaleCNS에서 세포체 쪽과 PB 쪽은 60/60 일치한다.
3. **상대 오프셋.**
   - hΔB 뉴런 j마다 집단 k가 보내는 입력 위상을 β_jk = arg Σ_{i∈k} W[j←i] e^{iα_i}로 구한다.
   - β_jk = c_j − O_k 모형을 가중(|Σ|) 원형 교대 최소제곱으로 맞춘다. O_dL은 0으로 둔다.
   - FB 좌표 c_j는 소거된다. 오프셋 간격과 중심차는 전역 회전·반사에 불변이다.
4. **대조.** 집단 안에서 α를 뒤섞는다(200회, 시드 20260923).

## 판정

- **D0 (MaleCNS, 방법 대조).** α와 E1 φ의 원형 R ≥ 0.9, C2′ 통과, 대조 통과율 ≤ 5%.
- **D1 (FlyWire).**
  - C2′(10단계와 같은 기준): 네 오프셋의 인접 간격이 모두 90±30°이고, d쌍·v쌍 중심차가 180±30°다.
  - 대조 통과율 ≤ 5%.

**종합.** D0 ∧ D1이면 `FB_PHASOR_GEOMETRY_REPLICATED`다. D0가 실패하면 `METHOD_CONTROL_FAILED`다.

**보고 (판정 아님).**
- 쌍 안 간격: 문헌 Lyu 2022는 앞 ±45°, 뒤 ±135°이므로 두 쌍 모두 약 90°다.
- 집단별 일관성과 입력량.
- PFN 입력 위상 응집도.
- MaleCNS에서 10단계 오프셋과의 최대 편차.

## 고정 전 방법 대조 실행 (18단계 교훈)

같은 코드의 `--control` 모드로 MaleCNS만 먼저 실행했다. 파일은 쓰지 않았다. 결과는 다음과 같다.

**해석 한계.**
- 이 검사는 네 위상자의 **기하**(C2′)만 본다.
- 회전 등변성(C1′)과 섞음 정확도(C3′)는 FB 좌표가 있어야 해서 FlyWire에서는 재지 않는다.
- 정적 배선(L0)이다.
