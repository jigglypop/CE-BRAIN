# A1 반복 10단계 결과 — 판정: A2_PHASOR_BASIS_NOT_SUPPORTED (C2′ 통과, C1′ 3/4, C3′ 미달)

모형은 7단계와 같은 선형 PFN→hΔB 모형이고, 1차 조화로 읽었다. 각 집단의 단독 응답으로 오프셋 $O_k$와 진폭 $A_k$를 추정했다.

| 판정 | 결과 |
|---|---|
| C1′ 집단별 회전 기울기 [0.9, 1.1], 잔차 < 15° | dL 0.94 (11.7°), **dR 0.896** (12.0°), vL 1.04 (7.9°), vR 0.96 (7.4°) → 3/4 통과 |
| C2′ 네 벡터 간격 90±30°, d/v쌍 중심차 180±30° | 간격 97.6 / 72.1 / 99.9 / 90.4°, 중심차 **178.8°** → **통과** |
| C3′ 섞음 오차 중앙값 < 10°, 90% 분위 < 20° | 16.8° / 32.9° (이득 175조) → 미달 |

**해석 (L0).**
- 실제 PFN→hΔB 배선의 선형 사상은 집단마다 거의 회전 등변이다(기울기 0.90–1.04).
- 네 위상자는 약 90° 간격이고, 앞쪽 쌍(PFNd)과 뒤쪽 쌍(PFNv)은 179° 차이다. 문헌의 "앞 ±45°, 뒤 ±135°" 기하가 커넥톰 선형 사상에서 재현된다.
- 섞었을 때의 위상 정확도(오차 중앙값 17°)는 기준에 못 미친다. hΔB가 19개뿐이라 원을 이산적으로 덮으면서 생기는 오차, 그리고 dR 집단의 약한 등변성이 원인 후보다.
- A2의 "조합이 벡터 합을 계산한다"는 **구조 기저(네 직교 위상자)까지 부분 지지**, 정밀 벡터 합은 **미달**로 기록한다.
