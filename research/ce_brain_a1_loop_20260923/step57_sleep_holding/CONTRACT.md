# A1 57단계 — 잠에서 범프가 흩어지는 까닭: 구동이 끊기면 붙잡기가 풀리는가 (사전등록)

작성: 2026-09-25. 56단계의 사후 진단만 알고 있는 상태에서 고정한다. 새 지표는 실제 자료로 계산하지 않았다.
- 합성 세션(업·다운 상태, 업 시작마다 범프 재설정)으로 확인했다.
  - 틈새 쌍 ρ = −0.01, 맞춤 연속 쌍 ρ = 0.995.
  - 논렘 0.3초 ρ = 0.92, 깸 0.997.
  - 깰 때 침묵 칸 비율 0.20 → 0.

## 왜

- 56단계에서 생쥐 머리방향 고리의 **구조**(세포 쌍 상관)는 31마리 모두에서 잠에도 살아 있었다.
- 깰 때 발화율은 거의 바뀌지 않았다.
- 사후 진단: 논렘에서는 범프 위치가 0.4초 안에 대부분 흩어진다(평균제곱변위가 포화치의 79%, 깸은 27%). 크게 바뀌는 것은 **붙잡기**다.
- 가설: 붙잡기에는 **끊기지 않는 구동**이 필요하다. 논렘의 다운 상태(침묵 칸)가 구동을 끊으면 범프가 다음 업 상태에서 새 위치에 선다. 연속 활동 안에서는 깸처럼 붙잡힌다.
  - A1 말로는 이렇다: 결합($L_g$)은 그대로이고 구동 $c$가 박자에 맞춰 끊긴다.
  - 파리 55단계의 R5 느린 파 게이트와 같은 모양이다.

## 지표: 잡음 없는 지속도 (반쪽 교차)

- HD 세포를 무작위로 두 절반 A, B로 나눈다(20회).
- 100 ms 칸마다 각 절반의 집단 벡터 각도 φ_A, φ_B를 구한다.
- 칸 쌍 집합 (t, t′)에 대해 다음을 계산한다.

$$\rho=\frac{\overline{\cos(\varphi_A(t)-\varphi_B(t'))+\cos(\varphi_B(t)-\varphi_A(t'))}/2}{\overline{\cos(\varphi_A(s)-\varphi_B(s))}}$$

- 두 절반의 추정 잡음이 독립이면 ρ = E[cos(실제 범프 이동)]이다. 1은 붙잡힘, 0은 흩어짐이다.
- 활동 칸: HD 스파이크 ≥ 4, 각 절반 ≥ 2. 침묵 칸: HD 스파이크 ≤ 1.
- 집우리만 쓰고, 광유전 구간은 뺀다. 적격 기준은 56단계와 같다.
