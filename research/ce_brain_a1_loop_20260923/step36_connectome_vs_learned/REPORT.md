# A1 36단계 결과 — 연결체 대 예측 학습 규칙의 종착점: 이동·반복 구조는 일치, PEN 윤곽 형태는 문턱 바로 아래

판정: **`CONNECTOME_DOES_NOT_MATCH_LEARNED_SOLUTION`**. V1·V2는 통과했고, V3(형태 상관 ≥ 0.7)만 0.66–0.69로 미달했다.

**양성 대조.** Vafidis et al. 2022 원 코드와 학습 완료 가중치로 어둠 속 적분 이득 1.032를 재현했다(저자 1.035).

## 사후 진단 (판정을 바꾸지 않음) — `diag_positive_part.py`

- 학습 해의 HR→HD 가중치는 에너지의 **64%**가 음수(억제) 엽이다. 시냅스 수는 음수가 될 수 없다.
- 학습 해의 **양수(흥분) 부분만** 비교하면, 연결체 PEN→EPG 윤곽과의 상관은 MaleCNS 0.96/0.94, hemibrain 0.96/0.95다.

## 해석 (L0, 두 개체, 문헌 식)

1. **회전 이동이 일치한다.** 예측 학습 규칙이 시각 경험만으로 스스로 찾은 회전 이동(±60°)과, 실제 두 초파리 연결체의 PEN 이동(±55°)이 5° 안에서 같다.
2. **반복 구조가 일치한다.** 학습된 HD→HD(국소 흥분 + 넓은 억제)는 연결체 EPG→EPG 직접 결합과 상관 0.88–0.94다.
3. **흥분 윤곽도 일치한다(사후).** 학습된 흥분 윤곽은 연결체와 0.94–0.96이다. 학습 해의 억제 엽은 실제 뇌에서 PEN이 아니라 다른 억제 뉴런(Δ7 등)이 맡아야 한다. 사전 기준(전체 윤곽 상관)은 이 부호 제약을 고려하지 못해 미달했다.
4. **학습 항에 대한 함의.**
   - 연결체의 핵심 구조(회전 이동, 국소 반복 흥분)는 **"시각 교사 + 예측 오차" 학습 규칙이 도달하는 해**와 같은 모양이다.
   - 곧 학습 항 $\dot g_{ij}=\eta\,[f(V_a)-f(pV_d)]_i\,x_j$가 연결체 구조를 설명하는 후보로 강해졌다.
   - 매끄러운 회전은 이 학습 해가 이득 1로 적분한다는 점에서 온다. 연결체 그대로의 모형에서 생긴 우물은 이 학습이 다듬는 미세 조정(35단계 합성: 가중 상관 0.93으로 우물 제거)의 몫이다.
5. **한계.**
   - 학습 해는 저자 모수의 망 하나다.
   - 연결체는 시냅스 수다.
   - 억제 엽을 Δ7 경로와 정량적으로 맞추는 일은 하지 않았다(HD→HD에서 Δ7 경유 계수는 ≈ 0).
   - FlyWire는 사구체 표지가 없어 제외했다.
