# A1 반복 7단계 결과 — 판정: A2_PHASOR_SUM_NOT_SUPPORTED (고정본·감사본 모두)

PFNd·PFNv 60개 뉴런에서 hΔB 19개로 가는 24,446개 시냅스로 선형 전파를 돌렸다. 입력은 헤딩 θ와 네 집단 이득 $a_k$다.

| 판정 | 고정본 | 감사본 (hΔB 구동의 평균을 뺌) |
|---|---|---|
| C1 회전 등변성 기울기 (기준 0.9–1.1) | −0.02 (잔차 1.8°) | 0.23 (잔차 22.9°) |
| C2 벡터 합 오차 중앙값 / 90% 분위 (기준 <15° / <30°) | 77° / 157° | 21° / 64° |
| C3 크기 상관 (기준 ≥0.9) | 0.17 | 0.85 |

## 원인 (사후 진단)

1. **고정본:** 입력 $1+\cos$의 상수항이 hΔB 축삭 각의 고르지 않은 분포 때문에 상쇄되지 않아 개체군 벡터를 지배했다. 그래서 출력 위상이 θ와 무관하게 거의 고정됐다. 읽기 설계의 결함이다.
2. **감사본:** 상수항을 빼도 θ가 한 바퀴 돌 때 출력은 0.23바퀴만 돈다.
   - FB는 고리가 아니라 부채꼴이다. hΔB 19개(인스턴스 14개)의 축삭 위치를 PFN 지형도로 만든 선형 각 척도로 바꾸면 원 전체를 덮지 못한다.
   - 3단계에서 이미 드러났듯 이 척도는 hΔB 기하(가지돌기–축삭 105° 대 문헌 180°)와 맞지 않는다.

## 결론

- A2의 "조합이 벡터 합을 계산한다"는 이 구조 모형으로는 **성립하지 않았다**. 다만 실패의 주원인은 FB 위상 좌표(부채꼴을 원에 사상하는 방법)라서, 가설에 대한 음성 증거로 세지 않는다. 미확립으로 둔다.
- **필요한 것:** 연결로 정한 FB 위상 좌표. 예를 들어 hΔB·FC·PFN 기둥 사이의 연결 윤곽으로 E1처럼 각을 추정하거나, 기둥 라벨(C1–C12)과 문헌의 기둥-각 대응을 쓴다. 이 좌표를 새 계약으로 고정한 뒤 재검사해야 한다.
