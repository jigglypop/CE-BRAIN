# A1 21단계 결과 — MB 같은 구획 재기록 고리: FlyWire에서 재현

판정: **`MB_SAME_COMPARTMENT_LOOPS_REPLICATED`** (R1·R2·R3 모두 통과).

- 계약·코드(sha256 `22414b36…b4da`)는 FlyWire MBON·DAN 연결을 계산하기 전에 고정했다.
- 고정 전에 유형 표 경로로 MaleCNS 5단계를 복원했다(F 0.318 대 0.316).

| | MaleCNS 수컷 | FlyWire 암컷 |
|---|---|---|
| MBON / DAN (구획 표지됨) | 93 / 326 | 92 / 317 |
| MBON→DAN 시냅스 | 9,307 | 7,438 |
| MBON 출력 중 DAN으로 | 3.8% | 4.0% |
| **R1** 같은 구획 비율 F / 대조 평균 (p) | 0.318 / 0.080 (< 1e-4) | **0.529 / 0.094 (< 1e-4)** |
| **R3** F / 대조 | 4.0 | **5.6** |
| **R2** MBON07(α1)→PAM11(α1) | 74 | **172** |
| 고리 시냅스 NT (Glu / ACh / GABA) | 1,854 / 699 / 410 | 2,090 / 1,214 / 630 |

**보고.**
- **고리 쌍별 강도의 개체 간 상관:** 두 자료에 모두 있는 (MBON 유형 → DAN 유형) 같은 구획 고리 48쌍에서 Spearman ρ = **0.83**이다.
- **상위 고리:** 두 개체에서 거의 같다.
  - MBON05→PAM07 (γ4): 407 / 396.
  - MBON11→PPL101 (γ1ped): 205 / 358.
  - MBON05→PAM08, MBON06→PAM10 (β1), MBON04→PAM05 (β′2), MBON16→PPL104 (α′3), MBON01→PAM01 (γ5).
- **표에 없는 FlyWire 유형:** MBON22, MBON26, PPL106–108, PPL201–204(각 2개). MaleCNS 인스턴스에 구획 토큰이 없는 유형이다. PPL2는 MB 밖을 지배한다.
- **주의:** FlyWire F(0.53)가 MaleCNS(0.32)보다 높다. FlyWire 연결표의 약한 연결 처리(판본별 문턱) 차이일 수 있고, 가르지 않았다.

## 해석 (L0, 두 개체)

- 인출 출력(MBON)이 같은 구획의 교사 신호(DAN)로 되돌아가는 **재기록 고리가 두 개체에서 우연보다 4–6배 많다**.
- 어느 구획 고리가 강한지도 개체 간에 보존된다(ρ 0.83).
- 문헌의 MBON-α1→PAM-α1 고리(Ichinose et al. 2015, 장기 기억 공고화)가 두 개체 모두에 있다.
- **A1 대응.** 교사 신호(DAN, 가소성 연산자)가 KC→MBON 결합($L_g$)을 바꾸고, 그 출력이 다시 같은 교사 신호를 켜는 닫힌 고리다. 기억 복구·공고화의 구조 기저가 두 개체에서 같다.
- 기능(공고화 여부)은 개입 자료가 필요하다(L4 아님).
