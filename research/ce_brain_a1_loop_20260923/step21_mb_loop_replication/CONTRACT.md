# A1 21단계 — MB 같은 구획 재기록 고리(5단계)를 FlyWire에서 재현 (사전등록)

작성: 2026-09-23. FlyWire MBON·DAN 연결을 계산하기 전에 고정한다.

**왜.** 기억 복구 알고리즘의 "재기록 고리"는 인출 출력(MBON)이 자기 기억을 쓴 같은 구획의 교사 신호(DAN)를 다시 켜는 구조다. 5단계에서 MaleCNS 한 개체로만 봤다(F 0.316 대 대조 0.079, p < 1e-4).

## 방법

- **구획 표.** MaleCNS 인스턴스를 5단계 파서로 읽어 (부류, 유형) → 구획 합집합 표를 만든다. MBON은 `>` 앞, DAN은 `<` 앞을 쓴다.
- **FlyWire 적용.** `cell_class`가 MBON 또는 DAN인 뉴런의 `cell_type`을 이 표에서 찾는다.
  - 쉼표로 묶인 유형(`MBON25,MBON34`)은 각 유형 구획의 합집합이다.
  - 표에 없는 유형은 제외하고 보고한다.
  - 표지 이전에는 FlyWire 연결을 쓰지 않는다.
- **통계.** 5단계와 같다. MBON→DAN 시냅스 중 같은 구획 비율 F, DAN 구획 표지 순열 10,000회, 시드 20260923.

## 판정 (FlyWire)

- **R1 (5단계 L1):** F > 대조 97.5% 분위이고 p < 0.01.
- **R2 문헌 고리:** MBON07(α1) → PAM11(α1) 시냅스 ≥ 10. 근거는 Ichinose et al. 2015이고, MaleCNS 값은 74다.
- **R3 효과 크기:** F / 대조 평균 ≥ 2. MaleCNS 값은 4.0이다.

**종합:** R1 ∧ R2 ∧ R3 → `MB_SAME_COMPARTMENT_LOOPS_REPLICATED`.

**보고 (판정 아님).**
- MBON 출력 중 DAN으로 가는 비율.
- MBON NT별 고리 시냅스.
- 두 자료에 모두 있는 (MBON 유형 → DAN 유형) 같은 구획 고리 시냅스의 Spearman 상관.
- 표에 없는 FlyWire 유형.

## 고정 전 MaleCNS 방법 대조 (`--control`, 파일 쓰지 않음)

유형 표 경로로 MaleCNS를 다시 계산했다.

| 항목 | 유형 표 경로 | 5단계 |
|---|---|---|
| F | 0.318 | 0.316 |
| 대조 평균 | 0.080 | 0.079 |
| F / 대조 | 4.0 | 4.0 |
| MBON07→PAM11 | 74 | 74 |

5단계와 같은 결과를 복원한다.

**해석 한계.** 정적 배선(L0)이다. 고리의 부호(ACh 양성, GABA·Glu 음성)는 NT 예측값이다. 기능적 공고화 여부는 개입 자료가 필요하다.
