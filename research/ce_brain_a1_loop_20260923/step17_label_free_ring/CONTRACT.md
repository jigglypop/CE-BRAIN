# A1 17단계 — 표지 없는 L_g 스펙트럼으로 두 개체의 방향 고리 판정 (사전등록)

작성: 2026-09-23. FlyWire의 이 연산자는 한 번도 계산하지 않은 상태에서 고정한다. MaleCNS 값(2b: 균일 0.808, 쌍 0.6312/0.6303, 다음 0.4597, ρ 0.996)은 이미 알고 있으므로, MaleCNS 쪽은 방법 대조 성격이다.

**왜.** 16단계의 윤곽 거리 위상 검사에서는 고리와 무관한 상대가 신호를 가렸다. A1의 대칭 결합 $L_g$ 자체의 선도 고유쌍을 보면, 사구체 표지 없이 두 개체를 같은 방식으로 판정할 수 있다.

## 연산자와 정의

- **연산자.** 2b와 같다.
  - 유형: EPG, PEN_a(PEN1), PEN_b(PEN2), PEG, Delta7.
  - `W = (w / 행합) × 부호`이고, Delta7만 −1이다. `w[post, pre]`는 시냅스 수다.
  - FlyWire는 같은 유형 이름을 쓰고, neuropil 행을 합산한다.
- **기억 쌍 (표지 없음).**
  - 고유값을 실수부 내림차순으로 정렬한다.
  - EPG 성분의 균일 비율 P0 ≥ 0.5인 모드는 균일 모드로 보고 건너뛴다.
  - 나머지 가운데 앞의 둘을 쌍으로, 셋째를 다음 모드로 둔다.
  - 복소 쌍이면 span은 (Re, Im)이다.
- **백색화.** span의 EPG 성분이 정규직교가 되도록 기저 B를 정한다. 이렇게 하면 회전만큼의 자유도만 남는다. 각 EPG에 2차원 점과 각 θ가 생긴다.
- **회전 비율 ρ.**
  - $Q=\tilde B^\top\Gamma W B$이고, 쌍대 기저는 2b와 같다.
  - Γ는 PEN의 **세포체 쪽**으로 정한다(좌 +1, 우 −1). 사구체 표지는 쓰지 않는다.
  - ρ는 기저 회전에 불변이다.

## 판정 (자료마다)

- **U1 고립 퇴화쌍.** 쌍 간격 (λ1−λ2)/|λ1| ≤ 0.10이고, 고립도 (λ2−λ3)/|λ1| ≥ 0.10이다.
- **U2 원.** EPG 점의 반지름 CV ≤ 0.25, 최대 각 간격 ≤ 60°, 합성 벡터 길이 ≤ 0.25.
- **U3 회전 생성자.** ρ ≥ 0.7.
- **U4 대조.**
  - 대조 행렬: (post 유형, pre 유형) 블록마다 뉴런 순서를 유형 안에서 독립적으로 섞는다. 블록 통계는 같고 일관된 고리 색인은 없다.
  - 200회 가운데 U1∧U2 통과 비율이 ≤ 5%여야 한다.
- **U5 접힘(차수 2) 서명.**
  - 세포체 좌·우 EPG가 각자 원 전체를 덮어야 한다: 각 쪽의 최대 각 간격 ≤ 90°, 합성 벡터 길이 ≤ 0.3.
  - E1(PB 직선 → 원 이중 감김)이면 각 반쪽이 45° 간격으로 원 전체를 덮는다. 감김수가 1이면 반원만 덮는다(간격 ≥ 180°).
- **U0 (MaleCNS만, 방법 대조).** 표지 없는 θ가 E1 φ를 복원한다. 부호·오프셋을 맞춘 원형 합성 길이 R ≥ 0.9여야 한다.

**종합.** MaleCNS가 U0–U5를 통과하고 FlyWire가 U1–U5를 통과하면 `LABEL_FREE_RING_OPERATOR_REPLICATED`다. MaleCNS가 실패하면 `METHOD_CONTROL_FAILED`다.

**보고 (판정 아님).**
- λ균일/λ쌍, 회전 속도.
- 8θ 교대 통계: E1이면 좌·우 모두 R8이 높고 오프셋은 180°다.
- 원 시냅스 수판.
- MaleCNS에서 세포체 쪽과 사구체 쪽의 일치율(PEN, EPG).

**실행 전 합성 검사 (scratchpad).**
- von Mises 원형 결합 48개: 쌍 간격 0.004, 고립도 0.56, CV 0.015 → U1·U2 통과.
- 무작위 행 정규화 행렬: 고립도 0.037, CV 0.46 → 둘 다 실패.

**해석 한계.** 정적 배선 스펙트럼(L0)이다. 동역학·개입 결론은 쓰지 않는다. FlyWire에는 사구체 표지가 없어 θ와 실제 PB 번호의 대응은 볼 수 없다.
