# A1 25b단계 — A1 + ReLU의 모수 없는 봉우리 폭이 문헌값(≈100°)과 맞는가 (사전등록)

작성: 2026-09-24. 연결체 망의 연속시간 고정점은 어느 자료에서도 계산하지 않았다. 25단계의 고정 판정(방법 결함으로 실패)은 그대로 둔다.

## 식

- 모형은 $\tau\dot x=-x+[gWx]_+$다. W는 18·22단계 확장망(5 기본 유형 + 선택 규칙의 억제 유형)의 입력 정규화 부호 행렬이다.
- 동차이므로 지속 봉우리는 비선형 고유벡터 =[Wx]_+/\Lambda$이고, 이득은 =1/\Lambda$로 정해진다. 자유 모수가 없다.
- 이동 멱반복 \leftarrow\mathrm{norm}(x+\eta[Wx]_+)$으로 구한다(η = 0.2, 최대 40,000회, 허용오차 1e-11). 주기 2 진동이 사라지고, 흐름의 우세 고정점으로 수렴한다.
- **유효 봉우리 조건.** 다음을 모두 만족해야 한다.
  - Λ ≥ 0.05·λ1.
  - 잔차 ‖[Wx]_+ − Λx‖/‖Λx‖ ≤ 1e-6.
  - 16칸 윤곽의 봉우리가 1개다.

| 억제가 과하면 | Λ → 0 (지속 봉우리 없음) |

단일 고리 폭 법칙은 다집단 망에서는 정확하지 않다(중간 집단의 문턱이 봉우리를 좁힌다). 그래서 법칙 대조는 판정에서 뺐다.

## 판정

- **W2 문헌.** 세 개체 모두 유효 봉우리가 있고, EPG FWHM이 [80°, 120°] 안에 있다.
  - 문헌: EB FWHM ≈ 100°, PB 반폭 약 2 사구체 = 90°(Turner-Evans et al. 2017, eLife 6:e23496).
  - 각도: MaleCNS·hemibrain은 E1, FlyWire는 표지 없는 θ이며, 16칸 평균으로 잰다.

**종합:** `PARAMETER_FREE_BUMP_WIDTH_MATCHES_LITERATURE` 또는 `..._NOT_MATCHED`.

**보고 (판정 아님).**
- λ0/λ1(EPG 조화 식별).
- 16칸 윤곽.
- 추가 균일 억제 c = 0–3(λ1 단위)을 훑어 FWHM이 100°가 되는 c* 찾기(역산).

**해석 한계.**
- 입력 정규화(시냅스 수 비례)와 동차 ReLU를 가정했다.
- 정적 배선이며, 활동 자료 대조가 아니다.
