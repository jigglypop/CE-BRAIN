# A1 43단계 — 파리 나침반의 문헌 학습 규칙은 보고된 "지도 학습" 사실들을 재현하는가 (사전등록)

작성: 2026-09-25. 아래 네 검사는 계산하지 않은 상태에서 고정한다. 사용자가 말한 학습 빈칸은 "경험이 연결(지도)을 어떻게 바꾸는가"다.

## 왜

- 37–42단계에서 선택과 매끄러운 회전은 기존 식(Kim 2017 국소 고리 + Noorman 2024 최적 조율)으로 모형 수준에서 풀렸다.
- 파리 나침반에서 실험으로 확인된 학습은 **고리 뉴런(시각, GABA)→EPG 시냅스 가소성**이다.
  - Fisher et al. 2019 Nature: 전·후 뉴런이 함께 활동하면 억제가 장기 약화된다(LTD). 강화(LTP)와 균형을 이룬다.
  - Kim et al. 2019 Nature: 함께 활동한 고리·EPG의 억제는 약해지고, EPG만 활동하면 강해진다.
- 이 규칙은 2차원 시각 장면을 1차원 방향 원 위에 **학습된 연결로 사상한다**. 대칭 장면에서는 사상이 두 겹으로 접힌다.

## 식 (ModelDB 261585 저자 코드 이식, `kim2019_model.py`)

- 고리: EPG 쐐기 32개, Kim 2017 국소 모형이다(α = 2.618, D = 5.188, β = 1.963, τ = 50 ms, [·] ∈ [0, 1000]).
- 시각: 방위 고리 뉴런 32개가 억제로 들어간다. 입력은 −W·r·2π/32이다.
- 회전: vel·(y_{i−1} − y_{i+1})/2이며, 속도는 실제 파리 비행 궤적(`pos_data.mat`, 400 s)에서 얻는다.
- 학습 (저자 기본 규칙):

$$\dot W_{ij}=\mathrm{clip}\big(W_{ij}+3f_v\varepsilon\,y_i\,(W_{max}-r_j-W_{ij})\big)-W_{ij},\quad \varepsilon=0.5,\;W_{max}=0.33$$

  - f_v는 속도²를 조건 전체 통계로 정규화한 것이다.
- 자극과 잡음은 `sim_cond.m`과 같다. 좁은 막대 κ = 15, 진폭 0.35, 시각 잡음 ±25%, 속도 잡음 ±10%다.
- 적분: ode45 대신 오일러(2 ms = τ/25)를 쓴다. 입력은 저자와 같이 10 ms 표본 사이를 선형 보간한다.

**이식 검증 (`check_port.py`, 저자 자체 점검 기준).**
- 정지 봉우리 총활동/해석해 S = 1.0000, 최고/해석해 = 1.013, 활성 10(해석해 M = 10)이다.
- 속도 척도: vel_1 → 0.97π rad/s(저자 π), vel_2 → 1.94π(2π), vel_4 → 3.77π(4π, 저자 "reasonably linear")다.

## 절차 (시드 10개 = 파리 10마리)

**K1 사상 형성 (Kim 2019 그림 2e).**
- 무작위 W에서 시작해 막대 하나, 자연 회전 400 s를 두 번(W를 이어 씀, 저자 `main_sim.m`과 같음) 학습한다.
- 둘째 회기의 봉우리–막대 차이각 결속 R이 ≥ 0.9이어야 한다.
- 같은 초기 W로 학습을 끈 대조는 R < 0.5여야 한다.

**K2 광유전 재사상 (Kim 2019 그림 2a–d, h; 파리에서 5분).**
- K1 망에서 저자 절차(360° 범위, 1.5 s × 8 위치)로, 차이각 = 기존 + 180°를 강제한다.
- 이어서 막대 하나 자연 회전 탐색을 한다.
- 처음 100 s의 차이각이 강제값에서 45° 이내, R ≥ 0.7, 기존 값에서 ≥ 90° 벗어나야 한다.

**K3 두 막대 (Kim 2019 확장 그림 3, Fisher 2019).**
- K1 망에서 180° 떨어진 두 막대로 400 s × 2 학습한 뒤, 막대 하나로 탐색한다.
- 처음 200 s에 기존 차이각 ±45°와 +180° ±45°가 **모두** 시간의 ≥ 10%를 차지하면 "두 차이각"이다.
- 가중 윤곽의 2차/1차 조화 힘 비가 > 1이면 "두 겹 사상"이다.

**K4 부분 사상 완성 (Kim 2019 그림 4, 파리 6/10).**
- K1 망에서 180° 범위만 짝짓는 절차로 기존 + 180°를 강제한 뒤, 전체 자연 회전 탐색을 한다.
- 처음 100 s 차이각이 강제값에서 45° 이내이고 R ≥ 0.7이어야 한다.

## 판정

- **K1** ≥ 8/10, **K2** ≥ 8/10(저자 모형의 주장), **K3 두 차이각** ≥ 5/10(파리 "일부 시행", 모형 예측), **K3 두 겹 사상** ≥ 8/10, **K4** ≥ 5/10(파리 6/10).
- **종합.** 모두 만족하면 `LITERATURE_LEARNING_RULE_REPRODUCES_MAP_FACTS`다.

## 해석 한계

- 이것은 문헌 모형의 **독립 재현**이다. 새 생물 증거가 아니다.
- 적분법이 저자(ode45)와 다르다.
- 가소성은 고리 뉴런→EPG만 다룬다. 반복 고리 자체의 학습은 다루지 않는다.
- 연결체와의 연결은 없다.
