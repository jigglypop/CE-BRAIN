# A1 반복 1단계 결과 — 판정: A1_RING_DYNAMICS_NOT_SUPPORTED (T1 실패)

- 뉴런: EPG 46, PEN_a 20, PEN_b 22, PEG 18, Δ7 42. 실제 시냅스 수를 수신 입력 비율로 정규화했고, Δ7만 억제다.
- 사전등록 격자 144조 중 T1(단서를 끈 뒤 200τ 동안 봉우리 유지)을 만족한 조합이 **0개**다.
- 최고 $R_b$는 0.12이고 위치는 임의(153°)였다.
- EPG 평균 활동이 $b$에 정비례했다(0.186 / 0.371 / 0.743). 망이 선형 영역에 머물러 대칭이 깨지지 않았다는 뜻이다.
- T2(적분)와 T3(봉우리 폭)는 T1 실패로 실행하지 않았다.

**해석 (사후, 미검증).** 이 실패는 A1의 반증이라기보다 동역학 모형의 명세 문제일 가능성이 크다. 후보는 셋이다.
1. EB의 전역 억제원(ring/ER 뉴런)이 빠졌다.
2. 정규화 뒤의 흥분 고리 이득이 격자 범위($g_E\le4$)에서 불안정 문턱에 못 미쳤다.
3. clip 비선형만으로는 부족하다.

**다음 단계.** 자유 동역학 모수 없이 가중치 행렬의 스펙트럼만으로 A1 구조를 본다. 연속 끌개가 있으려면 선도 비균일 고유쌍이 E1 원 위의 cos/sin 쌍이고 거의 겹쳐야(퇴화) 한다.
