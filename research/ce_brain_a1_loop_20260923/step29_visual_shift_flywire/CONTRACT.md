# A1 29단계 — 시각계 이동 연산자(T4/T5 네 방향 틀)를 FlyWire에서 재현 (사전등록)

작성: 2026-09-24. FlyWire T4/T5 입력 기하는 계산하지 않은 상태에서 고정한다. 기둥 배정 파일은 형식만 확인했다(열 이름, 유형 빈도, 좌표 관계). 자료는 원장 `flywire-783-codex`다.

## 왜

근본 식의 공통성 검사다. 방향 고리의 방향 연산자(좌·우 PEN의 반대 이동)와 같은 형태의 이동 연산자가 2차원 시각 격자에도 있는지 본다.

MaleCNS 한 개체에서 V1–V4를 확인했다(시각 연구 `ALGORITHM_A1.md`; 고정 판정은 NaN 결함으로 NOT_PROVED, 감사본은 전부 통과).

| MaleCNS 값 | 결과 |
|---|---|
| a–b | 178–179° |
| c–d | 152–161° |
| 두 축 사이 | 84–87° |
| R | 0.84–0.97 |
| T4 ≡ T5 | 7° 이내 |

## 방법 (MaleCNS와 같은 정의)

- **T4 벡터.** 각 T4a–d 뉴런에서 Mi4 입력의 시냅스 가중 중심에서 Mi9 입력의 가중 중심을 뺀다.
- **T5 벡터.** 각 T5a–d 뉴런에서 (Tm1+Tm2) 입력 중심에서 Tm9 입력 중심을 뺀다.
- **반구.** 같은 반구 입력만 쓰고, 입력의 80% 이상이 같은 반구인 뉴런만 쓴다.
- **좌표.** Codex `column_assignment`의 (p, q)를 평면 X = (q − p)/2, Y = (p + q)·√3/2로 바꾼다(한 칸 = 1).
  - 파일의 x = ⌊(q − p)/2⌋, y = p + q 관계와 정규 육각 격자를 따른 것이다.
  - 축 좌표는 60° 기저다.
- **길이 0 벡터.** 미리 제외한다. MaleCNS에서 NaN 결함을 일으켰던 부분이다.
- **연결.** FlyWire 783 proofread 연결(neuropil 합산)을 쓴다.

## 판정 (양쪽 눈 모두)

- **V1 반대 짝.** a–b 사이 각 ≥ 150°, c–d 사이 각 ≥ 150°.
- **V2 두 축.** a/b 축과 c/d 축 사이 ≥ 45°.
- **V3 일정한 이동.** 모든 아형에서 R ≥ 0.7이고, 크기 중앙값이 0.5–3칸이다.
- **V4 ON/OFF 같은 틀.** 같은 문자의 T4x와 T5x 중앙 방향이 30° 이내다.

**종합:** `A1_SHIFT_OPERATORS_REPLICATED_FLYWIRE` 또는 `A1_SHIFT_OPERATORS_NOT_REPLICATED_FLYWIRE`.

**해석 한계.**
- Codex 기둥 배정은 연결에 기반한 배정(Matsliah et al. 2024)이다. Mi4·Mi9·Tm 위치 오차가 벡터에 섞일 수 있다.
- 평면 좌표의 척도(√3/2)는 정규 육각 가정이다.
- 정적 배선(L0)이다.
