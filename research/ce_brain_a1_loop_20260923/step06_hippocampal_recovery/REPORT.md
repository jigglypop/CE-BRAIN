# A1 반복 6단계 결과 — 고정 판정: NOT_SUPPORTED (적격 조건 결함) / 감사본: SUPPORTED

Symanski odor-place 33세션 창 배열(8마리 쥐)을 썼다. 새 다운로드는 없다.

## 결함

세션 적격 조건(정답 시행이 냄새마다 8개 이상)을 **전체 시행**으로 셌다. 그래서 선택 연결이 풀리지 않은 CS41_01·02(101개·81개 미해결) 세션이 통과했다. 이 세션들에서는 쓸 수 있는 시행이 없어 CS41의 정답 판별 $D$가 NaN이 됐고, NaN 비교는 거짓이 되므로 R1·R3에서 CS41이 자동 실패로 세졌다.

감사본은 적격 조건만 "세 단서 창이 모두 유효하고 선택이 연결된 시행"으로 바꿨다. 그 결과 적격 세션은 29개에서 27개가 됐다. 고정 판정은 덮어쓰지 않는다.

## 결과 (감사본)

| 판정 | CA1 | PFC |
|---|---|---|
| R1 $D_{\rm late}>D_{\rm pre}$ (확인용, 기준 87.5%) | 0.75 (미달) | 0.75 (미달) |
| **R3** 오답의 $D_{\rm late}$ < 정답 (기준 80%) | **7/8 = 0.875** | **7/8** |
| **R3** 쥐 평균 오답 $D_{\rm late}$ < 0 | **−0.026** | **−0.104** |
| **R4** $\kappa_{\rm late}<\kappa_{\rm early}$ (기준 75%) | **8/8** | **8/8** |

- 판정은 감사 기준으로 `HIPPOCAMPAL_RECOVERY_ATTRACTOR_SUPPORTED`다(CA1의 R3·R4 통과).
- **단서 후 창 (주 판정에서 뺌, 이동 교란):** 쥐 대부분에서 정답 $D$는 +0.18~+2.07로 크고, 오답 $D$는 −0.22~−1.72다. 선택한 쪽 틀로 강하게 옮겨 가지만, 이동 경로 자체가 갈라지는 효과와 분리되지 않는다.

## 해석 (L2, 관측 상관)

- 쥐가 코를 넣고 단서를 받는 동안(이동 전), CA1·PFC 상태는 냄새별 틀로 수렴한다(수축비가 모든 쥐에서 줄어든다).
- 오답 시행에서는 상태가 **선택한 쪽 냄새의 틀에 약간 더 가깝다**. "다른 기억이 복구되어 행동을 정했다"는 A1 예측과 같은 방향이다.
- 후기 단서 창의 효과 크기는 작다(CA1 −0.026). 이 결과는 쥐 8마리의 후향 관측이며 개입 증거가 아니다. 뇌가 이렇게 작동한다는 결론(L4)은 쓰지 않는다.
- 이전 원장의 "직전 시행 이력은 선택 판독을 악화" 결과와 모순되지 않는다. 이 단계는 현재 시행 안의 수렴을 본 것이다.
