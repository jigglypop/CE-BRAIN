# A1 58단계 — 잠의 식: 기존 나침반 고리에 "구동 켜짐/꺼짐 교대" 하나만 더하면 생쥐 잠 수치가 나오는가 (사전등록)

작성: 2026-09-25. 모형은 짧은 세션으로 끝까지 도는지만 확인했다. 결과 값은 출력하지 않았다.

## 왜

- 생쥐 31마리(56–57단계)의 사실은 다음과 같다.
  - 잠에서도 고리 구조는 유지된다. 고리 지표의 논렘/깸 비는 0.98이다.
  - 다운 상태를 건너면 범프 위치가 지워진다(ρ −0.03).
  - 논렘의 0.3초 지속도는 0.32다(깸 0.98).
  - 업 상태 안에서도 붙잡기가 약하다(0.2초 0.64).
  - 깰 때 발화율은 그대로다.
- 파리 게이트(55단계)는 루프의 결합이 아니라 구동을 박자에 맞춰 바꾼다.
- 질문: A1의 기존 식(Kim 2017 국소 고리 + Noorman 2024 최적, 문턱선형, 42단계 `local_opt`)에 **구동 c(t)의 켜짐/꺼짐 교대** 하나만 더하면, 이 사실들이 조정 없이 나오는가.

## 판정 (주 변형 C_DOWN = −1, 5마리 중앙값)

| 기준 | 내용 | 생쥐 값 |
|---|---|---|
| M1 초기화 | 침묵 칸을 건넌 ρ ≤ 0.2 | −0.027 |
| M2 논렘에서 흩어짐 | 논렘 0.3초 ρ ∈ [0.1, 0.55] **그리고** 깸 ≥ 0.9 | 0.319 / 0.977 |
| M3 구조 유지 | 고리 지표 논렘/깸 ∈ [0.8, 1.2] | 0.98 |
| M4 업 상태 안의 약한 붙잡기 | 논렘 연속 활동 0.2초 ρ ∈ [0.4, 0.85] | 0.645 |

- 넷 다 맞으면 `SLEEP_EQUATION_REPRODUCES_MOUSE`, 아니면 `SLEEP_EQUATION_PARTIAL`(맞은 기준을 적는다).

**사전 예측.**
- M1 통과. 다운 상태 동안 활동이 다 꺼지고, 다음 업에서 잡음이 새 위치를 고른다.
- M3 통과. 결합이 그대로이기 때문이다.
- M2는 불확실하다. 업 상태 안에서 잘 붙잡히면 0.6 안팎으로 생쥐(0.32)보다 높을 수 있다.
- M4는 실패할 것이다. 대칭 고리는 업 상태 안에서 거의 완벽하게 붙잡는다(약 0.9).
- M2·M4가 실패하면, 생쥐의 업 상태 안 약한 붙잡기에는 구동의 켜짐/꺼짐 말고 다른 요소가 필요하다는 뜻이다(예: 잠 동안의 약한 이득, 잡음 증가, 신경조절).
