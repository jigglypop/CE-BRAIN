# A1 39단계 — 고정 전 검사 기록 (계약 전, 선택 검사 미계산)

## 1. 이식 확인

**`us_network.network_us`.** 저자 `fly_rec.network`를 한 줄씩 옮기고 체세포 교사 항 g₀(U*−u)를 더했다.
- g₀ = 0이면 4,000 학습 단계 동안 저자 코드와 차이가 **0.0**이다(`python us_network.py`).

**`us_fast.train_kernel`.** numba로 컴파일한 같은 식이다(`check_fast.py`).
- numpy 판본과의 차이는 가중 ≤ 3.6e-15, 오차 기록 ≤ 5.3e-15다. 세 조합(전류/오일러, 컨덕턴스 g₀ = 0.5/오일러, 컨덕턴스 g₀ = 6/지수)에서 확인했다.
- 속도는 12.2 µs/step으로 numpy의 약 8배다.

**체세포 지수 적분.** 선형 체세포 식을 한 단계 정확히 푸는 방식이다.
- 저자 학습 망에서 결과가 사실상 같다.

| 체세포 적분 | 어둠 봉우리 | 90°/s 이득 | 180°/s 이득 | 360°/s 이득 |
|---|---|---|---|---|
| 오일러 | 59.25°(0.998·fmax) | 1.007 | 1.059 | 1.033 |
| 지수 적분 | 59.25°(0.998·fmax) | 1.002 | 1.054 | 1.028 |

- 저자 dt = 0.5 ms는 체세포 시간 상수(1/(g_L+g_D) = 0.33 ms)보다 길다. 그래서 명시적 오일러는 (g_L+g_D+g₀)·dt < 2일 때만 안정하다.

## 2. 원형 1 — 저자 학습 망에서 계속 학습, 오일러, g₀ = 1·2·4 (`prototype_screen.py`)

- **발산했다**(u 넘침 → NaN). 원인은 오일러 안정 한계 (3+g₀)·0.5 ≥ 2다.
- 설계 결함이므로 모두 중단했다. 기록은 작업 폴더 `diverged_g1to4/`에 있다.

## 3. 원형 2 — 같은 조건, g₀ = 0.25·0.5·0.75 (안정 범위), 4,000 s

| g₀ | E_E | σ_t | 오차 처음→끝 (Hz) | 빛 → 어둠 3 s 봉우리 (시작 / 끝) |
|---|---|---|---|---|
| 0.25 | 1.16 | 0.53 | 0.33→0.34 | 없음(0.013·fmax) / 없음 |
| 0.5 | 1.16 | 0.45 | 0.59→0.62 | 없음 / 없음 |
| 0.5 | 1.16 | 0.53 | 0.71→0.76 | 없음 / 없음 |
| 0.5 | 1.30 | 0.53 | 0.79→0.86 | 없음 / 없음 |
| 0.75 | 1.16 | 0.53 | 1.14→1.44 | 없음 / 없음 |

- **약한 교사.** 영 상태에서 교사만으로는 봉우리가 켜지지 않는다. 봉우리 자리의 발화는 약 4.5 Hz, 나머지는 약 2 Hz였다. 저자 전류 교사는 봉우리 자리에서 약 24 Hz를 만든다.
- **포화 덫 (유도).** 저자 학습 망은 이미 포화 봉우리를 갖는다. 포화 영역에서는 f(u) ≈ f(pV) ≈ fmax여서 오차가 0이다. 따라서 교사가 무엇이든 그 영역을 되돌릴 학습 신호가 없다.
- **결론.** 컨덕턴스 교사 검사는 **무작위 초기값에서** 저자와 같은 학습 길이(8×10⁴ s)로 해야 한다. 교사는 충분히 세야 한다(g₀ ~ g_L+g_D). 이를 위해 체세포 지수 적분이 필요하다.

## 4. 원형 3 — 무작위 초기값, 8×10⁴ s, numba (`train_long.py`)

- 양성 대조: 저자 전류 교사(M = 4, σ = 0.15)를 오일러와 지수 적분으로 각각 학습한다(seed 41).
- 컨덕턴스 교사: 지수 적분, seed 42.
  - (g₀, E_E, σ_t) = (3, 1.16, 0.53), (6, 1.16, 0.53), (12, 1.16, 0.53), (6, 1.30, 0.53), (6, 1.16, 0.45).
- 보는 것은 오차 곡선, 어둠 봉우리 모양(3 s), 10 s 유지, 90·360°/s 적분 이득뿐이다. 선택 검사는 계산하지 않는다.
- **교사 선택 규칙 (결과 전에 정함).** 순서대로 모두 만족해야 한다.
  1. 3 s 어둠 봉우리가 1개이고, 최고 ≤ 0.8·fmax, FWHM 80–100°다.
  2. 10 s 어둠 뒤에도 봉우리 1개가 진폭 ≥ 0.25·fmax로 단서 22.5° 안에 있다.
  3. 90°/s 이득이 0.5–1.5이고 R² ≥ 0.9다.
  - 통과한 조합 가운데 FWHM이 90°에 가장 가까운 것을 고른다. 같으면 g₀가 작은 것을 고른다.
- 검사 망은 선택한 교사로 **새 seed(51)**에서 다시 학습한다. 같은 seed로 학습한 저자형 전류 교사 망을 짝 대조로 둔다.
