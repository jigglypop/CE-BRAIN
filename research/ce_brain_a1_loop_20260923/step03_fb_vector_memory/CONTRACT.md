# A1 반복 3단계 — FB 벡터 기억: PFN→hΔB 위상 이동이 네 기저 벡터를 만드는가

작성: 2026-09-23, 실행 전 고정. 계획 (2)에 해당한다.

**문헌 (Lyu, Abbott & Maimon 2022 Nature).**
- PFNd·PFNv의 PB 봉우리는 EPG 방향과 위상이 같다.
- PFN은 hΔB **축삭** 활동을 **±45°(PFNd)**, **±135°(PFNv)** 어긋난 위치에서 높인다.
- 이 네 벡터를 회전·배율·합산하면 타자 중심 이동 방향이 된다.

A1로 쓰면 이는 방향 원 위의 네 이동 연산자 $S_k$와 위상자 합이다.

## 측정 (MaleCNS만 사용, 기능 자료 없음)

- **PFN 입력 방향.** PFNd·PFNv 각 뉴런은 인스턴스의 PB 사구체 라벨에 E1 각 $\varphi$를 준다. 회귀용으로는 풀지 않은 값을 쓴다: L쪽 $(8-k)\cdot45°$, R쪽 $(k-1.5)\cdot45°$.
- **FB 축과 각 척도.**
  - `syn-partners`에서 ROI가 `FB`인 PFN 출력 시냅스의 발신 좌표를 모은다. 그 첫 주성분을 FB 가로축 $x$로 둔다.
  - PFN 뉴런별 출력 중심의 $x$를 네 집단(dL, dR, vL, vR)에 공통 기울기·집단별 절편으로 $\varphi$에 회귀한다. 척도는 $s=1/\text{기울기}$ (도/단위)다.
- **hΔB 구획.** hΔB 각 뉴런의 FB 입력 시냅스 중심을 가지돌기 쪽, 출력 시냅스 중심을 축삭 쪽으로 둔다.
- **실효 출력 위상.** PFN 뉴런 $i$가 hΔB에 준 시냅스들에 대해, 그 hΔB의 축삭 위치 $s\,x_{\rm axon}$을 시냅스 수로 가중해 원평균한다. 오프셋은 $o_i=\operatorname{wrap}(\psi_i-\varphi_i)$이다. 집단 오프셋 $O_g$는 $o_i$의 원평균이다.
- 오프셋은 전역 상수(기준점)까지만 정해진다. 따라서 **집단 사이 차이**만 판정한다.

## 판정

- **F1 PB→FB 지형도.** 공통 기울기 선형 적합 $R^2\ge0.8$.
- **F2 좌우 쌍.** 다음을 모두 만족해야 한다.
  - $\Delta_d=\operatorname{wrap}(O_{dL}-O_{dR})$, $\Delta_v=\operatorname{wrap}(O_{vL}-O_{vR})$.
  - $|\Delta_d|,|\Delta_v|\in[67.5°,112.5°]$ (문헌 90°).
  - 두 부호가 반대다(±45°와 ±135°).
- **F3 네 벡터가 90° 간격.** 네 집단 오프셋을 원 위에 정렬했을 때 인접 간격이 모두 $90°\pm30°$.

**보고:** PFN→hΔB 시냅스가 가지돌기 쪽과 축삭 쪽 중 어디에 더 가까운지(구획 표적) 비율, hΔB의 가지돌기–축삭 간 각 거리(문헌 약 180°).

**종합:** F1–F3 통과 → "FB 배선이 방향 원 위의 네 직교 이동 연산자(±45°, ±135°)를 담는다. 벡터 합(위상자 연산)의 구조적 기저다(L0)".
