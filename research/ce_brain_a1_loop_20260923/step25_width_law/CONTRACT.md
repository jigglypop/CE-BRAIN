# A1 25단계 — 폭 법칙: 스펙트럼만으로 기억 봉우리 폭이 정해지는가 (사전등록)

작성: 2026-09-24. 연결체 망의 비선형 고정점(봉우리)은 어느 자료에서도 계산하지 않았다.

**이미 본 값.**
- 확장망의 λ0/λ1(사후 값): MaleCNS 0.69, FlyWire 0.11, hemibrain 0.84.
- 1b단계 clip 모형 폭 162°.
- 문헌 봉우리 폭: EB FWHM ≈ 100°, PB 반폭 약 2 사구체로 EB 환산 90°. 폭은 회전 속도와 무관하다(Turner-Evans et al. 2017, eLife 6:e23496, Fig. 8–9).

## 식 (근본 식의 비선형 부분)

- **모형.** 문턱선형 동역학 $\tau\dot x=-x+[gWx]_+$는 동차다. 따라서 지속 봉우리는 이득 g와 무관하게 비선형 고유벡터 \propto[Wx]_+$로 정해진다.
- **폭 법칙.** 회전 불변 고리(조화 이득 =\lambda_m/\lambda_1$, m = 0, 1, 2)의 비선형 고유벡터 폭 $\mathrm{FWHM}(J_0,J_2)$다(`width_core.py`, sha256 `2912c4048725d14fd5afafe4d39cc05715f187fd5e2f5b2874d6c1d6719916de`).
  - J0, J1만 있을 때는 Ben-Yishai/Hansel–Sompolinsky 해석해와 같다.
  - hBc\cos\theta_c(\theta_c-\sin\theta_c\cos\theta_c)=\rho(\sin\theta_c-\theta_c\cos\theta_c)$
  - $\mathrm{FWHM}=2\arccos\frac{1+\cos\theta_c}{2}$

## 합성 검사 (`synthetic_check.py`, sha256 `f64d5ad99bdcbe80f80d335aa74e82572d97fbeddf885c6b0d82417baae74878`, 실제 자료 전)

- **해석해 대조.** 법칙 계산기는 해석해와 0.1° 안에서 같다. ρ = −0.49 → 99.8°, 0 → 120.2°, 0.69 → 152.8°.
- **2차 조화 효과.** J2 = 0.71을 넣으면 폭이 크게 준다. ρ = 0.11 → 91°, 0.69 → 114°.
- **이산 고리 대조.** 16 사구체 × 3 뉴런 이산 고리의 비선형 고유벡터와 0.5° 안에서 같다(152.5 대 152.8, 100.0 대 99.8, 94.75 대 94.2).

## 방법 (세 개체)

- **망.** 확장망(5 기본 유형 + 18·22단계 선택 규칙의 억제 유형), 입력 정규화 부호 행렬.
- **각도.** MaleCNS·hemibrain은 E1, FlyWire는 17단계 표지 없는 θ다.
- **스펙트럼.** λ1과 λ2는 EPG 조화로 식별한 1·2차 쌍의 평균이다(23단계 `harmonic_pair`). 노름 비중은 쓰지 않는다.
  - λ0은 P0 ≥ 0.5인 모드 중 실수부 최대인 것이다.
  - 그런 모드가 없으면 P0가 가장 큰 모드를 쓴다.
- **봉우리.** EPG에 cos 단서를 주고 정규화 문턱 멱반복을 4,000회 한다. 16칸 평균 윤곽의 FWHM(최댓값의 절반 기준)을 잰다.
- **추가 전역 억제.** c ∈ {0, 0.25, 0.5, 0.75, 1.0}. 모든 뉴런이 EPG 평균 활동에서 \lambda_1$만큼 억제를 받는다.

## 판정

- **W1 법칙 성립.**
  - 세 개체 모두 c = 0에서 |FWHM_sim − FWHM_law| ≤ 20°다.
  - 전체 15점 중 80% 이상이 20° 안에서 맞는다.
- **W2 문헌.** 세 개체 모두 c = 0(연결체 그대로)의 FWHM_sim이 [80°, 120°] 안에 있다.

**종합.**
- W1 ∧ W2이면 `WIDTH_LAW_SUPPORTED_THREE_INDIVIDUALS`다.
- W1만 성립하면 `WIDTH_LAW_HOLDS_LITERATURE_MISSED`다.
- 그 밖에는 `WIDTH_LAW_NOT_SUPPORTED`다.

**보고.** 봉우리 수, 마지막 변화량(수렴), J0, J2.

**해석 한계.**
- 동차 문턱선형을 가정했다. 포화나 역치 편향은 없다.
- 입력 정규화는 시냅스 수 비례 가정이다.
- 정적 배선에서 유도한 고정점이며, 활동 자료 대조(L3)는 아니다.
