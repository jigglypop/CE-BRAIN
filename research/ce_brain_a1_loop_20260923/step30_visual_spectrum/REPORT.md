# A1 30단계 결과 — 시각 가로 결합 = 고정 격자 라플라시안의 함수: 고정 판정 실패(결함 2건), 감사본은 네 눈 모두 통과

- 고정 판정: **`LATERAL_COUPLING_NOT_LATTICE_LAPLACIAN_FUNCTION`**.
- 계약·코드는 기둥 결합 스펙트럼을 계산하기 전에 고정했다. 합성 검사에서 국소 결합은 유사도 1.0, 뒤섞은 결합은 0.004였다.

| 눈 | 고정 판정 k=2 / k=6 | 결함 | 감사본 k=2 / k=6 | X, Y R² |
|---|---|---|---|---|
| MaleCNS 우 | **0.987 / 0.912** ✓ | 없음 | 같음 | 0.977 |
| MaleCNS 좌 | 0.496 / 0.806 ✗ | 격자에 고립 기둥 1개 → 여분의 0 고유값 | **0.990 / 0.831** ✓ | 0.977 |
| FlyWire 우 | 0.513 / 0.685 ✗ | 평면 좌표 60° 기저 오류 | **0.991 / 0.969** ✓ | 0.898 |
| FlyWire 좌 | 0.495 / 0.685 ✗ | 좌표 오류 + 결합 고립 기둥 | **0.983 / 0.929** ✓ | 0.969 |

모든 눈에서 대조 99% 분위는 0.006–0.013이었다.

## 결함 두 건 (결과 전 발견 못 함)

1. **연결 성분.** 고립 기둥이 여분의 0 고유값을 만들었다. 그래서 첫 "비자명" 모드가 성분 표시자가 됐다. 합성 검사는 연결 그래프만 써서 놓쳤다.
   - 감사본 `audit_components.py`는 H와 S 모두에서 연결된 가장 큰 공통 성분으로 제한했다(0–2개 제외).
2. **FlyWire 좌표.** 60° 기저 가정이 틀렸다. 가로 결합의 오프셋별 평균은 다음과 같다(`diag_neighbors.py`).

   | 오프셋 | FlyWire | MaleCNS |
   |---|---|---|
   | (±1,0) | 16.3 | 20.5 |
   | (0,±1) | 14.7 | 22.4 |
   | **(±1,±1)** | **7.9** | **12.3** |
   | (1,−1) | 0.6 | 0.9 |

   - 두 개체 모두 120° 기저다.
   - 감사본 `audit_embedding.py`는 X = p − q/2, Y = q·√3/2를 쓴다. 두 대각선 중 하나를 고르는 데 결합 자체(1비트)를 썼음을 밝힌다.

## 해석 (L0, 두 개체, 감사본 기준)

- **가로 결합은 격자 라플라시안의 함수다.** 고정된 기둥 위 가로 결합(대칭, 비대칭 1%)의 낮은 고유함수는 기둥 격자 라플라시안의 낮은 고유함수와 같다(k=6 유사도 0.83–0.97). 선도 쌍은 망막 좌표 함수 X, Y다(R² 0.90–0.98).
  - 방향 고리의 "결합 선도 쌍 = 원의 cos/sin"이 2차원 시각 격자에서는 "선도 쌍 = 평면 좌표"로 나타난다. 같은 식 $L_g=F(\Delta)$다.
- **결합이 만드는 계량은 비등방이다.**
  - 결합 스펙트럼의 λ2/λ1은 1.75–2.94로, 격자 자체(1.32–1.76)보다 크다.
  - 대각 (1,1) 결합은 축 결합의 **0.51(FlyWire)–0.57(MaleCNS)배**다. 두 개체에서 거의 같은 값이다(사후).
  - 결합으로 잰 거리가 한 방향으로 늘어나 있다는 뜻이다. 시각 연구의 코탄젠트 가설(39:39:20)과 같은 방향이며, 계량의 개체 공통 모수 후보다.
- **한계.** 이 검사는 곡률(구면)을 구별하지 않는다. 판정은 결함 수정 감사본에 의존한다.
