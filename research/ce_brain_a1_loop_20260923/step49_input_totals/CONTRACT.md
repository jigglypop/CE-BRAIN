# A1 49단계 — 우물은 입력 총량 차이 때문인가, 결합 모양 차이 때문인가 (사전등록)

작성: 2026-09-25. 정규화한 망에는 아무 검사도 계산하지 않은 상태에서 고정한다.

## 왜

- 47단계: 뉴런 수준 실제 배선은 최적 세기에서 우물 셋을 만든다.
- 사후 진단은 입력 총량(흥분성) 불균질을 가리켰다.
- 48단계: 동적 항상성은 설계 결함(목표 = 개체 평균, 큰 갱신 폭)으로 폭주해 기전을 시험하지 못했다.
- 그래서 **항상성이 완전히 끝난 상태의 대리**로 불균질성의 두 성분을 곧바로 가른다.
  - 뉴런마다 흥분 입력 총량과 억제 입력 총량을 개체 평균으로 정확히 맞춘다.
  - 결합 모양(누구에게서 얼마나 받는가의 비율)은 그대로 둔다.

## 망 (48단계 E·I, 문턱선형, c = 1)

| 망 | 구성 | 역할 |
|---|---|---|
| **N2_rn** | E와 I의 각 행을 행 합이 개체 평균이 되도록 곱셈 조절(시냅스 후 크기 조절, 대칭 깨짐) | 판정 |
| N2_rn_sym | N2_rn의 대칭 부분 | 보고 |
| N1_rn | 47단계 N1(각도 평균 결합, 실제 세포 수)에 같은 정규화(흥분·억제 부분 각각) | 보고 |

- 이득은 46단계 g*를 뉴런 수로 옮긴 값의 ±20% 안에서 유지 오차 최소(16위치)로 고른다.
- 속도는 PEN 좌우 차이이고, 행은 E와 같은 인자로 조절한다.

## 판정 (세 개체 각각)

- **H1.** N2_rn의 64위치 유지율(22.5°) ≥ 0.8 **그리고** 끝 자리 ≥ 12곳(47단계 N2는 3곳).
- **H2 (보조).** 엄격 연속 C1(최대 ≤ 5.625°, 중앙값 ≤ 2°).
- **H3 (보조).** S2 문턱 비 T180/T90 ∈ [0.8, 1.25].

**종합.** H1이 2개 개체 이상이면 `INPUT_TOTALS_EXPLAIN_WELLS`, 아니면 `WELLS_FROM_CONNECTION_PATTERNS`다.

**사전 예측.**
- H1은 통과한다(47단계 사후 진단).
- H2는 불확실하다. 결합 모양 차이가 남는다.

## 해석 한계

- 정적 대리이며, 실제 항상성 과정(시간, 목표값)은 다루지 않는다.
- 흐름 정규화·대칭화 가정이 있다.
- L4 근거가 아니다.
