# A1 18단계 결과 — 전역 억제 재현: 고정 판정 METHOD_CONTROL_FAILED (기준 이식 결함), 내용은 두 개체 같은 방향

계약·코드(sha256 `7264000c…134d`)는 FlyWire에서 규칙을 계산하기 전에 고정했다. 실행 시간은 8초다.

| | MaleCNS 수컷 | FlyWire 암컷 |
|---|---|---|
| 규칙이 고른 유형(뉴런 수) | ER1_a/b/c, ER2_a/b/c/d, ER3w_a/b/c, ER4d, ER4m, ER6 (GABA); ExR4/5/6 (Glu) — 16유형 | ER1, ER2, ER3w, ER4d, ER4m, ER6, EL, ExR1 (GABA); ExR5/6 (Glu) — 10유형 |
| 확장망 뉴런 | 297 | 314 |
| **G1** λ0/λ1 (확장 전 → 후) | 1.28 → **0.69** | 1.20 → **0.11** |
| 부호 뒤집기 대조(선택 유형 +1) λ0/λ1 | 1.30 | 1.71 |
| 기억 쌍 λ1 / λ2 | 0.2795 ± 0.0013i (켤레) | 0.294 / 0.279 |
| **G2-U1** 쌍 간격 / 고립도 | 0 / **0.086** | 0.052 / **0.087** |
| **G2-U2** EPG 원 CV / 최대 간격 / 합성 길이 | 0.136 / 15° / 0.02 | 0.235 / 34° / 0.02 |
| **G3** ρ | **0.983** | **0.938** |
| (보고) 반쪽별 최대 간격 좌/우 | 37° / 39° | 46° / 50° |

**고정 판정: `METHOD_CONTROL_FAILED`.** 두 자료 모두 G2의 U1 고립도(≥ 0.10)만 못 넘었다. G1, U2, G3는 두 자료 모두 통과했다.

**유형 겹침.** 세부 이름 기준 Jaccard는 0.24다. FlyWire는 ER1·ER2·ER3w를 아형으로 나누지 않는다. 계열 기준으로 보면 ER1, ER2, ER3w, ER4d, ER4m, ER6, ExR5, ExR6이 두 자료 공통이다. MaleCNS에만 ExR4가, FlyWire에만 EL과 ExR1이 있다.

## 사후 진단 (판정을 바꾸지 않음) — `diag_modes.py`, `diag_modes.json`

기억 쌍 바로 아래 모드를 분해했다.

| 모드 | MaleCNS: λ / EPG 노름 비중 / 조화 | FlyWire: λ / EPG 노름 비중 / 조화 |
|---|---|---|
| 기억 쌍 | 0.2795 / 0.17 / P1 0.97 (E1 φ 기준도 0.97) | 0.294, 0.279 / 0.16 / P1 0.97, 0.93 |
| **바로 아래 (고립도 계산에 쓰인 모드)** | 0.2554 / **0.01** / 혼합 | 0.2535 / **0.06** / 혼합 |
| 첫 EPG 2차 조화 쌍 | 0.184, 0.173 / 0.16 / P2 0.91, 0.90 | 0.202, 0.191 / 0.15–0.20 / P2 0.69, 0.83 |

- 고립도 판정에 쓰인 셋째 모드는 EPG에 거의 없는 모드다. 노름의 94–99%가 PEN·PEG·Δ7 등 EPG 밖에 있다.
- 17단계의 U1은 5유형 연산자에서 정한 기준이다. 확장망에 옮기면서 "EPG에 실린 모드만 비교한다"는 조건을 빠뜨렸다. 이는 기준 이식 결함이다.
- EPG에 실린 다음 모드(2차 조화 쌍)와 비교하면 간격은 MaleCNS 0.34, FlyWire 0.26이다(사후 값).
- **절차 교훈.** 기준을 새 연산자로 옮길 때는, 결과를 이미 아는 방법 대조 자료(MaleCNS)에 먼저 적용해 보고 고정해야 했다.

## 해석 (L0, 두 개체, 사후 진단 포함)

- **전역 억제원 선택.** 결과를 보지 않은 같은 규칙이 두 개체에서 ring(ER) 뉴런과 ExR 계열을 골랐다. 문헌이 EB 끌개의 전역 억제원으로 드는 세포군이다.
- **균일 모드 억제.** 이 세포군을 억제로 넣으면 두 개체 모두 균일 모드가 기억 쌍 아래로 내려간다(0.69, 0.11). 억제 부호를 뒤집으면 오히려 올라간다(1.30, 1.71). 뉴런 수가 늘어서가 아니라 억제이기 때문에 누른다.
- **끌개와 회전 보존.** 확장 후에도 기억 쌍은 EPG 위의 1차 조화 원이고(P1 0.93–0.97), PEN 회전 생성자는 오히려 강해진다(FlyWire ρ 0.78 → 0.94).
- **상태.** 사전등록 판정으로는 **미확립**이다. 고정 판정은 기준 이식 결함으로 실패했다. 내용은 두 개체 같은 방향이다. 편향 없는 확정에는 결과를 보지 않은 제3 개체(hemibrain)에서 수정 기준(EPG 비중 조건 추가)을 고정해 재현해야 한다.
