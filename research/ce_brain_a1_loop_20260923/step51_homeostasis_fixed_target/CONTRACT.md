# A1 51단계 — 목표 고정·완만한 갱신의 항상성 스케일링이 뉴런 수준 우물을 없애는가 (사전등록)

작성: 2026-09-25. 실제 연결체로는 아무것도 계산하지 않은 상태에서 고정한다(합성 행렬로 시간만 측정: 한 세대 0.28초).

## 왜

- 50단계는 뉴런 수준 우물의 원인을 둘로 갈랐다.
  - 방향당 E-PG 수는 두 개체에서 **완전히 같다**. 방향 결합 편차도 재현된다(p = 0.0005).
  - 그러나 **우물 위치는 재현되지 않는다**(표류 장 상관 −0.05).
  - 쌍 수준 불균질(d_E 0.62–0.88)은 고리가 견디는 한계(σ≈0.05–0.1)의 여러 배다.
- 그러면 개체마다 다른 불균질을 **활동 의존적으로 보상하는 기전**이 필요하다. 문헌의 대표 기전은 Renart, Song & Wang 2003(Neuron 38:473)의 항상성 시냅스 스케일링이다. 초록: 각 세포로 들어오는 흥분성 시냅스 전체를 곱셈으로 조절해 흥분성·시냅스 입력의 불균질을 보상한다.
- 48단계는 설계 결함으로 이 기전을 시험하지 못했다(목표 = 매 세대 개체 평균, 큰 갱신 폭, 폭주). 이번에 고친다.

## 규칙 (고정)

| 항목 | 값 |
|---|---|
| 망 | 48단계 E·I·A_pen(47단계 N2, 흐름 정규화 대칭 부분), 문턱선형, c = 1 |
| 스케일링 | W = g(diag(s)E − I), 속도 g·diag(s)A_pen. s_i는 E-PG i로 들어오는 흥분성 입력 전체에 곱한다 |
| 한 세대 | 시행 16회. 단서 중심 (k + u)·22.5°, u ~ U(0,1)은 세대마다 새로 뽑는다. 정지 상태에서 단서 20τ → 지연 30τ |
| 활동 평균 | 시행 전체(단서 + 지연)의 평균 발화율, 1τ 간격 표본 |
| 갱신 | s_i ← clip(s_i·clip(1 + β(r_T − r̄_i)/r_T, 0.95, 1.05), 0.2, 5). van Rossum, Bi & Turrigiano 2000의 비례형이며 β = 0.05, 200세대 |
| 목표 | r_T = 폭주 없는 첫 세대의 개체 평균, 이후 **고정** |
| 이득 | 47단계 N2의 최적 이득 g. 폭주한 세대는 s ← 0.95s로 기록한다 |
| 이후 | ±20% 안에서 이득 재최적화(유지 오차 최소, 16위치). 48단계 검사 묶음(64위치 유지, 회전, S1, S2) |
| 대조 | 학습된 s를 뉴런 사이에서 무작위로 섞는다(씨앗 고정). 이득 재최적화 후 유지 검사 |

## 판정 (세 개체 각각, 48·49단계와 같은 기준)

- **H1.** 유지율(22.5°) ≥ 0.8 **그리고** 끝 자리 ≥ 12곳.
- **H2 (보조).** 엄격 C1.
- **H3 (보조).** S2 비 ∈ [0.8, 1.25].
- **대조.** 섞은 s의 유지율 < 0.8이어야 효과가 특정적이다.

**종합.** H1이 2개 개체 이상이면 `HOMEOSTASIS_REMOVES_WELLS`, 아니면 `HOMEOSTASIS_DOES_NOT_REMOVE_WELLS`다.

**사전 예측.**
- 유지율은 크게 오른다.
- H1 통과는 불확실하다. 불균질이 한계의 6배이고, 스케일링은 뉴런당 1개 자유도뿐이다.
- 엄격 C1은 실패한다.
