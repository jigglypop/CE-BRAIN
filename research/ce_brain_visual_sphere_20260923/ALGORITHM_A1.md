# 알고리즘 A1 — 고정 격자 위의 대칭 계량 연산자 + 비대칭 이동 연산자

작성: 2026-09-23. 사용자 목표: "알고리즘 자체를 찾는 것". 방침: 사후 발견 → 역증명. 역증명 기준은 계산 전에 고정한다.

## A1 (두 사례에서 사후로 추린 식)

$$
\dot x=-L_g\,x+\sum_k u_k(t)\,S_k\,x\quad(+\text{비선형})
$$

- $x$: 고정된 뉴런 격자 위의 활동.
- $L_g$: 대칭 결합이 만드는 이산 라플라스–벨트라미 연산자. 표현 다양체의 계량·곡률·접힘(몫)을 담는다.
- $S_k$: 어긋난 위치의 입력을 비교하는 뉴런이 만드는 비대칭 이동 연산자. 방향성과 시간 흐름을 담는다.
- $u_k(t)$: 외부 구동. 방향 고리에서는 각속도, 시각계에서는 국소 운동이다.

**근거 (지금까지):**
- **방향 고리:**
  - EPG 직접 결합은 대칭이다(이동 0.16°).
  - Δ7은 접힘(몫)을 구현한다($R_\varphi$ 0.95).
  - PEN은 좌 +55°, 우 −55°로 일정하게 이동시킨다(50개 집단의 물리 좌표로 재현).
- **시각계:**
  - 기둥 사이 가로 결합은 대칭이다(비대칭 에너지 5–11%). 그 Regge 곡률은 양수이며, 물리적 판에서 온 것이 아니다.

**계량의 부호화 (가설, 이번에 판정하지 않음):** 결합 가중치는 코탄젠트 라플라시안 $w_{ij}=\tfrac12(\cot\alpha_{ij}+\cot\beta_{ij})$을 따른다. 관측 직접 결합 비 (1,0):(0,1):(1,1) = 39:39:20은 격자 삼각형 각 (54.9°, 54.9°, 70.3°)에 해당한다. 즉 (1,1) 방향 변이 15% 더 길다. 이 비는 눈 지도(다른 개체)로 따로 검증할 후보다.

## 역예측 V (시각계 이동 연산자, 계산 전 고정)

**측정:**
- 각 T4 뉴런의 입력 중 Mi4 입력 가중 중심에서 Mi9 입력 가중 중심을 뺀 벡터를 구한다.
- 각 T5 뉴런은 (Tm1 + Tm2) 입력 중심에서 Tm9 입력 중심을 뺀 벡터를 구한다.
- 위치는 육각 좌표를 평면 좌표로 바꿔 쓴다: $h_1e_1+h_2e_2$, $e_1=(1,0)$, $e_2=(-\tfrac12,\tfrac{\sqrt3}{2})$.
- 눈별·아형별로 벡터의 성분 중앙값, 단위 방향의 원형 집중도 R, 크기 중앙값을 구한다.

**판정 (양쪽 눈, T4·T5 각각):**
- **V1 비대칭 짝:** a와 b의 중앙 방향 사이 각이 150° 이상이고, c와 d도 150° 이상이다.
- **V2 두 축:** a/b 축과 c/d 축 사이 각이 45° 이상이다.
- **V3 격자 위의 일정한 이동:** 모든 아형에서 R ≥ 0.7이고, 크기 중앙값이 0.5–3칸이다.
- **V4 ON·OFF가 같은 틀:** 같은 문자의 T4x와 T5x 중앙 방향이 30° 이내다.

**종합:** V1–V4가 양쪽 눈 모두에서 통과하면 "시각계에서 A1의 $S_k$ 성분 역증명(구조 수준)"이다. 방향 고리의 PEN과 합쳐 A1의 두 성분이 두 계에서 같은 형태로 나타난 것이 된다.
