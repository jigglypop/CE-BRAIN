# 구조 피벗 결과: montage-decomposition

Status: IN_PROGRESS

## 현재까지 확인한 사실

기존 거래에서 version-pinned 연속신호 18개와 머리말 18개를 읽었고, 연속신호의
합계는 723,560,000바이트다. BrainVision 자료는 499.5 Hz, float32,
multiplexed 형식이며 머리말에 전체 채널 라벨이 있다. 따라서 같은 원자료를
객체별로 다시 스트리밍해 임상·인접 쌍극·머리말 전체 산술평균·잘못된 접촉
투영을 계산할 수 있다.

기존 H6 산출물은 선택된 임상·인접 접촉 파형만 보존했으므로 CAR 계산에는
원자료 723,560,000바이트를 다시 읽어야 한다. 새 workspace나 원자료 사본은
만들지 않고, 이 pivot 디렉터리에 작은 lock·진행 기록·결과·검증 witness만 둔다.

## 바로잡은 봉인 설계

기존 초안은 p19, UC004, UC005를 하나의 봉인 확인 묶음처럼 적었지만,
UC004와 UC005에는 PB 세션만 있다. TS와 PB가 모두 있는 봉인 참여자는 p19 한
명뿐이다. 따라서 모집단 TS-PB 신뢰구간·bootstrap·p값은 계산할 수 없고
계산하지 않는다. 봉인 판별은 p19 단일 환자의 paired montage pattern이며,
UC004와 UC005는 PB-only 기술값으로만 남긴다.
