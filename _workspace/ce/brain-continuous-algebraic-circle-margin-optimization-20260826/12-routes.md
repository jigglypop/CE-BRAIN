# Routes and counterexamples

Status: COMPLETE

## Passing routes

- a defective size-two zero Jordan block plus exterior eigenvalue, rank two;
- an irreducible `z^2-2` inside block without eigenvectors;
- a singleton parameter box with exact zero global gap;
- raw-unit scaling covariance.

## Refusal routes

- reference eigenvalue on the reference contour;
- center box violating the global Neumann sufficient condition;
- cell-budget exhaustion;
- radius box whose best algebraic margin is nonpositive;
- invalid reference/interval/radius/tolerance/budget contracts.

Failure of the Neumann or Frobenius sufficient condition is not proof that no
valid contour exists.
