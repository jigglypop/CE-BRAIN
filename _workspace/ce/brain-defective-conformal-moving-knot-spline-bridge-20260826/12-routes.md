# Candidate routes

Status: COMPLETE

| Route | Decision | Reason |
|---|---|---|
| Conformal block-norm split | Implemented | Holomorphic scalar geometry supports exact algebraic blocks. |
| Block Neumann resolvent | Implemented | Handles defective blocks and oblique projectors. |
| Eigenvector diagonalization | Rejected | Unnecessary and impossible for the Jordan fixture. |
| General shear reuse | Rejected | A real shear inverse is not a complex matrix function. |
| Automatic projector discovery | Deferred | Existing characteristic-factor route may supply a later successor. |
| Interval defective family | Deferred | Can compose with the new algebraic resolvent in a later Neumann bridge. |
