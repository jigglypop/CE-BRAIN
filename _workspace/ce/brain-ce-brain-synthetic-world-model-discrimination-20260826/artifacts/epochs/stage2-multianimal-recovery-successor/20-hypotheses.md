# Stage 2 successor hypotheses

Status: PREREGISTERED / OUTCOME_BLIND

- `H_recovery`: in each mouse, the trial-normalized isoflurane transfer pattern
  differs from awake and the recovery mean returns materially toward awake.
- `H_persistent_or_ordered`: recovery remains as far from awake as the
  isoflurane pattern, which is compatible with persistence, drift, block order
  or insufficient recovery.
- `H_heterogeneous`: the two animals disagree, or the direction is shared but
  uncertainty crosses the registered boundary.

These are observable-pattern hypotheses, not claims that anesthesia rewires
an anatomical graph. A recovery return weakens a simple monotone time-drift
story but cannot eliminate all order effects because the blocks were not
randomized.
