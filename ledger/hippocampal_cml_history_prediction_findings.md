# CML: 해마 이력이 다음 피질 전기 상태의 예측에 더하는 것

2026-09-20. [항목 내용 판독](hippocampal_cml_withincategory_findings.md)의 음수 결과를
보존하고, 같은 원신호에서 해마의 과거 활동이 피질 자체의 이력보다 다음 피질 상태를
추가로 예측하는지 검사했다. 고정 소스의 단회 실제 분석과 독립 대조를 완료했으며
주 점수는−0.0006170632 nats로 **후보식 채택을 지지하지 않았다**. 기존 내용 판독의
실패도 유지한다. 해마 검색 일반이나 전기 이력 일반의 부재를 뜻하지 않는다.

## 입력과 제외

[Metadata 지원](../data/local/hippocampal-reinstatement/cml-history-metadata-support-v1/metadata_support.json)은
이미 보유한 OpenNeuro ds004809:2.2.0, sub-R1004D/ses-0의31개 원 block을 조사했다.
중복 없는236개1초 record는30개 연속 구간,472개500ms bin으로 나뉜다. 직전 네 bin을
입력으로 다음 bin을 예측할 때 경계를 넘지 않는 후보는352행이다. 다운로드는 없다.

Metadata의 목록 경계가 섞인 두 구간은 신호 특징과 새 점수를 보기 전에 전체 제외했다.
Run12의 record2190–2203에는 list9 WORD 뒤 list10 START/PROB가 있고,
run17의2740–2745에는 list13 STOP과 list12 REC 사건이 있다. 번호를 임의로
교정하지 않았다. [고정 지원표](../data/local/hippocampal-reinstatement/cml-history-prediction-review-v1/root_decision_support.json)는
남은 **28구간·216record·432bin·320예측행·9목록·1명·1세션**과 제외20record를 분리한다.
사용·제외 구간은 원236record의 중복 없는 정확한 분할이어야 한다.

입력 cohort는 이미 알려진 회상 단어의 주변 기록을 모아 만들어졌다. 목록 보류
평가라도 이러한 후향적 표본 선택을 없애지는 않는다. Native sample 계약과 생리적
행동 동기화의 차이는 이전 원장을 따른다. 이번 예측은 EDF 내부의 동일 시계를 사용한다.

## 고정 특징과 비교식

[방법 결정](../data/local/hippocampal-reinstatement/cml-history-prediction-review-v1/root_method_decision.json)은
500ms의 비중첩 native-grid bin, 과거4bin, 다음1bin을 고정했다. 앞선 코드의
평균 제거·Hann periodogram·70≤f<150Hz 전력의 자연로그를 그대로 사용한다.
120Hz±2Hz를 제외하고 bin을 넘는 필터·PCA·baseline 차감은 하지 않는다. 과거
bin의 가장 늦은 표본은 예측 대상 시작보다 앞선다. 이 특징은 위상이나 ripple 검출값이 아니다.

피질은 기존 ECOG/ECOG140쌍 전체다. 해마 후보는 LOTD2–3,3–4,4–5,5–6의 네 쌍이다.
CA1/DG를 걸치는 접점이 있으므로 단일 subfield로 명명하지 않는다. 대조는 해마 후보
접점을 공유하지 않는 SEEG 쌍 중 이름 사전순 첫 네 개로, LOTD10–11,11–12,7–8,8–9다.
이들은 같은 LOTD shaft에 있고 두 쌍씩 접점을 공유한다. 바깥 접점의 atlas는
superiortemporal/inferiorparietal이다. 독립 shaft 네 개나 해마 기전의 생물학적 null이 아니다.

| 모형 | 과거 입력 | 입력 차원 |
|---|---|---:|
| `c_current` | 가장 최근 피질 bin | 140 |
| `c_history` | 피질의 최근4bin | 560 |
| `c_history_h_current` | 피질4bin + 가장 최근 해마 bin | 564 |
| `c_history_h_history` | 피질4bin + 해마4bin | 576 |
| `c_history_control_history` | 피질4bin + 대조 깊이전극4bin | 576 |

각 목록 전체를 한 번씩 보류한다. 학습 목록은 각각 동일한 총 가중치를 가지며,
각 학습 목록 안에서는 예측행의 가중치가 같다. 입력·목표의 가중 평균과 모집단
표준편차는 학습 목록에서만 정한다. 회상 정답 항목은 회귀 입력에 사용하지 않는다.
표준화 입력 X와 목표 Y에서 `sum_i w_i ||Y_i-X_i B||^2 + ||B||_F^2`를
최소화하는 ridge를 사용한다. 정규화 계수1을 고정하고 후보 탐색을 하지 않는다.
목표의 학습 분산이0이면 중단하고, 상수 입력 특징은 학습 자료에서만 제외한다.

모든 모형에 공통인 학습 목표 표준편차로 평가 오차를 나눈다. 한 출력 쌍의 두 모형
점수 차이는 `0.5*(기준 표준화오차^2-후보 표준화오차^2)`다. 이는 고정 공통 분산을
사용한 Gaussian 주변분포의 log 점수 차이다. 먼저140쌍을 평균하고 목록 안의 예측행을
평균한 뒤9목록을 균등 평균한다. 독립140표본이나 측정된 결합 공분산의 log 점수가 아니다.

주 평가는 `c_history_h_history`가 `c_history`에 더하는 점수다. 피질 이력,
해마 최근 bin, 해마 오래된 이력, 대조 전극 이력, 해마와 대조의 차이를 보조 비교로
미리 고정했다. 이전 SPARROW raw 그림과 이전 내용 판독의 특징·점수는 이미 봤다.
새 endpoint의 사전 고정 비교이며 완전한 파형 맹검이나 외부 확증 시험은 아니다.

## 예측 방향과 관측 기하의 구분

각 fold의 고정 표준화 좌표에서 출력 j의 작업 분포를 평균 `b_j^T u`, 분산1의 Gaussian으로
놓으면, 주변분포 Fisher의 채널 평균은 `G_work = B B^T / 140`이다. 이 식은
확률 모형에서 도출한 조건부 관측 민감도다. 대칭 양의 준정부호이며576입력 모형의
rank는 최대140이다. 전체 입력 공간의 양의 정부호성이나 물리 변화 비용을 보이지 않는다.
Ridge의 계수 벌점은 수치 추정 규칙이며 생물학적 계량의 영방향을 식별한 증거가 아니다.
Fold마다 표준화 좌표가 다르므로 수치 행렬을 그대로 합쳐 한 계량으로 취급하지 않는다.

고정 선형 예측기의 위 계량은 표준화 특징 좌표에서 상수다. 원 전압에서 비선형
log-power 특징으로 가는 Jacobian을 적용하면 좌표별 pullback은 달라질 수 있지만,
그 변화만으로 학습에 따른 신경 관계 변화가 관측된 것은 아니다. 해마 과거→피질 미래의
예측 방향은 시각과 회귀식에 들어 있고 대칭 계량만으로 그 방향을 복원할 수 없다.

예측 향상 자체도 인과 개입을 대신하지 않는다. 예를 들어 공통 잠재 입력 Z_t가
해마 관측 H_t에 즉시 나타나고 피질 C_(t+1)에 늦게 나타나면, H_t는 피질 과거를
넘어 미래 피질을 예측할 수 있다. 해마→피질의 직접 경로가 없어도 가능한 반례다.
[MVGC 저자의 방법 안내](https://users.sussex.ac.uk/~lionelb/MVGC/html/mvgchelp.html)도
시계열 가정과 전처리에 따른 해석 경계를 설명한다. 이번 ridge 주변점수 비교는
표준 MVGC 통계량이나 해당 검정의 재현으로 부르지 않는다.

## 검증과 현재 범위

[코드 검토](../data/local/hippocampal-reinstatement/cml-history-prediction-review-v1/review.json)와
관련 테스트3개를 통과했다. 테스트는 구간·미래 bin 경계, 목록 가중치와 별도 최소제곱
해의 일치, 보류 목표값을 바꿔도 해당 fold의 학습 계수·예측이 바뀌지 않음을 확인한다.
합성 helper 검사와 실제 실행 증거를 구분한다.

실제 실행은 정확히1회, 내부적으로9fold×5모형의 고정45fit, exit0이었다. 별도의
튜닝·추가fit·네트워크는0이다. [실행 영수증](../data/local/hippocampal-reinstatement/cml-history-prediction-run-v1/run_manifest.json)은
preserved wrapper의 명령과 실제 Python3.11.9·NumPy2.4.6·해석기 경로를 기록한다.
결과 SHA는 `b636c24addc25e76e362f675744ef13efafa3f64ad21af0ad95bcbf3eecc22d8`다.

[독립 검사](../data/local/hippocampal-reinstatement/cml-history-prediction-run-v1/independent_check.json)는
320행이 각각 한 번만 평가되고 학습/평가 목록이 겹치지 않음을 확인했다. 학습 목표의
평균·표준편차, 저장 오차, 여섯 비교와9목록 집계의 별도 산술은 최대 절대차0이었다.
과거 네 bin의 인덱스·800표본 인접·미래 제외도 대조했다.

선택된 첫·중간·마지막 사용 구간(run0,15,29)의 첫500ms bin에서148쌍의 특징을
직접 float64 DFT로 계산해 저장 FFT 특징과 비교했다. 최대 절대차는7.8271e−14다.
동결된 EDF reader는 재사용했지만 log-HFA FFT 함수는 호출하지 않았다. 이는 세 bin의
스펙트럼 특징 spot check이며 원 byte decoder 전체나 모든 특징의 독립 재구현은 아니다.

Source SHA는 `ad08d5d0d6ad571ca7a7c9c5ba15862c76df29c31af2fa2dd69c2f0551c368c8`,
support SHA는 `306fbe326e37cdfbb16598a78131df2f646b22226970ab21d98c6a672e0ac8d4`다.
고차원·상관 특징에서의 고정 ridge 절차 비교이므로, 개선이 있어도 어떤 해부학적
기전 때문인지 식별되지 않는다. 관측 단위는 고정 전극 쌍이며 개별 뉴런은 아니다.
기록은 uV 전위이며 막전류를 직접 측정한 값이 아니다. 공통 감각 입력·병적 활동·발화·
비정상성의 영향, 독립 세션 재현, 내용별 복원과의 연결은 남는다.

이 preparation에서 이 고정 관측식의 음수 점수 방향은 `BIO_EVIDENCE_L1` 범위의
관측 결과다. 독립 재현·기전 개입·학습에 따른 물리 계량·기억 내용 복원은 미확립이며
통합 기전을 L2 이상으로 올리지 않는다. 다음에는 평가 자료를 보며 이 식의 창을
조정하기보다, 독립 calibration에서 목표 관측량의 반복 신뢰성과 단순 예측 기준을
먼저 확인해야 한다. 해마 검색 질문은 그 관측량이 내용 복원과 연결되는지도 요구한다.
