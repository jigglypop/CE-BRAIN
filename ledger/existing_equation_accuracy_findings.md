# 기존 식의 정확도와 현재 연구 기준

2026-09-20 사용자 지시에 따라 해마 후속 분석을 중단하고 기존 식의 예측 정확도로
연구 순서를 다시 정했다. 과거 결과를 변경하지 않고 현재 코드·결과 해시와 저장 점수를
재검토했다. 서로 다른 표적의 RMSE와 교차엔트로피를 한 순위로 합치지 않는다.

후속 [수동 포트 확장과 유한시간 변화 비용](passive_port_mechanism_findings.md)은
원래 50 kHz 표본으로 단일·두 성분을 비교했다. IC 전체 오차는 8.72% 줄었지만
같은 holding 근처에서는 0.79%이며 절대 정확도 기준은 여전히 실패했다.
기존 단일 RC를 비교 기준으로 보존하고, 추가 성분의 필요성과 측정 보정을 검토한다.

## 1. 전기 반응의 기준: 기존 수동 RC 식

[기존 막 전기식 (11.1)](../paper/6_뇌/13_MaleCNS_전체망_기하와기억/11_전기상태에서_기억과_계량까지.md)의
작동점 주변 수동 특수형을 출발점으로 삼는다. 막전압 변화 $v$, 입력 전류 $u$,
막저항 $R_m>0$, 막정전용량 $C_m>0$, 접근저항 $R_s$, 기록된 bridge 보정값
$R_b$에 대해 SI 단위로

$$
C_m\dot v=u-v/R_m,\qquad
\widehat{\Delta V}=v+(R_s-R_b)u.
$$

동치인 상태식은 $\tau\dot\ell+\ell=u$, $v=R_m\ell$, $\tau=R_mC_m$다.
초기 상태를 포함한 해는

$$
\ell(t)=e^{-(t-t_0)/\tau}\ell(t_0)
+\frac1\tau\int_{t_0}^t e^{-(t-s)/\tau}u(s)\,ds.
$$

따라서 입력 이력이 현재 전압에 남는 항은 이미 기존 식 안에 있다. 추가 기억항이나
전달지연을 넣기 전에 이 충전·회복과 관측 보정이 실측을 얼마나 설명하는지 확인한다.
기존 시험 펄스 코드는 기준선 변화에 대한 초기 상태를 0으로 두며, pA·MOhm를
mV로 바꾸는 $10^{-3}$을 적용한다. 이 조건을 임의의 초기 상태에 그대로 확대하지 않는다.

**기존 실측 결과:** VC 시행 0–2에서 정한 유효 매개변수로 IC 시행 10–15를
재적합 없이 예측했다. 같은 준비의 5개 세포, 총 30개 세포×시행이다.
세포별 pooled RMSE 제곱을 동일 가중 평균한 뒤 제곱근을 취하면 다음과 같다.

| 동일 평가 표적: IC 시험 펄스 전압 변화 | RMSE, mV |
|---|---:|
| 기존 동적 RC 식 | 0.410681 |
| 같은 저항의 정적 식 | 3.605018 |
| 전압 변화 0 기준선 | 2.171755 |

RC의 RMSE 감소율은 각각 88.61%, 81.09%다. 세포별로 5/5, 개별 시행에서도
30/30에서 두 기준선보다 낫다. 그러나 잔차는 기준선 잡음의 4.38–11.42배로, 기존의 3배 이하 기준은
**0/5 통과**다. 상대 예측의 출발점으로 채택하며 완성된 생리식으로 판정하지 않는다.
여러 동물에서의 독립 재현도 아니다. 기록된 bridge 값은 독립적인 장치 보정값이 아니다.

검토한다. 원인을 막·전극·bridge 중 하나로 특정한 결과는 아니다. 구간은 진단용으로
나눈 개발 분석이며, 저장 trace 간격은 0.1 ms다. 원래 0.02 ms 표본 전체의 RMSE를
독립 재현하거나 0.1 ms보다 짧은 edge 구조를 판정한 것은 아니다.

## 2. MaleCNS에서는 기존 연결 예측식을 유지

세포 $j$의 30개 표적 범주 접촉수 $c_{jk}$를 예측하는 기존 식은

$$
\widehat p_{jk}
=\frac{C_{g(j),k}-c_{jk}+\alpha/30}
{\sum_l C_{g(j),l}-\sum_l c_{jl}+\alpha}.
$$

$C_{g,k}$는 집단 $g$의 접촉수 합이다. 예측할 세포의 전체 source 행을 집단 합에서
제외한다. 비교 집단은 superclass와 (superclass, type)이며, 세부형에 다른 활성 source가
없으면 상위 집단으로 돌아간다. 기존 $\alpha=1$ 결과에서 접촉 가중 교차엔트로피는
0.99592373에서 0.88648577 nats/contact로 10.988589% 감소했다.
활성 source 165,665개 중 94.0265%에서 개선했다.

이는 같은 개체의 구조 예측이다. 연결을 이용해 정의됐을 수 있는 type 표지의 독립성,
새 개체로의 전이, 전류·전압 예측은 확인하지 않았다. `cb_endocrine`은
$\alpha=1,10,100$ 모두 악화했으므로 전체 평균 개선으로 예외를 지우지 않는다.
접촉 확률의 정규화는 source별 절대 효능과 물리 시간상수를 주지 않는다.

## 3. 정확한 이력 축약식의 역할

기존 전체망 전달식에서 숨은 상태를 소거한 식

$$
y_{t+1}=My_t+SD^tz_0+
\sum_{r=0}^{t-1}SD^{t-1-r}E y^A_r
$$

은 유지한다. $y$는 관측 상태, $y^A$는 그중 활성 범주, $z_0$는 초기 숨은 잔차,
$M$은 순간 전달, $D$는 숨은 잔차 전파, $E$는 숨은 상태로의 유입,
$S$는 숨은 상태가 관측에 주는 영향이다. 필요한 초기항과 전체 이력을 보존하면
54개 초기 probe에서 동일 전체망 계산과의 최대 half-L1 차이는 두 기준 lifting에서
각각 $6.212\times10^{-13}$, $7.844\times10^{-13}$이다.

이 값은 공급한 그래프 동역학의 대수적 재현 오차다. **실측 신경 예측 정확도로
사용하지 않는다.** 이력을 자르면 일부 음수 확률이 생기므로 짧은 식이 정확한 식을
대체했다고 판정하지 않는다. 정의와 실측과의 경계는
[기존 이력 축약 장](../paper/6_뇌/13_MaleCNS_전체망_기하와기억/08_관측경계와_이력축약의_성공과실패.md)을 따른다.

## 4. 다음 식을 채택하는 기준

전기 예측은 먼저 기존 RC 잔차의 충전·회복 구간을 확인한다. 동일 표적과 동일
보류 자료에서 기준식과 비교하며, 항을 늘린 뒤 학습 오차가 줄었다는 이유로 채택하지
않는다. 이미 본 보류 자료로 수정 방향을 찾으면 개발 분석으로 표시하고 새로운
보류 자료의 성능과 구별한다. 전기 반응과 관측 잡음이 정해진 뒤 기능적 거리·변화
비용의 리만 계량으로 연결한다. 리만 가정은 유지하되 미확립 전류 결합을 계량의
실측 근거로 사용하지 않는다.

기존 차동 전류의 교차 세포 전달, AP 이력과 VC20Hz 이력식은 보류 조건 간 개선이
안정되지 않아 기준으로 승격하지 않는다. 조용한 전압 상태의 직전값 예측은 유용한
비교 기준이다. 현재 전체 뇌의 전기식·학습식이 완성됐다는 결론은 없다.

이번 재검토는 저장 결과의 재집계와 제한된 계산 확인이다. 원자료 다운로드,
새 매개변수 적합, 기존 결과 덮어쓰기 없이 진행했다. 원래 코드·결과와 재검토
산출물의 해시는 데이터 원장에서 조회한다.
