# 해마·전전두엽의 단서 조건부 선택 판독

2026-09-20. [지역 연결 정정](hippocampal_tetrode_region_findings.md) 뒤33세션의 입력을
같은 시간창으로 연결했다. 질문은 **관측한 단서·움직임·과거 행동을 주고도 신경 발화
기록이 실제 선택의 보류 판독을 개선하는가**다. 기억한 사건의 내용 복원과는 구분한다.

## 입력과 창

기존23세션에9개를 추가하고, 원 tetrode 지역 대응으로 적격이 된 CS39_05도 확보했다.
추가9개의 network body는44,516,815B/63요청, CS39_05는609,034B/7요청이다.
기존 HDF 캐시의 index를 재사용했고206·정확한 Content-Range·ETag·길이를 본문 전에
확인했다. 원 ZIP member는 CRC32·크기, 저장 배열은 SHA·shape·dtype을 확인했다.
추가9개 collector의 자체 행동 진단 실패는 보존하고 별도 진단에서 실제 입력을 확인했다.
CS39_05는 수집 receipt를 먼저 닫고 행동 검사를 분리했다.

전체33세션은1,284유닛과3,414시행이다. 실제 선택은3,232시행에서 연결됐고 CS41_01의
101개와 CS41_02의81개는 원 DIO와 NP의 시간 범위 불일치로 미해결이다. 원저자 코드의
단일 epoch 보정 규칙만으로 다른 시간의 DIO를 대입하지 않았다.

모든 창은500ms의 반열린 구간이다. 단서 전은 NPon 전500ms, 초기 단서는 NPon 뒤500ms,
후기 단서는 NPoff 전500ms, 단서 후는 NPoff 뒤500ms다. 실제 위치 표본이2개 이상,
양 끝100ms 이내, 내부 gap100ms 이하이고 같은 과제 구간에 포함돼야 한다.
보간하지 않는다. 단서 후 창은 실제 선택이나 다음 NP를 포함하면 제외한다.

초기32세션에서 단서 전·중 창은 선택이 확인된3,210개 모두 유효했다. 단서 후에는
710개에서 선택이500ms 전에 일어나2,500개만 남는다. 이710개는 CS41의278개와 CS42의
432개다. 원논문의 짧은 미로 조건도 있어 이 제외가 모든 동물을 같은 비율로 줄이지 않는다.
CS39_05의22개를 더한33세션의 공통 창은2,522시행이다.

초기23세션에서 초기/후기 단서 창은2,113/2,454시행에서 겹쳤다. 같은 시행의 네 창을
서로 독립적인 관측으로 취급하지 않는다. Units에 `obs_intervals`가 없어 spike0은 저장
event list에서의0이며 생물학적 침묵이나 unit의 연속 검출을 입증하지 않는다.

[초기32세션 창](../verify/Q-NPF-04/hippocampal_reinstatement/odor_place_windows_result.json)의
배열을 바꾸지 않고 [33세션 창](../verify/Q-NPF-04/hippocampal_reinstatement/odor_place_windows_complete_result.json)으로
확장했다. 최초 창 검사는13개, 확장 검사는3개다. 고정 표본에서 spike count360개와 위치
feature120창을 독립 계산해 일치했고, 무효 창의0 placeholder는 별도 valid mask로 구분한다.

## 판독 비교의 조건

[판독 소스](../verify/Q-NPF-04/hippocampal_reinstatement/odor_place_choice_readout.py)는
단서·시간·직전 행동·창 안의 위치/속도 요약을 기본 입력으로 둔다. 기본 입력에 CA1,
PFC, 두 지역의 현재 count 또는 두 지역의 현재+직전 시행 count를 각각 더한다.
직전 신경·행동 이력은 같은 task/source epoch이며 현재 창 전에 끝나야 한다.
모든 모형에 과거 관측의 유효 여부를 동일하게 제공한다. 현재 정오답은 feature가 아니다.
신경활동을 더하는 네 모형은 CA1/PFC 원자료 지역이 확인된 유닛만 사용하며 OB/기타는 합동 모형에도 넣지 않는다.

count는 `sqrt(count+3/8)`로 변환한다. 각 세션의 공통 시행을 시간순5블록으로 나누고
학습 쪽에서 보류 블록에 바로 인접한 시행도 하나씩 제외한다. 학습 자료 안의3블록에서만
정규화와 L2 계수0.03/0.3/3을 선택한다. 보류 시행을 바꿔도 해당 fold의 적합과 계수 선택이
변하지 않는 반례 검사를 포함해 [관련 검사](../tests/test_odor_place_choice_readout.py)10개를 통과했다.
각 outer 학습 집합에 두 단서 각각의 실제 좌/우 선택이 모두 있어야 한다.

점수는 실제 선택의 log loss이며, 기본 모형보다 감소한 양을 nats/trial로 표시한다.
양수는 이 후보의 추가 판독 이득이다. 세션 안에서는 시행 평균, rat 안에서는 세션 동일가중,
전체에서는 rat 동일가중을 적용한다. 많은 유닛이나 시행을 독립 동물처럼 세지 않는다.
단서 전 비교에도 현재 단서를 조건으로 주므로 실시간 예측으로 해석하지 않는다.
위치 요약은 머리 방향·호흡·의도를 모두 통제한 측정이 아니다.

## 첫 판독 결과와 해석

입력33세션에서 공통 창2,522시행을 얻었고, 최종8마리·27세션·2,364시행을 평가했다.
CS41_01/02는 실제 선택 미해결로 공통 창이0개다. CS31_02(61시행), CS39_04(25),
CS39_05(22), CS39_03(50)은 하나 이상의 outer 학습 집합에 네 칸이 없어 제외했다.
제외와 분모는 성능을 보고 바꾸지 않았다. 시간 블록 검증은 세션 내 보류 비교이며
새 동물·날짜 전이나 과거 자료만으로 미래를 예측하는 검증은 아니다.

아래는 rat 동일가중의 기본 모형 대비 log loss 감소량(nats/trial)이다. 마지막 열만
CA1+PFC 현재 모형 대비 직전 시행 신경 이력을 더한 순증분이다.

| 500ms 창 | CA1 현재 | PFC 현재 | CA1+PFC 현재 | 현재+직전 이력 | 이력 순증분 |
|---|---:|---:|---:|---:|---:|
| 단서 전 | −0.016618 | −0.022871 | −0.028886 | −0.050696 | −0.021809 |
| 단서 초기 | −0.027996 | −0.008392 | −0.033434 | −0.045623 | −0.012189 |
| 단서 후기 | −0.035102 | +0.008848 | −0.018427 | −0.044108 | −0.025681 |
| 단서 종료 뒤 | +0.029175 | +0.023824 | +0.040395 | +0.029188 | −0.011207 |

단서 종료 뒤에는 세 현재 활동 모형 모두 기본 모형보다 보류 점수가 좋았다.
직전 시행 발화 이력의 추가는 네 창 모두 집계 점수를 악화시켰다. 결과를 본 뒤 최적 창이나
모형을 골라 단일 성공으로 보고하지 않으며 유의성·신뢰구간은 산출하지 않았다.
이 실패는 특정500ms count와 직전 시행 이력 후보의 결과이며 기억이나 모든 시간 이력의
부재를 뜻하지 않는다. 당장의 선택, 움직임과 남은 행동 상태도 신경 신호에 담길 수 있다.

독립 검산은 예측 NPZ621배열에서 gain432개를 다시 계산했고, outer fold540개에서
보류 시행의 정확히 한 번 포함과 원 시행 번호±1 제외를 확인했다. 정규화·계수 선택은
학습 자료만 쓰는10개 검사로 확인했다. 결과 JSON과 소스·검사·배열은 이후 바꾸지 않는다.

‘복원 포인트’ 가설의 다음 관측 대상은 **단서에 제시되지 않은 연결 내용**이다.
현재 선택 판독을 그 내용의 재활성화로 대체할 수 없다. 부호화 때의 내용 표현이 회상에서
되살아나는지, 사건/문맥이 같을 때와 섞였을 때 구별되는지, 감각·운동 설명 뒤에도 남는지를
관측해야 한다. 현재 자료는 CA1/PFC이며 CA3 패턴 완성을 직접 측정하지 않는다.
검색의 방향성과 학습에 따른 리만 계량 변화는 여전히 미확립이다.
