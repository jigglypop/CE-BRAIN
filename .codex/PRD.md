# 연구 PRD — 고정점과 신경 리만 메트릭

## 목표

**리만기하학을 바탕으로 점을 고정하고, 뉴런의 연결과 부가 기능으로 리만 메트릭을 표현하는 모형을 세우고 검증한다.** 사용자와 합의한 중심 주제다. 특정 데이터의 반응 비교나 다운로드 완료로 목표를 바꾸지 않는다.

점의 정체와 좌표를 고정한 상태에서 연결·효능·단기 가소성·흥분성·전도지연이 무엇을 바꾸는지 명시한다. 물리적 뉴런 위치, 신경 상태공간, 출력 분포의 좌표를 구분하고 서로 옮길 때 사상을 적는다. 물리적 점 고정은 신경 활동을 상수로 둔다는 뜻이 아니다.

## 요구사항과 완료 근거

| 요구사항 | 확인할 근거 |
|---|---|
| 고정점과 기하 정의 | 공간·좌표·접벡터·고정량·변화량을 명시한 모형 |
| 연결·부가 기능 → 메트릭 | 변수의 단위·역할, 대칭성·양의 정부호·정칙성·좌표변환 조건 |
| 구별 가능한 관측 예측 | 기전별 변화가 관측량에 들어가는 계산, 위약·단순 대안과의 구별 |
| 실제 자료 검증 | 출처·측정모형·고정 기준·독립 평가·음성 결과와 식별 한계 |
| 이해 가능한 설명 | 수학적 구성과 생물학적 확인을 구분한 한글 설명·근거 경로 |

정의로 만든 양의 정부호 행렬, 합성 검사, 평균 형광 차이만으로 실제 뇌 메트릭을 확인했다고 하지 않는다. 메트릭이 정의됐다는 사실만으로 신경 궤적이 측지선이라는 결론도 내리지 않는다.

## 현재 출발점과 다음 검사

- 2026-09-06 사용자의 추가 요청에 따라 **해마·호르몬의 분자식과 반응식**을 평가했다. [해마·호르몬 화학반응 평가](../paper/검증_원장/고정뉴런_해마호르몬_화학반응_평가.md)에 코르티솔·코르티코스테론·에스트라디올·옥시토신·멜라토닌·인간 인슐린의 분자식, 여섯 반응 표현의 원자·전하 보존 검사, 추가 후보 가정 20개를 정리했다. 1차 해마 문헌은 방출·표면 수용체·발화 양식·가소성에 서로 다른 효과를 보고한다. 특히 2022년 아로마타제 차단 자료는 암컷 CA1 억제 사건의 빈도 증가와 진폭 비유의성을 구분해야 한다. 이는 원문 보고값 대조이며 공개 수치파일은 확보하지 못해 독립 재분석은 미실행이다. 관련 형식 테스트 4개는 통과했지만 **국소 호르몬·수용체 상태 → 같은 고정 뉴런의 기능 → 교정된 전달 성분 → 독립 방향별 비용**의 통합 사상은 L0·미확립이다. 호르몬 농도를 메트릭 전체에 곱하거나 다른 동물의 문헌 효과를 기존 Allen 세포의 측정값으로 대입하지 않는다. 기존 전기 기록 후속 경로는 보존하며 호르몬을 측정하지 않은 자료에서는 화학 효과를 확정하지 않는다.
- 2026-09-05 사용자의 추가 요청에 따라, **뉴런의 고정점 표현과 기본 리만 메트릭을 유지하면서 대안 가정·공리를 먼저 넓힌다.** [대안 공리 후보 원장](../paper/검증_원장/고정뉴런_리만메트릭_대안공리_후보원장.md)에 17개 계열 136개 후보와 10개 조합 예시를 정리했다. 전 항목은 L0 후보이며 동시에 채택한 공리나 생물학적 확인 결과가 아니다. 다음 분석은 서로 다른 후보를 구분할 관측을 선택한 뒤 진행한다.
- 조건부 구성과 연결 변화 미분식은 [회로 계량 논문](../paper/6_뇌/11_리만계량_라우팅_논문.md)에 있다. 물리공간의 계량과 상태공간의 pullback/Fisher 성과를 합산하지 않는다.
- 실패한 후보와 기전별 식별 요구는 [Q-NPF-04 명세](../verify/Q-NPF-04/spec.md)에 있다. 과거 등록 계약과 실패 기록은 보존한다.
- 최근 S1·S2 계산은 평균 반응 비교다. 후속 자료를 분석하기 전에 중심 사상의 어느 항을 판별하는지 적는다.
- [고정점 전류 비용 후보](../paper/검증_원장/고정뉴런_전류비용_리만계량.md)는 선형 연결과 순환 성분으로 상수 공간 계량을 구성하고 합성 검사를 통과했다. 총전류를 고정한 전력 비용에는 순환 성분이 들어가지만 반대 방향 자체는 계량만으로 구별되지 않는다. 이 후보의 실제 뇌 검증은 미실행이다.
- 같은 검사에서 보유 Allen DB의 3D 위치 18,076개와 수치상 비공면인 4세포 이상 실험 2,692개를 확인했다. 좌표 보유나 수치 rank를 생물학적 식별로 세지 않는다.
- [실제 위치·전기 기록 결합](../paper/검증_원장/고정뉴런_위치와전기기록_결합.md)에서 같은 다섯 세포의 VC 기록과 독립 명령을 확보했다. 공통 −10 mV 명령에 클램프 전류 합이 −483 pA 변해, 이를 닫힌 연결망의 전류로 바로 대입할 수 없음을 확인했다. 클램프 반응 관측은 L1, 계량은 여전히 L0다.
- [막 회로 보류 예측](../paper/검증_원장/고정뉴런_막회로_보류예측.md)은 같은 세포의 50개 VC 기록과 30개 IC 기록을 평가했다. RC가 단순 저항보다 개선됐지만 다섯 세포 전체의 사전 오차 기준은 통과하지 못했다. 또한 순환이 있는 회로와 없는 회로가 동일한 전류 비용 계량을 만드는 반례가 있으므로 **현재 전류 비용 계량만으로 연결 방향·순환·전체 회로를 유일하게 복원한다는 요구는 성립하지 않는다.** 독립 전류 응답이 필요하다.
- [차동 전류 검증](../paper/검증_원장/고정뉴런_차동전류_전달검증.md)에서 같은 다섯 세포의 실제 순차 전류 입력 rank 5를 확인했다. 그러나 첫 시행의 세포 간 전달행렬은 두 부호 보류에서 대각 모형보다 오차가 3.30배·2.14배 커졌다. 이 고정 선형 전달 후보는 실패했으며 연결 부재를 뜻하지 않는다. 같은 DB에는 흥분성 연결 두 방향이 보고돼 있다. 후속 검사의 한 경로는 **동일 세포의 발화 유발 사건·충실도·시냅스 지연과 전류 → 독립 반복 예측 → 선택한 연결·계량 사상의 적격성**이다. 열린 회로·화학 시냅스·이력 의존 후보도 경쟁시키며, 닫힌 균형 가정을 모든 후보의 선행조건으로 요구하지 않는다. 공간 메트릭은 여전히 실제 검증 미완료다.
- 다음 핵심 검사는 고정된 점·관측 기준 아래 **모형이 주장하는 채널**을 따로 바꿔 구별 가능한 관측 차이를 확인하는 것이다. 영반응·공선성·잡음으로 식별하지 못하면 모형 또는 관측 설계의 한계를 기록한다.
- [발화 이력 보류 예측](../paper/검증_원장/고정뉴런_발화이력_보류예측.md)은 같은 5점의 알려진 흥분성 연결 두 개를 46개 동시 기록에서 검사했다. 첫 연결의 유효 학습/시간 보류/주파수 보류는 16/17/5회다. 약화 후보가 시간 보류에서 조금 개선됐지만 20 Hz 보류에서 약화·촉진 모두 영반응보다 오차가 커져 전이 필요조건을 통과하지 못했다. 둘째 연결은 9/2/0회와 표적 클램프 전환으로 평가가 부족했다. 같은 위치에서도 측정 모드·주입 경계·막 작동점이 달라짐을 반영해야 한다. 이력 후보를 실제 공간 계량으로 채택하지 않으며, 다음 사상 검사는 **관측·경계·상태 조건을 반영한 연결 효능 → 전도도 교정 → 구성과 독립인 방향별 비용**을 구분한다. 같은 자료의 단순 재분할을 새 확인 근거로 세지 않는다.

- [열린 경계와 계량 식별](../paper/검증_원장/고정뉴런_열린경계_계량식별.md)은 외부 경계를 포함한 선형 단자 모형에서 총전류 보상 조건을 명시해 고정점 공간 계량을 구성했다. 직접 뉴런 간 변 없이도 양의 비등방 계량이 나오는 정확한 예가 있다. 실제 다섯 세포의 공통 입력 하나를 똑같이 설명하면서 서로 다른 계량을 만드는 연속적인 회로 후보도 확인했다. 따라서 이 관측만으로 연결·계량을 유일하게 정할 수 없다. 두 유지전압 기록 역시 자극 세포 상태가 함께 바뀌어 전류에서 전도도를 교정하기에 부족하다. 이는 기존 관측의 사후 식별 검토이며 새 생물학적 확인이 아니다. 다음 진행 조건은 **같은 작동점의 독립 입력·실제 단자 전압 교정·경계 수지 → 연결과 구동력 분리 → 구성에 쓰지 않은 방향별 비용 예측**이다. 조건부 수학 검사는 5개 통과했고 공간 계량의 실제 검증은 미완료다.

- [전기 연결 별 모양 검증](../paper/검증_원장/고정뉴런_전기연결_별모양_검증.md)은 보유 DB의 전기 연결 양성 212쌍을 조사해, 하나의 4점 연결 성분이 세 공간 방향을 이루는 experiment 2771을 찾았다. 같은 일곱 세포의 실제 순차 입력 rank 7과 작은 신호 기준을 확인하고, 첫 시행으로 다음 두 시행을 예측했다. 그러나 네 대상 세포의 교차 오차는 영반응보다 1.67배·1.21배 컸고, 별 모양 모형은 필요한 양의 교차 전달값을 안정적으로 얻지 못해 적합 부적격이었다. 공간적 배치와 수동 연결 표지만으로 전도도·메트릭을 채택하지 않는다. 다음 후보는 **기준선의 시간 변화와 막·접합 과도 응답을 분리한 관측모형**이며, 현재 자료를 본 수정은 개발 단계다. 미개봉 큰 입력을 쓸 때에는 진폭 의존성·회복 조건을 별도로 고정해야 한다.

- [과도 응답 개발 검사](../paper/검증_원장/고정뉴런_과도응답_개발검사.md)는 같은 전기 연결 후보의 이미 본 세 시행에서 직선 추세를 제거하고, 두 RC 필터의 교차 응답을 다른 시행에 예측했다. 열두 교차 방향의 오차는 영예측의 1.017배·0.988배·0.994배로 개발 기준 0.8배를 통과하지 못했다. 한 학습 조합에서는 자기응답의 느린 계수도 음수였다. 이는 새 독립 검증이 아니며, 실제 drift 분리·막 상수·전도도·계량을 채택하지 않는다. 큰 입력 sweep 13–15의 응답은 미개봉으로 유지했다. 다음 경로는 **같은 실험의 VC 명령·유지전압·전극 조건에서 독립 방향 입력의 적격성을 먼저 확인하고, 교정 가능한 응답만 전도도 질문으로 연결하는 것**이다. 준비만으로 실제 공간 계량의 증거를 승격하지 않는다.

- [전압 고정 교차 전류 반복성](../paper/검증_원장/고정뉴런_전압고정_교차전류_반복성.md)은 같은 전기 연결 후보의 10개 VC 기록에서 독립 명령 rank 7을 확인했다. 명령은 70 mV·약 1.5 ms의 큰 펄스였으며, 유지전압이 −70/−55 mV로 나뉘어 각 조건의 앞 두 시행으로 뒤 세 시행을 예측했다. **−70 mV에서는 교차 전류 반복성 필요조건을 통과**했다(영예측 대비 오차 0.522·0.588·0.608배). −55 mV와 두 조건 전체 기준은 실패했다. 관측은 L1이지만, 큰 명령과 교정되지 않은 직렬·기준전극 때문에 접합 전도도·공간 계량으로 승격하지 않는다. 직접 연결이 없는 회로와 있는 회로가 모든 명령에 같은 단자 전류를 만드는 공통 기준전극 반례도 확인했다. 다음은 **MIES 시험 펄스 원장의 실제 측정 저항과 시각·모드 → 전극·막 교정 가능 범위 → 전도도와 독립 비용**이다. IC 13–15번 응답은 미개봉이다.

- [시험 펄스 교정 가능성](../paper/검증_원장/고정뉴런_시험펄스_교정가능성.md)은 같은 NWB에서 실제 TP 87쌍과 열 개 VC 시행 직전의 측정 저항을 확보했다. UTC와 정밀 시작시각으로 대응하고 시행 안의 TP도 직접 계산했다. 대상 네 점의 삽입/원장 peak 비율은 0.840–1.013, 후기 비율은 0.920–1.107이지만 참 접근저항 교정 완료는 아니다. 모든 세포에 주는 공통 TP 전체 파형이 같으면서 개별 전극 저항·공통 기준전극·접합이 다른 동적 반례가 성립한다. 다음은 **같은 NWB의 전체 프로토콜에서 작고 독립적인 양·음 입력과 보정 채널의 존재를 확인 → 관측모형의 식별 가능 범위 → 연결·독립 비용**이다. 실제 TP 보유는 L1이며 뇌 메트릭은 미확립이다.

- 자료 노출 상태 갱신: 전체 MIES numerical 원장 추출에는 IC 13–15번의 `USER_Delta V`·저항 적합 요약이 포함됐다. acquisition 원파형은 미열람이지만 **13–15번을 완전히 미열람인 보류 자료로 사용하지 않는다.** 이전 원장의 미개봉 표기는 당시 상태이며, 이후 독립 평가에서는 이 노출을 반영한다.

- [전체 프로토콜 입력 적격성](../paper/검증_원장/고정뉴런_전체프로토콜_입력적격성.md)은 같은 파일의 89개 시행·623쌍 채널을 조사하고 추가 IC 73개 시행의 명령을 확인했다. `acquisition/timeseries`의 VC 시행은 기존 0–9번뿐이지만, 추가 IC에는 양의 단독 입력 rank 7과 여러 시행의 진폭을 합치면 rank 7인 FastRheo·LP FastRheo가 있다. 양의 독립 입력만으로도 선형 전달의 대수적 식별은 가능하므로 양·음 입력을 모든 후보의 필수조건으로 요구하지 않는다. 소신호성·같은 막 상태는 미확인이다. 별도 `StoredTestPulses_*`의 1,250×7/8 파형 저장 구조도 발견했으며, 시각·단위·열 대응과 파형은 다음 검사다. 관측모형을 정확히 알 때 독립 동적 응답에서 전극·막 행렬을 분리하는 조건부 정리도 확인했다. 다음 경로는 **별도 TP의 시각·채널 교정 → 실제 전극·필터 관측모형**, 또는 **역치 자극의 여러 독립 진폭 → 발화 전 작은 반응·막 상태 안정성 → IC 전달 예측**이다. 전체 numerical 원장에는 0–88번의 응답·QC 요약이 포함돼 있으므로 이 자료들을 완전히 미열람인 보류로 쓰지 않는다. 입력 확보는 L0이며 공간 계량의 실제 검증은 미완료다.

- [역치 반응과 TP 시각 검사](../paper/검증_원장/고정뉴런_역치반응과TP시각_검사.md)는 FastRheo 19×7 실제 기록에서 원파형 개봉 전 고정한 분할·25–100 ms 소신호 기준을 적용했다. 일곱 세포 모두 통과한 것은 16번 하나여서 입력 rank가 7→1이 됐고, 적격 평가 시행이 없어 전달 예측을 실행하지 않았다. 네 대상 점만 통과한 30–33번도 그 점들의 입력은 모두 0이고 다른 세포만 구동돼 독립 입력 근거가 아니다. 이는 지정한 소신호 영역의 적격성 부족이며 일반적 비선형성·연결 부재를 확정하지 않는다. 별도 TPStorage에서 24,974개 시각 행과 headstage·ADC/DAC·mode·holding 속성을 확보했다. 8개 파형 표본과 같은 번호 property 행의 시각은 7–10 ms 차였지만, 기존 원장 TP 최근접 후보는 원장 시각보다 1.365–1.529초 앞섰다. 후보의 HoldingCmd_VC 원시 값은 약 −70이며, 이것이 mV holding을 뜻한다면 뒤쪽 acquisition 설정 −55 mV와 차이가 있다. 단위·업데이트 의미와 실제 파형 대조가 필요하다. 다음은 **특정 저장 TP의 시각·압축 7열 순서·단위 → property 저항과 실제 파형 → 원장·삽입 TP의 조건 차이**다. 실제 반응 관측은 L1, 인덱스는 L0이며 공간 메트릭은 미확립이다.

- [저장 TP 대응과 공통 입력 식별](../paper/검증_원장/고정뉴런_저장TP대응과_공통입력_식별.md)은 열 개 별도 TP의 70채널 실제 파형을 읽어, 기준선의 정확 일치로 압축 열을 headstage에 대응하고 저항 속성을 재현했다. 속성을 float32로 반올림하면 원장 기준선·저항 210개와 모두 일치한다. 원장 peak는 이번 자료에서 자극 후 0.10·0.12 ms의 두 표본 평균으로 재현되며 순간 전류가 아니다. 삽입·저장 TP에 같은 계산법을 쓰면 네 대상 점의 peak 저항 비율 중앙값은 약 0.999지만 참 전극 저항 교정은 아니다. 또한 **세포별 동적 반응이 전체 모드를 드러내고, 대각 막용량·상호성·명시한 전극 모형이 맞으면 공통 입력 하나로도 회로를 유일하게 식별하는 조건부 두 세포 예**를 확인했다. 과거 동일 세포 공통 모드 반례와 양립하며 모든 회로의 유일성을 뜻하지 않는다. 실제 자료의 필터·모드 안정성·holding 속성 의미는 미확인이다. 다음은 **실제 TP 전환부와 보상·필터 관측모형 → 안정적인 모드와 반복 예측 → 전극·막 후보의 적격성**이다. 파형 관측은 L1, 대응·조건부 수학은 L0이며 실제 뇌 메트릭은 미확립이다.

- [TP 동역학과 관측모형 검사](../paper/검증_원장/고정뉴런_TP동역학과_관측모형_검사.md)는 이미 본 열 개 저장 TP의 시작 부분으로 필터 포함 후보를 적합하고 종료·후속 반복을 예측했다. 실제 삽입 명령은 70채널 모두 10.02 ms여서, 이를 저장 TP의 길이 후보로 적용하면 앞 블록 후속 종료 오차가 약 27→16 pA로 줄었다. 저장 DAC 자체의 길이를 확인한 것은 아니다. 빠른 극의 범위도 넓혔지만 선택한 2모드 후보의 전체 기준은 통과하지 못했고, 높은 차수는 학습 개선과 함께 심한 조건수 문제를 보였다. device 7에는 네 TP의 종료 후 2.46–3.23 nA 안쪽 방향 전류가 있었으며 원인은 미분류다. 반복 차분에서 변동 문턱을 넘는 방향은 두 시간 블록 모두 하나뿐이어서 일곱 모드의 안정적인 관측을 확인하지 못했다. 정확한 내부 차원이 1이라는 뜻은 아니다. 다음은 **저장 TP의 실제 명령·필터·보상 계보**, 또는 **종료 후 사건과 동시 전류를 외부 경계·능동 막 후보로 구별하는 관측**이다. 사건을 외생적 독립 입력으로 간주하지 않는다. 실제 전류 관측은 L1, 후보 검사는 개발 단계이며 전극·접합·공간 계량의 실제 식별은 미완료다.

- [종료 후 사건과 동시 전류 검사](../paper/검증_원장/고정뉴런_종료후사건과_동시전류_검사.md)는 device 7의 여섯 큰 사건을 분리하고, 두 사건에서 정한 관측 전류 관계를 두 기록의 네 사건과 시간 대조에 적용했다. 동시 비례 모형의 RMSE/영예측은 0.994–1.017로 거의 개선되지 않았고, 시간 이동 모형의 일부 개선은 후기 사건에서 재현되지 않았다. 여섯 채널×네 계열 모두 사건 특이성 기준을 통과하지 못했다. DB에서 0·1·2·5·6→7 화학 시냅스는 양성, 7의 나가는 방향과 전기 연결은 음성이므로 device 7을 사건 출발점으로 확정하지 않는다. 조건부 단일원·이상 관측에서는 고주파 전류비로 공통 기준/직접 전달을 구분할 수 있지만, 현재 유한 창 회귀값을 저항비로 대입하지 않았다. 다음은 **같은 세포의 기록된 순차 명령 → 다섯 incoming 화학 방향과 음성 비교 → 같은 목표 세포·조건의 반응 시각·반복성**이다. 현재 음성 결과는 지정한 개발 검사의 미확립이며 연결 부재나 실제 뇌 메트릭의 확인이 아니다.

- [유입 화학 전달과 반복 변동 검사](../paper/검증_원장/고정뉴런_유입화학전달과_반복변동_검사.md)는 같은 시각피질 목표 뉴런의 여섯 입력 방향에서 720개 VC 자극 창을 추출했다. 연결 표지와 mode×holding별 적합 QC를 구분해, 표지 양성 다섯 방향과 VC 적합 통과 두 방향을 별도로 평가했다. 앞 두 기록에서 정한 pulse별 평균은 후속 세 기록에서 두 holding 모두 반복성 기준을 통과하지 못했다. 다섯 방향의 RMSE/영예측은 −70 mV에서 1.228·1.507·1.227, −55 mV에서 1.087·1.078·1.375였다. 펄스를 합친 경쟁 모형도 기준 0.8을 통과하지 못했다. 기준선 제거 후 1 nA를 넘는 25개 창을 포함해 모두 계산했으며, 실패를 화학 연결 부재로 해석하지 않는다. 사후 반복 변동 진단은 결정론적 파형 문턱과 확률적 반응의 구분 필요성을 보였으나 실제 잡음·방출 변동의 분리는 미확인이다. 다음 경로는 **실제 입력 사건의 대응 → 자극에 맞춘 반복 성분과 내인성 전류·관측 오차 분리 → 새로운 적격 자료의 예측 → 전도도와 독립 공간 비용**이다. 관측은 L1·개발 단계이며 해마·호르몬이나 실제 메트릭의 확인이 아니다.

- [배경 전류와 전도도 단위 검사](../paper/검증_원장/고정뉴런_배경전류와_전도도단위_검사.md)는 같은 목표 뉴런의 열 개 연속 VC 기록에서 큰 안쪽 전류 124개를 검출했고, 84개가 지정한 명령 주변 밖에 있었다. −70 mV의 인접 사건 간격 25개 중 23개는 1.2초±1 ms여서 생물학적 사건과 주기적 관측 성분을 구별해야 한다. 기존 파형 예측의 −55 mV 제곱오차 80.53%가 학습·평가 사건 주변 3.36% 시간에 겹쳤지만, 이는 사후 동반 비율이며 사건 제거 효과나 기존 실패의 재판정이 아니다. 별도로 공식 생산 정의와 DB 1,236행을 대조해 `effective_conductance`가 수치 오차 없이 V/V 무차원 비율로 재현됨을 확인했다. 수동 단일 구획·정상상태·알려진 누설 전도도를 추가하면 조건부 변환은 가능하지만 현재 자료에서는 이 전제들을 검증하지 못했다. 다음은 **주기적 성분과 실제 명령·동시 채널 대응 → 전달 성분의 관측모형 → 독립 전도도 교정·방향별 비용**이다. 전류 관측은 L1, 단위·조건부 수학은 L0이며 호르몬 기전·실제 공간 메트릭은 미확립이다.

- [주기 전류와 채널 관측모형 검사](../paper/검증_원장/고정뉴런_주기전류와_채널관측모형_검사.md)는 기존 배경 사건 84개의 일곱 동시 채널을 추출하고, 실제·시간 대조창 모두 명령에서 떨어진 54개를 주 분석에 사용했다. 단순 비례 모형은 다른 여섯 채널의 후속 기록에서 안정적 개선을 얻지 못했다. 그림을 본 뒤 추가한 변화율 모형은 −70 mV의 channel 6에서 RMSE/영예측 0.927·0.922·0.909로 개선됐지만 −55 mV에서 재현되지 않았다. 이는 개발 자료의 관측 관계이며 지연·필터·누화·생물학적 전달을 구별하지 않는다. 비례 계수는 무차원, 변화율 계수는 ms로 전도도가 아니다. 다음 전류 비용 경로는 **채널 관측·필터 교정과 독립 입력 → 물리 전달·독립 비용**이다. 병행 가능한 구조 후보는 **고정점의 거리·방향 → 다른 실험의 연결 표지 예측**이며, 연결확률 비용과 물리 전력 비용을 구분하고 정의·단위·대칭성·독립 평가를 먼저 고정한다. 전류 비용 후보의 전도도 요건을 모든 리만 후보의 필수조건으로 확대하지 않는다. 실제 공간 메트릭과 호르몬 원인은 미확립이다.

- [숨은 방향 비용과 연결 관측 검사](../paper/검증_원장/고정뉴런_숨은방향비용과_연결관측_검사.md)는 기존 28,616쌍·1,036 donor의 같은 분할에서 원 좌표 Z와 XY의 비용을 따로 적합하고, X/Y축 대조와 정확한 rank 2·rank 1 경계를 비교했다. radial 후보의 비율은 학습 목적값만으로 1차원 프로파일을 탐색했으며, 모든 Z 후보는 양의 SPD 내부였다. 그러나 Z/XY 계량 비율은 0.039–0.775로 달랐고, Z 분리 radial의 전체 OOF log loss 0.284490은 등방 0.284449나 XY 경계 0.284437보다 낮지 않았다. 핵심 차이의 고정 예측 donor 재표집 구간은 모두 0을 포함했다. 양의 계수를 얻은 사실만으로 숨은 3D 비용을 확인하지 않으며, XY 경계 성능을 실제 뇌가 2차원이라는 결론으로 바꾸지 않는다. 이미지 대응을 검사한 양 끝 세포의 18,747쌍도 재적합 없이 요약했고 확인 근거로 승격하지 않았다. 원 Z는 공식 코드에서 절단면 기준 깊이 계산에 쓰이지만 실제 pia 법선은 아니다. 다음 구조 경로는 **절단면 기준 세포 깊이·probe 관측량의 같은 세포 대응 → 연결 표지의 관측모형 → 방향 비용과 검출·표본 선택의 구별**이다. 전류·호르몬의 독립 관측 요구는 유지한다. 선택된 표지 관측은 L1이며 3D 통합 계량은 L0·미확립이다.

- [절단면 깊이와 연결 관측모형 검사](../paper/검증_원장/고정뉴런_절단면깊이와_연결관측모형_검사.md)는 같은 28,616쌍·1,036 donor 분할에서 깊이·최종 자극 횟수를 예측 변수로 추가했다. 평균 깊이 유효값은 24,533쌍이며 범위 밖·결측은 원값을 보존하고 지시자로 남겼다. 횟수는 nonsynaptic class로 선택해 800에서 제한했다. 깊이·횟수 포함 후에도 거리 항은 다섯 fold 모두에서 예측을 개선했으며, 전체 log loss 추가 개선량은 0.009229에서 0.008398로 줄었다. 차이 +0.000831의 고정 예측 donor 재표집 구간은 [0.000438, 0.001240]이다. 최종 횟수의 사후성과 결측 지시자의 문맥·벌점 중복 때문에 이를 검출 편향의 교정량이나 횟수만의 독립 정보로 해석하지 않는다. 미지 민감도 아래 다른 SPD 비용이 같은 관측확률을 만들 수 있는 조건부 검사도 통과했다. 작은 DB의 기록 테이블은 비어 있어 이번 적합에는 잡음을 넣지 않았고, medium DB의 같은 postsynaptic 세포 9,342개 신원·좌표 일치 확인 뒤 필요한 기록 잡음을 별도로 수집 중이다. 다음은 **진행 중인 동일 수집의 완료·입력 검증 → 같은 cohort의 잡음 포함 관측모형 → 거리·방향 비용과 관측 조건의 구별**이다. 수집 완료나 예측 개선을 실제 검출률·호르몬 기전·개인별 공간 메트릭의 확인으로 승격하지 않는다. 관련 검사 5개는 통과했으며 전체 목표는 미완료다.

- [기록 잡음과 방향 비용 검사](../paper/검증_원장/고정뉴런_기록잡음과_방향비용_검사.md)는 진행 중이던 medium DB 수집을 완료해 같은 postsynaptic 세포 9,342개 중 8,300개의 유효 평균 IC 잡음을 확보했다. 결측 1,042개는 QC IC 기록 0개 또는 1개인 경우이며, 모든 대상 수집을 확인한 뒤 전체 28,616쌍을 유지했다. 같은 donor 분할에서 잡음 포함 등방 모형의 log loss는 0.273248로 잡음 없는 0.277058보다 개선됐고, 같은 관측변수 안에서 거리의 추가 개선량은 0.008258이었다. 그러나 Z 분리 0.273376은 등방이나 XY 경계보다 좋아지지 않았다. - [EM 위치와 연결 기록 보류 예측](../paper/검증_원장/고정뉴런_EM위치와_연결기록_보류예측.md)은 보유 MICrONS v1718의 같은 뉴런 1,348개·방향쌍 1,815,756개를 사용해 두 평가 노드를 모두 학습에서 제외하는 15블록 비교를 완료했다. 원 voxel 해상도 4/4/40 nm로 위치를 µm로 옮기고, 기존 145,598개 annotation과 78,301개 양성 방향쌍을 유지했다. 기록이 없는 쌍을 참 연결 부재로 확정하지 않는다. 재구성 전략만 조건으로 둔 전체 log loss는 문맥만 0.177870, 등방 quadratic 0.166576, 축별 quadratic 0.165513, 등방 radial 0.165471이었다. 공개 세포형 포함 시 각각 0.150599, 0.141854, 0.141418, 0.139782이며 등방 radial이 축별 quadratic보다 15블록 모두 낮다. 축별 계수는 모두 SPD 내부이고 quadratic 안에서는 개선되지만, 관측 연결함수와 방향 비용을 분리해야 한다. 주 비교의 full axon→clean dendrite 하위집단에서는 모든 공통 거리 후보가 문맥만보다 나빠지고, 공개 세포형 포함 시에는 개선된다. 재구성 전략·세포형의 인과 교정이나 공통 공간 법칙을 확정하지 않는다. 같은 목적함수의 Schur Newton으로 전체 계산을 완료했으며, 원 해법의 2블록 기록은 보존했다. 관련 검사 5개와 수치 해법 검사 4개를 통과했다. 다음 구조 경로는 **같은 radial 연결함수의 등방·방향 비교 → 재구성 조건별 거리 효과라는 관측 대안과 구별 → 별도 체적·독립 기능 관측으로 전이**다. 한 체적의 내부 노드 보류를 독립 동물 확인으로 세지 않으며, 전류·해마 호르몬 통합과 유일한 실제 뇌 메트릭은 L0·미완료다.

## 범위와 진행 조건

행동·의식·발달·완전한 인과 매개는 해당 주장을 할 때 추가 검증한다. 중심 모형의 첫 검증에 모두를 필수조건으로 붙이지 않는다. 신규성이나 강한 숫자 예측도 모든 모형 구성의 필수조건은 아니다.

다음 행동은 `검증할 사상/가정 → 필요한 관측 → 판별 계산 → 통과·실패의 의미`로 설명할 수 있어야 한다. 설명할 수 없으면 그 가지를 진행하지 말고 주제에 맞는 작업으로 복귀한다. 기존 수집과 원자료는 중복 생성·자동 삭제하지 않는다. 전체 목표는 위 요구사항의 실제 근거가 모두 갖춰졌을 때만 완료로 판단한다.
