# 에이전트 운영 — 적은 호출, 필요한 설명

주 에이전트는 Astra다. 작은 작업은 직접 끝낸다. 역할 목록은 선택지이며 모두 호출하는 순서가 아니다.

| 역할·작업 | 모델 | 추론 |
|---|---|---|
| reader: 파일·출처·자료 구조 확인 | Luna | medium |
| implementer: 일반 구현 | Terra | medium |
| reviewer: 수학·기전·핵심 반례 검토 | Astra | high |
| explainer: 기전 설명·문서 초안 | Terra | low |

보조 역할은 [네 개](../agents/README.md)로 유지한다. 유도·통합·최종 판단은 주 에이전트가 맡는다. 생물·일반 역할을 중복 생성하지 않는다.

생물학 키워드만으로 고비용 모델을 고르지 않는다. 근거 충돌·핵심 불확실성이 있으면 그 쟁점만 상위 모델로 넘긴다. 지원하지 않는 모델이면 실패를 알리고 대체 모델을 명시한다. 실제 비용·토큰 절감률은 사용 기록 없이 단정하지 않는다.

## 호출과 문맥

- 명시적으로 허용된 범위에서만 위임한다. 기본은 직접 처리, 필요한 하위 작업은 최대 2개다. 재위임하지 않는다.
- 목표 한 문장, 필요한 파일·구간, 질문, 완료 조건, 쓰기 허용 경로만 전달한다. 다른 모델을 지정할 때 전체 대화를 복제하지 않는다. 현재 도구가 지원하는 인자를 확인한다.
- 구현은 지정된 파일 소유자 한 명이 맡는다. 같은 파일을 동시에 편집하지 않는다. 검토자는 안정된 결과를 읽기 전용으로 본다. Git·최종 판정·원장 반영은 주 에이전트가 맡는다.
- 짧은 결과를 위해 별도 파일·영수증을 만들지 않는다. 재현에 필요한 코드·자료·정식 근거만 파일로 남긴다. 긴 도구 출력은 필요한 행만 읽는다.
- 결론 → 근거 → 한계 → 다음 행동 순서의 쉬운 한글로 설명한다. 내부 반환은 기본 8줄 안팎이며 핵심 반례와 불확실성을 생략하지 않는다. JSON만 강요하지 않는다.

## 연구와 대기

- 연구 단계 시작·중요한 결과·방향 전환 때 사용자가 현재 기전을 이해하도록 설명한다. `고정한 점 / 바꾸는 연결·기능 / 메트릭과의 관계 / 확인한 사실과 가설 / 다음 판별`을 쉬운 한글 4~6문장으로 연결한다. 도구 상태만 반복하지 않는다.
- 이 설명의 책임은 주 에이전트에게 있다. 단순한 단계는 직접 설명하고, 복잡한 기전이나 사용자가 별도 설명을 요청한 경우 explainer에 현재 근거만 전달해 초안을 받는다. 별도 호출 없이도 설명은 빠뜨리지 않는다. 다운로드 비율만 바뀌면 같은 기전 설명을 되풀이하지 않는다.

- 중심 목표는 [PRD](../PRD.md)를 따른다. 부분 작업으로 최종 목표를 바꾸지 않는다.
- 자료는 원장부터 확인하며 다운로드·재검토는 [데이터 규칙](data_policy.md)에 따라 허용된다. 고정 용량을 이유로 같은 승인을 반복 요청하지 않는다.
- 수집 중에는 같은 프로세스 핸들을 확인한다. 관찰 시간 초과만으로 재시작하지 않는다. 대기는 대기로 보고하며 새 과학적 진전이나 감사 문서를 만들지 않는다.
- 대기 중에는 이미 필요한 독립 작업만 한다. 수신률 확인에 별도 LLM 에이전트를 쓰지 않는다. 상태 보고는 짧게 하되 실행 환경의 보고 주기를 따른다.
- 작은 수정에 전 역할 감사·전체 테스트·새 연구 계약을 요구하지 않는다. 명시적으로 요청된 정식 감사 항목은 생략하지 않는다.

역할 설정은 `.codex/agents/*.toml`, 목록은 해당 폴더의 README다. 현재 세션 도구가 역할 파일을 자동으로 읽지 않으면 모델·추론·지침을 명시적으로 전달한다. 파일 변경이 이미 실행 중인 세션의 모델을 바꿨다고 보고하지 않는다.

설정 형식: [OpenAI 공식 하위 에이전트 안내](https://learn.chatgpt.com/docs/agent-configuration/subagents).
