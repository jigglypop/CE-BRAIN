규칙의 정본이다. 기계 검사는 `.codex/hooks/repository_harness.py`가 수행하고

## 1. 링크 정책

1. 활성 문서의 상대 링크는 저장소 안에 실제로 존재하는 파일만 가리킨다. 깨진 링크는
   경고 표시나 취소선으로 남기지 않고 **제거**한다.
2. 대상이 저장소 안에서 이동했으면 링크를 새 경로로 다시 지정한다. 대상이 저장소 밖에
   있으면 링크를 해제하고 본문 텍스트만 남긴다.
3. 연구 run의 workspace(`_workspace/ce/<run>/...`)는 이 저장소에 없다. 그 경로로 가는
   링크는 금지한다. 근거를 가리켜야 하면 run ID와 파일명을 백틱으로 인용하고, 그 파일이
   형제 증거 저장소 `ce-runs`(`CE_RUNS_PATH`)에 있음을 문장으로 밝힌다.
4. LaTeX 수식 안의 `](...)` 꼴은 링크로 세지 않는다. 검사기는 경로처럼 보이는 대상만
   본다.
5. 문서를 갱신하는 커밋은 같은 커밋에서 깨진 링크를 함께 정리한다.

## 2. 수기 누적 문서의 논문화

### 2.1 정의

다음 중 하나에 해당하는 논문형 문서는 **수기 누적 문서**로 본다.

- run이 끝날 때마다 번호 없는 `##` 절을 파일 끝에 덧붙여 자란 단일 파일
- 200 KB를 넘는 단일 Markdown (검사기 상한 `NARRATIVE_DOC_MAX_BYTES`)
- 처음 읽는 독자가 읽는 순서를 파일 안에서 찾을 수 없는 문서

`paper/검증_원장/` 아래 원장은 표 형식 감사 문서이므로 이 상한에서 제외한다. 다만
링크 정책은 원장에도 그대로 적용한다.

### 2.2 정본 형식

논문형 정본은 주제 폴더 하나와 그 안의 `00_논문목차.md`, 그리고 목차가 순서대로 조립하는
장 파일들이다. 장 파일 이름은 `NN_주제.md`이고 각 파일은 `#` 제목 한 줄로 시작한다.
`00_논문목차.md`는 제목, 한 문단 초록, 주장 상한(claim ceiling)과 증거 등급, 원장 링크,
장 목록, 재현 경로, 논문화 상태를 담는다. 실증·뇌 논문의 필수 장 구성은
`paper/README.md` 3절을 따른다.

### 2.3 전환 절차

1. **1차 구조 전환**: 내용을 바꾸지 않고 `##` 경계에서 파일을 장으로 나눈다. 원 파일은
   삭제하고 같은 이름의 폴더로 바꾼다. 원 파일을 가리키던 테스트·링크를 폴더로 옮긴다.
2. **2차 서사 재작성**: 각 장을 "동기 → 전개 → 결과 → 다음 장으로의 연결" 구조로 다시
   쓰고 3절의 처음 읽는 독자 게이트를 통과시킨다. 이 단계 전까지 목차의 논문화 상태는
   `구조 전환 완료 / 서사 재작성 대기`다.
3. 새 run 결과는 파일 끝에 절을 덧붙이지 않고 역할이 맞는 장을 제자리 갱신한다. 겹치지
   않는 새 논증·자료·결과일 때만 새 장을 만들고 목차에 연결한다.
4. v2, v3, `_new`, `_final` 같은 파생 사본을 정본 폴더에 두지 않는다. 판본 역사는 git과
   증거 저장소가 보관한다.

## 3. 문서 유형, 형식 출처, 처음 읽는 독자 게이트

문서는 **원장(ledger)**과 **논문형** 두 유형으로 나눈다. 원장은 주장·지위·수치를 표와
항목으로 관리하는 감사 문서이고 태그 나열이 기본이다. 논문형(강의·유도·논문 원고·독자
가이드)은 서사가 기본이고 태그는 서사에 붙는다. 태그 블록만 나열한 논문형 문서는
미완성 원고로 취급한다.

형식 출처 표지 `[정의]`·`[정리]`·`[공리]`·`[산출]`·`[경험식]`·`[미완성]`·`[예측]`의 뜻은
`paper/README.md` 1절이 정본이다. 뇌 주장에는 `BIO_EVIDENCE_L0`–`L4`
(`brain_evidence_ladder.md`)를 함께 붙인다.

논문형 문서는 탈고 후 처음 읽는 독자로 다시 읽으며 다음을 검사한다. 하나라도 어기면
완성으로 보고하지 않는다.

1. 모든 기호는 첫 등장에서 말로 된 이름과 한 줄 의미를 함께 받는다.
2. 정의·도입한 대상은 같은 문서 뒤에서 반드시 사용된다.
3. 각 절의 첫 문장은 이전 절과의 논리적 연결을 말한다.
4. 아직 정의되지 않은 개념에 의존하는 문장이 없다.
5. 독자가 종이와 펜만으로 각 유도를 재현할 수 있다.

문체 규칙 요약: 본문은 완결된 문단 산문으로 쓴다. 수식 구분자는 `$$`와 `$`만 쓴다.
정리·보조정리·따름정리를 구분해 라벨을 붙이고 증명은 "증명."으로 시작해 □로 끝낸다.
이중 피동, "~에 있어서", "~에 대한" 남용, "~를 가진다", "~로부터" 남용, "~의" 연쇄는
고쳐 쓴다.

완전한 반례가 있는 부모 명제는 활성 문서에서 삭제하고, 좁혀서 참이 된 명제만 별도
`[정리]`·`[산출]`로 다시 쓴다. 재도입을 막는 증인은 테스트 코드에만 남긴다. 전제 누락이나
계산 미완료처럼 반례가 완전하지 않으면 `[미완성]`으로 둔다.

## 4. 소유권 (direct 모드)

이 저장소는 별도 작성자 에이전트 없이 주 작업자가 직접 편집한다. 원장과 논문형이 함께
바뀌면 원장을 먼저 안정화하고, 그 뒤 논문형 문서를 원장을 읽기 전용 입력으로 삼아
고친다. 같은 변경에서 두 유형을 동시에 편집하지 않는다. 논문형 문서에서 원장 충돌을
발견하면 원장을 고치지 말고 위치와 필요한 보조정리를 보고한다.
