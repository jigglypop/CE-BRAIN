# 데이터 관리와 재검토

목적은 이미 받은 자료를 쉽게 찾아 재사용하는 것이다. 원장은 다운로드 허가서나 과학적 적격성 판정서가 아니다.

1. **먼저 찾는다.** [데이터 원장](../../ledger/data_registry.md)에서 출처·판본·파일명·보유 위치를 검색한다. 폴더만 등록된 경우 안의 목록과 기존 수집 영수증부터 확인한다.
2. **같은 자료는 재사용한다.** 출처·판본·파일을 대조하고, 파일의 SHA-256이 같으면 바이트가 같은 자료로 취급한다. URL이나 폴더명이 달라도 중복일 수 있다. 이름만 같다고 동일하다고 단정하지 않는다.
3. **진행 중인 수집은 이어간다.** `.partial` 파일이나 수집 프로세스가 있으면 새 다운로드를 시작하지 않는다. 중단된 경우 서버의 재개 지원과 원격 판본을 확인한 뒤 이어받는다. 재개가 불가능하면 이유를 기록하고 다시 받는다.
4. **필요한 자료는 받는다.** 로컬에 없거나 손상됐거나 다른 판본이 필요하면 사용자 요청 범위 안에서 공식 출처를 찾아 필요한 파일부터 받는다. 요청에 포함되지 않은 비용·접근 권한·현저한 범위 확대가 있을 때만 구체적인 대상·용량·목적을 제시해 확인한다. 같은 허가를 반복해서 묻지 않는다.
5. **수집 결과를 남긴다.** 출처, 판본, 파일, 위치, 크기, SHA-256, 확인 시점, 수집 이유를 등록한다. 원본은 자동 삭제하지 않는다. 해시는 등록 시 계산하고 일상 조회에서 전량 재계산하지 않는다. 분석에 쓰는 파일이 바뀌었거나 무결성이 의심되면 해당 파일을 다시 검증한다.
6. **재검토는 가능하다.** 같은 자료라도 새 질문·오류 수정·방법 변경·사용자 요청이 있으면 다시 읽고 분석할 수 있다. 질문, 이유, 사용한 데이터 ID와 판본, 이전·새 결과 경로를 해당 분석 기록에 남긴다. 목적 없는 같은 검사를 반복하지 않는다.

과거의 `STOP`, `BLOCKED`, `PUBLIC_DATA_SUFFICIENCY_FROZEN`은 당시 질문·계약의 판정이다. 원자료를 다시 읽는 행위를 금지하지 않는다. 새 검토는 과거 기록을 보존하고, 달라진 가정과 결론을 별도로 기록한다. 확인자료를 본 뒤 바꾼 분석을 사전 예측으로 바꾸거나, 재검토 허용을 봉인된 일회성 실험의 재실행 허가로 해석하지 않는다.

자료의 보유 여부와 과학적 적격성도 구분한다. 전체 인과사슬을 판별하지 못하더라도 요청된 부분 질문에 도움이 되면 사용할 수 있다. 부족한 변수와 주장 상한을 밝히고, 다운로드 완료를 가설의 지지로 보고하지 않는다.
