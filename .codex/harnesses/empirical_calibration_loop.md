# 실측 교정 루프 하네스

Status: `CANONICAL_EMPIRICAL_CALIBRATION_LOOP_V2`

판본일: 2026-09-02

실측과 계산이 어긋날 때 재실행·허용오차 완화·사후 식 변경 대신 원인을 가장
작은 증인에서 분류하는 규약이다.

## 1. 진입과 상한

- 같은 명령의 단순 재실행은 비결정성 확인용 1회만 허용한다.
- 한 불일치당 최대 3사이클, 사이클당 가설 1건·조치 1건만 허용한다.
- 원 endpoint를 바꿀 수 없는 P1/P2 보완 때문에 실측 계산을 중단하지 않는다.

## 2. 바꿀 수 있는 것과 없는 것

결과 확인 뒤에도 교정 가능한 것은 구현 오류, 사전등록된 자유 파라미터,
1차 출처로 갱신된 관측 기준선뿐이다. 다음은 바꿀 수 없다.

- tolerance, rank/condition cutoff, fixture와 acceptance matrix
- endpoint, threshold, seed, split, window와 제외 기준
- 형식 지위와 `BIO_EVIDENCE` 등급

이를 바꿔야만 통과하면 새 계약이며 원 판본은 실패·정지 영수증으로 보존한다.

## 3. 원인 분류

| 순서 | 클래스 | 판별 신호 | 허용 조치 |
|---|---|---|---|
| 1 | D 차원·단위 | $10^n$, $2\pi$, 시간·길이·전압 단위의 상수배 | 단위·무차원화 수정 |
| 2 | I 구현 | oracle과 첫 중간연산에서 분기 | 해당 코드만 수정 |
| 3 | P 정밀도 | dtype·상쇄·condition number 의존 | 안정한 solve·정밀도 수정; tolerance 완화 금지 |
| 4 | C convention | 부호·기저·순서 재배열로 일치 | 계약의 한 convention으로 통일 |
| 5 | B 기준선·측정 | 예측은 안정하지만 인용값·관측연산자가 잘못됨 | 1차 출처 확인 뒤 기준선/측정모형 판본 갱신 |
| 6 | T 이론 | D--B를 재현 가능하게 기각해도 잔차 유지 | 반례 잠금 뒤 새 구조 계약 |

## 4. 사이클

1. 불일치를 보이는 가장 작은 fixture 또는 한 생물단위로 줄인다.
2. 직렬화한 중간값에서 첫 분기점을 찾는다.
3. D→I→P→C→B→T 순으로 분류한다.
4. 허용된 조치 한 건만 적용한다.
5. 최소 증인만 재검하고, 통과하면 원 실패 수준까지만 확장한다.
6. 예측값, 관측값, 불확도, 잔차, 조치와 판정을 기록한다.

관측 오차 $\sigma$가 있을 때
$z=(\mathrm{pred}-\mathrm{obs})/\sigma$를 기록한다. $|z|\le1$은 관측 정합일
뿐 증명이 아니며, $1<|z|\le3$은 tension, $|z|>3$은 원인분류 진입 신호다.
$\sigma$가 없으면 상대편차만 보고 z 등급을 쓰지 않는다.

## 5. 종료

- **수렴:** 교정 불가 항목을 건드리지 않고 원 실패 검사가 통과.
- **T 확정:** 실패식·정의역·증인을 잠그고 구조적으로 다른 후속 경로를 설계.
- **3사이클 소진:** 정확한 재개 입력을 적고 `BLOCKED`로 기록.
- **endpoint 미평가:** 장치·입력 차단을 생물학적 양성·음성으로 쓰지 않음.

새 식은 통과해도 독립 확인 전 `[경험식]`이다. 서로 다른 관측량마다 파라미터를
따로 조정하거나 같은 confirmation 자료로 제안과 확인을 동시에 하지 않는다.
